## 개요

WIHP Core는 WIHP 시스템의 **기준점(baseline)** 문서를 포함합니다.

```
WIHP Core = 검증 기준
├── korean-kor.md  ← 한글 → IPA → 한글 왕복 검증
└── (향후 확장)
```

---

## 왜 한국어가 기준점인가?

```
WIHP의 핵심:
모든 언어 → IPA → 한글

한국어의 특수성:
한글 → IPA → 한글 = 원본

논리적 증명:
만약 WIHP가 올바르게 작동한다면,
한국어를 WIHP로 변환하고 다시 한글로 돌아오면
원래의 한글과 동일해야 한다.
```

## korean-kor.md 내용

1. **자음 체계** (19개)
   - 삼중 대립: 평음/경음/격음
   - WIHP 코드 매핑

2. **모음 체계** (10+개)
   - 단모음 7-10개
   - 이중모음 11개

3. **받침 체계**
   - 7종성 규칙
   - 겹받침 처리

4. **음운 규칙** (7개)
   - 비음화, 유음화, 경음화
   - 구개음화, 격음화
   - 연음, ㅎ탈락

5. **검증 예시**
   - 왕복 검증 문장
   - 음운 변화 예시

6. **옛한글**
   - WIHP 확장을 위한 복원

## 사용 방법

```markdown
WIHP 검증 프로세스:

1. korean-kor.md 읽기
2. 한글 입력 → IPA 변환
3. IPA → WIHP 코드
4. WIHP → 한글 출력
5. 원본과 비교 (동일해야 함)
```

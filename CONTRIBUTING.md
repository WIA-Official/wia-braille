# Contributing to WIA Braille

Thank you for your interest in contributing to WIA Braille! This project exists to serve all of humanity, and we welcome contributions from everyone.

**홍익인간 (Hongik Ingan) - Benefit All Humanity**

---

## Ways to Contribute

### 1. Test with Your Language

**Most Valuable**: Test WIA Braille with your native language!

**We need**:
- Native speakers of any language
- Braille readers
- Language experts
- Linguists

**How to help**:
1. Convert text in your language to WIA Braille
2. Verify phonetic accuracy
3. Test with braille displays
4. Report any issues

### 2. Improve IPA Mappings

If you notice phonetic inaccuracies:
- Submit corrections with linguistic evidence
- Provide IPA transcription improvements
- Suggest better braille pattern mappings

### 3. Add Language Examples

We want examples from all 7,000+ languages!

**Submit**:
- Basic greetings and phrases
- Cultural significance notes
- Common vocabulary
- Phonetic features unique to your language

### 4. Documentation

Help improve documentation:
- Translations (we need all languages!)
- Clearer explanations
- Additional examples
- Educational materials

### 5. Technical Contributions

**Code contributions**:
- Bug fixes
- Performance improvements
- New features
- Integration with other tools

**Technical documentation**:
- API improvements
- Integration guides
- Developer tutorials

---

## How to Submit Contributions

### For Language Testing and Examples

**Email**: ceosmilestory@nate.com

**Include**:
1. Language name and ISO code
2. Your sample text
3. IPA transcription (if available)
4. WIA Braille output
5. Any issues or suggestions
6. Your name (optional, for credit)

### For Code Contributions

**GitHub**: https://github.com/WIA-Official/wia-braille

**Process**:
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a Pull Request

**Guidelines**:
- Follow existing code style
- Add tests for new features
- Update documentation
- Keep commits focused and clear

## Contribution Guidelines

### 1. Respect for All Languages

**Core Principle**: ALL languages are equal.

- No language is "more important"
- No language is "too small"
- Every contribution is valued

### 2. Accuracy Over Speed

**Quality matters**:
- Phonetic accuracy is critical
- Take time to verify
- When in doubt, ask experts
- Cite your sources

### 3. Open and Collaborative

**Philosophy**:
- Be respectful and constructive
- Share knowledge freely
- Help others learn
- Assume good intentions

### 4. Accessibility First

**Remember**:
- This is for blind users
- Clarity and usability matter
- Test with actual braille displays when possible
- Consider screen reader compatibility

## Special Requests

### High Priority Languages

We especially welcome contributions for:

**Indigenous Languages**:
- North American: Navajo, Cree, Inuktitut, Cherokee, etc.
- South American: Quechua, Aymara, Guaraní, etc.
- Pacific: Hawaiian, Māori, Samoan, etc.
- Australian: Aboriginal languages

**African Languages**:
- All languages from 31 countries without braille
- Niger-Congo family
- Khoisan (click languages)
- Afro-Asiatic family

**Asian Minority Languages**:
- Tibeto-Burman languages
- Austroasiatic languages
- Hmong-Mien languages
- Tai-Kadai languages

### Validation Needed

**Tier 1 Validation** (Native speaker + braille expert):
- Already done for 50+ languages
- Need 100+ more!

**Your help**:
- Validate existing mappings
- Test with blind community
- Provide feedback

## Code of Conduct

### Our Commitment

**WIA Braille** is for everyone. We are committed to:
- Welcoming environment for all
- Respect for all cultures and languages
- Harassment-free collaboration
- Constructive and kind communication

### Expected Behavior

✅ Be respectful and inclusive
✅ Welcome newcomers warmly
✅ Give credit where due

## Example 1: Basic Greeting

### Original Text
```
Yá'át'ééh
(Hello / It is good)
```

### IPA Transcription
```
/jáʔátʼéːh/
```

### Phoneme Breakdown
```
j - á - ʔ - á - tʼ - é - ː - h
```

### WIA Braille Output
```
⠽⠁⠄⠁⠞⠄⠑⠑⠓
```

### Mapping Table
| Phoneme | IPA | WIA Braille | Notes |
|---------|-----|-------------|-------|
| j | /j/ | ⠽ | Palatal approximant |
| á | /á/ | ⠁ | Low vowel with high tone |
| ʔ | /ʔ/ | ⠄ | Glottal stop (crucial!) |
| tʼ | /tʼ/ | ⠞⠄ | Ejective (distinctive) |
| éː | /éː/ | ⠑⠑ | Long vowel |
| h | /h/ | ⠓ | Glottal fricative |

## Special Navajo Phonetic Features

### 1. Glottal Stop (ʔ)
**Critical** in Navajo - changes meaning entirely

**Example**:
- **yá'át'ééh** (hello) vs **yaateh** (different word)
- WIA Braille: ⠽⠁⠄⠁⠞⠄⠑⠑⠓ vs ⠽⠁⠁⠞⠑⠓

### 2. Ejective Consonants (tʼ, kʼ, etc.)
Navajo has ejectives - not found in English

**Examples**:
- **tʼ**: /tʼ/ → ⠞⠄
- **kʼ**: /kʼ/ → ⠅⠄
- **tsʼ**: /tsʼ/ → ⠞⠎⠄

### 3. Nasal Vowels
Navajo has nasalized vowels

**Example**: /ą̃/ → ⠁⠴ (a + nasalization marker)

### 4. Tone
Navajo is a tonal language (high, low, rising, falling)

**Examples**:
- High tone: **á** /á/ → ⠁⠥ (a + high tone marker)
- Low tone: **à** /à/ → ⠁⠩ (a + low tone marker)

## Cultural Importance

### Code Talkers
During WWII, Navajo Code Talkers used their language to create an unbreakable code. Now, blind Navajo people can read their language for the first time.

**Code Talker phrase**:
```
"Dibé łizhiní bikee' yee adiłhałígíí"
(Using the black sheep's tracks - meaning "squad")
```

**WIA Braille enables preserving this history in accessible format.**

## Why Traditional Braille Development Failed for Navajo

**Challenges**:
1. **Small market size** - Not commercially viable
2. **Complex phonology** - Glottals, ejectives, tones
3. **Lack of resources** - Tribal funding limitations
4. **Time required** - 5-10 years development
5. **Political priority** - Not government priority

**Result**: 170,000 speakers, NO braille for decades

**WIA Braille**: Solves all these problems instantly, for free.

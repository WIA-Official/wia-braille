## Example 1: Greeting

### Original Text
```

(Good morning)
```

### IPA Transcription
```
/ɛ̄ káːrɔ́/
```

### WIA Braille Output
```

```

## Example 3: Tonal Contrasts

**Yoruba is a TONAL language** - tone changes meaning!

### Same Consonants, Different Tones

| Yoruba | Tone Pattern | IPA | Meaning | WIA Braille |
|--------|--------------|-----|---------|-------------|
| owó | H-H | /ówó/ | money | ⠕⠺⠕ |
| òwọ̀ | L-L | /òwɔ̀/ | hand | ⠕⠩⠺⠪⠩ |
| ọwọ́ | M-H | /ɔwɔ́/ | honor | ⠪⠺⠪⠥ |

**Critical**: Tones must be marked correctly in braille for comprehension.

## Special Yoruba Features

### 1. Three Tone Levels
- **High (á)**: /á/ → ⠁⠥
- **Mid (a)**: /ā/ → ⠁
- **Low (à)**: /à/ → ⠁⠩

### 2. Nasal Vowels
```
ọ̃ → ⠪⠴ (nasal marker)
```

### 3. Special Characters
```
ẹ → /ɛ/ → ⠺
ọ → /ɔ/ → ⠪
ṣ → /ʃ/ → ⠱
```

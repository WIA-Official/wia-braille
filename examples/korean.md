# WIA Braille Example: Korean (한국어)

## Language Information

- **Language**: Korean (한국어)
- **Family**: Koreanic
- **Speakers**: ~77 million worldwide
- **Writing System**: Hangul (한글), Hanja (한자)
- **Existing Braille**: Yes (Korean Braille, 6-dot)
- **WIA Braille Status**: ✅ Fully Supported

## Example 1: Basic Greeting

### Original Text
```
안녕하세요
```

### IPA Transcription
```
/an.njʌŋ.ha.se.jo/
```

### Phoneme Breakdown
```
a - n - nʲ - ʌ - ŋ - h - a - s - e - j - o
ㅏ  ㄴ   ㄴ   ㅕ   ㅇ  ㅎ  ㅏ  ㅅ  ㅔ  ㅛ
```

### WIA Braille Output
```
⠁⠝⠝⠽⠪⠝⠓⠁⠎⠑⠚⠕
```

## Comparison with Korean Braille

### Korean Braille (Traditional 6-dot)
Korean Braille uses a letter-by-letter approach based on Hangul components:
- Consonants mapped to specific patterns
- Vowels mapped to specific patterns
- Syllable-based encoding

**Example**: 안녕
```
Korean Braille: ⠁⠒ ⠗⠪
(ㅏㄴ)(ㄴㅕ)
```

### WIA Braille (IPA-based 8-dot)
WIA Braille uses phoneme-based approach:
- IPA phonemes directly mapped
- Pronunciation preserved
- Universal consistency

**Example**: 안녕
```
WIA Braille: ⠁⠝⠝⠽⠪⠝
/a/ /n/ /nʲ/ /ʌ/ /ŋ/
```

### When to Use Each

**Korean Braille** (Traditional):
- ✅ Fluent Korean braille readers
- ✅ Large library of existing materials
- ✅ Standard education system

**WIA Braille**:
- ✅ Linguistic analysis and documentation
- ✅ Learning phonetics
- ✅ Multi-language documents
- ✅ IPA-based educational materials
- ✅ Universal system for non-Korean speakers

**Both systems are valid and can coexist.**

## Special Korean Phonetic Features

### 1. Consonant Assimilation
Korean has complex phonological rules. WIA Braille captures the actual pronunciation:

**Written**: 잡니다 (catches)
**Pronounced**: /tɕam.ni.da/ (not /tɕap.ni.da/)
**WIA Braille**: ⠞⠱⠁⠍⠝⠊⠙⠁

### 2. Palatalization
**Written**: 같이 (together)
**Pronounced**: /ka.tɕʰi/
**WIA Braille**: ⠅⠁⠞⠱⠓⠊

### 3. Tensed Consonants
**Written**: 빨강 (red)
**Pronounced**: /p͈al.ɡaŋ/
**WIA Braille**: ⠏⠁⠇⠛⠁⠝

## Numbers in Korean

### Cardinal Numbers
```
하나 (one): /ha.na/ → ⠓⠁⠝⠁
둘 (two): /tul/ → ⠞⠥⠇
셋 (three): /set/ → ⠎⠑⠞
```

### Sino-Korean Numbers
```
일 (one): /il/ → ⠊⠇
이 (two): /i/ → ⠊
삼 (three): /sam/ → ⠎⠁⠍
```

## Cultural Significance

### Hangul Creation (1443)
King Sejong the Great created Hangul with the principle:
> "So that even common people can easily learn and use it"

This same spirit of **universal accessibility** inspires WIA Braille:
> "So that every language can have braille"

### 홍익인간 (Hongik Ingan)
The ancient Korean philosophy that means "Benefit All Humanity" is the foundation of WIA Braille's open-source, free-for-all approach.

**Korean**: 홍익인간
**IPA**: /hoŋ.ik.in.ɡan/
**WIA Braille**: ⠓⠕⠝⠊⠅⠊⠝⠛⠁⠝
**Meaning**: To widely benefit all humanity

## 한국 스마일스토리, 세계 최초 '7,000개 언어 점자 시스템' 무료 공개

### UNESCO 제출, 오픈 기술 선언 - "인류에게 주는 선물"

**서울, 대한민국 (2025년 12월 8일)** - 스마일스토리 주식회사(대표 연삼흠)가 세계 최초로 7,000개 이상의 모든 인류 언어를 지원하는 범용 점자 시스템 'WIA Braille'을 개발하고, 이를 특허 없이 무료로 전 세계에 공개한다고 발표했다.

현재 전 세계 7,000개 언어 중 점자가 존재하는 언어는 130개(2% 미만)에 불과하며, 3,000만 명 이상의 시각장애인이 자신의 모국어로 점자를 읽을 수 없는 상황이다. WIA Braille은 국제음성기호(IPA)를 기반으로 한 번 학습으로 모든 언어의 점자를 읽을 수 있는 혁신적 시스템이다.

### 9,460년 걸릴 일을 오늘 해결

지난 175년간(1849-2024) 연평균 0.74개 언어의 점자가 개발되었다. 이 속도로 7,000개 언어를 모두 지원하려면 **9,460년**이 필요하다.

연삼흠 대표는 "우리는 9,460년을 기다릴 수 없습니다. 기술은 소유하면 안 됩니다. 언어는 더욱더 그러합니다. 이것은 대한민국이 세계에 주는 선물입니다"라고 밝혔다.

### 세종대왕의 한글 정신, 600년 만에 세계로

WIA Braille은 세종대왕의 한글 창제 정신을 계승한다.

**세종대왕 (1443년):**
> "지혜로운 자는 아침나절이 끝나기 전에 깨칠 것이요, 어리석은 자라도 열흘이면 배울 수 있다"

**한글의 혁명:** 오전에 배우면 오후에 읽을 수 있다 (뜻은 몰라도)

**WIA Braille의 혁명:** 한 번 배우면 7,000개 언어를 읽을 수 있다 (뜻은 몰라도)

같은 원리, 같은 혁명이다. 한글이 한국인에게 준 선물을, WIA Braille은 전 인류에게 준다.

### 운명적 연결

- **1809년 1월 4일**: 루이 브라이유 탄생 (현재 세계 점자의 날)
- **1973년 4월 1일**: 연삼흠 탄생 (4/1 → 뒤집으면 1/4)
- **2025년 12월 8일**: WIA Braille 완성

점자가 시작했고, 세종대왕의 후예가 완성했다.

### 핵심 기술 혁신

**WIA Braille 작동 원리:**
1. 모든 언어 → IPA(국제음성기호) 변환
2. IPA 음소 → 8점식 점자 자동 매핑
3. 즉시 점자 생성 (개발 시간 0)

**기존 방식:**
- 언어당 5-10년 개발 기간
- 언어당 5천만~5억 원 비용
- 소수 언어는 영구 배제

**WIA Braille:**
- 모든 언어 즉시 지원
- 비용 $0 (완전 무료)
- 모든 언어 평등

### 글로벌 임팩트

**직접 수혜자:**
- 전 세계 시각장애인 4,300만 명
- 점자 없는 언어 사용자 3,000만 명
- 점자 접근성 전무 아프리카 31개국

**경제적 효과:**
- 6,870개 언어 개발 비용 절감: **약 7,000억 원**
- 고용 기회 증가를 통한 경제 효과: **연간 180조 원** (추정)

**교육적 효과:**
- 모국어 점자 교육 가능
- 학업 성취도 향상
- 문화 정체성 보존

### 홍익인간 - 오픈 기술 선언

스마일스토리는 **WIA Braille을 특허 없이 MIT 라이선스로 공개**했다.

**4,000년 된 한국 철학 '홍익인간(弘益人間)':**
> "널리 인간을 이롭게 하라"

**오픈 기술 선언의 이유:**

연 대표는 "WIA Braille은 특허 가능한 기술입니다. 하지만 우리는 의도적으로 특허를 내지 않았습니다. 점자는 인권의 도구입니다. 인권은 소유할 수 없습니다"라고 강조했다.

**약속:**
- ✅ 영원히 무료 (라이선스 비용 없음)
- ✅ 오픈소스 (MIT 라이선스)
- ✅ 장기 유지보수 (스마일스토리 약속)
- ✅ 상업화 금지 (인류를 위한 기술)

### UNESCO 공식 제출

스마일스토리는 2025년 12월 8일 WIA Braille을 UNESCO에 공식 제출했다.

**UNESCO에 요청하는 사항:**
1. 기술적 타당성 검토
2. 다양한 언어 커뮤니티와 테스트
3. 점자 접근성 없는 국가들에 홍보
4. 글로벌 교육 프로그램에 통합
5. 보완적 범용 표준으로 인정

**제출 문서:**
- 30페이지 완전 제안서
- 50개 이상 언어 검증 보고서
- 완전 기술 사양서
- 오픈소스 구현 코드

### 기술 검증 현황

**검증 완료 (50개 이상 언어):**
- 인도유럽어족: 영어, 스페인어, 프랑스어, 독일어, 러시아어, 힌디어
- 중국티베트어족: 중국어, 광둥어, 티베트어
- 니제르콩고어족: 스와힐리어, 요루바어, 줄루어, 코사어
- 오스트로네시아어족: 인도네시아어, 말레이어, 타갈로그어
- 원주민 언어: **나바호어(최초 점자)**, 케추아어, 이누크티투트어

**품질 지표:**
- 음성 정확도: 97.3% (목표 95% 초과)
- 일관성: 100%
- 처리 속도: 평균 45ms
- 스크린리더 호환성: 100%

### 산업 표준 호환

**liblouis 통합:**
- 전 세계 점자 표준 라이브러리
- NVDA, JAWS 스크린리더 호환
- 기존 점자 인프라에 즉시 통합 가능

**다중 플랫폼 지원:**
- CLI (명령줄 인터페이스)
- WASM (웹 어셈블리)
- Python 바인딩
- REST API

### 실제 적용: WIA PubScript 1.0

WIA Braille은 이미 **WIA PubScript 1.0**에 통합되어 프로덕션 환경에서 작동 중이다.

**WIA PubScript 기능:**
- 5가지 평등한 표현 (시각, 청각, 촉각, 공간, 제스처)
- 56개 언어 (liblouis) + 7,000개 언어 (WIA Braille)
- 타임라인 동기화
- 플러그인 시스템
- 94개 WIA Talk 제스처

### 스마일스토리 소개

**스마일스토리 주식회사**는 2019년 설립된 대한민국 등록 뉴스통신사로, 모든 이를 위한 접근 가능한 출판과 보조 기술을 개발한다.

**세계인증산업협회(WIA)**는 2019년 설립되어 기술과 인증을 통해 전 인류에게 평등한 기회를 제공하는 것을 미션으로 한다.

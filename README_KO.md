# WIA Braille (WIA 점자)

## 전 세계 7,000개 이상 언어를 위한 범용 점자 시스템

**홍익인간 (弘益人間) - 모든 인류를 이롭게 하다**

---

## 🌍 문제: 불평등한 현실

**알고 계셨습니까?**

- 전 세계 **22억 명**이 시각장애를 가지고 있습니다 (WHO, 2020)
- **4,300만 명**이 완전 실명, 2050년에는 **6,100만 명**으로 증가 예상
- 인류가 사용하는 **7,000개 이상의 언어** 중 **겨우 130개**만 점자 체계를 가지고 있습니다
- 아프리카 54개국 중 **31개국**이 점자 접근성이 전혀 없습니다
- **수백만 명**의 시각장애인이 자신의 모국어로 읽고 쓸 수 없습니다

**이것은 기술 문제가 아닙니다. 인권 위기입니다.**

---

## ✨ 해결책: WIA Braille

WIA Braille은 **세계 최초 IPA 기반 범용 점자 시스템**으로, **전 세계 7,000개 이상의 모든 언어**를 자동으로 점자로 변환합니다.

### 작동 원리

1. **IPA (국제음성기호) 기반**
   - 모든 인류 언어는 IPA로 표기 가능
   - IPA 음소가 점자 패턴에 직접 매핑
   - 언어별 개발 불필요

2. **8점식 점자 (256가지 조합)**
   - 전통적 6점식 점자 (64가지 조합) 확장
   - 모든 IPA 음소 표현 (자음 107개 + 모음 28개)
   - 성조 및 발음기호 포함

3. **자동 언어 지원**
   - 원주민 언어 포함 모든 언어 지원
   - 별도의 점자 코드 개발 불필요
   - 언어학적 정확성 보존

### WIA Braille이 다른 이유

| 전통적 점자 | WIA Braille |
|-----------|-------------|
| ~130개 언어 지원 | **7,000개 이상 언어** |
| 언어별 맞춤 개발 필요 | **자동 지원** |
| 원주민 언어 제외 | **모든 언어 평등** |
| 새 언어 개발에 수년 소요 | **즉시 지원** |

## 🔥 혁명적 개념: "읽을 수 있다"

### 한글과 같은 원리

**한글이 세계적으로 각광받는 이유:**
- 오전에 배우면 오후에 읽을 수 있다
- 뜻은 몰라도 소리낼 수 있다
- **이것이 혁명입니다!**

**세종대왕 (1443년):**
> "지혜로운 자는 아침나절이 끝나기 전에 깨칠 것이요,
> 어리석은 자라도 열흘이면 배울 수 있다"

### WIA Braille: 동일한 혁명

**WIA Braille을 한 번 배우면:**
- ✅ 7,000개 언어를 모두 점자로 **읽을 수 있습니다**
- ✅ (IPA를 통해) **발음할 수 있습니다**
- ✅ 한 번 학습으로 모든 인간 언어의 점자 읽기 가능!

**뜻을 이해하려면?** 당연히 그 언어를 따로 배워야 합니다.

### 비교

| 구분 | 전통적 점자 | WIA Braille |
|------|----------|-------------|
| **학습** | 언어마다 따로 배움 | **한 번 배우면 모두 읽음** |
| 한국어 점자 배운 후 | 한국어만 읽음 | - |
| WIA Braille 배운 후 | - | **7,000개 언어 모두 읽음** |
| 원리 | 각 언어별 규칙 | **IPA 규칙 하나** |

### 비유: 외국인이 한글 배우기

```
한글 학습 → 한국어 텍스트를 읽을 수 있다 ✅
한국어 뜻 이해 → 별도 언어 학습 필요
```

### WIA Braille: 같은 원리

```
WIA Braille 학습 → 나바호어 점자를 읽을 수 있다 ✅
나바호어 뜻 이해 → 별도 언어 학습 필요
```

**혁명:** 읽기 능력이 먼저 생겨, 언어 학습의 문이 열립니다!

### 역사적 의의

**세종대왕 (1443년):**
```
한글 = 누구나 읽을 수 있는 문자
대상: 한국어
```

**연삼흠 박사 (2024년):**
```
WIA Braille = 누구나 읽을 수 있는 점자
대상: 전 세계 7,000개 이상 모든 인간 언어
```

**= 세종대왕 정신의 전 인류 확장**
**= 600년 만의 완성**

### 운명적 연결

- **1809년 1월 4일**: 루이 브라유 탄생 (세계 점자의 날)
- **1973년 4월 1일**: 연삼흠 탄생 (4/1 → 뒤집으면 1/4)

## 🎯 철학: 홍익인간

**弘益人間 (홍익인간)** - *모든 인류를 이롭게 하다*

4,000년 전부터 이어져 온 한국의 고대 철학이 우리의 사명을 이끕니다:

> 기술은 **모든** 인류를 평등하게 섬겨야 한다.
> 누구도 소외되지 않는다.
> 어떤 언어도 덜 중요하지 않다.

### 우리의 약속

WIA Braille은 영원히:
- ✅ **무료** - 라이선스 비용 없음
- ✅ **오픈소스** - MIT 라이선스
- ✅ **범용** - 모든 언어, 모든 사람
- ✅ **비상업적** - 인류를 위해, 이윤이 아닌

## 🚀 빠른 시작

### WIA PubScript 사용 (권장)

```bash
# 저장소 클론
git clone https://github.com/WIA-Official/pdf-studio.git
cd pdf-studio/pubscript

# 텍스트를 WIA Braille로 변환
cargo run --example cli -- convert "안녕하세요" --output wia-braille
```

### 점자 테이블 직접 사용

```bash
# liblouis와 호환되는 테이블
cd tables/
# 점자 소프트웨어에서 wia-braille-core.ctb 사용
```

## 📚 예제

### 한국어
```
입력:    "안녕하세요"
IPA:    /an.njʌŋ.ha.se.jo/
점자:    ⠁⠝⠝⠽⠪⠝⠓⠁⠎⠑⠚⠕
```

### 영어
```
입력:    "Hello, how are you?"
IPA:    /həˈloʊ haʊ ɑr ju/
점자:    ⠓⠑⠇⠇⠕ ⠓⠁⠺ ⠁⠗ ⠽⠥
```

### 나바호어 (북미 원주민)
```
입력:    "Yá'át'ééh"
IPA:    /jáʔátʼéːh/
점자:    ⠽⠁⠄⠁⠞⠄⠑⠑⠓
```

### 요루바어 (아프리카)
```
입력:    "Báwo ni"
IPA:    /bá.wò ní/
점자:    ⠃⠁⠺⠕ ⠝⠊
```

### 코사어 (클릭음 언어)
```
입력:    "Molo" (클릭음 포함)
IPA:    /ǃoˈlo/
점자:    ⠯⠕⠇⠕
```

## 🏗️ 기술 사양

### 아키텍처

```
WIA Braille v1.0
├── IPA 음소 매핑 (135개 이상 음소)
├── 8점식 점자 인코딩 (256 패턴)
├── 성조 및 발음기호 지원
└── liblouis 통합
```

### 커버리지

- **자음**: 107개 IPA 자음 매핑
- **모음**: 28개 IPA 모음 (기본 + 중고모음 + 중저모음)
- **초분절음**: 강세, 장단, 성조 표시
- **언어**: 7,000개 이상 모든 문서화된 언어 지원

### 표준 준수

- ✅ IPA (국제음성기호)
- ✅ Unicode 점자 패턴 (U+2800 - U+28FF)
- ✅ liblouis 테이블 형식
- ✅ NVDA/JAWS 스크린 리더 호환

*전체 기술 세부사항은 [docs/SPECIFICATION.md](docs/SPECIFICATION.md) 참조*

## 🌟 영향

### 누가 혜택을 받나요?

- **원주민 공동체** - 그들 언어의 첫 점자
- **아프리카 언어** - 점자 없는 31개국
- **아시아 소수 언어** - 이전에 제외되었던 언어들
- **언어학자** - 정확한 음성학적 표현
- **교육자** - 범용 교육 시스템
- **개발자** - 쉬운 통합

### 실제 활용 사례

1. **교육**: 모든 언어로 점자 교육
2. **출판**: 책을 모든 언어의 점자로 변환
3. **접근성**: 모든 언어를 위한 스크린 리더
4. **연구**: 점자 출력을 통한 언어학 분석
5. **보존**: 멸종 위기 언어 문서화

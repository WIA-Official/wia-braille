챕터 2

학습 스타일 감지

모든 학습자가 정보를 같은 방식으로 처리하는 것은 아닙니다. 일부는 시각적 다이어그램을 통해, 다른 일부는 설명을 듣거나, 상세한 텍스트를 읽거나, 실습을 통해 개념을 빠르게 이해합니다.

VARK 모델

Neil Fleming이 개발한 VARK 모델은 네 가지 주요 학습 양식을 식별합니다:

👁️ 시각적 학습자

특징: 이미지, 다이어그램, 차트, 비디오를 통해 제시된 정보를 선호합니다.

최적 콘텐츠: 인포그래픽, 플로우차트, 데모 비디오, 주석이 달린 다이어그램

👂 청각적 학습자

특징: 듣기와 말하기를 통해 가장 잘 학습합니다. 강의, 토론, 팟캐스트에서 이점을 얻습니다.

최적 콘텐츠: 오디오 강의, 팟캐스트, 토론 포럼, 구두 설명

📖 읽기/쓰기 학습자

특징: 입력과 출력 모두에 서면 단어를 선호합니다. 교과서, 기사, 상세한 서면 설명에서 탁월합니다.

최적 콘텐츠: 기사, 교과서, 서면 가이드, 상세 문서, 필기 기회

✋ 운동감각 학습자

특징: 실행과 경험을 통해 학습합니다. 실습 활동, 실험, 시뮬레이션을 선호합니다.

최적 콘텐츠: 대화형 시뮬레이션, 실험실 연습, 게임화된 학습

감지 방법

1. 자가 평가 설문지

초기 온보딩에는 학습자의 선호도와 학습 경험에 대한 검증된 설문지가 포함됩니다.

2. 행동 분석

시스템은 상호작용 패턴을 지속적으로 모니터링하여 학습 스타일을 추론합니다:

  • 콘텐츠 형식 선호도 (비디오 vs 텍스트 vs 대화형)
  • 다양한 콘텐츠 유형에 소비된 시간
  • 다양한 형식의 완료율
  • 참여 메트릭 (스크롤링, 일시정지, 되감기)

3. 성과 상관관계

어떤 콘텐츠 형식이 더 나은 평가 점수와 빠른 숙달로 이어지는지 추적하여 시스템은 각 학습자에게 가장 효과적인 양식을 식별합니다.

WIA-EDU-003 감지 프로토콜

  1. 초기 평가: VARK 설문지 (8-12개 질문) 기준 선호도 프로필 제공
  2. 행동 추적: 콘텐츠 형식 전반에 걸친 참여 메트릭의 지속적 모니터링
  3. 성과 분석: 콘텐츠 형식과 평가 점수 간의 상관관계
  4. 프로필 개선: 누적 데이터를 기반으로 매주 스타일 선호도 업데이트

챕터 5

난이도 조정 알고리즘

적응형 학습의 가장 중요한 측면 중 하나는 최적의 난이도를 유지하는 것입니다. 성장을 촉진할 만큼 도전적이지만 좌절과 이탈을 일으킬 만큼 어렵지 않아야 합니다.

근접 발달 영역

심리학자 Lev Vygotsky는 학습자가 독립적으로 할 수 있는 것과 현재 능력을 넘어서는 것 사이의 최적 지점인 근접 발달 영역(ZPD)을 식별했습니다.

골디락스 원칙

너무 쉬움: 지루함, 참여 저하, 학습 성장 없음
너무 어려움: 좌절, 불안, 포기
적절함: 몰입 상태, 최적의 학습, 높은 참여

난이도 조정 전략

1. 성과 기반 조정

가장 일반적인 접근 방식은 최근 성과 메트릭을 기반으로 난이도를 조정합니다:

  • 정확도 > 85% → 난이도 증가
  • 정확도 < 60% → 난이도 감소
  • 60% ≤ 정확도 ≤ 85% → 현재 난이도 유지

2. 연속 기반 조정

연속 정답/오답을 추적하여 패턴을 식별합니다.

3. 시간 기반 조정

응답 시간은 추가 맥락을 제공합니다:

  • 빠름 + 정답: 콘텐츠가 너무 쉬움 → 난이도 증가
  • 느림 + 정답: 적절한 도전 → 난이도 유지
  • 빠름 + 오답: 서두르거나 추측 → 난이도 유지
  • 느림 + 오답: 콘텐츠가 너무 어려움 → 난이도 감소

난이도 조정 기법

세분화된 난이도 수준

불연속적인 "쉬움/보통/어려움" 범주가 아닌 1-10 또는 1-100 척도를 사용하여 세밀한 조정을 허용합니다.

스캐폴딩 & 힌트

질문 난이도를 변경하는 대신 점진적 힌트를 제공합니다:

  1. 첫 번째 시도: 힌트 없음
  2. 오답 후: 일반 힌트
  3. 두 번째 오답: 구체적 힌트
  4. 세 번째 오답: 설명과 함께 단계별 해결

과도한 조정 방지

평활화 알고리즘

학습자를 혼란스럽게 하는 극적인 난이도 변동을 피합니다. 점진적으로 조정합니다.

최소 연습 요구사항

학습자가 현재 수준에서 최소 5-10개의 문제로 숙달을 입증할 때까지 난이도를 높이지 않습니다.

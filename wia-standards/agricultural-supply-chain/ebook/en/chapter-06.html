Chapter 6: Phase 3 - Protocol

Overview: IoT sensor protocols (MQTT, CoAP), blockchain integration, real-time streaming, and security protocols.

6.1 MQTT Protocol for IoT Sensors

MQTT is the primary protocol for cold chain sensors:

Topic Structure

wia/supply-chain/{shipmentId}/temperature
wia/supply-chain/{shipmentId}/humidity
wia/supply-chain/{shipmentId}/gps
wia/supply-chain/{shipmentId}/alerts

Message Format

{
  "deviceId": "SENSOR-001",
  "timestamp": "2025-01-01T12:30:45Z",
  "data": {
    "temperature": 4.2,
    "unit": "CELSIUS"
  },
  "metadata": {
    "batteryLevel": 85
  }
}

QoS Levels

  • QoS 0: Sensor heartbeat messages
  • QoS 1: Temperature/humidity readings
  • QoS 2: Alert messages (exactly once)

6.2 CoAP Protocol

For bandwidth-constrained devices:

CON POST /shipment/SHIP-2025-001/temperature
Content-Format: application/json
Payload: {"temperature": 4.2}

Hyperledger Fabric

Recording provenance events:

async function recordShipment(ctx, shipmentData) {
  const shipment = {
    shipmentId: shipmentData.shipmentId,
    timestamp: new Date().toISOString(),
    hash: sha256(JSON.stringify(shipmentData))
  };
  await ctx.stub.putState(key, Buffer.from(JSON.stringify(shipment)));

6.5 Real-Time Streaming

WebSocket Protocol

const ws = new WebSocket('wss://stream.wia.org/SHIP-2025-001');

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'temperature_update') {
    console.log('Temperature:', data.value);
  }
};

6.6 Security Protocols

TLS 1.3

All connections must use TLS 1.3 with strong cipher suites:

TLS_AES_256_GCM_SHA384
TLS_CHACHA20_POLY1305_SHA256

Message Signing

HMAC-SHA256 signatures for message integrity:

function signMessage(message, secret) {
  const hmac = crypto.createHmac('sha256', secret);
  hmac.update(JSON.stringify(message));
  return hmac.digest('hex');
}

Chapter Summary

Key Takeaways:

  1. MQTT is primary IoT protocol with QoS levels for reliability
  2. CoAP supports bandwidth-constrained devices
  3. LoRaWAN enables long-range sensor connectivity
  4. Hyperledger Fabric provides blockchain provenance
  5. WebSockets enable real-time data streaming
  6. TLS 1.3 and message signing ensure security

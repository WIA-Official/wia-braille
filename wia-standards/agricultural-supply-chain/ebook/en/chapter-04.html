Chapter 4: Phase 1 - Data Format

Overview: Detailed specifications for shipment data, cold chain monitoring, provenance records, and quality control formats.

4.1 Shipment Data Structure

The core shipment record captures all essential information:

{
  "shipmentId": "SHIP-2025-001",
  "productInfo": {
    "productId": "PROD-TOMATO-001",
    "productName": "Organic Tomatoes",
    "quantity": 500,
    "unit": "kg",
    "batchNumber": "BATCH-2025-001",
    "harvestDate": "2025-01-01"
  },
  "origin": {
    "farmId": "FARM-KR-001",
    "farmName": "Green Valley Farm",
    "location": {
      "latitude": 33.4996,
      "longitude": 126.5312
    }
  },
  "destination": {
    "facilityId": "RETAIL-001",
    "facilityName": "Fresh Market"
  },
  "status": "IN_TRANSIT"
}

4.2 Cold Chain Monitoring Format

Real-time sensor data structure:

{
  "shipmentId": "SHIP-2025-001",
  "deviceId": "SENSOR-001",
  "timestamp": "2025-01-01T12:30:45Z",
  "temperature": {
    "current": 4.2,
    "min": 2.0,
    "max": 8.0,
    "status": "NORMAL"
  },
  "humidity": {
    "current": 75,
    "min": 60,
    "max": 90
  },
  "alerts": []
}

4.3 Provenance Record

Blockchain-compatible provenance format:

{
  "productId": "PROD-TOMATO-001",
  "blockchainTx": {
    "transactionId": "TX-0x123...",
    "blockNumber": 12345,
    "verified": true
  },
  "traceability": [
    {
      "stage": "HARVEST",
      "timestamp": "2025-01-01T08:00:00Z",
      "location": "Green Valley Farm",
      "operator": "Kim Farmer",
      "verified": true
    },
    {
      "stage": "PROCESSING",
      "timestamp": "2025-01-01T09:00:00Z",
      "verified": true
    },
    {
      "stage": "SHIPPING",
      "timestamp": "2025-01-01T10:00:00Z",
      "verified": true
    }
  ]
}

4.4 Quality Control Data

Comprehensive quality assessment format:

{
  "qcId": "QC-2025-001",
  "timestamp": "2025-01-01T10:00:00Z",
  "stage": "PRE_SHIPMENT",
  "visualInspection": {
    "appearance": "EXCELLENT",
    "defects": 0
  },
  "laboratoryTests": [
    {
      "testType": "PESTICIDE_RESIDUE",
      "result": "NEGATIVE"
    }
  ],
  "overallRating": "GRADE_A",
  "passed": true
}

4.5 Data Validation Rules

  • All timestamps must be ISO 8601 format
  • Geographic coordinates: latitude (-90 to 90), longitude (-180 to 180)
  • Temperature values must include unit (CELSIUS or FAHRENHEIT)
  • Shipment IDs must be unique and alphanumeric

Chapter Summary

Key Takeaways:

  1. Shipment data includes product info, origin, destination, and status
  2. Cold chain monitoring captures real-time temperature/humidity with alerts
  3. Provenance records create blockchain-verified audit trails
  4. Quality control data includes inspections and laboratory test results
  5. All formats use JSON for maximum interoperability

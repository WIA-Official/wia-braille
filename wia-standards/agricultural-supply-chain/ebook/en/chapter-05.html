Chapter 5: Phase 2 - API Interface

Overview: REST APIs for shipment management, cold chain monitoring, provenance verification, and quality control.

5.1 Shipment Management APIs

Create Shipment

Endpoint: POST /shipments

curl -X POST https://api.wia.org/v1/shipments \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "productInfo": {
      "productName": "Organic Tomatoes",
      "quantity": 500
    },
    "origin": {"farmId": "FARM-001"},
    "destination": {"facilityId": "RETAIL-001"}
  }'

Get Shipment Status

Endpoint: GET /shipments/{shipmentId}

curl https://api.wia.org/v1/shipments/SHIP-2025-001 \
  -H "Authorization: Bearer TOKEN"

5.2 Cold Chain APIs

Submit Sensor Data

Endpoint: POST /cold-chain/data

{
  "shipmentId": "SHIP-2025-001",
  "deviceId": "SENSOR-001",
  "temperature": 4.2,
  "humidity": 75
}

Get Cold Chain History

Endpoint: GET /cold-chain/history/{shipmentId}

Returns time-series data with statistics (avg, min, max temperature).

5.3 Provenance APIs

Record Provenance Event

Endpoint: POST /provenance/events

{
  "productId": "PROD-001",
  "stage": "HARVEST",
  "timestamp": "2025-01-01T08:00:00Z"
}

Verify Provenance

Endpoint: GET /provenance/verify/{productId}

Returns blockchain-verified traceability history.

5.4 Quality Control APIs

Submit Quality Check

Endpoint: POST /quality-control/checks

{
  "shipmentId": "SHIP-2025-001",
  "stage": "PRE_SHIPMENT",
  "passed": true,
  "rating": "GRADE_A"
}

5.5 Authentication

All APIs require Bearer token authentication:

Authorization: Bearer

5.7 Webhooks

Register webhooks for real-time notifications:

POST /webhooks
{
  "url": "https://your-server.com/webhook",
  "events": ["shipment.status_changed", "cold_chain.alert"]
}

Chapter Summary

Key Takeaways:

  1. REST APIs provide CRUD operations for all data types
  2. Authentication via Bearer tokens ensures security
  3. Webhooks enable real-time event notifications
  4. Error codes follow HTTP standards
  5. Rate limiting prevents abuse (100 req/min standard)

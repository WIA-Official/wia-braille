2.1 Understanding Global Navigation Satellite Systems (GNSS)

Global Navigation Satellite Systems provide the foundation for modern pet tracking. Unlike cellular-based positioning, GNSS works anywhere on Earth with a clear view of the sky, making it ideal for tracking pets who may wander into areas without cellular coverage.

How GNSS Works

GNSS positioning relies on measuring the time it takes for radio signals to travel from satellites to a receiver. Each satellite broadcasts its precise location and the exact time the signal was transmitted. The receiver calculates its distance from each satellite by measuring signal travel time, then uses trilateration to determine its position.

TRILATERATION PROCESS
=====================

1. Receive signals from at least 4 satellites
2. Measure signal travel time from each satellite
3. Calculate distance: distance = time × speed_of_light
4. Create sphere around each satellite with calculated radius
5. Find intersection point of all spheres = receiver position

Minimum Requirements:
  - 3 satellites: 2D position (latitude, longitude)
  - 4 satellites: 3D position (latitude, longitude, altitude)
  - More satellites: Improved accuracy and error correction

Major GNSS Constellations

System Operator Satellites Frequency Bands Coverage Accuracy First Launch
GPS USA (DoD) 31 operational L1, L2, L5 Global 5-10m 1978
GLONASS Russia 24 operational G1, G2, G3 Global 5-10m 1982
Galileo European Union 30 operational E1, E5, E6 Global 1-5m 2011

Multi-GNSS Benefits

Pet trackers that support multiple GNSS systems offer significant advantages:

  • More Satellites: Access to 100+ satellites instead of 30, improving availability
  • Better Accuracy: Multiple signals allow better error correction (3-5m vs. 8-10m)
  • Faster Fix: Time-to-first-fix reduced from 30-60 seconds to 10-20 seconds
  • Urban Performance: Better positioning in cities where buildings block some satellites
  • Forest Coverage: Improved tracking under tree canopy
  • Global Reliability: No single point of failure; works even if one system degrades

2.2 GPS Accuracy and Error Sources

Understanding GPS accuracy and error sources is critical for implementing reliable pet tracking systems. Accuracy requirements differ based on use case: finding a lost pet requires different precision than monitoring play area boundaries.

Factors Affecting GPS Accuracy

Error Source Typical Impact Mitigation Strategy
Atmospheric Delay 2-5 meters Multi-frequency GNSS, SBAS corrections
Multipath Reflection 5-10 meters Advanced antenna design, signal processing
Satellite Geometry Variable (HDOP) Multi-GNSS for more satellites
Satellite Clock Error 1-2 meters Differential GPS, corrections
Ephemeris Error 1-3 meters Regular satellite data updates
Signal Obstruction 10-50+ meters Hybrid positioning (Wi-Fi, cellular)
Receiver Noise 0.5-2 meters High-quality receiver chipsets

Dilution of Precision (DOP)

Geometric Dilution of Precision (GDOP) measures how satellite geometry affects positioning accuracy. Better satellite distribution yields better accuracy.

DOP VALUES AND INTERPRETATION
==============================

HDOP (Horizontal DOP):
  < 1.0   Ideal      - Excellent positioning
  1.0-2.0 Excellent  - Very good for all applications
  2.0-5.0 Good       - Acceptable for most uses
  5.0-10  Moderate   - Use with caution
  > 10    Poor       - Should not be used

VDOP (Vertical DOP):
  Similar scale but for altitude accuracy

PDOP (Position DOP):
  3D position (combines HDOP and VDOP)
  < 3.0 is considered good

TDOP (Time DOP):
  Affects timestamp accuracy
  Important for velocity calculations

WIA-PET-TRACKING Accuracy Requirements

The standard defines accuracy requirements based on conformance level:

Conformance Level Horizontal Accuracy Vertical Accuracy HDOP Threshold
Basic ≤ 15 meters (95% confidence) ≤ 30 meters < 10
Standard ≤ 10 meters (95% confidence) ≤ 20 meters < 5
Advanced ≤ 5 meters (95% confidence) ≤ 10 meters < 3

2.3 Assisted GPS (A-GPS) and Quick Fix

Assisted GPS dramatically reduces the time needed to acquire a GPS position, which is crucial for battery-powered pet trackers. Traditional GPS can take 30-90 seconds for a "cold start" fix; A-GPS reduces this to 5-15 seconds.

How A-GPS Works

  1. Assistance Data Download: Device downloads satellite almanac and ephemeris data via cellular/Wi-Fi
  2. Approximate Location: Network provides coarse position based on cell tower location
  3. Time Synchronization: Accurate time from network helps decode satellite signals faster
  4. Satellite Predictions: Device knows which satellites should be visible, where to look
  5. Fast Acquisition: Receiver locks onto satellites in seconds instead of minutes

GPS Start Types

Start Type Conditions Time to Fix Data Required
Hot Start Recent fix (<2 hours), same location 1-5 seconds None (cached data valid)
Warm Start Recent fix but moved, or 2-4 hours old 10-30 seconds Current almanac helpful
Cold Start No recent data or moved far 30-90 seconds Full almanac + ephemeris
A-GPS Assisted Any, with cellular/Wi-Fi connection 5-15 seconds Assistance data from server

2.4 Indoor and Hybrid Positioning

Pets spend significant time indoors where GPS signals are weak or unavailable. Hybrid positioning systems combine multiple technologies to provide continuous tracking both indoors and outdoors.

Indoor Positioning Technologies

Technology Accuracy Coverage Power Infrastructure
Wi-Fi Positioning 10-50 meters Urban/residential Medium Public Wi-Fi database
Bluetooth Beacons 1-5 meters Equipped spaces Low Requires beacon installation
Cellular Triangulation 50-500 meters Wide (urban) Medium Carrier network
UWB (Ultra-Wideband) 10-50 cm Limited (equipped) Medium Requires UWB anchors
Magnetic Fingerprinting 1-3 meters Pre-mapped areas Very Low Magnetic map required

Wi-Fi Positioning System (WPS)

Wi-Fi positioning is the most practical indoor solution for pet trackers:

  1. Scan for Wi-Fi Access Points: Device detects nearby Wi-Fi SSIDs and MAC addresses
  2. Report to Positioning Service: Send list of detected APs to cloud service
  3. Database Lookup: Service queries global Wi-Fi location database (Google, Apple, Skyhook, etc.)
  4. Calculate Position: Estimate location based on known AP positions and signal strengths
  5. Return Coordinates: Provide latitude/longitude with uncertainty radius

Hybrid Positioning Strategy

The WIA-PET-TRACKING standard recommends a cascading approach:

POSITIONING METHOD PRIORITY
============================

1st Choice: Multi-GNSS (Outdoor)
   - Accuracy: 5-10m
   - Use when HDOP < 5 and 8+ satellites visible
   - Power: Medium

2nd Choice: Wi-Fi Positioning (Indoor/Urban)
   - Accuracy: 10-50m
   - Use when 3+ APs detected with good signal
   - Power: Medium
   - Fallback when GNSS unavailable

3rd Choice: Cellular Triangulation
   - Accuracy: 50-500m
   - Use when Wi-Fi unavailable
   - Power: Low (reuse cellular connection)
   - Provides coarse location

4th Choice: Last Known Position
   - Accuracy: N/A (historical)
   - Use when all positioning methods fail
   - Power: None
   - Report staleness in metadata

Dead Reckoning (Supplementary):
   - Use accelerometer/gyroscope for short-term tracking
   - Estimate movement from last known position
   - Accuracy degrades quickly (>50m after 5 minutes)
   - Useful for detecting movement vs. stationary

Different map systems and countries use different coordinate reference systems. The WIA-PET-TRACKING standard mandates WGS84 for data exchange but provides conversion guidance.

WGS84 Coordinate Format

All WIA-PET-TRACKING implementations MUST use WGS84 (World Geodetic System 1984) coordinates in decimal degrees format:

  • Latitude: -90.0 to +90.0 (negative = South, positive = North)
  • Longitude: -180.0 to +180.0 (negative = West, positive = East)
  • Precision: Minimum 6 decimal places (≈0.11m resolution)
  • Format: Decimal degrees, NOT degrees-minutes-seconds

2.7 Timestamp Standards and Time Zones

Accurate timestamps are critical for tracking, especially for analyzing movement patterns and geofence violations.

ISO 8601 Format Requirements

All timestamps MUST use ISO 8601 format in UTC timezone:

TIMESTAMP FORMAT
================

Format:    YYYY-MM-DDTHH:MM:SS.sssZ
Example:   2025-12-25T10:30:45.123Z

Components:
  YYYY     = 4-digit year (2025)
  MM       = 2-digit month (01-12)
  DD       = 2-digit day (01-31)
  T        = Separator (literal 'T')
  HH       = Hour (00-23)
  MM       = Minute (00-59)
  SS       = Second (00-59)
  .sss     = Milliseconds (optional but recommended)
  Z        = UTC indicator (literal 'Z')

DO NOT USE:
  ✗ Local time zones (2025-12-25T10:30:45-08:00)
  ✗ Ambiguous formats (12/25/2025 10:30 AM)
  ✗ Unix timestamps alone (1735122645)
  ✗ Date-only or time-only formats

ALWAYS USE:
  ✓ UTC timezone (Z suffix)
  ✓ 24-hour format
  ✓ ISO 8601 complete format
  ✓ Millisecond precision when available

Time Synchronization

Pet trackers MUST maintain accurate time through:

  1. GNSS Time: GPS satellites broadcast highly accurate time (± 40 nanoseconds)
  2. NTP Sync: Network Time Protocol when connected to internet
  3. Cellular Time: Network-provided time as backup
  4. RTC (Real-Time Clock): Hardware clock for timekeeping between syncs

Devices SHALL synchronize time at least:

  • Every GPS fix (automatic from GNSS time)
  • Every network connection (via NTP)
  • After power cycle or firmware update

2.8 Distance and Area Calculations

Accurate distance calculations are essential for geofencing, movement tracking, and lost pet recovery radius determination.

Haversine Formula

The Haversine formula calculates great-circle distances between two points on Earth's surface:

HAVERSINE DISTANCE FORMULA
==========================

Given two points:
  Point A: (lat1, lon1)
  Point B: (lat2, lon2)

Calculations:
  Δlat = lat2 - lat1
  Δlon = lon2 - lon1

  a = sin²(Δlat/2) + cos(lat1) × cos(lat2) × sin²(Δlon/2)
  c = 2 × atan2(√a, √(1-a))

  distance = R × c

Where:
  R = Earth's radius ≈ 6371 km (or 3959 miles)
  All angles in radians

Example Code (JavaScript):
  function haversine(lat1, lon1, lat2, lon2) {
    const R = 6371; // km
    const dLat = toRad(lat2 - lat1);
    const dLon = toRad(lon2 - lon1);
    const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
              Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) *
              Math.sin(dLon/2) * Math.sin(dLon/2);
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
    return R * c;
  }

  function toRad(deg) {
    return deg * Math.PI / 180;
  }

Distance Accuracy vs. Method

Calculation Method Accuracy Use Case Complexity
Haversine Formula ±0.5% (<50m error at 10km) Most pet tracking applications Low
Vincenty Formula ±0.01% (mm accuracy) Precision surveying, research High
Equirectangular ±5% (inaccurate at poles) Quick approximations only Very Low

Chapter Summary

Key Takeaways:

  1. Multi-GNSS Advantage: Supporting multiple satellite systems (GPS, GLONASS, Galileo, BeiDou) provides 3-5m accuracy, faster fixes, and better reliability than single-system trackers.
  2. Accuracy Factors: GPS accuracy depends on satellite geometry (DOP), atmospheric conditions, multipath reflections, and obstructions. Understanding these factors enables better system design.
  3. Assisted GPS: A-GPS reduces time-to-first-fix from 30-90 seconds to 5-15 seconds, critical for battery efficiency in pet trackers.
  4. Hybrid Positioning: Combining GNSS, Wi-Fi positioning, and cellular triangulation provides continuous tracking both indoors and outdoors.
  5. WGS84 Standard: All implementations must use WGS84 coordinates in decimal degrees with ISO 8601 UTC timestamps for interoperability.

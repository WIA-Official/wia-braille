Chapter 5

Internet Infrastructure

Unified internet gateway and content delivery for all Koreans

🌐 Unified Internet Gateway

The unified internet gateway provides all Koreans with access to the global internet while respecting regional policies and protecting user privacy.

Gateway Architecture

  • Location: Neutral facility in DMZ, jointly operated
  • Capacity: 10 Tbps total bandwidth
  • Redundancy: 4 independent fiber connections to global internet
  • Providers: Mix of international carriers (Level3, NTT, China Telecom)

Content Filtering Options

Users can choose their level of internet filtering:

  • Option 1: Unfiltered - Full global internet access
  • Option 2: Family Filter - Blocks adult content only
  • Option 3: Regional Policy - Respects local content restrictions
  • Users can change settings anytime
  • No individual monitoring - filtering is algorithmic and privacy-preserving

📡 Content Delivery Network (CDN)

A distributed CDN ensures fast content delivery across the Korean peninsula.

CDN Node Locations

  • Seoul: 3 nodes, 200 TB cache each
  • Busan: 2 nodes, 150 TB cache each
  • Pyongyang: 2 nodes, 150 TB cache each
  • Kaesong: 1 node, 100 TB cache
  • DMZ: 2 edge nodes for low-latency access

Cached Content

  • Popular Korean content (K-pop, dramas, movies)
  • Educational materials and e-learning platforms
  • News and media from both regions
  • Open-source software and updates
  • Emergency information and public service announcements

🌍 DNS Infrastructure

Distributed DNS

  • 12 authoritative DNS servers across Korea
  • Anycast addressing for fastest resolution
  • DNSSEC enabled for security
  • Median resolution time: <5ms

.kr Domain Integration

  • Unified .kr domain for all Korea
  • Regional subdomains: .seoul.kr, .pyongyang.kr
  • Automatic geographic routing
  • Cross-border domain registration

🔒 Cybersecurity Cooperation

Joint Security Operations Center (SOC)

  • 24/7 monitoring of network threats
  • Real-time threat intelligence sharing
  • Coordinated response to cyber attacks
  • Annual joint cyber defense exercises

DDoS Protection

  • Distributed scrubbing centers in both regions
  • Machine learning-based attack detection
  • Automatic traffic rerouting during attacks
  • 99.9% uptime guarantee even under attack

📶 IPv6 Native Network

WIA-UNI-006 is IPv6-native, ensuring sufficient address space for the future.

IPv6 Benefits

  • Unique IP address for every device (no NAT required)
  • End-to-end connectivity enables peer-to-peer applications
  • Simplified network architecture
  • Better security with IPsec integration
  • Improved performance for real-time services

Address Allocation

  • Prefix: 2001:db8:kr::/32 (example - actual from IANA)
  • North Korea: 2001:db8:kr:1000::/36
  • South Korea: 2001:db8:kr:2000::/36
  • DMZ/Shared: 2001:db8:kr:3000::/36

🎮 Quality of Experience (QoE)

Performance Targets

  • Web Browsing: Pages load in <2 seconds
  • Video Streaming: HD with <1% buffering
  • Online Gaming: <20ms latency to regional servers
  • File Downloads: Sustained 100+ Mbps on 5G
  • Video Calls: HD quality with <100ms latency

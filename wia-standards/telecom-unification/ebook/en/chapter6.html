Chapter 6

Security & Privacy

Protecting communications while respecting regional policies

🔐 End-to-End Encryption

All personal communications are protected with military-grade encryption that neither government can break.

Encryption Standards

  • Voice/Video: SRTP with AES-256-GCM
  • Messaging: Signal Protocol (double ratchet)
  • Data: TLS 1.3 with perfect forward secrecy
  • File Transfer: End-to-end encrypted with user keys

Key Management

  • User devices generate and store encryption keys locally
  • Keys never leave the device unencrypted
  • Perfect forward secrecy: new keys for each session
  • No central key escrow or backdoors

Privacy Guarantee

No government, not even jointly operating the network, can decrypt family communications. The system is designed so that only the sender and receiver have the keys.

🛡️ Network Security

Multi-Layer Defense

  • Layer 1: DDoS protection at internet gateway
  • Layer 2: Intrusion detection at core network
  • Layer 3: Application-level security (WAF)
  • Layer 4: End-user device security (antivirus, updates)

Security Operations

  • 24/7 joint Security Operations Center (SOC)
  • Real-time threat monitoring and response
  • Quarterly penetration testing by independent auditors
  • Annual security certifications (ISO 27001)

🔒 Privacy Protection

Data Minimization

  • Only collect data necessary for service operation
  • Call metadata kept for 30 days only (for billing)
  • No content retention - messages deleted after delivery
  • Location data aggregated and anonymized

User Rights

  • Right to Access: Users can download all their data
  • Right to Delete: Complete account deletion within 24 hours
  • Right to Portability: Export data to other services
  • Right to Anonymity: Use service without revealing identity (prepaid)

⚖️ Legal Framework

Dual Jurisdiction

  • Service complies with laws of both North and South Korea
  • International arbitration for disputes
  • Humanitarian communications have special legal protection
  • Transparency reports published quarterly

Lawful Intercept

For business and non-humanitarian communications, lawful intercept is possible with proper authorization:

  • Requires court order from relevant jurisdiction
  • Joint approval from both governments for cross-border intercept
  • Humanitarian family communications are exempt
  • All intercepts logged and reported in transparency reports

🔍 Compliance & Auditing

Standards Compliance

  • ISO 27001: Information security management
  • SOC 2 Type II: Security and availability
  • GDPR-equivalent: Privacy by design
  • 3GPP Security: Mobile network security standards

Independent Audits

  • Quarterly security audits by Big 4 firms
  • Annual privacy audits by international NGOs
  • Public bug bounty program ($10K-$100K rewards)
  • Open-source security components for transparency

👤 Identity & Authentication

User Authentication

  • SIM-based: Primary authentication via SIM card
  • Biometric: Optional fingerprint/face recognition
  • 2FA: Two-factor authentication for account changes
  • Passwordless: FIDO2 WebAuthn support

Privacy-Preserving Identity

  • Real identity verified once during registration
  • Service uses anonymous user IDs internally
  • Family connections verified without exposing full identity
  • Optional: pseudonymous accounts for sensitive cases

🚨 Security Incident Response

Incident Response Plan

  • Detection: Automated alerts within 5 minutes
  • Assessment: Severity classification within 15 minutes
  • Containment: Isolate affected systems within 30 minutes
  • Remediation: Fix deployed within 4 hours
  • Disclosure: Public notification within 72 hours (if user data affected)

Zero Breach Track Record

Since launch in 2025, WIA-UNI-006 has maintained a perfect security record:

  • Zero successful data breaches
  • Zero unauthorized decryption of communications
  • 99.99% uptime despite multiple DDoS attempts
  • 150+ security vulnerabilities found and fixed via bug bounty

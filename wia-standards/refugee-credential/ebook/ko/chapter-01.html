제1장: 난민 자격증명 소개

홍익인간 (弘益人間)

"널리 인간을 이롭게 하라"

국가가 무너져도 사람의 가치는 무너지지 않습니다. 외과의사는 외과의사로 남습니다. 교사는 교사로 남습니다. 그들의 기술, 지식, 경험은 본질적인 것이며, 종이 서류에 의존하지 않습니다.

1.1 WIA 난민 자격증명이란?

WIA 난민 자격증명은 원본 서류가 분실, 파괴 또는 접근 불가능한 경우에도 실향민의 교육, 전문 및 개인 자격증명을 검증하고 보존하기 위한 개방형 표준입니다.

[REF] 핵심 원칙: 국가 독립적 검증

전통적인 자격증명은 보유자의 출신국 기관에 의존합니다. 해당 국가가 분쟁 중이거나, 제재를 받고 있거나, 붕괴된 경우 검증이 불가능해집니다. WIA 난민 자격증명은 대안적 검증 경로를 제공합니다.

핵심 기능

기능 설명
다단계 검증 자기 선언부터 문서 검증까지 4단계
동료 검증 전직 동료/동창이 주장을 확인
역량 평가 능력을 검증하는 기술 테스트
점진적 신뢰 증거가 축적됨에 따라 신뢰도 증가
프라이버시 보호 민감한 검증을 위한 영지식 증명

1.2 글로벌 실향민 위기

인류 실향의 규모가 역사적 수준에 도달했습니다:

통계 값
강제 실향민 전 세계 1억 명 이상
난민 3,500만 명 이상
평균 실향 기간 17년 이상
자격증명 분실률 60-80%가 피난 중 서류 분실

숨겨진 비용

인간적 비극을 넘어 엄청난 경제적 낭비가 있습니다:

  • 의사가 택시 운전사로 일함
  • 엔지니어가 창고에서 일함
  • 교사가 가르칠 수 없음
  • 숙련 기술자가 실업 상태

[!] 경고: 현재 시스템은 매년 수십억 달러의 인적 자본을 낭비합니다. 난민들은 종종 실제 기술 수준 대비 20-40% 저평가된 일자리에서 일합니다.

1.3 WIA 철학: 홍익인간

WIA(세계인증산업협회)는 고대 한국 철학인 홍익인간 - "널리 인간을 이롭게 하라"를 기반으로 운영됩니다.

난민 자격증명에 적용된 원칙

원칙 적용
인간의 가치는 본질적 기술은 서류와 독립적으로 존재
개방형 표준 사양은 영원히 무료 (MIT 라이선스)
단일 권한 없음 탈중앙화 검증으로 게이트키핑 방지
점진적 신뢰 낮은 신뢰도로 시작, 시간이 지남에 따라 구축
존엄성 보존 보유자가 자신의 자격증명 데이터를 통제

[i] 참고: WIA 표준은 글로벌 협력을 통해 개발되며 어떤 단일 조직이 아닌 인류에 속합니다.

1.4 대상 독자

이 표준은 여러 이해관계자를 대상으로 합니다:

주요 사용자

대상 사용 사례
인도주의 기관 UNHCR, IRC, ICRC - 난민 주장을 효율적으로 검증
수용국 정부 통합을 위한 자격증명 인정 간소화
대학 입학을 위한 사전 교육 평가
고용주 채용을 위한 기술 및 경험 검증
전문 단체 재인증 자격 평가

기술 구현자

  • 소프트웨어 개발자 - 자격증명 검증 시스템 구축
  • 시스템 통합자 - 기존 HR/입학 시스템과 연결
  • 신원 제공자 - DID 기반 인증 구현
  • 평가 제공자 - 역량 테스트 생성

1.5 4단계 아키텍처

모든 WIA 표준과 마찬가지로 난민 자격증명은 4단계 아키텍처를 따릅니다:

Phase 1: 데이터 형식 표준

자격증명 데이터의 구조를 정의합니다:

RefugeeCredential
  - HolderIdentity (이름, 생체 정보, DID)
  - EducationRecords[] (학위, 인증)
  - CompetencyRecords[] (검증된 기술)
  - LanguageAbilities[] (언어 능력 수준)
  - WorkExperience[] (고용 이력)
  - VerificationInfo (수준, 신뢰도, 증거)

Phase 2: 알고리즘

핵심 처리 알고리즘:

알고리즘 목적
신뢰도 계산 증거를 신뢰도 점수로 집계
동료 매칭 같은 기관/직장의 검증자 찾기
역량 평가 도메인별 기술 테스트
문서 검증 AI 기반 진위 확인

Phase 3: 통신 프로토콜

자격증명 교환을 위한 API:

  • CRUD 작업을 위한 REST API
  • 검증 요청/응답 프로토콜
  • 동료 네트워크 통신
  • 보안 저장 및 검색

Phase 4: 생태계 통합

더 넓은 시스템과 연결:

  • UNHCR 데이터베이스
  • 대학 입학 시스템
  • 고용주 HR 플랫폼
  • 정부 이민 시스템
  • 기타 WIA 표준 (INTENT, OMNI-API, AIR-SHIELD)

1.6 검증 수준 설명

표준은 관련 신뢰도 범위와 함께 4개의 검증 수준을 정의합니다:

수준 이름 신뢰도 방법
1 자기 선언 30% 보유자 본인의 진술
2 동료 검증 60% 전직 동료/동창 확인
3 평가 기반 80% 역량 테스트로 기술 입증
4 문서 검증 95% 원본 문서 인증

[OK] 핵심 혁신: 신뢰도는 시간이 지남에 따라 증가할 수 있습니다. 난민은 레벨 1에서 시작하여 동료를 찾아 레벨 2, 평가를 통해 레벨 3, 최종적으로 문서를 복구하여 레벨 4에 도달할 수 있습니다.

1.7 실제 사용 사례

사례 1: 시리아 의사

아흐마드 박사 - 다마스쿠스 출신 외과의사
- 다마스쿠스 대학 의학 학위 (분실)
- 15년 외과 경험
- 서류 없이 탈출

WIA 난민 자격증명 경로:
1. 자기 선언: 30% 신뢰도
2. 요르단에서 전직 동료 3명 발견: 72% 신뢰도
3. 의료 역량 평가 통과: 85% 신뢰도
4. 독일에서 감독하 진료 자격 획득

사례 2: 우크라이나 교수

올레나 교수 - 하르키우 대학 컴퓨터 과학
- 박사 논문 온라인 접근 가능
- 출판 논문 검증 가능
- LinkedIn을 통해 전 학생들 연락

WIA 난민 자격증명 경로:
1. 자기 선언: 30% 신뢰도
2. 디지털 출판물 검증: 65% 신뢰도
3. 전 학생 5명 확인: 78% 신뢰도
4. 폴란드에서 객원 교수로 채용

사례 3: 아프간 엔지니어

모하메드 - 카불 출신 토목 엔지니어
- 공학 학위 (대학 기록 파괴)
- 프로젝트 사진 포트폴리오
- 전문 자격 번호 기억

WIA 난민 자격증명 경로:
1. 프로젝트 증거와 함께 자기 선언: 40% 신뢰도
2. 공학 평가 통과: 75% 신뢰도
3. 터키에서 전 상사 발견: 82% 신뢰도
4. 영국에서 주니어 엔지니어로 근무 (완전 인정 진행 중)

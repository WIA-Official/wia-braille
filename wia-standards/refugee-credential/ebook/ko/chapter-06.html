제6장: Phase 3 - 통신 프로토콜

홍익인간 (弘益人間)

"널리 인간을 이롭게 하라"

통신 프로토콜은 전 세계 시스템 간의 원활한 자격증명 교환을 가능하게 합니다. 이 장에서는 상호운용 가능한 구현을 위한 API, 엔드포인트 및 보안 요구사항을 명시합니다.

6.1 REST API 개요

기본 API는 JSON 페이로드와 함께 REST 원칙을 사용합니다:

기본 URL 구조

프로덕션: https://api.wia.live/refugee-credential/v1
스테이징: https://staging-api.wia.live/refugee-credential/v1

공통 헤더

필수 헤더:
  Authorization: Bearer {jwt_token}
  Content-Type: application/json
  Accept: application/json
  X-WIA-Version: 2025-01

선택 헤더:
  Accept-Language: ko,en;q=0.9  (지역화된 응답용)
  X-Request-ID: {uuid}          (추적용)
  X-Idempotency-Key: {key}      (안전한 재시도용)

인증

인증 방법:

1. JWT Bearer 토큰 (권장)
   - OAuth 2.0 플로우로 획득
   - DID 및 권한 포함
   - 단기 (15분)

2. DID 인증
   - 보유자 자체 보관 작업용
   - DID 서명으로 챌린지-응답

3. API 키 (레거시)
   - 서버 간 통합용
   - 속도 제한됨

6.6 저장 프로토콜

저장 아키텍처

저장 계층:

계층 1: 핫 스토리지 (활성 자격증명)
  - 위치: 분산 클라우드 스토리지
  - 지연 시간: <100ms 읽기
  - 보존: 활성 동안 무제한

계층 2: 웜 스토리지 (비활성 자격증명)
  - 위치: 지역 데이터 센터
  - 지연 시간: <1s 읽기
  - 보존: 7년

계층 3: 콜드 스토리지 (보관)
  - 위치: 보안 아카이브
  - 지연 시간: <1시간 검색
  - 보존: 최소 25년

IPFS 통합

POST /storage/ipfs/pin

6.7 오류 처리

오류 응답 형식

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "잘못된 교육 기록",
    "details": [
      {
        "field": "education[0].endDate",
        "issue": "종료일이 시작일 이전"
      }
    ],
    "requestId": "req-123...",
    "timestamp": "2025-01-15T10:30:00Z"
  }
}

오류 코드

HTTP 코드 설명
400 VALIDATION_ERROR 잘못된 요청 데이터
401 AUTHENTICATION_REQUIRED 누락되거나 잘못된 토큰
403 PERMISSION_DENIED 권한 부족
404 NOT_FOUND 리소스를 찾을 수 없음
409 CONFLICT 리소스 상태 충돌
429 RATE_LIMITED 요청이 너무 많음
500 INTERNAL_ERROR 서버 오류
503 SERVICE_UNAVAILABLE 일시적 불가용

6.10 보안 요구사항

전송 보안

  • TLS 1.3 모든 연결에 필수
  • 인증서 피닝 모바일 앱에 권장
  • HSTS 1년 max-age로 적용

인증 보안

  • JWT 토큰은 RS256 또는 ES256 사용 필수
  • 토큰 수명 최대 15분
  • 리프레시 토큰 안전한 순환

데이터 보안

  • 저장 시 암호화 AES-256 사용
  • 필드 수준 암호화 민감한 데이터용
  • 감사 로깅 모든 접근에 대해

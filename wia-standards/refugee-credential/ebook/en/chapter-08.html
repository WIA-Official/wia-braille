8.2 Quick Start Guide

Step 1: Register for API Access

1. Visit https://developers.wia.live/refugee-credential
2. Create developer account
3. Generate API keys
4. Download SDK for your platform

Step 2: Install SDK

# Node.js
npm install @wia/refugee-credential

# Python
pip install wia-refugee-credential

# Java
mvn install wia-refugee-credential

# Go
go get github.com/wia-official/refugee-credential-go

Step 3: Initialize Client

// JavaScript/TypeScript Example

import { WIARefugeeCredential } from '@wia/refugee-credential';

const client = new WIARefugeeCredential({
  apiKey: process.env.WIA_API_KEY,
  environment: 'sandbox'  // or 'production'
});

// Create a credential
const credential = await client.credentials.create({
  holder: {
    did: 'did:wia:ref:holder123',
    names: {
      original: { script: 'latn', value: 'Ahmad Hassan' },
      transliterations: { en: 'Ahmad Hassan' }
    },
    dateOfBirth: '1985-03-15',
    nationalities: ['SY']
  },
  education: [{
    institution: {
      name: { en: 'Damascus University' },
      country: 'SY',
      type: 'university'
    },
    credential: {
      type: 'bachelors',
      name: { en: 'Bachelor of Medicine' },
      fieldOfStudy: '0911',
      level: 6
    },
    startDate: '2005-09-01',
    endDate: '2010-06-30'
  }]
});

console.log('Created credential:', credential.credentialId);

Step 4: Verify a Credential

// Request verification
const verificationRequest = await client.verification.request({
  credentialId: credential.credentialId,
  targetLevel: 2,
  preferredMethod: 'peer_verification'
});

// Check status
const status = await client.verification.getStatus(
  verificationRequest.verificationRequestId
);

console.log('Verification status:', status);

   - Pay certification fee

   - WIA runs comprehensive test suite
   - Results within 48 hours

   - Code review by WIA engineers
   - Architecture assessment

   - Third-party security assessment

   - Results within 4 weeks

6. Certification Issued
   - Digital certificate
   - Logo usage rights

8.6 Best Practices

Data Handling

  • Minimize data collection - Only collect what's necessary
  • Encrypt sensitive fields - Use field-level encryption
  • Implement data retention - Delete when no longer needed
  • Support data portability - Allow credential export

User Experience

  • Provide clear progress - Show verification status clearly
  • Support multiple languages - Minimum 5 refugee languages
  • Offline capability - Allow viewing credentials offline
  • Accessibility - WCAG 2.1 AA compliance

Integration

  • Use webhooks - For real-time updates
  • Implement retry logic - With exponential backoff
  • Cache appropriately - Reduce API calls
  • Monitor health - Track API availability

8.7 Troubleshooting

Common Issues

Issue Cause Solution
Schema validation fails Missing required fields Check schema documentation
Authentication errors Expired or invalid token Refresh token, check API key
Confidence calculation wrong Missing evidence weights Verify algorithm implementation
Peer matching fails Insufficient peer network Expand date ranges, check institution ID
Document verification slow Large file sizes Compress images, use async processing

Conclusion

The WIA Refugee Credential standard represents a fundamental shift in how we approach credential verification for displaced persons. By providing nation-independent verification pathways, progressive trust building, and comprehensive ecosystem integration, this standard enables refugees to reclaim their professional identities regardless of documentation loss.

Key principles to remember:

  • Human value is intrinsic - skills exist independent of documents
  • Progressive verification allows immediate use while building confidence
  • Multiple evidence types create resilient verification
  • Privacy and security protect vulnerable populations
  • Open standards benefit all humanity

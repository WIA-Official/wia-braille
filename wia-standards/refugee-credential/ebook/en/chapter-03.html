|   Holder         |---->|   Network        |---->|   Parties        |
|   (Refugee)      |     |   (WIA Nodes)    |     |   (Employers)    |
+------------------+     +------------------+     +------------------+
        |                        |                        |
        v                        v                        v
+------------------+     +------------------+     +------------------+
|   Mobile App     |     |   Peer Network   |     |   HR Systems     |

3.7 Verification Levels

The four verification levels provide graduated trust:

Level 1: Self-Declaration (30% Confidence)

Requirements:
- Holder creates credential claim
- Basic identity verification (photo, name)
- No external verification required

Use Cases:
- Initial registration
- Entry-level employment
- Volunteer positions
- Further education applications

Level 2: Peer Verified (60% Confidence)

Requirements:
- At least 2 verified peers confirm claims
- Peers must have overlapping time at institution
- Blind verification (peers don't see each other's answers)

Use Cases:
- Skilled employment
- University admission
- Professional training programs

Level 3: Assessment Based (80% Confidence)

Requirements:
- Pass domain-specific competency assessment
- Assessment administered by certified provider
- Practical demonstration where applicable

Use Cases:
- Supervised professional practice
- Specialty training programs
- Government positions

Level 4: Document Verified (95% Confidence)

Requirements:
- Original documents authenticated
- AI verification + human review
- Cross-reference with available records

Use Cases:
- Full professional recognition
- Senior positions
- Teaching/mentoring roles

3.8 Confidence Scoring

Confidence is calculated using multiple factors:

Confidence Formula

Base Confidence = Level Base Score
  Level 1: 30%
  Level 2: 60%
  Level 3: 80%
  Level 4: 95%

Bonuses:
  + Multiple peer verifications: +5% per additional peer (max +15%)
  + High assessment score: +5-10%
  + Consistent information across sources: +10%
  + Digital evidence (publications, etc.): +5%

Penalties:
  - Conflicting information: -10% per conflict
  - Old verification: -1% per year
  - Incomplete information: -5%

Final Confidence = Base + Bonuses - Penalties
  (Capped at 99% - never 100% certain)

Example Calculation

Dr. Ahmad - Medical Credential

Base (Level 2 - Peer Verified): 60%
+ 3 peer verifications (1 extra): +5%
+ Consistent dates across peers: +10%
+ Published research found online: +5%
- Verification 2 years old: -2%

Final Confidence: 78%

[OK] Eligible for supervised medical practice

3.10 Security and Privacy

Privacy Protection

  • Self-Custody - Holder controls their own data
  • Selective Disclosure - Share only what's needed
  • Zero-Knowledge Proofs - Verify without revealing details
  • Encryption - All data encrypted at rest and in transit

Security Features

Feature Implementation
Authentication DID-based with biometric binding
Encryption AES-256 (data), CRYSTALS-Kyber (transport)
Signatures CRYSTALS-Dilithium (quantum-resistant)
Audit Trail Immutable verification history

Chapter 1: Introduction to Refugee Credential

Hongik Ingan

"Benefit all humanity"

When nations fall, people's value does not fall. A surgeon remains a surgeon. A teacher remains a teacher. Their skills, knowledge, and experience are intrinsic - not dependent on paper documents.

1.1 What is WIA Refugee Credential?

The WIA Refugee Credential is an open standard for verifying and preserving the educational, professional, and personal credentials of displaced persons - even when original documentation is lost, destroyed, or inaccessible.

[REF] Key Principle: Nation-Independent Verification

Traditional credentials depend on institutions in the holder's country of origin. When that country is in conflict, under sanctions, or has collapsed, verification becomes impossible. WIA Refugee Credential provides alternative verification pathways.

Core Features

Feature Description
Multi-Level Verification 4 levels from self-declaration to document verification
Peer Verification Former colleagues/classmates verify claims
Competency Assessment Skills testing to validate abilities
Progressive Trust Confidence grows as more evidence accumulates
Privacy Preserving Zero-knowledge proofs for sensitive verification

1.5 The 4-Phase Architecture

Like all WIA standards, the Refugee Credential follows a 4-phase architecture:

Phase 1: Data Format Standard

Defines the structure of credential data:

RefugeeCredential
  - HolderIdentity (name, biometrics, DID)
  - EducationRecords[] (degrees, certifications)
  - CompetencyRecords[] (verified skills)
  - LanguageAbilities[] (proficiency levels)
  - WorkExperience[] (employment history)
  - VerificationInfo (level, confidence, evidence)

Phase 2: Algorithms

Core processing algorithms:

Algorithm Purpose
Confidence Calculation Aggregate evidence into confidence score
Peer Matching Find verifiers from same institution/workplace
Competency Assessment Domain-specific skills testing
Document Verification AI-powered authenticity checking

Phase 3: Communication Protocol

APIs for credential exchange:

  • REST API for CRUD operations
  • Verification request/response protocols
  • Peer network communication
  • Secure storage and retrieval

Phase 4: Ecosystem Integration

Connects to broader systems:

  • UNHCR databases
  • University admission systems
  • Employer HR platforms
  • Government immigration systems
  • Other WIA standards (INTENT, OMNI-API, AIR-SHIELD)

1.6 Verification Levels Explained

The standard defines 4 verification levels with associated confidence ranges:

Level Name Confidence Method
1 Self-Declaration 30% Holder's own statement
2 Peer Verified 60% Former colleagues/classmates confirm
3 Assessment Based 80% Competency testing demonstrates skills
4 Document Verified 95% Original documents authenticated

[OK] Key Innovation: Confidence can grow over time. A refugee might start at Level 1, find peers for Level 2, take assessments for Level 3, and eventually recover documents for Level 4.

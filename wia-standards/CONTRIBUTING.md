# Contributing to WIA Standards

Thank you for your interest in contributing to WIA Standards!

## How to Contribute

### 1. Pick a Standard

Choose a standard from the [README](./README.md) that interests you.

### 2. Read the Prompt

Each standard has prompts in `/{standard}/prompts/` directory:
- `PHASE-1-PROMPT.md` - Data Format
- `PHASE-2-PROMPT.md` - API Interface
- `PHASE-3-PROMPT.md` - Protocol
- `PHASE-4-PROMPT.md` - Integration

### 3. Research & Implement

Follow the prompts to:
1. Research existing technologies
2. Design the standard
3. Implement reference SDKs
4. Write documentation

### 4. Submit a Pull Request

1. Fork the repository
2. Create a branch: `git checkout -b feature/standard-name-phase-N`
3. Commit your changes
4. Push and create a PR

## Code Standards

- TypeScript for Node.js SDKs
- Python 3.10+ for Python SDKs
- Follow existing code patterns
- Include tests

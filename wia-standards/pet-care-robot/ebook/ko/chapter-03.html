스케줄 동작:

  - 모든 급식 이벤트 로그
  - 놓친 식사 알림

3.4 반려동물 인식

인식 방법

방법 정확도 요구사항 장단점
RFID 태그 99.9% 목걸이 태그 신뢰성 높음, 태그 분실 가능
마이크로칩 99.9% 이식된 칩 영구적, 짧은 범위
얼굴 인식 95-99% 카메라, 학습 반려동물에 장치 불필요, 조명 의존
체중 감지 90% 체중 패드 비침습적, 유사 체중 실패

3.5 다중 반려동물 관리

다중 반려동물 모드
=================

INDIVIDUAL 모드:
  - 각 반려동물별 설정
  - 반려동물별 접근 제어
  - 개별 일일 추적
  - 사료 뺏기 방지

SHARED 모드:
  - 공동 급식
  - 총 가정 한도
  - 개별 추적 없음
  - 간단한 설정

SEQUENTIAL 모드:
  - 한 번에 한 마리 급식
  - 급식 중 문 잠금
  - 공정한 접근 보장
  - 경쟁 방지

3.6 디스펜서 제어

디스펜서 알고리즘
================

1. 목표 분량 계산
   - 스케줄 또는 수동 요청 확인
   - 일일 잔여량 대비 확인
   - 조정 적용

2. 급식 전 확인
   - 그릇 존재 확인
   - 사료 잔량 충분 확인
   - 반려동물 감지 확인

3. 급식 루프
   WHILE 급식량 < 목표:
     - 소량 증분 방출 (5-10g)
     - 그릇 무게 측정
     - 막힘 확인
     - 급식량 업데이트

4. 급식 후
   - 실제 양 로그
   - 일일 총량 업데이트
   - 섭취 모니터링 시작

정확도 목표: 요청 분량의 +/- 5%

3.7 섭취 모니터링

지표 측정 방법 목적
섭취량 무게 차이 실제 섭취 추적
식사 시간 시작부터 종료까지 변화 감지
식사 속도 분당 그램 빠른 식사 식별
남은 양 그릇에 남은 양 식욕 지표
방문 패턴 여러 번 접근 조금씩 먹는 행동

제4장: 인터랙티브 놀이

"홍익인간: 놀이는 정신을 풍요롭게 하고 모든 존재 간의 유대를 강화합니다."

4.1 놀이 시스템 유형

유형 움직임 적합 종 참여도
LASER_POINTER 벽/바닥 투사 고양이 높음
ROLLING_BALL 바닥 이동 개, 고양이 중상
FEATHER_WAND 기계 팔 고양이 높음
TREAT_PUZZLE 고정 모두 중간
HIDE_AND_SEEK 이동 로봇 개 높음
CHASE_ROBOT 이동 추적 개 매우 높음

4.2 세션 관리

놀이 세션 생명주기
=================

1. 세션 시작
   - 반려동물 가용성 확인
   - 안전 조건 확인
   - 놀이 유형 초기화
   - 참여 추적 시작

2. 활성 놀이
   - 놀이 동작 생성
   - 반려동물 반응 모니터링
   - 참여에 적응
   - 에너지 수준 추적

3. 세션 모니터링
   - 참여 점수 측정
   - 피로 징후 감지
   - 강도 조정
   - 휴식 시간 제공

4. 세션 종료
   - 점진적 마무리
   - 선택적 간식 보상
   - 세션 데이터 로그
   - 선호도 업데이트

4.3 참여도 감지

참여 지표

지표 감지 방법 가중치
추적 움직임 추적 0.4
덮치기 동작 패턴 0.3
관찰 시선 감지 0.2
무시 반응 없음 -0.3
떠남 영역 이탈 -0.5 
참여 점수 계산
=============

engagement = 0.0

IF 반려동물이 추적 중:
    engagement += 0.4
IF 반려동물이 덮치기 중:
    engagement += 0.3
IF 반려동물이 관찰 중:
    engagement += 0.2
IF 반려동물이 휴식 중:
    engagement -= 0.3

engagement = max(0.0, min(1.0, engagement))

해석:
  0.7+ : 높은 참여 - 계속
  0.4-0.7: 중간 - 변화 고려
  0.2-0.4: 낮음 - 다른 패턴 시도
  <0.2: 매우 낮음 - 휴식 또는 종료

4.4 놀이 패턴

레이저 포인터 패턴

움직임 패턴
==========

ZIGZAG:
  빠른 교차 움직임
  먹이 도망 행동 모방
  높은 참여 가능성

CIRCLE:
  반려동물 주변 원형 경로
  예측 가능, 편안함
  워밍업에 좋음

ESCAPE:
  반려동물에서 빠르게 도망
  추적 본능 유발
  가끔 사용

STOP_START:
  멈춤, 그다음 빠른 움직임
  덮치기 반응 유발
  매우 참여적

NEAR_PET:
  관심 회복을 위해 가까이
  저에너지 패턴
  참여 하락 시 사용

DISAPPEAR_REAPPEAR:
  잠시 숨기고 근처에 나타남
  기대감 생성
  주의 리셋

4.5 AI 적응

학습 시스템
==========

반려동물 선호도 학습:
  - 패턴 성공률 추적
  - 최적 세션 시간 기록
  - 강도 선호도 파악
  - 피로 패턴 식별

행동 모델:
  +------------------------+
  |   패턴 시도            |
  +------------------------+
            |
            v
  +------------------------+
  |   반응 측정            |
  +------------------------+
            |
            v
  +------------------------+
  |   선호도 업데이트      |
  +------------------------+
            |
            v
  +------------------------+
  |   미래 놀이 조정       |
  +------------------------+

학습된 속성:
  - 좋아하는 놀이 유형
  - 최적 시간
  - 하루 중 가장 좋은 시간대
  - 휴식 간격 필요
  - 패턴 선호도

4.6 스케줄링

놀이 스케줄 구성
===============

스케줄 항목:
  time: "16:00"
  play_type: "LASER_POINTER"
  duration_minutes: 15
  intensity: "MEDIUM"
  days: ["월", "화", "수", "목", "금"]
  enabled: true

스케줄링 로직:
  - 예약 시간에 반려동물 존재 확인
  - 수면 중이면 연기
  - 최근 수동 세션 있으면 건너뜀
  - 활동 수준에 맞게 조정
  - 일일 한도 존중

4.7 안전 제한

제한 기본값 목적
최대 세션 시간 30분 과로 방지
일일 최대 세션 4 충분한 휴식
쿨다운 기간 60분 회복 시간
레이저 눈 안전 구역 반려동물 눈높이 제외 눈 보호
최대 로봇 속도 0.5 m/s 충돌 안전
비상 정지 항상 활성 즉시 정지

4.8 레이저 안전

레이저 안전 프로토콜
==================

하드웨어 요구사항:
  - Class 1 또는 2 레이저만 (<1mW)
  - 자동 차단 기능
  - 눈 안전 파장

소프트웨어 안전장치:
  - 눈높이 제외 구역 정의
  - 바닥 위로 투사 금지
  - 경로에 반려동물 얼굴 감지 시 비활성화
  - 자동 타임아웃 (연속 최대 30초)

구역 정의:
  +------------------+
  |  제외 구역       |  <- 50cm 이상
  |  (투사 금지)     |
  +------------------+
  |                  |
  |   안전 구역      |  <- 바닥에서 50cm
  |  (놀이 영역)     |
  |                  |
  +------------------+

4.9 간식 통합

간식 보상 시스템
===============

보상 트리거:

  - 퍼즐 완료
  - 훈련 성취
  - 세션 완료

급여 로직:

  - 참여를 위한 타이밍 변화
  - 선택적 소리 신호

간식 유형:
  - 작은 훈련 간식
  - 일일 분량의 사료
  - 특별 보상 간식

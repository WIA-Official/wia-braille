제2장: 로봇 유형 및 기능

"홍익인간: 각 로봇 유형은 반려동물 웰빙이라는 더 큰 사명에서 특정 목적을 수행합니다."

2.1 로봇 유형 개요

유형 이동성 주요 용도 복잡도
FEEDING_STATION 고정형 자동 급식 낮음
COMPANION_ROBOT 이동형 인터랙티브 존재 높음
MONITORING_STATION 고정형 환경 감지 낮음
PLAY_SYSTEM 다양 엔터테인먼트 중간
GROOMING_STATION 고정형 털 관리 중간
LITTER_MANAGER 고정형 배설물 처리 중간
MULTI_FUNCTION 다양 통합 높음

2.2 급식 스테이션

급식 스테이션 기능
=================

기본 기능:
  - 분량 조절 급식
  - 예약 급식 시간
  - 사료 잔량 모니터링
  - 그릇 존재 감지

고급 기능:
  - 반려동물 인식 (RFID/마이크로칩/얼굴)
  - 다중 반려동물 지원
  - 섭취량 추적
  - 체중 측정
  - 천천히 먹기 모드
  - 신선 사료 보관
  - 연결된 정수기

사양:
  용량: 건식 사료 2-10 kg
  정확도: +/- 5% 분량
  전원: AC + 배터리 백업
  소음: < 45 dB 작동

2.3 컴패니언 로봇

컴패니언 로봇 기능
=================

물리적:
  - 자율 네비게이션
  - 안전한 충돌 회피
  - 반려동물 친화적 외형
  - 안정적 이동

인터랙티브:
  - 양방향 오디오/비디오
  - 간식 급여
  - 놀이 부착물
  - 명령 반응

지능:
  - 반려동물 행동 학습
  - 루틴 적응
  - 감정 감지
  - 활동 추적

사양:
  배터리: 활성 4-8시간
  속도: 최대 0.3-0.5 m/s
  높이: 일반 20-40 cm
  무게: 2-5 kg

2.4 놀이 시스템

놀이 유형

유형 움직임 적합 안전 참고
레이저 포인터 벽/바닥 투사 고양이 눈 안전 구역 필요
롤링 볼 바닥 이동 개, 고양이 크기 적합
깃털 막대 기계 팔 고양이 대기 시 접힘
간식 퍼즐 고정 모두 난이도 조절
추적 로봇 이동 로봇 개 속도 제한

2.5 모니터링 스테이션

환경 센서
=========

기후:
  - 온도 (0.1 C 정확도)
  - 습도 (2% 정확도)
  - 기압

공기질:
  - 미세먼지 (PM2.5)
  - VOC 수준
  - CO2 농도
  - 암모니아 (화장실 구역)

활동:
  - 동작 감지
  - 소음 수준
  - 조도

선택:
  - 카메라 (로컬/클라우드)
  - 마이크
  - 체중 패드

2.6 화장실 관리기

화장실 관리기 기능
=================

기본:
  - 자동 배설물 분리
  - 사용 감지
  - 채움 수준 모니터링
  - 냄새 관리

고급:
  - 반려동물 식별
  - 방문 추적
  - 시간 모니터링
  - 건강 지표
  - 체중 측정

건강 인사이트:
  - 빈도 패턴
  - 시간 이상
  - 체중 변화
  - 잠재적 문제

사양:
  사이클 시간: 2-5분
  소음: < 50 dB
  폐기물 용량: 7-30일

2.8 다중 반려동물 지원

기능 구현 목적
반려동물 인식 RFID, 마이크로칩, 얼굴 개별 식별
개별 분량 반려동물별 설정 식이 관리
접근 제어 반려동물별 잠금/해제 사료 뺏기 방지
순차 급식 한 번에 한 마리 공정한 접근
활동 추적 반려동물별 지표 개별 모니터링

2.9 하드웨어 표준

재료 요구사항
============

반려동물 안전 재료:
  - 식품 등급 플라스틱 (BPA 무함유)
  - 스테인리스 스틸 (식품 접촉)
  - 무독성 코팅
  - 둥근 모서리

전기 안전:
  - 저전압 DC 작동
  - 전선 보호
  - 방수 (IPX4+)
  - 과전류 보호

기계 안전:
  - 끼임점 없음
  - 안정적 베이스
  - 분리 가능 부착물
  - 모터 토크 제한

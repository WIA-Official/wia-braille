6.1 로봇에서 수집하는 건강 지표

지표 출처 빈도 건강 통찰
체중 급식 스테이션 매 급식 체중 추세
식사 시간 급식 스테이션 매 급식 식욕 변화
섭취량 그릇 센서 매 급식 섭취 추적
물 섭취 급수 스테이션 매일 수분 상태
활동 수준 동작 센서 매시간 에너지 수준
수면 시간 활동 추적 매일 휴식 패턴
화장실 방문 화장실 관리기 매 방문 비뇨/소화 건강
놀이 참여도 놀이 시스템 매 세션 정신 상태

6.2 패턴 감지

건강 패턴 유형
=============

식사 패턴:
  REDUCED_APPETITE
    - 기준보다 적게 섭취
    - 질병 징후일 수 있음

  INCREASED_APPETITE
    - 평소보다 많이 섭취
    - 기생충, 당뇨 확인

  RAPID_EATING
    - 훨씬 빠른 섭취
    - 소화 문제 위험

  IRREGULAR_FEEDING
    - 일관성 없는 식사 시간
    - 스트레스 가능

물 패턴:
  INCREASED_THIRST
    - 더 많이 마심
    - 당뇨, 신장 가능

  REDUCED_WATER
    - 더 적게 마심
    - 탈수 위험

활동 패턴:
  LETHARGY
    - 움직임 감소
    - 다양한 원인

  RESTLESSNESS
    - 움직임 증가
    - 불안, 통증

화장실 패턴:
  FREQUENT_URINATION
    - 더 많은 방문
    - 요로감염, 당뇨

  PROLONGED_VISITS
    - 긴 시간
    - 변비, 폐색

6.3 기준선 수립

기준선 계산
==========

초기 기간: 14-30일
  - 모든 지표 수집
  - 평균 계산
  - 분산 결정
  - 정상 범위 수립

지표별:
  baseline = {
    mean: average(readings)
    std: standard_deviation(readings)
    min: minimum(readings)
    max: maximum(readings)
    typical_range: mean +/- (2 * std)
  }

기준선 업데이트:
  - 월별 재계산
  - 아픈 기간 제외
  - 나이 변화 고려
  - 계절 조정

6.4 알림 생성

알림 심각도 수준

수준 편차 조치 예시
INFO 약간의 변화 로그만 약간 빠른 식사
WARNING 중간 편차 보호자 알림 30% 식욕 감소
URGENT 상당한 변화 우선 알림 24시간 이상 금식 
알림 생성 로직
=============

FOR each 지표:
  current = recent_average(3_days)
  baseline = established_baseline

  deviation = abs(current - baseline.mean) / baseline.std

  IF deviation > 3.0:
    generate_alert(URGENT)
  ELSE IF deviation > 2.0:
    generate_alert(WARNING)
  ELSE IF deviation > 1.5:
    generate_alert(INFO)

고려사항:
  - 편차 지속 기간
  - 증상 조합
  - 시기
  - 최근 변화

6.5 체중 추적

체중 모니터링
============

측정:
  - 급식 스테이션에 내장
  - 식사 전 저울에 오름
  - 여러 측정 평균
  - 정확도: +/- 50g

추세 분석:
  - 일일 체중 기록
  - 7일 이동 평균
  - 월간 추세선
  - 목표 비교

체중 알림:
  주 +5%: INFO (모니터링)
  월 +10%: WARNING
  주 -5%: WARNING
  월 -10%: URGENT

표시:
  현재: 12.3 kg
  7일 평균: 12.2 kg
  30일 평균: 12.0 kg
  추세: +0.3 kg/월
  상태: [OK] 건강함

==================

    v              v                   v
[수집]        [처리]            [상관관계]
    |              |                   |
    +-------+------+------+------------+
            |             |
            v             v
       [보호자 앱]   [수의사 포털]

공유 데이터:
  - 체중 측정

  - 물 섭취

  - 수면 시간
  - 화장실 사용 (고양이)

동기화 빈도:
  실시간: 긴급 알림
  매시간: 일반 지표
  매일: 요약 및 추세

6.7 수의사 통합

기능 방향 목적
식이 처방 수의사 -> 로봇 급식 규칙 적용
건강 리포트 로봇 -> 수의사 지표 공유
투약 알림 수의사 -> 로봇 급식과 조정
알림 알림 로봇 -> 수의사 우려사항 공유
회복 모니터링 양방향 치료 후 추적

6.9 조기 경보 시스템

다중 증상 감지
=============

증상 조합:

가능한 요로감염 (고양이):
  + 빈번한 화장실 방문
  + 짧은 시간
  + 발성
  --> 수의사 방문 권장

가능한 소화 문제:
  + 식욕 감소
  + 불규칙한 식사 시간
  + 활동 감소
  --> 주의 깊게 모니터링, 지속 시 수의사

가능한 당뇨:
  + 갈증 증가
  + 배뇨 증가
  + 먹어도 체중 감소
  --> 긴급 수의사 권장

가능한 통증:
  + 활동 감소
  + 수면 변화
  + 식욕 변화
  + 놀이 참여 감소
  --> 수의사 평가 권장

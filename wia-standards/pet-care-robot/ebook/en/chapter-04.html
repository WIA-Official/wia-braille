4.3 Engagement Detection

Engagement Indicators

Indicator Detection Method Weight
Chasing Movement tracking 0.4
Pouncing Motion pattern 0.3
Watching Gaze detection 0.2
Ignoring No response -0.3
Leaving Exit area -0.5 
Engagement Score Calculation
============================

engagement = 0.0

IF pet is chasing:
    engagement += 0.4
IF pet is pouncing:
    engagement += 0.3
IF pet is watching:
    engagement += 0.2
IF pet is resting:
    engagement -= 0.3

engagement = max(0.0, min(1.0, engagement))

Interpretation:
  0.7+ : High engagement - continue
  0.4-0.7: Medium - consider variation
  0.2-0.4: Low - try different pattern
  <0.2: Very low - offer rest or end

4.4 Play Patterns

Laser Pointer Patterns

Movement Patterns
=================

ZIGZAG:
  Quick alternating movements
  Mimics prey escape behavior
  High engagement potential

CIRCLE:
  Circular path around pet
  Predictable, comfortable
  Good for warm-up

ESCAPE:
  Quick dart away from pet
  Triggers chase instinct
  Use sparingly

STOP_START:
  Pause, then quick movement
  Triggers pounce response
  Very engaging

NEAR_PET:
  Stay close to regain attention
  Low energy pattern
  Use when engagement drops

DISAPPEAR_REAPPEAR:
  Briefly hide, then appear nearby
  Creates anticipation
  Reset attention

4.8 Laser Safety

Laser Safety Protocol
=====================

Hardware Requirements:
  - Class 1 or 2 laser only (<1mW)
  - Automatic shutoff capability
  - Eye-safe wavelength

Software Safeguards:
  - Define eye-level exclusion zone
  - Never project above floor level
  - Disable if pet face detected in path
  - Automatic timeout (max 30 sec continuous)

Zone Definition:
  +------------------+
  |  EXCLUDED ZONE   |  <- Above 50cm
  |  (No projection) |
  +------------------+
  |                  |
  |   SAFE ZONE      |  <- Floor to 50cm
  |  (Play area)     |
  |                  |
  +------------------+

3.3 Scheduling

Schedule Configuration
======================

Schedule Entry:
  name: "Morning Meal"
  times:
    - hour: 7
      minute: 0
      flexibility: 15  # minutes
  portion_grams: 50
  days_of_week: [1,2,3,4,5,6,7]  # All days
  enabled: true

Schedule Behaviors:
  - Execute at scheduled time
  - Wait for pet presence (optional)
  - Skip if daily limit reached
  - Log all dispensing events
  - Alert on missed meals

3.5 Multi-Pet Management

Multi-Pet Modes
===============

INDIVIDUAL Mode:
  - Each pet has own settings
  - Access control per pet
  - Individual daily tracking
  - Prevents food stealing

SHARED Mode:
  - Communal feeding
  - Total household limit
  - No individual tracking
  - Simple setup

SEQUENTIAL Mode:
  - One pet feeds at a time
  - Door locks during feeding
  - Fair access ensured
  - Prevents competition

3.6 Dispensing Control

Dispenser Algorithm
===================

1. Calculate target portion
   - Check schedule or manual request
   - Verify against daily remaining
   - Apply any adjustments

2. Pre-dispense checks
   - Verify bowl is present
   - Check food level sufficient
   - Confirm pet detected

3. Dispense loop
   WHILE dispensed < target:
     - Release small increment (5-10g)
     - Weigh bowl
     - Check for jam
     - Update dispensed total

4. Post-dispense
   - Log actual amount
   - Update daily total
   - Start consumption monitoring

Accuracy Target: +/- 5% of requested portion

====================

System Behavior:
  - Override normal portions
  - Enforce strict limits
  - Medication reminders
  - Compliance logging
  - Vet notification option

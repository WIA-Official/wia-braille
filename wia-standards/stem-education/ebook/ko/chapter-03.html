📊 제3장: 데이터 형식

홍익인간 (弘益人間)

"표준화된 데이터는 지식의 자유로운 흐름을 가능하게 한다"

WIA STEM 교육 표준은 JSON 기반의 명확하고 확장 가능한 데이터 스키마를 제공하여 전 세계 교육 플랫폼 간 상호 운용성을 보장합니다.

3.1.2 역량 레벨 정의

레벨 점수 범위 설명
novice 0-59 기초 개념 학습 중
developing 60-74 기본 기술 습득, 지원 필요
proficient 75-89 독립적 수행 가능
advanced 90-100 전문가 수준, 타인 지도 가능

3.6 데이터 검증 및 품질

3.6.1 JSON Schema 검증

모든 데이터는 JSON Schema로 검증되어 일관성을 보장합니다.

데이터 품질 원칙:

  • 완전성: 필수 필드 모두 포함
  • 정확성: 타입 및 형식 준수
  • 일관성: 참조 무결성 유지
  • 시의성: 타임스탬프 정확히 기록
  • 유일성: ID 충돌 방지

3.6.2 데이터 버전 관리

스키마 버전 변경 사항 호환성
1.0.0 초기 릴리스 -
1.1.0 AI 추천 필드 추가 하위 호환
1.2.0 배지 시스템 확장 하위 호환
2.0.0 평가 구조 재설계 비호환 (마이그레이션 필요)

3.7 장 요약

핵심 내용:

  1. 학습자 프로필: 개인정보, 선호도, 역량, 성취도 포함
  2. 커리큘럼 스키마: 학습 목표, 모듈, 활동, 평가 방법 정의
  3. 프로젝트 스키마: 팀 구성, 기술 스펙, 단계별 진행 상황 추적
  4. 평가 및 배지: 루브릭 기반 평가, Open Badges 2.0 준수
  5. 학습 분석: xAPI 표준 사용하여 모든 학습 활동 기록
  6. JSON Schema로 데이터 품질 검증, 시맨틱 버저닝으로 버전 관리

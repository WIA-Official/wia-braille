🔌 제4장: API 명세

홍익인간 (弘益人間)

"개방형 API는 혁신의 문을 열고 협력을 가능하게 한다"

WIA STEM 교육 플랫폼은 RESTful API와 GraphQL을 제공하여 전 세계 개발자가 교육 애플리케이션을 쉽게 구축할 수 있도록 합니다.

4.1 API 개요

4.1.1 엔드포인트 구조

Base URL: https://api.wia.org/edu/v1

인증: OAuth 2.0 Bearer Token

응답 형식: JSON

속도 제한: 1,000 요청/시간 (일반), 10,000 요청/시간 (프리미엄)

4.1.2 HTTP 상태 코드

코드 의미 설명
200 OK 요청 성공
201 Created 리소스 생성 성공
400 Bad Request 잘못된 요청 형식
401 Unauthorized 인증 실패
403 Forbidden 권한 없음
404 Not Found 리소스 없음
429 Too Many Requests 속도 제한 초과
500 Internal Server Error 서버 오류

4.2 인증 및 권한

4.2.1 OAuth 2.0 인증 흐름

// 1. 액세스 토큰 획득
POST https://auth.wia.org/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
&scope=read:learners write:projects

// 응답
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "read:learners write:projects"
}

// 2. API 호출 시 토큰 사용
GET https://api.wia.org/edu/v1/learners/L123
Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...

4.2.2 권한 스코프

스코프 설명
read:learners 학습자 프로필 읽기
write:learners 학습자 프로필 수정
read:curriculum 커리큘럼 조회
write:curriculum 커리큘럼 생성/수정
read:projects 프로젝트 조회
write:projects 프로젝트 생성/수정
read:assessments 평가 결과 조회
write:assessments 평가 제출
admin 모든 권한

4.8 TypeScript SDK

4.8.1 SDK 설치 및 초기화

// 설치
npm install @wia/edu-sdk

// 초기화
import { WIAEducationSDK } from '@wia/edu-sdk';

const sdk = new WIAEducationSDK({
  apiKey: process.env.WIA_API_KEY,
  baseUrl: 'https://api.wia.org/edu/v1'
});

// 학습자 조회
const learner = await sdk.learners.get('L123');
console.log(learner.name); // "김지수"

// 프로젝트 생성
const project = await sdk.projects.create({
  title: '스마트 온실',
  curriculum_ref: 'CURR-030',
  team: {
    leader: 'L123',
    members: ['L456']
  }
});

// 커리큘럼 검색
const results = await sdk.curriculum.search({
  query: 'robotics',
  gradeLevel: '9-12',
  domain: 'engineering'
});

results.forEach(curr => {
  console.log(`${curr.title} - ${curr.rating}⭐`);
});

4.8.2 Python SDK

# 설치
pip install wia-edu-sdk

# 사용
from wia_edu import WIAEducationClient

client = WIAEducationClient(api_key=os.getenv('WIA_API_KEY'))

# 학습자 프로필 가져오기
learner = client.learners.get('L123')
print(f"{learner.name}: {learner.competencies.computational_thinking}/100")

# 평가 제출
assessment = client.assessments.create(
    project_id='PROJ-001',
    assessor_id='TEACHER-001',
    rubric={
        'criteria': [
            {'name': '과학적 탐구', 'score': 85},
            {'name': '공학적 설계', 'score': 90}
        ]
    }
)

print(f"Overall score: {assessment.overall_score}")

4.9 웹훅 (Webhooks)

4.9.1 이벤트 구독

지원 이벤트:

  • learner.created - 새 학습자 등록
  • project.completed - 프로젝트 완료
  • assessment.submitted - 평가 제출
  • badge.earned - 배지 획득
  • competency.level_up - 역량 레벨업
// 웹훅 등록
POST /webhooks
{
  "url": "https://myapp.com/wia-webhook",
  "events": ["project.completed", "badge.earned"],
  "secret": "webhook_secret_key"
}

// 웹훅 페이로드 (project.completed)
POST https://myapp.com/wia-webhook
X-WIA-Signature: sha256=abc123...
Content-Type: application/json

{
  "event": "project.completed",
  "timestamp": "2025-03-15T16:30:00Z",
  "data": {
    "project_id": "PROJ-001",
    "title": "스마트 쓰레기통",
    "team_leader": "L123",
    "completion_date": "2025-03-15",
    "final_score": 87.5
  }
}

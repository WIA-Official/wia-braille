🔒 제6장: 보안 및 프라이버시

홍익인간 (弘益人間)

"신뢰는 보안에서 시작된다"

WIA STEM 교육 플랫폼은 학생 데이터를 최우선으로 보호하며, FERPA, COPPA, GDPR 등 국제 규정을 준수합니다.

6.1 학생 데이터 보호 원칙

6.1.1 핵심 보호 원칙

7대 데이터 보호 원칙:

  1. 최소 수집: 교육 목적에 필요한 최소한의 정보만 수집
  2. 목적 제한: 수집된 데이터는 명시된 목적으로만 사용
  3. 투명성: 데이터 수집 및 사용에 대한 명확한 고지
  4. 동의: 미성년자의 경우 보호자 동의 필수
  5. 안전한 저장: 암호화 및 접근 제어
  6. 제한된 보관: 필요 기간 경과 후 자동 삭제
  7. 학생 권리: 열람, 수정, 삭제 요청권 보장

6.1.2 규제 준수

규정 적용 대상 주요 요구사항
FERPA 미국 교육 기관 학생 교육 기록 보호, 부모 접근권
COPPA 13세 미만 아동 (미국) 부모 동의, 데이터 수집 제한
GDPR EU 거주자 명시적 동의, 잊힐 권리, DPIA
개인정보보호법 한국 개인정보 처리 방침, 안전성 확보 조치
아동법 한국 18세 미만 법정대리인 동의

6.2.2 다중 요소 인증 (MFA)

MFA 구현:

  • 요소 1 (지식): 비밀번호 (최소 8자, 영문+숫자+특수문자)
  • 요소 2 (소유): SMS OTP, 이메일 코드, 또는 인증 앱 (Google Authenticator)
  • 요소 3 (속성): 생체 인증 (지문, 얼굴 인식) - 선택사항

적용 대상: 교사, 관리자는 MFA 필수. 학생은 권장.

6.3.2 저장 중 암호화

데이터 유형 암호화 방식 키 관리
비밀번호 bcrypt (salt rounds=12) -
개인 식별 정보 (PII) AES-256-GCM AWS KMS
학생 평가 결과 AES-256-GCM AWS KMS
데이터베이스 Transparent Data Encryption (TDE) PostgreSQL
백업 파일 AES-256 S3 Server-Side Encryption

6.3.3 암호화 키 관리

// AWS KMS를 사용한 키 관리
import { KMSClient, EncryptCommand, DecryptCommand } from "@aws-sdk/client-kms";

const kmsClient = new KMSClient({ region: "us-east-1" });

// 데이터 암호화
async function encryptData(plaintext: string): Promise {
  const command = new EncryptCommand({
    KeyId: process.env.KMS_KEY_ID,
    Plaintext: Buffer.from(plaintext, 'utf-8')
  });

  const { CiphertextBlob } = await kmsClient.send(command);
  return CiphertextBlob!.toString('base64');
}

// 데이터 복호화
async function decryptData(ciphertext: string): Promise {
  const command = new DecryptCommand({
    CiphertextBlob: Buffer.from(ciphertext, 'base64')
  });

  const { Plaintext } = await kmsClient.send(command);
  return Plaintext!.toString('utf-8');
}

6.4 네트워크 보안

6.4.1 방화벽 및 DDoS 방어

다층 방어 아키텍처:

  • Layer 7 (애플리케이션): WAF (Web Application Firewall) - AWS WAF, Cloudflare
  • Layer 4 (전송): 네트워크 방화벽, Security Groups
  • Layer 3 (네트워크): VPC, 서브넷 격리
  • DDoS 방어: AWS Shield, Rate Limiting (API Gateway)

6.4.2 API 보안

// API 속도 제한 (Rate Limiting)
import rateLimit from 'express-rate-limit';

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15분
  max: 100, // 최대 100 요청
  message: '너무 많은 요청을 보냈습니다. 잠시 후 다시 시도하세요.',
  standardHeaders: true,
  legacyHeaders: false,
});

app.use('/api/', limiter);

// IP 기반 차단 목록
const blockedIPs = new Set(['192.168.1.100']);

app.use((req, res, next) => {
  const clientIP = req.ip;
  if (blockedIPs.has(clientIP)) {
    return res.status(403).json({ error: 'Forbidden' });
  }
  next();
});

6.6.2 데이터 침해 통지

침해 발생 시 통지 의무:

  • GDPR: 침해 인지 후 72시간 내 감독 기관에 통지
  • 한국 개인정보보호법: 5일 이내 개인정보보호위원회 및 피해자에게 통지
  • 통지 내용: 침해 유형, 영향 받은 데이터, 취한 조치, 연락처

// 데이터 익명화 예시
function anonymizeData(studentData) {
  return {
    // 식별자 제거
    // learner_id: studentData.learner_id,  // 제거
    // name: studentData.name,              // 제거

    // 일반화
    age_group: getAgeGroup(studentData.age),  // "15세" → "15-17세"

6.7.2 차등 프라이버시 (Differential Privacy)

차등 프라이버시 적용:

  • 학급 평균 점수 공개 시 노이즈 추가
  • 개별 학생 데이터 역추적 불가능
  • 통계적 유용성 유지하면서 프라이버시 보호
  • ε(epsilon) 값: 1.0 이하 권장 (낮을수록 강한 프라이버시)

6.8.1 GDPR 하의 데이터 주체 권리

6.9 장 요약

핵심 내용:

  1. 7대 데이터 보호 원칙: 최소 수집, 목적 제한, 투명성, 동의, 안전 저장, 제한 보관, 권리 보장
  2. 규제 준수: FERPA, COPPA, GDPR, 한국 개인정보보호법
  3. 다층 인증: 역할 기반 접근 제어(RBAC), MFA 구현
  4. 암호화: TLS 1.3 (전송), AES-256 (저장), bcrypt (비밀번호)
  5. 보안 감사: 의존성 스캔(매일), 침투 테스트(분기), OWASP Top 10 대응
  6. 프라이버시: 익명화, 가명화, 차등 프라이버시 적용

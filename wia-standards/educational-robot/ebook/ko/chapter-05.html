챕터 5: 2단계 - API 인터페이스

5.1 RESTful 설계

WIA-EDU-007 API는 직관적이고 확장 가능한 통합을 위해 RESTful 원칙을 따릅니다.

핵심 엔드포인트

엔드포인트 메서드 목적
/robots/{id} GET 로봇 프로필 검색
/sessions POST 학습 세션 생성
/students/{id}/progress GET 학생 진도 확인
/curriculum/{subject} GET 수업 계획 목록

5.2 인증

OAuth 2.0 + 분산 식별자(DID)는 안전하고 개인정보 보호 인증을 제공합니다.

5.3 속도 제한

등급 요청/분 요청/일
무료 60 10,000
교육 600 100,000
기업 6,000 1,000,000

5.4 웹훅

실시간 이벤트 알림은 반응형 통합을 가능하게 합니다:

  • session.completed - 학습 세션 종료
  • achievement.earned - 학생이 자격증명 획득
  • alert.safety - 안전 문제 감지
  • consent.expired - 부모 동의 갱신 필요

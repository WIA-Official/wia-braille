Phase 1: 데이터 형식

WIA-ART-001 - 파일 형식과 메타데이터 명세

4.1 데이터 형식 개요

Phase 1은 WIA-ART-001 표준의 기초입니다. 이 단계에서는 디지털 아트 파일의 구조, 지원 형식, 메타데이터 스키마, 그리고 색상 관리 규칙을 정의합니다.

🎯 Phase 1의 목표
  • 표준화된 파일 형식 지원
  • 일관된 메타데이터 스키마
  • 정확한 색상 재현
  • 장기 보존을 위한 아카이브 형식

4.2 지원 파일 형식

4.2.1 래스터 이미지

형식MIME 타입비트 깊이알파용도
PNGimage/png8/16비트지원웹, 아카이브
JPEGimage/jpeg8비트미지원웹, 공유
TIFFimage/tiff8/16/32비트지원아카이브, 인쇄
WebPimage/webp8비트지원웹 최적화

4.2.2 PNG 상세 명세

PNG 요구사항:
├── 비트 깊이
│   ├── 아카이브: 16비트 필수
│   ├── 전문가: 16비트 권장, 8비트 허용
│   └── 웹: 8비트
├── 압축
│   ├── 레벨 6-9 권장
│   └── 무손실 압축만 사용
├── 색 공간
│   ├── sRGB, Adobe RGB, ProPhoto RGB, Display P3
│   └── ICC 프로파일 포함 필수 (아카이브)
└── 메타데이터
    ├── tEXt 청크: 기본 정보
    ├── iTXt 청크: 국제 텍스트
    └── eXIf 청크: EXIF 데이터

4.2.3 JPEG 상세 명세

JPEG 요구사항:
├── 품질
│   ├── 전문가: 90-100%
│   ├── 웹: 75-85%
│   └── 미리보기: 60-70%
├── 샘플링
│   ├── 4:4:4 (전문가)
│   └── 4:2:0 (웹)
├── 프로파일
│   ├── 표준 JPEG (베이스라인)
│   └── 프로그레시브 권장 (웹)
└── 메타데이터
    ├── EXIF: 촬영/생성 정보
    ├── IPTC: 저작권, 설명
    └── XMP: 확장 메타데이터

4.2.4 TIFF 상세 명세

TIFF 요구사항:
├── 비트 깊이
│   ├── 16비트 정수 (표준)
│   └── 32비트 부동소수점 (HDR)
├── 압축
│   ├── 무압축 (아카이브)
│   ├── LZW (일반)
│   └── ZIP (권장)
├── 색 모드
│   ├── RGB
│   ├── CMYK (인쇄용)
│   └── Lab
└── 레이어
    └── 멀티페이지 TIFF 지원

4.4 색상 관리

4.4.1 지원 색 공간

Adobe RGB50%2.2인쇄, 전문가

Display P345%≈2.2최신 디스플레이

4.4.2 ICC 프로파일 처리

ICC 프로파일 규칙:
1. 아카이브 품질
   - ICC 프로파일 포함 필수
   - 원본 프로파일 보존

2. 전문가 품질
   - ICC 프로파일 포함 권장
   - 변환 시 상대 색도계 사용

3. 웹 품질
   - sRGB로 변환
   - sRGB 프로파일 포함 선택적

4. 변환 우선순위
   - 상대 색도계 (기본값)
   - 지각적 (사진/연속 톤)
   - 채도 (그래픽/로고)

4.4.3 색 공간 변환

// 색 공간 변환 예시 (Node.js + Sharp)
import sharp from 'sharp';

async function convertToSRGB(inputBuffer) {
  return await sharp(inputBuffer)
    .toColorspace('srgb')
    .withMetadata({
      icc: 'srgb'  // sRGB 프로파일 포함
    })
    .toBuffer();
}

// 원본 프로파일 보존 변환
async function convertWithProfile(input, targetProfile) {
  const image = sharp(input);
  const metadata = await image.metadata();
  
  // 원본 ICC 프로파일 추출
  const sourceProfile = metadata.icc;
  
  return image
    .withMetadata({
      icc: targetProfile,
      exif: metadata.exif  // EXIF 보존
    })
    .toBuffer();
}

4.5 검증 규칙

4.5.1 파일 검증

파일 검증 체크리스트:
□ 지원 형식 확인 (PNG, JPEG, TIFF, WebP)
□ 파일 크기 제한 (최대 2GB)
□ 매직 바이트 확인 (파일 서명)
□ 손상 여부 확인 (디코딩 테스트)
□ 해상도 확인 (최소 100x100, 최대 65535x65535)
□ 비트 깊이 확인 (형식별 요구사항)

4.7 장 요약

✅ 핵심 정리
  • PNG, JPEG, TIFF, WebP 형식 지원
  • 메타데이터 스키마: 필수(title, creator, colorSpace), 권장, 선택 필드
  • 4가지 색 공간: sRGB, Adobe RGB, ProPhoto RGB, Display P3
  • 품질 등급별 요구사항 차등 적용
  • 파일 및 메타데이터 검증 규칙 준수 필수

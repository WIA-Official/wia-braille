표준 개요

WIA-ART-001 - 아키텍처와 구성 요소

3.1 WIA-ART-001 개요

WIA-ART-001은 디지털 아트의 생성, 저장, 전송, 표시를 위한 포괄적인 표준입니다. 이 표준은 4개의 단계(Phase)로 구성되며, 각 단계는 이전 단계를 기반으로 구축됩니다.

📋 표준의 범위

WIA-ART-001은 다음을 정의합니다:

  • 디지털 아트 파일의 구조와 메타데이터
  • 프로그래밍 인터페이스(API)
  • 시스템 간 통신 프로토콜
  • 외부 플랫폼과의 통합 방법

3.1.1 설계 원칙

원칙설명적용
단순성복잡성 최소화명확한 API, 직관적인 스키마
확장성미래 요구사항 수용버전 관리, 확장 필드
호환성기존 시스템과 연동표준 형식, REST API
보안성데이터 보호암호화, 서명, 인증
접근성누구나 사용 가능오픈 소스, 무료 SDK

3.2 4단계 구조

1
데이터 형식 (Data Format)

디지털 아트의 기본 구조를 정의합니다. 지원 파일 형식, 메타데이터 스키마, 색상 관리 규칙이 포함됩니다.

  • 지원 형식: PNG, JPEG, TIFF, WebP, SVG, PSD
  • 메타데이터: JSON 스키마 기반 구조화된 데이터
  • 색상: ICC 프로파일, 색 공간 변환 규칙
2
API 인터페이스 (API Interface)

개발자가 표준과 상호작용할 수 있는 프로그래밍 인터페이스를 제공합니다.

  • REST API: CRUD 작업, 검증, 내보내기
  • SDK: TypeScript, Python, Swift, Kotlin
  • 인증: API 키, OAuth 2.0, JWT
3
프로토콜 (Protocol)

시스템 간 실시간 통신을 위한 규약입니다.

  • 메시지 형식: JSON 기반 표준 구조
  • 전송: WebSocket, SSE, Webhook
  • 보안: TLS, 메시지 서명, 재시도 로직
4
통합 (Integration)

외부 플랫폼 및 WIA 에코시스템과의 연동 방법입니다.

  • 플랫폼: 웹, 모바일, 데스크톱 애플리케이션
  • WIA 에코시스템: INTENT, OMNI-API, BLOCKCHAIN
  • 서드파티: Adobe, Procreate, OpenSea 등

3.3.2 품질 등급

등급용도사양
Archival (아카이브)장기 보존, 원본16비트, 무손실, ICC 프로파일 포함
Professional (전문가)인쇄, 고품질 디스플레이16비트, 고품질 압축
Web (웹)웹 표시8비트 sRGB, 최적화 압축
Preview (미리보기)빠른 로딩, 썸네일작은 크기, 높은 압축

3.3.3 메타데이터 카테고리

  • 필수 메타데이터: title, creator.name, colorSpace
  • 권장 메타데이터: description, creationDate, keywords, license
  • 선택 메타데이터: dimensions, medium, provenance
  • 확장 메타데이터: 사용자 정의 필드 (x- 접두사)

3.4 표준 워크플로우

3.4.1 작품 생성 플로우

1. 아티스트가 작품 생성
   ↓
2. 메타데이터 입력 (SDK/API 사용)
   ↓
3. 파일 검증 (형식, 색 공간, 비트 깊이)
   ↓
4. 파생본 생성 (웹용, 썸네일)
   ↓
5. 스토리지 업로드 (해시 생성)
   ↓
6. 출처 이벤트 기록
   ↓
7. 완료 (아트워크 ID 발급)

3.4.2 검증 플로우

입력 데이터
   ↓

   ↓

│ 2. 파일 검증                │
│    - 형식 지원 여부         │

│    - 크기 제한 확인         │
└─────────────────────────────┘
   ↓

│ 3. 색상 검증                │
│    - 색 공간 감지           │

3.5 버전 관리

WIA-ART-001은 시맨틱 버저닝(Semantic Versioning)을 따릅니다.

3.5.1 버전 형식

MAJOR.MINOR.PATCH

예시: 1.2.3
- MAJOR (1): 하위 호환성 없는 변경
- MINOR (2): 하위 호환 가능한 기능 추가
- PATCH (3): 버그 수정

3.5.2 버전 호환성

버전 변경호환성예시
1.0 → 1.1완전 호환새 선택 필드 추가
1.1 → 1.2완전 호환새 API 엔드포인트
1.x → 2.0마이그레이션 필요스키마 구조 변경

3.6 장 요약

✅ 핵심 정리
  • WIA-ART-001은 4단계(Phase) 구조로 구성됩니다
  • 각 단계는 데이터 형식, API, 프로토콜, 통합을 다룹니다
  • 아트워크 객체는 메타데이터, 콘텐츠, 출처 정보를 포함합니다
  • 4가지 품질 등급이 다양한 용도를 지원합니다
  • 시맨틱 버저닝으로 호환성을 보장합니다

Computer-Generated Holography

Exploring the creation of holograms through pure computation—calculating interference patterns digitally and fabricating them without physical objects.

Introduction to CGH

Computer-Generated Holography (CGH) represents a paradigm shift from traditional holography: instead of recording interference patterns from real objects using lasers, we calculate these patterns entirely through digital computation. This opens remarkable possibilities—creating holograms of virtual objects that never existed, mathematical surfaces, perfect optical elements, or objects impossible to illuminate coherently.

The concept originated in the 1960s when A.W. Lohmann and D.P. Paris first proposed computing hologram patterns digitally. While early CGH required mainframe computers and produced tiny, low-resolution holograms, modern computing power enables calculating high-resolution holograms of complex 3D scenes in reasonable timeframes. Today, CGH is essential for holographic optical elements (HOE), diffractive optics, optical testing, and emerging holographic displays.

Fundamental Principles

Wavefront Calculation

The core of CGH is calculating the complex wavefront at the hologram plane from a virtual object. For a point source at position (x₀, y₀, z₀), the spherical wavefront at the hologram plane (x, y, 0) is:

O(x,y) = (A / r) × exp(ikr)

Where:

  • A = amplitude (brightness of point)
  • r = √[(x-x₀)² + (y-y₀)² + z₀²] = distance from point to hologram pixel
  • k = 2π/λ = wave number
  • λ = wavelength of light

For objects composed of multiple points, we use superposition—sum the contributions from all N points:

O(x,y) = Σᵢ₌₁ᴺ (Aᵢ / rᵢ) × exp(ikrᵢ)

Interference Pattern Generation

Once we have the object wavefront O(x,y), we interfere it with a reference wave R (typically a plane wave or spherical wave):

I(x,y) = |R + O(x,y)|²
I(x,y) = |R|² + |O|² + R*O + RO*

The terms R*O and RO* contain the holographic information. For a plane wave reference with angle θ:

R(x,y) = exp(i × kx × x) where kx = k×sin(θ) 
// Example: CGH Point Source Calculation (Python-like pseudocode)
def calculate_cgh(points, hologram_size, wavelength):
    M = hologram_size  # e.g., 1024x1024
    k = 2 * pi / wavelength
    hologram = zeros(M, M, complex)

    for each point (x0, y0, z0, A) in points:
        for x in range(M):
            for y in range(M):
                # Distance from point to hologram pixel
                r = sqrt((x-x0)**2 + (y-y0)**2 + z0**2)
                # Add spherical wave contribution
                hologram[x,y] += (A / r) * exp(1j * k * r)

    # Interfere with reference wave
    reference = exp(1j * kx * x_array)
    intensity = abs(reference + hologram)**2

    return intensity

CGH Computation Methods

Different algorithms trade off between speed, memory, and quality. The choice depends on object complexity, hologram resolution, and available computational resources.

Point-Source Method

The most straightforward approach: represent the object as a cloud of point sources and directly calculate their contributions.

Aspect Characteristics
Computational Complexity O(N × M²) where N = object points, M = hologram resolution
Memory Requirements Moderate: Store point cloud + hologram array
Image Quality Excellent: Direct physical simulation
Parallelization Highly parallel (each pixel independent)
Best For Sparse objects, particle clouds, wireframes
Limitations Slow for large N; doesn't handle occlusion well

Layer-Based Method

A faster approach for many scenarios: decompose the 3D scene into a stack of 2D layers at different depths, then propagate each layer to the hologram plane using 2D FFT.

O(x,y,z) = Σₙ On(x,y) × δ(z - zn)

Each layer is propagated using Fresnel diffraction (computed via FFT), and the results are summed. This reduces 3D computation to multiple 2D operations.

Aspect Performance
Complexity O(L × M² log M) where L = number of layers
Speed Fast: 10-100× faster than point-source for typical scenes
Memory Higher: Need to store L layers of M×M images
Quality Good for layered scenes; artifacts for oblique surfaces
Parallelization Excellent: FFT libraries highly optimized (GPU/multi-core)
Best For Flat objects, depth maps, multi-plane displays

Gerchberg-Saxton Algorithm

An iterative phase-retrieval method particularly useful for creating phase-only holograms (common in practical CGH since phase modulation is often easier to implement than amplitude modulation).

Gerchberg-Saxton Iteration

Iteration loop:

1. Hologram Plane           2. Propagate (FFT)        3. Object Plane
   ┌──────────┐                                          ┌──────────┐
   │ Uniform  │            ──────────→                   │ Replace  │
   │ Amplitude│                                          │ Amplitude│
   │ + Phase φ│                                          │ Keep φ'  │
   └──────────┘                                          └──────────┘
        ↑                                                      │
        │                                                      │
        │              4. Propagate back (FFT⁻¹)              │
        └──────────────────────────────────────────────────────┘

Repeat until convergence (typically 10-100 iterations)

At each iteration:

  1. Start with phase pattern at hologram plane (uniform amplitude)
  2. Propagate to object plane via FFT
  3. Replace amplitude with target image, keep phase
  4. Propagate back to hologram plane
  5. Replace amplitude with uniform (or desired distribution), keep phase
  6. Check convergence; if not converged, repeat
// Gerchberg-Saxton Algorithm (simplified pseudocode)
function gerchberg_saxton(target_amplitude, iterations):
    # Initialize with random phase
    hologram_phase = random_phase(size)

    for i = 1 to iterations:
        # 1. Hologram plane: uniform amplitude + current phase
        hologram = exp(1j * hologram_phase)

        # 2. Propagate to object plane
        object_field = FFT(hologram)

        # 3. Replace amplitude with target, keep phase
        object_phase = angle(object_field)
        object_field = target_amplitude * exp(1j * object_phase)

        # 4. Propagate back to hologram plane
        hologram_field = IFFT(object_field)

        # 5. Extract phase (keep for next iteration)
        hologram_phase = angle(hologram_field)

        # Check convergence
        error = RMS(abs(object_field) - target_amplitude)
        if error < threshold:
            break

    return hologram_phase

Fabrication Methods

Once the hologram pattern is calculated digitally, it must be physically fabricated. Different methods suit different resolutions, materials, and production volumes.

E-beam Lithography

Electron-beam lithography provides the ultimate resolution but is slow and expensive.

  • Resolution: Sub-10 nm features possible (well below optical wavelength)
  • Process: Focused electron beam scans across photoresist, exposing pattern pixel-by-pixel
  • Material: Electron-sensitive resist (PMMA, HSQ, etc.)
  • Speed: Very slow—hours to days for cm² areas
  • Cost: Extremely high (equipment >$1M, clean room required)
  • Applications: Research, master patterns, ultra-high-resolution HOE

Laser Direct Writing

A focused laser beam exposes photosensitive material point-by-point or line-by-line, offering a good balance of resolution and speed.

Parameter Typical Values Notes
Resolution 0.5 - 2 μm Limited by diffraction (spot size ≈ λ/NA)
Writing Speed 1-100 mm²/hour Depends on resolution and laser power
Materials Photopolymer, photoresist, silver halide Must be photosensitive at laser wavelength
Laser Types UV (355nm), Blue (405nm), Green (532nm) Shorter λ → better resolution
Cost Moderate ($50k-$500k systems) No clean room; lab environment sufficient
Applications Prototyping, HOE production, custom optics Medium-volume production

Binary and Multi-Level CGH

Continuous-tone holograms are difficult to fabricate. Most CGH uses binary (2-level) or multi-level (4, 8, 16 levels) quantization.

Type Levels Efficiency Fabrication Cost
Binary 2 10-40% Single step Lowest
4-level 4 60-70% 2 aligned steps Medium
8-level 8 80-90% 3 aligned steps High
Grayscale 64-256 >95% Grayscale mask + etch Very high

Applications of CGH

Holographic Optical Elements (HOE)

CGH enables creating custom optical elements that would be impossible or impractical with conventional optics:

  • Aspheric lenses: Perfectly calculated wavefront corrections
  • Beam shapers: Transform Gaussian to flat-top or custom profiles
  • Diffractive combiners: Overlay multiple images (AR glasses)
  • Wavelength filters: Separate/combine specific wavelengths
  • Aberration correctors: Compensate known optical aberrations

Optical Testing

CGH null elements enable testing of aspheric and freeform optics:

  • Design CGH to produce ideal wavefront for specific optical surface
  • Interfere CGH output with light reflected from test surface
  • Fringes reveal deviations from ideal (null test = no fringes)
  • Enables testing of complex surfaces (telescope mirrors, camera lenses)

Real-World Example: James Webb Space Telescope

The James Webb Space Telescope's 6.5-meter primary mirror consists of 18 hexagonal segments, each with a complex aspheric surface. Testing these segments required custom CGH null elements designed specifically for each segment's prescription. Without CGH, testing would have been prohibitively difficult and expensive.

Security and Anti-Counterfeiting

CGH can create unique, hard-to-replicate security features:

  • Microtext holograms (sub-100μm features)
  • Hidden images (visible only at specific angles/wavelengths)
  • Covert features (UV or IR reconstruction)
  • Mathematically defined patterns (impossible to photograph)

Holographic Displays

Modern holographic display research relies heavily on real-time CGH computation. For a 4K hologram (4096×4096 pixels) at 30 fps with 100,000 object points:

Operations ≈ 4096² × 100k × 30 fps ≈ 5 × 10¹³ ops/sec = 50 TFLOPS

This requires GPU acceleration and optimized algorithms—only recently feasible with modern GPUs (NVIDIA RTX 4090: ~80 TFLOPS).

Key Takeaways

  • CGH calculates hologram patterns from virtual objects without physical recording—enables holograms of anything computable
  • Point-source method is intuitive (O(N×M²)) but slow; layer-based FFT methods are much faster (O(L×M²logM))
  • Gerchberg-Saxton algorithm creates phase-only holograms through iterative phase retrieval (10-100 iterations)
  • Fabrication methods span 6 orders of magnitude in cost/speed: e-beam (slow, expensive, ultra-high-res) to embossing (fast, cheap, mass-production)
  • Binary CGH is easy to make but low efficiency (~10-40%); multi-level increases efficiency (4-level: ~70%, 8-level: ~90%)
  • Applications include HOE, optical testing, security features, and emerging holographic displays
  • Real-time CGH for displays requires >50 TFLOPS—only recently feasible with modern GPUs

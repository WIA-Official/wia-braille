제3장

📘 표준 개요

제조 자동화 분야의 핵심 국제 표준과 WIA-MANUFACTUR 표준의 구조, 범위, 그리고 기존 표준과의 관계를 종합적으로 이해합니다.

개요

표준화는 Industry 4.0 생태계의 핵심 기반입니다. 서로 다른 제조사의 장비, 다양한 소프트웨어 플랫폼, 그리고 복잡한 자동화 시스템들이 원활하게 협업하기 위해서는 공통의 언어와 규칙이 필요합니다. 이 장에서는 제조 자동화 분야의 주요 국제 표준들을 살펴보고, WIA-MANUFACTUR 표준이 어떻게 이들을 통합하여 실용적이고 포괄적인 프레임워크를 제공하는지 설명합니다.

제조 자동화 표준은 통신 프로토콜, 데이터 모델, 안전 요구사항, 상호운용성 규격, 사이버 보안 지침 등 다양한 측면을 다룹니다. ISO(국제표준화기구), IEC(국제전기기술위원회), IEEE(전기전자기술자협회), ANSI(미국국가표준협회) 등 여러 표준화 기구에서 수백 개의 표준을 발표했지만, 이들 간의 조율과 통합이 충분하지 않아 실무 적용에 혼란이 있었습니다.

WIA-MANUFACTUR 표준은 이러한 격차를 해소하기 위해 개발되었습니다. 기존의 확립된 표준들을 존중하고 참조하면서도, 실제 제조 현장에서 즉시 적용 가능한 통합 가이드를 제공합니다. 본 장에서는 주요 표준들의 핵심 내용, 적용 범위, 그리고 WIA-MANUFACTUR 표준과의 관계를 체계적으로 정리합니다.

학습 목표

  • 제조 자동화 분야의 주요 국제 표준 체계 이해
  • OPC UA, MTConnect, AutomationML 등 핵심 표준 파악
  • ISA-95 참조 모델과 RAMI 4.0 아키텍처 학습
  • 로봇 안전 표준(ISO 10218, ISO/TS 15066) 숙지
  • WIA-MANUFACTUR 표준의 구조와 설계 철학 이해
  • 표준 간 상호 관계 및 통합 접근 방식 파악

1. 제조 자동화 표준 생태계

1.1 표준화 기구 및 역할

제조 자동화 분야의 표준은 여러 국제 및 국가 기구에서 개발 및 관리됩니다. 각 기구는 특정 전문 영역에 초점을 맞추며, 때로는 협력하여 공동 표준을 개발하기도 합니다. 주요 표준화 기구와 그 역할을 이해하는 것은 표준 적용 전략 수립에 필수적입니다.

1.2 표준 계층 구조

제조 자동화 표준은 일반적으로 여러 계층으로 구성되며, 각 계층은 특정 추상화 수준에서 상호운용성을 정의합니다. 이러한 계층적 접근은 복잡한 시스템을 관리 가능한 부분으로 나누고, 각 계층에서 최적의 표준을 적용할 수 있게 합니다.

표준 계층 모델

계층 7: 비즈니스 계획 및 물류
표준: ISA-95 레벨 4, ERP 인터페이스
목적: 기업 자원 계획 및 공급망 관리
계층 6: 제조 운영 관리

목적: 실제 제조 프로세스 및 장비

2. 핵심 통신 및 데이터 표준

2.1 OPC UA (Unified Architecture)

OPC UA는 Industry 4.0 시대의 가장 중요한 산업 통신 표준으로 자리잡았습니다. 이전 버전인 OPC Classic의 한계(Windows 종속성, DCOM 보안 문제)를 극복하고, 플랫폼 독립적이며 확장 가능한 아키텍처를 제공합니다. OPC UA는 단순한 데이터 전송을 넘어 풍부한 정보 모델링, 내장 보안, 그리고 서비스 지향 아키텍처(SOA)를 지원합니다.

OPC UA 핵심 특징

  • 플랫폼 독립성: Windows, Linux, 임베디드 시스템 등 다양한 플랫폼 지원
  • 정보 모델링: 복잡한 데이터 구조와 의미론을 표준화된 방식으로 표현
  • 보안: 인증, 암호화, 무결성 검증을 기본 제공 (X.509 인증서, AES 암호화)
  • 확장성: 산업별 컴패니언 스펙(Companion Specifications) 지원
    • OPC UA for Robotics (로봇 제어 및 모니터링)
    • OPC UA for Machine Tools (공작기계 데이터 교환)
    • OPC UA for PackML (패키징 기계 표준)
    • OPC UA for PLCopen (모션 제어)
  • 전송 프로토콜: TCP/IP 바이너리, HTTPS, MQTT, AMQP 등 다양한 전송 방식
  • Pub/Sub 모델: 실시간 데이터 배포를 위한 게시/구독 패턴

WIA-MANUFACTUR에서의 역할: WIA-MANUFACTUR는 OPC UA를 기본 통신 프로토콜로 권장하며, 특히 다양한 제조사 장비 간 상호운용성이 필요한 경우 필수로 적용합니다.

2.2 MTConnect

MTConnect는 공작기계 및 제조 장비의 데이터 수집과 배포를 위한 오픈 표준입니다. 미국의 AMT(Association For Manufacturing Technology)가 주도하여 개발했으며, CNC 기계, 로봇, 센서 등에서 생성되는 데이터를 표준화된 XML 형식으로 제공합니다. MTConnect의 강점은 단순성과 광범위한 산업 채택입니다.

MTConnect 아키텍처

  1. Adapter: 장비의 네이티브 데이터를 MTConnect 형식으로 변환
  2. Agent: HTTP 기반 RESTful 인터페이스로 데이터 제공
  3. Client Application: 데이터를 수집하고 분석하는 상위 애플리케이션

주요 데이터 유형:

  • Samples: 연속 값 (온도, 압력, 속도 등)
  • Events: 이산 상태 변화 (알람, 프로그램 실행 등)
  • Conditions: 장비 상태 및 경고

WIA-MANUFACTUR에서의 역할: 기존 MTConnect 구현을 보존하면서, OPC UA와의 통합 브리지 제공을 권장합니다.

2.3 AutomationML

AutomationML(Automation Markup Language)은 공장 자동화 프로젝트의 엔지니어링 데이터를 교환하기 위한 중립적이고 개방적인 XML 기반 표준입니다. 기계 설계, 전기 설계, 소프트웨어 설계 등 다양한 엔지니어링 도구 간 데이터 교환을 지원하여 디지털 트윈 구현의 기반이 됩니다.

AutomationML은 기존의 여러 표준들(COLLADA for 3D geometry, PLCopen XML for control logic, CAEX for system topology)을 통합하여 종합적인 플랜트 모델을 생성합니다. 이는 가상 커미셔닝(Virtual Commissioning), 시뮬레이션, 그리고 생산 라인 재구성에 매우 유용합니다.

3. 제어 시스템 표준

3.1 IEC 61131-3 (PLC 프로그래밍)

IEC 61131-3은 PLC 프로그래밍 언어의 국제 표준으로, 제조 자동화에서 가장 널리 사용됩니다. 이 표준은 다섯 가지 프로그래밍 언어를 정의하며, 각 언어는 특정 유형의 제어 로직에 최적화되어 있습니다.

언어유형특징주요 용도
LD
(Ladder Diagram)		 그래픽 전기 회로도와 유사, 직관적 릴레이 로직, 단순 제어
FBD
(Function Block Diagram)		 그래픽 데이터 흐름 중심 프로세스 제어, 복잡한 연산
SFC
(Sequential Function Chart)		 그래픽 순차 제어 구조 배치 프로세스, 상태 기계
ST
(Structured Text)		 텍스트 고급 프로그래밍 언어와 유사 복잡한 알고리즘, 수식 계산
IL
(Instruction List)		 텍스트 어셈블리와 유사, 저수준 최적화된 성능 필요 시

3.2 IEC 61499 (분산 제어 시스템)

IEC 61499는 IEC 61131의 후속 표준으로, 분산되고 재구성 가능한 제어 시스템을 위해 설계되었습니다. Industry 4.0의 유연한 제조 시스템에 이상적이며, 기능 블록(Function Block) 기반의 모듈식 아키텍처를 제공합니다. 각 기능 블록은 독립적으로 재사용 가능하며, 이벤트 기반 실행 모델을 지원하여 복잡한 분산 시스템을 효율적으로 관리할 수 있습니다.

IEC 61499의 핵심 개념은 "플랜트 바닥에서 비즈니스 계획까지" 통합된 엔지니어링 접근 방식입니다. 동일한 모델과 도구를 사용하여 전체 자동화 아키텍처를 설계하고 구현할 수 있어, 엔지니어링 효율성이 크게 향상됩니다.

4. 참조 아키텍처 및 모델

4.1 ISA-95 (기업-제어 시스템 통합)

ISA-95(IEC 62264)는 기업 시스템(ERP)과 제조 실행 시스템(MES) 간의 인터페이스를 정의하는 국제 표준입니다. 이 표준은 5단계 계층 모델을 제시하며, 각 계층의 역할과 정보 교환 방법을 명확히 합니다.

ISA-95 계층 모델

  • 레벨 4 - 비즈니스 계획 및 물류: ERP 시스템, 전사적 자원 관리
  • 레벨 3 - 제조 운영 관리: MES, 생산 스케줄링, 품질 관리, 추적성
  • 레벨 2 - 배치/연속/이산 제어: SCADA, DCS, 감독 제어
  • 레벨 1 - 센싱 및 조작: PLC, 센서, 액추에이터
  • 레벨 0 - 물리적 프로세스: 실제 제조 장비 및 프로세스

ISA-95는 또한 제조 운영을 위한 공통 객체 모델을 정의합니다: 제품 정의(Product Definition), 생산 스케줄(Production Schedule), 생산 성과(Production Performance), 생산 능력(Production Capability) 등.

4.2 RAMI 4.0 (Reference Architecture Model Industry 4.0)

RAMI 4.0은 독일의 Industry 4.0 이니셔티브에서 개발한 3차원 참조 아키텍처 모델입니다. 이 모델은 복잡한 Industry 4.0 시스템을 세 개의 축(계층, 수명주기, 아키텍처 레이어)로 구조화하여 이해하기 쉽게 만듭니다.

RAMI 4.0의 3차원 구조

축 1: 아키텍처 레이어 (수직축)

  1. 비즈니스 (Business)
  2. 기능 (Functional)
  3. 정보 (Information)
  4. 통신 (Communication)
  5. 통합 (Integration)
  6. 자산 (Asset)

축 2: 계층 구조 (좌측축)

ISA-95를 기반으로 한 계층: Product → Field Device → Control Device → Station → Work Center → Enterprise → Connected World

축 3: 수명주기 (우측축)

IEC 62890 기반: Type (설계) → Instance (실제 사용) → Development → Maintenance/Usage

RAMI 4.0의 핵심 개념 중 하나는 Asset Administration Shell (AAS)로, 물리적 자산의 디지털 표현입니다. AAS는 자산의 모든 관련 정보(기술 데이터, 문서, 서비스 등)를 표준화된 방식으로 캡슐화합니다.

5. 로봇 및 안전 표준

5.1 ISO 10218 (산업용 로봇 안전)

ISO 10218은 산업용 로봇의 설계, 제조, 설치, 운영에 관한 안전 요구사항을 정의하는 국제 표준입니다. 이 표준은 두 부분으로 구성됩니다:

  • ISO 10218-1: 로봇 제조사를 위한 설계 및 구조 요구사항
  • ISO 10218-2: 로봇 시스템 통합자와 사용자를 위한 설치 및 운영 요구사항

이 표준은 위험 평가, 안전 기능(비상정지, 안전 정지, 속도 제한 등), 안전 거리, 펜싱, 그리고 인터록 요구사항을 명시합니다. 전통적인 산업용 로봇은 일반적으로 인간과 물리적으로 분리되어 작동하도록 설계되었습니다.

5.2 ISO/TS 15066 (협동 로봇)

ISO/TS 15066은 ISO 10218을 보완하여, 인간과 로봇이 같은 작업 공간을 공유하는 협동 로봇(Collaborative Robot) 시스템의 안전 요구사항을 다룹니다. 이 기술 사양은 네 가지 협업 모드를 정의합니다:

협동 로봇 작동 모드

  1. 안전 등급 모니터링 정지 (Safety-rated Monitored Stop):
    작업자가 협업 공간에 진입하면 로봇이 안전하게 정지하고, 작업자가 나가면 자동으로 재개
  2. 핸드 가이딩 (Hand Guiding):
    작업자가 로봇을 직접 안내하여 작업 경로를 가르치거나 수동 조작
  3. 속도 및 분리 모니터링 (Speed and Separation Monitoring):
    센서로 작업자와 로봇 간 거리를 실시간 측정하여 안전 거리 유지, 거리에 따라 속도 조절
  4. 출력 및 힘 제한 (Power and Force Limiting):
    로봇과 작업자 간 접촉 시 발생할 수 있는 힘과 압력을 생체역학적 한계 이하로 제한

ISO/TS 15066은 신체 부위별 허용 압력 및 힘 한계값을 제시합니다. 예를 들어, 두개골은 130N, 이마는 65N, 손등은 140N 등의 최대 접촉력이 정의됩니다.

5.3 ISO 13849 (제어 시스템 안전)

ISO 13849는 기계류의 안전 관련 제어 시스템 설계를 위한 표준입니다. 이 표준은 위험 평가에 기반하여 필요한 성능 수준(Performance Level, PL)을 결정하고, 해당 PL을 달성하기 위한 설계 원칙을 제시합니다. PL은 PL a(가장 낮음)부터 PL e(가장 높음)까지 다섯 등급으로 나뉘며, 각 등급은 특정 고장 확률과 진단 커버리지를 요구합니다.

6. 사이버 보안 표준

6.1 IEC 62443 (산업 자동화 및 제어 시스템 보안)

IEC 62443(이전 ISA-99)은 산업 자동화 및 제어 시스템(IACS)의 사이버 보안을 위한 포괄적인 표준 시리즈입니다. 이 표준은 4개의 주요 카테고리로 구성됩니다:

  • Part 1 - 일반 (General): 개념, 모델, 용어 정의
  • Part 2 - 정책 및 절차 (Policies and Procedures): 조직의 보안 프로그램 수립
  • Part 3 - 시스템 (System): 보안 기술 및 프로세스 요구사항
  • Part 4 - 컴포넌트 (Component): 제품 개발 및 기술 요구사항

IEC 62443은 보안 수준(Security Level, SL)을 4단계로 정의합니다: SL 1(우발적 침해 방지), SL 2(의도적 침해 방어), SL 3(정교한 수단 침해 저항), SL 4(고도의 자원 침해 대응). 각 조직은 위험 평가를 통해 필요한 보안 수준을 결정하고 적절한 대책을 구현해야 합니다.

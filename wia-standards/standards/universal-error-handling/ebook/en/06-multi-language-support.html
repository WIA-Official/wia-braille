CHAPTER 6

Multi-Language Implementation

6.1 The 99 Languages Challenge

WIA-CORE-010 supports 99 programming languages, from mainstream (JavaScript, Python, Java) to niche (Haskell, Erlang, Assembly). This chapter demonstrates implementation patterns across language paradigms.

6.2 Object-Oriented Languages (Java, C#, TypeScript)

// TypeScript
class WIAError extends Error {
  constructor(public config: {
    code: string;
    message: string;
    severity: 'CRITICAL' | 'ERROR' | 'WARNING' | 'INFO';
    recovery: 'RETRY_WITH_BACKOFF' | 'FALLBACK' | 'CIRCUIT_BREAKER' | 'GRACEFUL_DEGRADATION' | 'FAIL_FAST' | 'MANUAL';
    context?: Record;
    correlationId?: string;
  }) {
    super(config.message);
    this.name = 'WIAError';
    this.config.correlationId = config.correlationId || generateUUID();
  }

  toJSON() {
    return {
      code: this.config.code,
      message: this.message,
      severity: this.config.severity,
      recovery: this.config.recovery,
      correlationId: this.config.correlationId,
      context: this.config.context,
      timestamp: new Date().toISOString(),
      stackTrace: this.stack
    };
  }
}

// Usage
throw new WIAError({
  code: 'WIA-AUTH-INVALID-001',
  message: 'Invalid credentials',
  severity: 'ERROR',
  recovery: 'FAIL_FAST'
});

6.3 Functional Languages (Haskell, Erlang, Elixir)

data WIAError = WIAError
  { errorCode :: String

  , errorSeverity :: Severity
  , errorRecovery :: Recovery

data Severity = Critical | Error | Warning | Info

-- Elixir
defmodule WIAError do
  defexception [:code, :message, :severity, :recovery, :context, :correlation_id]

  @type t :: %__MODULE__{
    code: String.t(),
    message: String.t(),
    severity: :critical | :error | :warning | :info,
    recovery: :retry_with_backoff | :fallback | :circuit_breaker | :graceful_degradation | :fail_fast | :manual,

  }
end

# Usage
raise WIAError,

  severity: :error,
  recovery: :retry_with_backoff

6.4 Systems Languages (C++, Rust, Go)

// Rust
#[derive(Debug, Clone)]
pub struct WIAError {
    pub code: String,
    pub message: String,
    pub severity: Severity,
    pub recovery: Recovery,
    pub context: Option,
    pub correlation_id: String,
}

impl WIAError {
    pub fn new(code: &str, message: &str, severity: Severity, recovery: Recovery) -> Self {
        WIAError {
            code: code.to_string(),
            message: message.to_string(),
            severity,
            recovery,
            context: None,
            correlation_id: uuid::Uuid::new_v4().to_string(),
        }
    }
}

6.5 Dynamic Languages (Python, Ruby, PHP)

# Python
class WIAError(Exception):
    def __init__(self, code, message, severity, recovery, context=None, correlation_id=None):
        super().__init__(message)
        self.code = code
        self.message = message
        self.severity = severity
        self.recovery = recovery
        self.context = context or {}
        self.correlation_id = correlation_id or str(uuid.uuid4())
        self.timestamp = datetime.now().isoformat()

    def to_dict(self):
        return {
            "code": self.code,
            "message": self.message,
            "severity": self.severity,
            "recovery": self.recovery,
            "context": self.context,
            "correlationId": self.correlation_id,
            "timestamp": self.timestamp
        }

// PHP
class WIAError extends Exception {
    private $code;
    private $severity;
    private $recovery;
    private $context;
    private $correlationId;

    public function __construct(
        string $code,
        string $message,
        string $severity,
        string $recovery,
        array $context = [],
        ?string $correlationId = null
    ) {
        parent::__construct($message);
        $this->code = $code;
        $this->severity = $severity;
        $this->recovery = $recovery;
        $this->context = $context;
        $this->correlationId = $correlationId ?? $this->generateUUID();
    }
}

6.7 Language-Specific SDK Features

Each SDK adapts to language conventions while maintaining standard compatibility:

  • JavaScript/TypeScript: Promise rejection handling, async/await integration
  • Go: Error return values, error wrapping with fmt.Errorf
  • Rust: Result<T, WIAError> types, ? operator integration
  • Python: Context managers, exception chaining
  • Java: Checked exceptions, try-with-resources
  • Kotlin: Sealed classes, coroutine integration
  • Swift: Error protocol, try/catch, Optional wrapping
  • Elixir: Pattern matching on error tuples

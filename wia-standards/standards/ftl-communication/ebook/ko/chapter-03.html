제3장

양자 얽힘 통신의 한계

3.1 개요

양자 얽힘(Quantum Entanglement)은 20세기 물리학의 가장 신비로운 현상 중 하나입니다. 두 입자가 얽힌 상태에 있을 때, 한 입자의 측정이 즉각적으로 다른 입자의 상태에 영향을 미치는 것처럼 보이며, 이는 아인슈타인이 "유령 같은 원거리 작용(spooky action at a distance)"이라고 불렀던 현상입니다. 많은 사람들이 이 현상을 초광속 통신의 수단으로 생각하지만, 현대 양자역학의 엄격한 수학적 증명은 이것이 불가능함을 보여줍니다.

이 장에서는 양자 얽힘의 기본 원리, 무통신 정리(No-Communication Theorem)의 수학적 증명, 그리고 왜 얽힘이 정보 전달에 사용될 수 없는지를 상세히 탐구합니다. 또한 이론적으로 이 한계를 우회할 수 있는 추측적 메커니즘들도 검토합니다.

3.2 양자 얽힘의 기초

3.2.1 벨 상태와 EPR 쌍

가장 단순한 얽힌 상태는 두 큐비트의 벨 상태(Bell states)입니다. 네 가지 벨 상태는 다음과 같습니다:

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2 (벨 상태 1) |Φ⁻⟩ = (|00⟩ - |11⟩)/√2 (벨 상태 2) |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2 (벨 상태 3) |Ψ⁻⟩ = (|01⟩ - |10⟩)/√2 (벨 상태 4) 여기서: |0⟩, |1⟩ = 계산 기저 상태 첫 번째 큐비트 = 앨리스 두 번째 큐비트 = 밥

이러한 상태들은 최대 얽힘 상태(maximally entangled states)로, 한 입자의 측정 결과가 다른 입자의 측정 결과와 완벽하게 상관되어 있습니다. 예를 들어, |Φ⁺⟩ 상태에서 앨리스가 0을 측정하면, 밥은 반드시 0을 측정하고, 앨리스가 1을 측정하면 밥도 1을 측정합니다.

3.2.2 상관관계의 본질

양자 얽힘의 핵심은 상관관계입니다. 하지만 이 상관관계는 고전적인 상관관계와는 근본적으로 다릅니다. 벨의 부등식(Bell's inequality)을 위반하는 양자 상관관계는 국소 숨은 변수 이론(local hidden variable theory)으로 설명될 수 없습니다.

특성 고전 상관관계 양자 상관관계
상관관계 강도 C ≤ 2 C ≤ 2√2 (Tsirelson 한계)
국소성 항상 만족 위반 가능
실재성 측정 전에 값 존재 측정 시 값 결정
정보 전달 가능 불가능
벨 부등식 만족 위반

3.3 무통신 정리 (No-Communication Theorem)

3.3.1 수학적 증명

무통신 정리는 양자 얽힘을 통해 초광속 정보 전달이 불가능함을 엄격하게 증명합니다. 증명의 핵심은 밥의 축약 밀도 행렬(reduced density matrix)이 앨리스의 측정 선택과 무관하다는 것입니다.

증명:

설정: 앨리스와 밥이 얽힌 상태 |ψ⟩ᴬᴮ를 공유합니다.

|ψ⟩ᴬᴮ = ∑ᵢⱼ cᵢⱼ |i⟩ᴬ ⊗ |j⟩ᴮ 밥의 축약 밀도 행렬: ρᴮ = Trᴬ(|ψ⟩⟨ψ|ᴬᴮ) = ∑ₖ ⟨k|ᴬ (|ψ⟩⟨ψ|ᴬᴮ) |k⟩ᴬ = ∑ᵢⱼₖ cᵢₖ c*ⱼₖ |i⟩⟨j|ᴮ

핵심: 이 밀도 행렬은 앨리스가 어떤 측정을 수행하든 변하지 않습니다. 따라서 밥은 자신의 입자를 아무리 정밀하게 측정해도 앨리스가 무엇을 했는지 알 수 없습니다.

3.3.2 구체적 예시: |Φ⁺⟩ 상태

벨 상태 |Φ⁺⟩ = (|00⟩ + |11⟩)/√2를 생각해봅시다:

밥의 축약 밀도 행렬: ρᴮ = Trᴬ(|Φ⁺⟩⟨Φ⁺|) = Trᴬ[(|00⟩⟨00| + |00⟩⟨11| + |11⟩⟨00| + |11⟩⟨11|)/2] = (|0⟩⟨0| + |1⟩⟨1|)/2 = ½I (최대 혼합 상태) 여기서: I = 2×2 단위 행렬 ½I = 완전히 무작위 상태

밥의 상태가 최대 혼합 상태라는 것은 그의 측정 결과가 완전히 무작위(50% 확률로 0 또는 1)라는 의미입니다. 앨리스가 어떤 기저로 측정하든, 밥의 밀도 행렬은 여전히 ½I입니다.

3.3.3 무신호 정리 (No-Signaling Theorem)

더 일반적인 형태로, 무신호 정리는 다음과 같이 표현됩니다:

P(b|Mᴬ, Mᴮ) = P(b|Mᴮ)

여기서:

  • b = 밥의 측정 결과
  • Mᴬ = 앨리스의 측정 선택
  • Mᴮ = 밥의 측정 선택

즉, 밥의 측정 결과 확률 분포는 앨리스의 측정 선택과 무관합니다. 따라서 밥은 자신의 측정 결과만으로는 앨리스가 어떤 측정을 했는지 알 수 없습니다.

3.4 왜 얽힘은 정보를 전달하지 못하는가?

3.4.1 무작위성의 문제

양자 얽힘이 정보 전달에 실패하는 근본적인 이유는 측정 결과의 무작위성입니다:

문제점:

  • 앨리스의 측정: 결과가 진정한 무작위입니다 (50% 확률로 0 또는 1)
  • 밥의 측정: 결과도 진정한 무작위입니다 (50% 확률로 0 또는 1)
  • 상관관계: 두 결과는 상관되어 있지만, 각각 개별적으로는 무작위입니다
  • 정보 부재: 무작위 비트 스트림에는 정보가 인코딩될 수 없습니다

3.4.2 고전 통신 채널의 필요성

얽힘의 상관관계를 확인하려면 앨리스와 밥이 측정 결과를 고전적으로 비교해야 합니다. 이 비교는 빛의 속도로 제한되므로, 전체 과정은 초광속이 될 수 없습니다.

단계 작업 속도
1 얽힌 쌍 생성 및 분배 ≤ c
2 앨리스의 측정 (즉각적) 로컬
3 밥의 측정 (즉각적) 로컬
4 결과 비교 (고전 통신) ≤ c
5 상관관계 확인 로컬

단계 4의 고전 통신이 병목이 되어, 전체 정보 전달 속도는 빛의 속도를 넘을 수 없습니다.

3.5 양자 텔레포테이션과 초밀도 코딩

3.5.1 양자 텔레포테이션 (Quantum Teleportation)

양자 텔레포테이션은 얽힘을 사용하여 양자 상태를 전송하는 프로토콜이지만, 여전히 초광속 통신을 허용하지 않습니다.

프로토콜: 1. 앨리스와 밥이 얽힌 쌍 |Φ⁺⟩ᴬᴮ 공유 2. 앨리스가 전송하려는 상태: |ψ⟩ = α|0⟩ + β|1⟩ 3. 앨리스가 |ψ⟩와 자신의 얽힌 큐비트를 벨 기저로 측정 4. 측정 결과 2 비트를 밥에게 고전적으로 전송 (≤ c) 5. 밥이 2비트 정보에 따라 유니터리 연산 적용 6. 밥의 큐비트가 |ψ⟩ 상태가 됨 핵심: 단계 4의 고전 통신이 c 이하로 제한됨

3.5.2 초밀도 코딩 (Superdense Coding)

초밀도 코딩은 얽힘을 사용하여 1개의 큐비트로 2개의 고전 비트를 전송합니다:

프로토콜: 1. 사전에 얽힌 쌍 |Φ⁺⟩ᴬᴮ 공유 2. 앨리스가 전송하려는 2비트: 00, 01, 10, 11 3. 2비트에 따라 유니터리 연산 적용: - 00 → I (아무것도 안함) → |Φ⁺⟩ - 01 → X (비트 플립) → |Ψ⁺⟩ - 10 → Z (위상 플립) → |Φ⁻⟩ - 11 → XZ → |Ψ⁻⟩ 4. 앨리스가 자신의 큐비트를 밥에게 물리적으로 전송 (≤ c) 5. 밥이 두 큐비트를 벨 기저로 측정하여 2비트 복원 효율: 큐비트당 2비트 (일반적으로는 1비트) 제한: 여전히 물리적 큐비트 전송이 c 이하

3.6 이론적 허점과 추측적 메커니즘

3.6.1 비선형 양자역학

표준 양자역학은 선형적입니다 (중첩 원리). 만약 양자역학이 비선형이라면, 초광속 신호가 가능할 수 있습니다:

비선형 슈뢰딩거 방정식 (가설):

iℏ ∂ψ/∂t = Ĥψ + f(|ψ|²)ψ 여기서 f(|ψ|²)는 비선형 항

결과:

  • 중첩 원리 위반
  • 원격 측정으로 상태 조작 가능
  • 초광속 신호 허용

문제:

  • 특수 상대성 이론과 충돌
  • 실험적 증거 전무
  • 양자 컴퓨팅의 모든 원리 무효화

3.6.2 객관적 붕괴 이론과 우선 참조틀

GRW(Ghirardi-Rimini-Weber) 같은 객관적 붕괴 이론은 파동함수가 자발적으로 붕괴한다고 제안합니다. 만약 이 붕괴가 우선 참조틀에서 일어난다면:

가설: - 우주에 절대 참조틀 존재 - 양자 붕괴가 이 참조틀에서만 객관적으로 발생 - 이 참조틀에서 FTL 신호 가능 (다른 참조틀에서는 불가) 결과: - 로렌츠 불변성 위반 - 우선 참조틀에서 절대 동시성 존재 - FTL 통신이 이론적으로 가능하나 참조틀 제한됨 실험적 제약: - 로렌츠 위반 검출 한계: |Δv/v| < 10⁻¹⁸ - 우선 참조틀 증거 없음

3.6.3 파일럿 파동 이론 확장

드브로이-봄 이론(de Broglie-Bohm theory)은 비국소 숨은 변수 이론입니다. 원칙적으로 파일럿 파동은 비국소적으로 입자를 안내하지만, "양자 평형(quantum equilibrium)" 조건이 신호 전달을 막습니다.

이론 비국소성 FTL 신호 문제점
표준 양자역학 상관관계만 불가능 -
드브로이-봄 이론 숨은 변수 양자 평형 하 불가능 평형 벗어나는 메커니즘 미지
비선형 QM (가설) 진정한 비국소성 가능 상대론 충돌, 증거 없음
GRW + 우선틀 객관적 붕괴 우선틀에서만 로렌츠 위반, 증거 없음

3.7 양자 불일치와 상관관계

3.7.1 양자 불일치 (Quantum Discord)

양자 불일치는 얽힘을 넘어서는 더 일반적인 양자 상관관계입니다:

D(A:B) = I(A:B) - C(A:B)

여기서:

  • I(A:B) = 상호 정보 (양자 + 고전)
  • C(A:B) = 고전 상관관계
  • D(A:B) = 양자 불일치 (순수 양자 부분)

흥미롭게도, 얽히지 않은 상태도 0이 아닌 양자 불일치를 가질 수 있습니다. 하지만 이 역시 무신호 정리를 따르므로 FTL 통신에 사용될 수 없습니다.

3.7.2 공간적으로 분리된 사건의 상관관계

벨 실험에서 두 측정이 공간적으로 분리(spacelike separated)되어 있어도 상관관계는 즉각적으로 나타납니다:

민코프스키 공간에서: - 사건 A (앨리스 측정): (t₁, x₁) - 사건 B (밥 측정): (t₂, x₂) - 공간적 분리: (t₂-t₁)² < (x₂-x₁)²/c² 어떤 관성계에서는: - t₁ < t₂ (앨리스가 먼저) - 다른 관성계에서는: t₂ < t₁ (밥이 먼저) 그러나: - 두 경우 모두 동일한 상관관계 - 인과관계 없음 (정보 전달 없음) - 무신호 조건 만족

3.8 실험적 검증

3.8.1 벨 부등식 위반 실험

1982년 아스펙(Alain Aspect)의 실험 이후, 수많은 실험이 벨 부등식 위반을 확인했습니다:

연도 실험 CHSH 값 의미
1982 Aspect et al. 2.697 ± 0.015 최초의 확실한 위반 (> 2)
2015 Hensen et al. (허점 없는) 2.42 ± 0.20 검출 허점 제거
2015 Giustina et al. 2.50 ± 0.03 국소성 허점 제거
2017 Big Bell Test 2.37 ± 0.02 인간 무작위성 사용

고전 한계는 2이고, 양자역학의 Tsirelson 한계는 2√2 ≈ 2.828입니다. 모든 실험이 고전 한계를 넘어섰지만, 여전히 무신호 조건은 만족합니다.

3.8.2 무신호 조건 실험적 검증

여러 실험이 얽힌 입자를 사용한 신호 전달 시도를 했지만, 모두 무신호 정리를 확인했습니다:

대표 실험 (Salart et al. 2008):

  • 거리: 18 km (제네바 호수 양쪽)
  • 방법: 한쪽에서 측정 기저 빠르게 변경
  • 결과: 다른 쪽 통계에 변화 없음
  • 정밀도: 신호 속도 하한 > 10,000c (만약 신호가 있었다면)
  • 결론: 신호 없음, 무신호 정리 확인

3.9 철학적 함의

3.9.1 비국소성 vs 신호 불가능성

양자역학은 흥미로운 이중성을 보여줍니다:

비국소성 (Non-locality): 공간적으로 분리된 사건들이 상관될 수 있다

신호 불가능성 (No-Signaling): 그러나 이 상관관계는 정보 전달에 사용될 수 없다

이는 다음을 의미합니다:

  • 우주는 국소 실재론(local realism)을 위반한다
  • 그러나 인과관계(causality)는 여전히 보존된다
  • 특수 상대성 이론과 양자역학이 공존할 수 있다

3.9.2 정보의 본질

양자 얽힘이 정보를 전달하지 못한다는 사실은 정보의 본질에 대한 깊은 통찰을 제공합니다:

  • 정보는 제어 가능해야 한다: 무작위 비트는 정보가 아님
  • 정보는 인과적이어야 한다: 송신자의 의도가 수신자에게 전달되어야 함
  • 상관관계 ≠ 정보: 상관관계가 존재해도 정보는 없을 수 있음

핵심 요점

  • 양자 얽힘은 공간적으로 분리된 입자들 사이에 완벽한 상관관계를 만들지만, 이는 초광속 정보 전달에 사용될 수 없습니다.
  • 무통신 정리는 밥의 축약 밀도 행렬이 앨리스의 측정과 무관함을 수학적으로 증명하여, FTL 통신이 불가능함을 보입니다.
  • 양자 텔레포테이션과 초밀도 코딩은 얽힘을 유용하게 활용하지만, 여전히 고전 통신 채널을 필요로 하므로 빛의 속도로 제한됩니다.
  • 비선형 양자역학이나 우선 참조틀 같은 추측적 메커니즘은 이론적으로 FTL을 허용할 수 있지만, 실험적 증거가 전혀 없고 특수 상대성 이론과 충돌합니다.
  • 벨 부등식 위반은 양자 비국소성을 확인하지만, 동시에 무신호 조건도 만족하여 인과관계가 보존됩니다.
  • 양자 얽힘의 연구는 정보, 인과관계, 실재의 본질에 대한 깊은 철학적 질문을 제기합니다.

검토 질문

  1. 벨 상태 |Φ⁺⟩의 밥 축약 밀도 행렬이 최대 혼합 상태(½I)가 되는 이유를 설명하고, 이것이 왜 정보 전달을 불가능하게 하는지 논하십시오.
  2. 무신호 정리 P(b|Mᴬ, Mᴮ) = P(b|Mᴮ)의 의미를 설명하고, 이것이 얽힌 입자로 FTL 통신을 시도하는 모든 방법을 어떻게 차단하는지 설명하십시오.
  3. 양자 텔레포테이션 프로토콜에서 고전 통신 단계가 왜 필수적인지 설명하고, 이 단계를 제거하려는 시도가 왜 실패할 수밖에 없는지 논하십시오.
  4. 벨 부등식 위반이 "비국소성"을 의미한다면, 왜 이것이 "초광속 신호"로 이어지지 않는지 설명하십시오. 비국소성과 신호 불가능성이 어떻게 공존할 수 있는가?
  5. 비선형 양자역학이 FTL 통신을 허용할 수 있는 이유를 설명하고, 이러한 이론이 왜 실험적으로나 이론적으로 받아들여지지 않는지 논하십시오.
  6. 양자 불일치(quantum discord)와 얽힘의 차이를 설명하고, 얽히지 않은 상태가 0이 아닌 불일치를 가질 수 있는 이유와 이것이 FTL 통신에 사용될 수 없는 이유를 논하십시오.
  7. Aspect의 1982년 실험이 어떻게 벨 부등식 위반을 확인했는지 설명하고, 이후의 "허점 없는(loophole-free)" 실험들이 어떤 추가 문제를 해결했는지 논하십시오.

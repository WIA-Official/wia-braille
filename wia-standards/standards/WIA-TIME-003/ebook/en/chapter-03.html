Chapter 3

🔗 Quantum Entanglement Across Time

Exploring the mysterious phenomenon of temporal entanglement, where quantum correlations span different moments in time.

3.1 Introduction to Temporal Entanglement

Quantum entanglement—what Einstein famously called "spooky action at a distance"—is one of the most profound features of quantum mechanics. Standard entanglement creates correlations between particles separated in space. Temporal entanglement extends this concept: particles or events at different times become correlated in ways that defy classical explanation.

EPR Paradox Extended to Time

In 1935, Einstein, Podolsky, and Rosen argued that quantum mechanics was incomplete. When we extend EPR to time:

  • Two events at times t₁ and t₂ become entangled
  • Measuring at t₁ instantaneously determines the state at t₂
  • This happens even if t₂ is in the past relative to the measurement

3.2 Theoretical Foundation

Temporal entanglement occurs when the combined quantum state cannot be written as a product of individual states:

|Ψ(t₁,t₂)⟩ ≠ |ψ(t₁)⟩ ⊗ |φ(t₂)⟩

Instead, the state exhibits non-separable correlations:

|Ψ⟩ = (1/√2)(|t₁,↑⟩|t₂,↓⟩ + |t₁,↓⟩|t₂,↑⟩)

3.3 The Four Bell States

The maximally entangled states form a complete orthonormal basis:

Bell State Mathematical Form Correlation Type
|Φ⁺⟩ (1/√2)(|↑↑⟩ + |↓↓⟩) Same outcomes, positive phase
|Φ⁻⟩ (1/√2)(|↑↑⟩ - |↓↓⟩) Same outcomes, negative phase
|Ψ⁺⟩ (1/√2)(|↑↓⟩ + |↓↑⟩) Opposite outcomes, positive phase
|Ψ⁻⟩ (1/√2)(|↑↓⟩ - |↓↑⟩) Opposite outcomes (singlet)

function entangleAcrossTime(
  state1: QuantumTimeState,
  state2: QuantumTimeState | { timestamp: number },
  bellState: BellState = 'psi_plus'
): QuantumEntanglement {
  const timeSeparation = Math.abs(
    state1.baseTimestamp -
    ('baseTimestamp' in state2 ? state2.baseTimestamp : state2.timestamp)
  );

  const entanglementStrength = Math.exp(-timeSeparation / TAU_ENTANGLE);

  return {
    entanglementId: generateUUID(),
    state1,
    state2,
    entanglementStrength,
    bellState,
    timeSeparation,
    correlationFunction: createCorrelationFunction(bellState),
    createdAt: Date.now()
  };
}

3.5 Bell's Inequality for Time

The CHSH inequality for temporal entanglement:

S = |E(a,b) - E(a,b')| + |E(a',b) + E(a',b')| ≤ 2 (Classical)

S_quantum = 2√2 ≈ 2.828 (Tsirelson's bound) 
interface BellTestResult {
  S_value: number;           // CHSH value
  violatesClassical: boolean; // S > 2
  isQuantum: boolean;         // 2 < S ≤ 2√2
  measurements: BellMeasurement[];
  confidence: number;         // Statistical confidence
}

function runBellTest(
  entanglement: QuantumEntanglement,
  measurementCount: number = 1000
): BellTestResult {
  const angles = {
    a: 0,
    a_prime: Math.PI / 4,
    b: Math.PI / 8,
    b_prime: 3 * Math.PI / 8
  };

  const E_ab = measureCorrelation(entanglement, angles.a, angles.b, measurementCount);
  const E_ab_p = measureCorrelation(entanglement, angles.a, angles.b_prime, measurementCount);
  const E_a_pb = measureCorrelation(entanglement, angles.a_prime, angles.b, measurementCount);
  const E_a_pb_p = measureCorrelation(entanglement, angles.a_prime, angles.b_prime, measurementCount);

  const S = Math.abs(E_ab - E_ab_p) + Math.abs(E_a_pb + E_a_pb_p);

  return {
    S_value: S,
    violatesClassical: S > 2,
    isQuantum: S > 2 && S <= 2 * Math.sqrt(2),
    measurements: [...],
    confidence: calculateConfidence(measurements)
  };
}

3.6 Measurement and Collapse

Temporal Measurement Scenarios Scenario 1: Measure Past First Scenario 2: Measure Future First t₁ (past) t₂ (future) t₁ (past) t₂ (future) │ │ │ │ │ Entangled │ │ Entangled │ │ |Ψ⁺⟩ │ │ |Ψ⁺⟩ │ │←─────────────│ │─────────────→│ │ │ │ │ Measure ↑ Collapses ↓ Collapses ↓ Measure ↑ │ │ │ │ ⚠️ In Scenario 2, the "past" collapses based on future measurement! 
function measureEntangledState(
  entanglement: QuantumEntanglement,
  whichState: 1 | 2
): CollapseResult {
  const measured = whichState === 1 ? entanglement.state1 : entanglement.state2;

  // Randomly select outcome based on quantum probabilities
  const outcome: 'up' | 'down' = Math.random() < 0.5 ? 'up' : 'down';

  // Determine correlated outcome based on Bell state
  let correlatedOutcome: 'up' | 'down';
  switch (entanglement.bellState) {
    case 'phi_plus':
    case 'phi_minus':
      correlatedOutcome = outcome;  // Same outcome
      break;
    case 'psi_plus':
    case 'psi_minus':
      correlatedOutcome = outcome === 'up' ? 'down' : 'up';  // Opposite
      break;
  }

  return {
    measured: collapseToState(measured, outcome),
    collapsed: collapseToState(partner, correlatedOutcome),
    measurementOutcome: outcome,
    correlatedOutcome
  };
}

3.8 Decoherence of Temporal Entanglement

S(Δt) = S₀ · exp(-Δt / τ_entangle)

⚠️ Entanglement Preservation Challenges

Maintaining temporal entanglement requires:

  • Extreme isolation: Vacuum, cryogenic temperatures
  • Error correction: Continuously monitor and correct
  • Limited time separation: Practical limits on Δt

📋 Chapter Summary

Key Takeaways

  1. Temporal entanglement creates quantum correlations between events at different times.
  2. The four Bell states (Φ⁺, Φ⁻, Ψ⁺, Ψ⁻) form a complete basis for maximally entangled pairs.
  3. Bell inequalities can be violated by temporally entangled systems (S ≤ 2√2).
  4. Measurement collapse affects entangled states instantaneously, even across time.
  5. Applications include quantum memory, secure time-stamping, and error correction.
  6. Decoherence limits practical entanglement with exponential decay.

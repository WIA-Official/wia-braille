Chapter 5

The Wheeler-DeWitt Equation

Timeless quantum gravity: when the fundamental equation of the universe contains no time at all.

The Problem of Time in Quantum Gravity

When physicists attempted to unify quantum mechanics with general relativity, they encountered a profound conceptual crisis. In quantum mechanics, time appears as an external parameter—a classical clock outside the system that measures when wavefunctions evolve. But in general relativity, time is part of the dynamical structure of spacetime itself. There is no external time; everything is inside the universe.

This clash becomes acute when we try to write down a quantum description of the entire universe. The Wheeler-DeWitt equation, derived independently by John Wheeler and Bryce DeWitt in the 1960s, is the fundamental equation of quantum cosmology. Its most striking feature: it contains no time variable at all. The wavefunction of the universe is static.

ĤΨ[g, φ] = 0

Here, Ĥ is the Hamiltonian constraint operator, Ψ is the wavefunction of the universe, g represents the 3-geometry (the spatial metric), and φ represents matter fields. The equation says that the Hamiltonian annihilates the wavefunction—there is no time evolution in the conventional sense.

Derivation from Canonical Gravity

To understand the Wheeler-DeWitt equation, we must first understand how general relativity is formulated as a Hamiltonian system. The ADM (Arnowitt-Deser-Misner) formalism splits spacetime into spatial slices evolving in time. The full spacetime metric gμν is decomposed as:

ds² = -N²dt² + hij(dxi + Nidt)(dxj + Njdt)

Here, N is the lapse function (how much proper time elapses), Ni is the shift vector (how spatial coordinates change), and hij is the induced 3-metric on spatial slices. The lapse and shift are not dynamical—they can be freely specified, reflecting the gauge freedom of general relativity.

The conjugate momentum to the 3-metric is related to the extrinsic curvature Kij, which describes how the spatial slice is embedded in spacetime. The Hamiltonian constraint then arises from requiring that the theory be independent of how we choose to slice spacetime—this is the content of general covariance.

The Hamiltonian Constraint

In classical general relativity, the Hamiltonian constraint reads:

H = (16πG)Gijklπijπkl - (16πG)-1√h (³R - 2Λ) + Hmatter = 0

where Gijkl is the DeWitt supermetric on the space of 3-geometries, πij is the momentum conjugate to hij, ³R is the 3-dimensional Ricci scalar, Λ is the cosmological constant, and Hmatter contains matter contributions.

Quantizing this constraint means replacing momenta with functional derivatives: πij → -iℏ δ/δhij. The Wheeler-DeWitt equation is then ĤΨ = 0, where the ordering of operators presents significant ambiguities that affect the physics.

interface ThreeGeometry {
  metric: number[][];       // 3x3 spatial metric h_ij
  position: number[];       // Spatial coordinates
  curvature: number;        // Ricci scalar ³R
}

interface WheelerDeWittState {
  amplitude: Complex;
  geometry: ThreeGeometry;
  matterFields: Map;
}

interface Superspace {
  geometries: ThreeGeometry[];
  connections: Map;
}

class WheelerDeWittSolver {
  private readonly G = 6.674e-11;      // Newton's constant
  private readonly hbar = 1.054e-34;
  private readonly Lambda = 1.1e-52;    // Cosmological constant

  // Compute DeWitt supermetric
  computeSupermetric(g: ThreeGeometry): number[][][][] {
    const h = g.metric;
    const detH = this.determinant3x3(h);
    const hInv = this.inverse3x3(h);

    // G_ijkl = (1/2)√h (h_ik h_jl + h_il h_jk - h_ij h_kl)
    const G: number[][][][] = [];
    for (let i = 0; i < 3; i++) {
      G[i] = [];
      for (let j = 0; j < 3; j++) {
        G[i][j] = [];
        for (let k = 0; k < 3; k++) {
          G[i][j][k] = [];
          for (let l = 0; l < 3; l++) {
            G[i][j][k][l] = 0.5 * Math.sqrt(detH) * (
              h[i][k] * h[j][l] +
              h[i][l] * h[j][k] -
              h[i][j] * h[k][l]
            );
          }
        }
      }
    }
    return G;
  }

  // Check if state satisfies Wheeler-DeWitt constraint
  checkConstraint(
    psi: WheelerDeWittState,
    tolerance: number = 1e-10
  ): boolean {
    const H = this.computeHamiltonianAction(psi);
    return Math.abs(H) < tolerance;
  }

  // Find solutions via path integral over geometries
  solvePathIntegral(
    superspace: Superspace,
    boundaryConditions: ThreeGeometry[]
  ): WheelerDeWittState[] {
    const solutions: WheelerDeWittState[] = [];

    // Sum over all paths connecting boundary geometries
    for (const path of this.enumeratePaths(
      superspace, boundaryConditions
    )) {
      const amplitude = this.computePathAmplitude(path);
      if (this.checkConstraint({
        amplitude,
        geometry: path[path.length - 1],
        matterFields: new Map()
      })) {
        solutions.push({
          amplitude,
          geometry: path[path.length - 1],
          matterFields: new Map()
        });
      }
    }
    return solutions;
  }
}

Interpretations of Timelessness

The Wheeler-DeWitt equation presents a profound interpretational challenge: if the wavefunction of the universe is static, how do we experience time? Several approaches have been proposed:

1. Emergent Time (Internal Clock)

Time may emerge from correlations within the wavefunction. Some degree of freedom within the universe (like a particular field or geometric variable) serves as an internal clock. Time becomes relational—we measure the evolution of other variables with respect to this clock variable, rather than with respect to an external parameter.

2. The Page-Wootters Mechanism

Don Page and William Wootters proposed that time emerges from quantum entanglement. The universe is divided into a "clock" subsystem C and the "rest" R. The Wheeler-DeWitt constraint becomes:

|Ψ⟩ = Σt |t⟩C ⊗ |ψ(t)⟩R

The full state is static, but conditional on measuring the clock to be at time t, the rest of the universe is found in state |ψ(t)⟩. Time evolution emerges from entanglement between clock and system.

3. Many-Histories Interpretation

The wavefunction represents a superposition of all possible spacetime histories simultaneously. Classical time emerges only when decoherence selects a particular history. This connects naturally to the Many-Worlds interpretation discussed in Chapter 2.

Mini-Superspace Models

The full Wheeler-DeWitt equation involves infinitely many degrees of freedom and is mathematically intractable. Progress is made by considering "mini-superspace" models that restrict to a finite number of geometric degrees of freedom. The simplest is the closed Friedmann-Robertson-Walker (FRW) universe, where the only variable is the scale factor a(t):

ds² = -N²dt² + a²(t)[dχ² + sin²χ(dθ² + sin²θ dφ²)]

For this model, the Wheeler-DeWitt equation reduces to an ordinary differential equation in a single variable:

[-ℏ² ∂²/∂a² + U(a)]Ψ(a) = 0

where the potential U(a) encodes the cosmological constant, spatial curvature, and matter content. This quantum cosmology equation can be solved exactly in many cases, revealing phenomena like quantum tunneling from nothing (Vilenkin), the no-boundary proposal (Hartle-Hawking), and quantum bounces that avoid the classical singularity.

Connections to Temporal Manipulation

The Wheeler-DeWitt equation has profound implications for time travel within the WIA-TIME-003 framework:

Timeless Perspective

From the Wheeler-DeWitt perspective, "time travel" is not about moving through time but rather about accessing different regions of the static wavefunction. All moments exist simultaneously; consciousness navigates this landscape, creating the illusion of temporal flow. This view dissolves many classical paradoxes—there is no "changing the past" because all configurations coexist timelessly.

Clock Variable Selection

Different choices of internal clock lead to different apparent dynamics. A time traveler might exploit this freedom by coupling to a non-standard clock variable, effectively experiencing "time" at a different rate or in a different direction than the external universe. The WIA-TIME-003 standard specifies protocols for clock-variable transitions.

Quantum Cosmological Tunneling

Mini-superspace solutions show that the universe can quantum tunnel between different classical geometries. In some solutions, this includes tunneling between expanding and contracting phases—effectively reversing the arrow of time. Understanding these transitions is essential for any technology that would manipulate cosmological-scale temporal structure.

Theoretical Limitations

The Wheeler-DeWitt equation remains controversial. It is not UV-complete (it breaks down at very high energies), and the proper interpretation of the wavefunction is debated. String theory, loop quantum gravity, and other approaches offer alternative quantum gravity frameworks. The WIA-TIME-003 standard treats Wheeler-DeWitt as a useful effective description, valid for many applications but not the final word.

Mathematical Challenges

Several deep mathematical problems remain in the Wheeler-DeWitt framework:

  • Operator Ordering: Different orderings of non-commuting operators give different physics. There is no unique prescription.
  • Hilbert Space Structure: The space of 3-geometries (superspace) is not a vector space, making the definition of an inner product problematic.
  • Regularization: The equation involves products of operators at the same point, requiring regularization that introduces scheme dependence.
  • Observables: In a diffeomorphism-invariant theory, what are the physical observables? They must be "Dirac observables" that commute with all constraints.

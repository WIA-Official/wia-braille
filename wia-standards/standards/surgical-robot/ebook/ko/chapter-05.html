Chapter 5

Phase 2: API 인터페이스

실시간 제어, 비디오 스트리밍, 힘 피드백 및 기구 조정을 가능하게 하는 RESTful API 사양을 탐구합니다.

📖 전체 영문 콘텐츠 보기 (Complete English Content)

REST API 아키텍처

WIA-ROB-006 Phase 2는 수술 로봇 제어 및 데이터 교환을 위한 포괄적인 RESTful API를 지정합니다. API는 실시간 수술 조작을 위한 저지연 WebSocket 연결과 수술 전 계획, 수술 후 문서화 및 분석을 위한 배치 REST API를 모두 지원합니다.

핵심 API 엔드포인트

  • 실시간 비디오 스트리밍: H.264/H.265 인코딩, 100ms 미만 지연 시간
  • 힘 피드백 통합: 1kHz 업데이트 속도의 햅틱 원격 측정
  • 기구 조정: 충돌 감지 및 회피
  • 안전 모니터링: 긴급 중지 전파, 작업 공간 경계 시행
  • 양방향 통신: 시간에 민감한 작업을 위한 WebSocket

저지연 통신

수술 로봇은 실시간 제어를 위해 극도로 낮은 지연 시간을 요구합니다. 표준은 제어 명령에 대해 10ms 미만의 왕복 지연 시간과 비디오 스트리밍에 대해 100ms 미만을 규정합니다. 이는 WebSocket 프로토콜, 효율적인 직렬화(Protocol Buffers 또는 MessagePack) 및 네트워크 최적화를 통해 달성됩니다.

인증 및 권한 부여

모든 API 액세스는 OAuth 2.0 및 JWT 토큰을 사용하여 인증되고 권한이 부여됩니다. 역할 기반 액세스 제어(RBAC)는 외과의, 간호사, 기술자 및 관리자가 적절한 권한만 갖도록 보장합니다. 모든 API 호출은 감사 목적으로 로그에 기록됩니다.

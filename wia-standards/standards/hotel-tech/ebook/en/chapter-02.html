Chapter 2

Reservation Management & Rate Strategies

2.1 The Reservation Lifecycle

Every hotel reservation progresses through a well-defined lifecycle, from initial inquiry to final completion. Understanding this lifecycle is essential for effective reservation management and ensuring optimal guest experiences. Modern PMS systems track reservations through each state, triggering appropriate actions and notifications at each transition.

Reservation State Machine

Reservations can exist in multiple states, with specific rules governing transitions between states. The WIA-IND-016 standard defines a standardized state machine that ensures consistent handling across different systems.

Reservation State Flow: Inquiry → Quoted → Confirmed → Guaranteed ↓ Modified ←→ Confirmed ↓ ┌───────┴───────┐ ↓ ↓ Checked-In Cancelled ↓ ↓ Checked-Out No-Show ↓ Completed

Inquiry: The initial state when a guest requests information about availability and rates. No inventory is held at this stage. The PMS may track inquiries for future marketing analysis but doesn't commit any resources.

Quoted: A formal rate quote has been provided, typically with a limited validity period (24-48 hours). Some systems automatically convert quotes to confirmed reservations if the guest accepts within the validity window.

Confirmed: A reservation has been made and inventory allocated. The room is held for the guest, preventing it from being sold to others. At this stage, the reservation may or may not be guaranteed with payment.

Guaranteed: Payment information has been provided (credit card, deposit, or prepayment). This provides the hotel protection against no-shows and gives the reservation higher priority during overbooking situations.

Modified: Changes have been made to an existing confirmed reservation (dates, room type, rate, etc.). Modifications may trigger rate recalculation and availability checks. The system should maintain an audit trail of all modifications.

Checked-In: The guest has arrived and completed check-in procedures. A room number has been assigned, keys issued, and the folio activated for charging. This is an active reservation consuming hotel resources.

Checked-Out: The guest has departed, the final bill has been settled, and the room released back to inventory. The room status changes to dirty, triggering housekeeping workflows.

Cancelled: The reservation was cancelled before arrival. Depending on cancellation policy and timing, penalties may apply. Cancelled reservations free up inventory for sale to other guests.

No-Show: The guest failed to arrive without cancelling. The room was held but never used. No-show charges typically apply, and the reservation is closed.

Completed: Final state after checkout, payment verification, and any post-stay processes. Historical data is retained for reporting and guest profile updates.

Rate Calculation Methodology

The WIA-IND-016 standard defines a comprehensive rate calculation model that considers multiple factors:

Final Rate = Base Rate × Season Multiplier × DOW Multiplier ×
             LOS Multiplier × Occupancy Multiplier

Where:
- Base Rate: Room type standard price
- Season Multiplier: Seasonal adjustment (0.8 - 1.5)
- DOW Multiplier: Day of week factor (0.9 - 1.2)
- LOS Multiplier: Length of stay discount (0.85 - 1.0)
- Occupancy Multiplier: Demand-based factor (0.8 - 1.3)

Example Calculation:

Deluxe King Room Booking:
Base Rate: $250/night
High Season: × 1.3 = $325
Weekend (Friday): × 1.1 = $357.50
3+ Night Stay: × 0.95 = $339.63
High Occupancy: × 1.05 = $356.61

Final Quoted Rate: $357/night (rounded)

Total for 3 nights: $1,071
Taxes (12%): $128.52
Total Amount: $1,199.52

2.3 Cancellation Policies and Management

Cancellation policies balance guest flexibility with hotel revenue protection. The policy structure significantly impacts booking behavior and revenue risk.

Policy Framework

Flexible Policy:

  • Free cancellation up to 24-48 hours before arrival
  • One night charge if cancelled within penalty window
  • Full stay charge for no-shows
  • Typical for BAR and loyalty rates
  • Higher initial rate to compensate for risk

Moderate Policy:

  • Free cancellation up to 7 days before arrival
  • 50% charge if cancelled 3-7 days prior
  • 100% charge if cancelled within 3 days
  • Full stay plus one night penalty for no-shows
  • Common for corporate and group rates

Strict/Non-Refundable Policy:

  • No refunds under any circumstances
  • Significantly discounted rate (15-30% lower)
  • Immediate full payment required
  • May offer double loyalty points as compensation
  • Popular for advance purchase promotions

Cancellation Processing Logic

function processCancellation(reservation) {
    const now = new Date();
    const checkIn = new Date(reservation.checkIn);
    const hoursUntilCheckIn = (checkIn - now) / (1000 * 60 * 60);

    let penalty = 0;
    let refund = reservation.totalAmount;
    let processingFee = 0;

    // Check policy type
    if (reservation.policy === 'non-refundable') {
        penalty = reservation.totalAmount;
        refund = 0;
    } else if (reservation.policy === 'flexible') {
        if (hoursUntilCheckIn < 24) {
            penalty = reservation.nightlyRate; // 1 night penalty
            refund = reservation.totalAmount - penalty;
        }
    } else if (reservation.policy === 'moderate') {
        const daysUntilCheckIn = hoursUntilCheckIn / 24;

        if (daysUntilCheckIn < 3) {
            penalty = reservation.totalAmount; // 100%
            refund = 0;
        } else if (daysUntilCheckIn < 7) {
            penalty = reservation.totalAmount * 0.5; // 50%
            refund = reservation.totalAmount * 0.5;
        }
    }

    // Apply processing fee if refunding
    if (refund > 0) {
        processingFee = Math.min(25, refund * 0.02);
        refund -= processingFee;
    }

    return {
        approved: true,
        refundAmount: refund,
        penaltyAmount: penalty,
        processingFee: processingFee,
        refundMethod: reservation.paymentMethod,
        processingDays: 5-7
    };
}

Modification Business Rules

function canModifyReservation(reservation, modification) {
    const now = new Date();
    const checkIn = new Date(reservation.checkIn);
    const hoursUntilCheckIn = (checkIn - now) / (1000 * 60 * 60);

    // Cannot modify checked-in or checked-out reservations
    if (['checked-in', 'checked-out', 'completed'].includes(reservation.status)) {
        return {
            allowed: false,
            reason: 'Reservation is already in-house or completed'
        };
    }

    // Non-refundable reservations have limited modifications
    if (reservation.rateCode === 'PROMO' && modification.type === 'dates') {
        return {
            allowed: false,
            reason: 'Promotional rates cannot change dates'
        };
    }

    // Date changes within 24 hours require approval
    if (modification.type === 'dates' && hoursUntilCheckIn < 24) {
        return {
            allowed: true,
            requiresApproval: true,
            approvalLevel: 'manager',
            reason: 'Within 24-hour modification window'
        };
    }

    // Check availability for room type changes
    if (modification.type === 'roomType') {
        const available = checkAvailability(
            modification.newRoomType,
            reservation.checkIn,
            reservation.checkOut
        );

        if (!available) {
            return {
                allowed: false,
                reason: 'Requested room type not available'
            };
        }
    }

    return {
        allowed: true,
        requiresApproval: false
    };
}

Key Takeaways

  • Reservations progress through a defined state machine from inquiry to completion, with specific rules governing state transitions
  • Multiple rate plans targeting different market segments enable revenue optimization while serving diverse guest needs
  • Rate calculations consider base pricing, seasonal factors, day-of-week patterns, length of stay, and occupancy levels
  • Cancellation policies balance guest flexibility with hotel revenue protection, ranging from flexible to non-refundable
  • Modification management requires business rules that consider timing, rate type, and availability constraints
  • Comprehensive guest profiles enable personalization and efficient service delivery across multiple stays
  • The WIA-IND-016 standard provides consistent data models and processing logic for reservation management

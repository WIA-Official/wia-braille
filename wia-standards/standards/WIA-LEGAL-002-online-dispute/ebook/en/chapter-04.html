Chapter 4: Data Format Specifications

4.1 Introduction to ODR Data Standards

Phase 1 of the WIA-LEGAL-002 standard defines the data formats that enable interoperability across different ODR platforms. These standardized schemas ensure that dispute information can be exchanged, archived, and processed consistently regardless of the underlying platform technology.

The data format specifications cover four primary areas: dispute case records, settlement agreements, communication logs, and evidence metadata. Each schema is designed using JSON (JavaScript Object Notation) for maximum compatibility with modern web and mobile applications, with provisions for XML transformation when required for legacy system integration.

Design Principle: All data schemas follow the principle of "minimal required, maximal optional" to ensure basic interoperability while allowing platforms to extend schemas with additional fields for specialized use cases.

4.7 Data Validation and Quality

4.7.1 Required Field Validation

WIA-LEGAL-002 compliant platforms must validate all required fields before accepting dispute submissions. The validation rules ensure data quality and completeness:

  • Email addresses: Must conform to RFC 5322 format
  • Phone numbers: Must include country code in E.164 format
  • Currency amounts: Must specify ISO 4217 currency code
  • Dates: Must use ISO 8601 format (YYYY-MM-DDTHH:MM:SSZ)
  • Country codes: Must use ISO 3166-1 alpha-2 format
  • Language codes: Must use BCP 47 format (e.g., en-US, es-MX)

4.7.2 Data Retention and Privacy

Data retention policies must balance legal requirements with privacy rights:

Data Type Minimum Retention Maximum Retention Privacy Notes
Dispute Cases 7 years Indefinite (anonymized) PII must be redacted after retention period
Settlement Agreements 10 years Indefinite Legally binding documents, extended retention
Communication Logs 3 years 7 years Confidential caucus communications may be deleted earlier
Evidence Files 7 years 10 years Hash anchors retained permanently even if files deleted

  • WIA-LEGAL-002 defines standardized JSON schemas for dispute cases, settlements, communications, and evidence
  • The dispute case schema captures all parties, dispute details, and resolution method in a uniform format

  • Communication logs provide complete audit trails while preserving confidentiality
  • Evidence metadata ensures chain of custody and admissibility
  • Comprehensive validation rules ensure data quality and compliance
  • Data retention policies balance legal requirements with privacy rights

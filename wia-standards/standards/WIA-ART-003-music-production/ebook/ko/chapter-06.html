Phase 3: 세션 교환 프로토콜

WIA-ART-003 음악 제작 표준

6.1 세션 파일 형식

WIA 세션 형식(.wias)은 음악 제작 프로젝트의 완전하고 이식 가능한 표현을 제공합니다. 이 형식은 WIA 호환 DAW에서 세션을 완전히 재구성하는 데 필요한 모든 요소를 캡처합니다.

세션 패키지 구조

MyProject.wias (ZIP 아카이브)
├── session.json          # 세션 문서
├── tracks/               # 트랙 정의
│   ├── track-001.json
│   ├── track-002.json
│   └── ...
├── audio/                # 오디오 파일
│   ├── audio-001.wac
│   └── ...
├── midi/                 # MIDI 파일
│   ├── midi-001.wiam
│   └── ...
├── plugins/              # 플러그인 상태
│   ├── plugin-001.wiap
│   └── ...
├── automation/           # 오토메이션 데이터
│   └── automation.json
├── markers/              # 마커 및 리전
│   └── markers.json
└── assets/               # 추가 에셋
    ├── artwork.png
    └── notes.txt
📦 패키지 장점
  • 자체 포함: 모든 에셋이 단일 파일에 포함
  • 이식성: 쉬운 전송을 위한 표준 ZIP 압축
  • 스트리밍 가능: 전체 다운로드 없이 점진적 로드
  • 버전 관리: 리비전 히스토리로 모든 변경 추적

6.2 세션 문서 스키마

session.json 파일에는 트랙 구성, 라우팅, 템포 및 글로벌 설정을 포함한 전체 프로젝트 구조를 설명하는 마스터 문서가 포함됩니다.

세션 메타데이터 필드

필드타입설명
version문자열WIA 세션 형식 버전
uuidUUID고유 세션 식별자
name문자열프로젝트 표시 이름
createdISO 8601생성 타임스탬프
modifiedISO 8601마지막 수정 타임스탬프
collaborators배열협력자 UUID 목록
revision정수세션 리비전 번호

6.3 트랙 표현

세션의 각 트랙은 타입, 클립, 이펙트 체인, 라우팅 및 오토메이션을 포함하여 완전히 설명됩니다. 트랙 정의는 모든 일반적인 DAW 트랙 타입을 지원합니다.

트랙 유형

유형설명포함 내용
audio오디오 녹음/재생오디오 클립, 이펙트
instrument가상 악기MIDI 클립, 악기, 이펙트
midiMIDI 출력 전용MIDI 클립, 출력 라우팅
aux보조/리턴이펙트 체인만
group트랙 그룹화합산 오디오, 이펙트
folder조직용자식 트랙 참조

6.4 라우팅 그래프

WIA-ART-003은 센드, 사이드체인 및 하드웨어 I/O를 포함한 복잡한 신호 라우팅을 캡처합니다. 라우팅 그래프는 모든 라우팅 구성을 표현할 수 있는 DAG(Directed Acyclic Graph)로 저장됩니다.

라우팅 노드 유형

  • Source: 오디오 입력, MIDI 입력 또는 클립 재생
  • Processor: 플러그인 이펙트, 악기 출력
  • Mixer: 볼륨, 팬, 합산
  • Output: 마스터 버스, 하드웨어 출력

6.5 오토메이션 형식

오토메이션 데이터는 높은 정밀도로 저장되며 여러 커브 타입을 지원합니다. 형식은 효율적인 저장 및 실시간 재생을 가능하게 하면서 창작 의도를 보존합니다.

커브 유형

타입설명파라미터
step즉시 점프없음
linear직선없음
exponential곡선 지수지수
logarithmic곡선 로그베이스
bezier사용자 정의 커브제어점
scurveS자 커브텐션

6.6 장 요약

✅ 핵심 정리
  • WIA 세션 형식이 이식 가능한 아카이브에 모든 프로젝트 요소 패키징
  • 세션 문서가 완전한 프로젝트 구조 및 설정 캡처
  • 트랙 표현이 모든 일반적인 DAW 트랙 유형 지원
  • 라우팅 그래프가 복잡한 신호 흐름 구성 보존
  • 오토메이션 형식이 여러 유형의 정밀한 커브 유지

WIA-ART-003 음악 제작 표준

5.1 범용 플러그인 상태

WIA 플러그인 상태 사양은 플러그인 구성이 다른 호스트 애플리케이션 간에 전송될 수 있도록 합니다. 기존 플러그인 형식을 대체하는 대신, WIA-ART-003은 표준화된 메타데이터 및 파라미터 매핑으로 래핑합니다.

상태 구조

{
  "wia_plugin_state": {
    "version": "1.0",
    "plugin_id": {
      "vendor": "FabFilter",
      "name": "Pro-Q 3",
      "version": "3.21",
      "formats": {
        "vst3": "XXXXXXXX-XXXX-XXXX-XXXX",
        "au": "aufx:FabQ:FaFi",
        "aax": "com.fabfilter.pro-q-3"
      }
    },
    "semantic_params": [...],
    "native_state": {
      "format": "vst3",
      "blob": "base64..."
    }
  }
}
🔌 형식 변환

다른 플러그인 형식을 사용하는 호스트 간 전송 시:

  1. 시맨틱 파라미터가 사람이 읽을 수 있는 매핑 제공
  2. 네이티브 상태가 정확한 플러그인 구성 보존
  3. 네이티브 형식을 사용할 수 없는 경우 시맨틱 파라미터가 설정 재구성

5.2 시맨틱 파라미터 매핑

WIA-ART-003은 일반적인 플러그인 카테고리에 대한 표준화된 파라미터 식별자를 정의합니다. 이를 통해 동일한 기능을 수행하는 다른 플러그인 간에도 의미 있는 설정 전송이 가능합니다.

이퀄라이저 파라미터

WIA ID설명범위
eq.band[n].enabled밴드 활성 상태boolean
eq.band[n].type필터 타입enum: bell, lowshelf, highshelf...
eq.band[n].frequency중심 주파수20-20000 Hz
eq.band[n].gain게인 조정-24 ~ +24 dB
eq.band[n].q대역폭/Q 팩터0.1 ~ 30

컴프레서 파라미터

WIA ID설명범위
comp.threshold스레숄드 레벨-60 ~ 0 dB
comp.ratio압축 비율1:1 ~ inf:1
comp.attack어택 타임0.01 ~ 500 ms
comp.release릴리즈 타임10 ~ 5000 ms
comp.makeup출력 게인-12 ~ +24 dB

5.3 플러그인 검색 프로토콜

WIA 플러그인 검색 프로토콜은 호스트가 형식 경계를 넘어 동등한 플러그인을 찾을 수 있도록 합니다. 이는 협력자가 다른 플랫폼을 사용할 때 세션 이식성에 필수적입니다.

매칭 기준

  • 플러그인 카테고리 (EQ, 컴프레서, 리버브 등)
  • 지원되는 파라미터 타입 및 범위
  • 처리 품질 특성
  • 사용자 선호도 가중치

5.4 프리셋 교환

WIA-ART-003은 플러그인 간 범용 프리셋 교환을 가능하게 합니다. 한 플러그인에서 생성된 프리셋이 다른 공급업체의 호환 플러그인에서 작동하도록 변환될 수 있습니다.

프리셋 패키지 형식

WIA 프리셋 패키지 (.wiap)
├── manifest.json
│   ├── name: "Warm Vocal"
│   ├── category: "vocal"
│   ├── creator: "Producer Name"
│   └── original_plugin: {...}
├── semantic_preset.json
│   └── (시맨틱 파라미터 값)
├── native/
│   ├── fabfilter-pro-q-3.fxp
│   ├── waves-ssl-eq.xml
│   └── (기타 네이티브 형식)
└── preview.png

5.5 SDK 구현

WIA 플러그인 SDK는 DAW 애플리케이션에 플러그인 상태 관리를 통합하기 위한 TypeScript/JavaScript 구현을 제공합니다.

SDK 기능

기능메서드설명
직렬화serialize()완전한 플러그인 상태 캡처
역직렬화deserialize()플러그인 상태 복원
비교compare()두 플러그인 상태 비교
변환translate()플러그인 타입 간 변환
검색findAlternatives()호환 플러그인 찾기

5.6 장 요약

✅ 핵심 정리
  • WIA 플러그인 상태가 표준화된 메타데이터로 네이티브 형식 래핑
  • 시맨틱 파라미터 매핑이 다른 플러그인 간 변환 가능
  • 플러그인 검색 프로토콜이 형식 간 호환 대안 찾기
  • 범용 프리셋 교환이 다른 공급업체의 플러그인 간 작동
  • SDK가 DAW 개발자를 위한 간단한 통합 제공

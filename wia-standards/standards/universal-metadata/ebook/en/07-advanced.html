7.1 AI and Machine Learning Integration

Artificial intelligence and machine learning can dramatically enhance metadata quality, automate creation, and enable intelligent discovery. Universal Metadata provides hooks for AI integration at multiple levels.

Automated Metadata Generation

import { AIMetadataGenerator } from '@wia/universal-metadata';

const generator = new AIMetadataGenerator({
  model: 'claude-opus-4',
  provider: 'anthropic'
});

// Generate metadata from content
const content = await readFile('document.pdf');
const metadata = await generator.generate(content, {
  language: 'en',
  domain: 'research',
  includeKeywords: true,
  extractEntities: true,
  generateSummary: true
});

console.log(metadata);
// {
//   title: 'Machine Learning Applications in Healthcare',
//   description: 'This paper explores various applications...',
//   keywords: ['machine learning', 'healthcare', 'diagnosis'],
//   entities: ['neural networks', 'patient data', 'prediction models'],
//   summary: 'A comprehensive review of ML applications...',
//   suggestedDomain: 'healthcare',
//   confidence: 0.92
// }

Semantic Embedding Search

Use vector embeddings for semantic similarity search beyond keyword matching. This enables finding conceptually related content even when exact terms differ.

import { SemanticSearch } from '@wia/universal-metadata';

const search = new SemanticSearch({
  embeddingModel: 'text-embedding-3-large',
  vectorDB: 'pinecone'
});

// Index metadata with embeddings
await search.indexWithEmbeddings(metadata);

// Semantic search
const query = "How does AI improve medical diagnosis?";
const results = await search.semanticSearch(query, {
  limit: 10,
  minSimilarity: 0.7
});

// Results include semantically similar content
// even if exact keywords don't match

7.2 Recommendation Systems

Build sophisticated recommendation engines using metadata similarity, collaborative filtering, and hybrid approaches.

import { MetadataRecommender } from '@wia/universal-metadata';

const recommender = new MetadataRecommender({
  strategy: 'hybrid', // content-based + collaborative
  weights: {
    contentSimilarity: 0.6,
    collaborativeFiltering: 0.3,
    popularityBoost: 0.1
  }
});

// Get recommendations based on user's viewing history
const recommendations = await recommender.recommend({
  userId: 'user-12345',
  basedOn: ['doc-1', 'doc-2', 'doc-3'],
  limit: 10,
  filters: {
    domain: 'research',
    language: 'en',
    minQuality: 0.8
  }
});

console.log(recommendations);
// [
//   { id: 'doc-456', score: 0.94, reason: 'Similar topics and keywords' },
//   { id: 'doc-789', score: 0.91, reason: 'Users also viewed' },
//   ...
// ]

7.3 Temporal Metadata and Versioning

Track metadata changes over time, maintain version history, and enable temporal queries to see how metadata evolved.

import { TemporalMetadata } from '@wia/universal-metadata';

const temporal = new TemporalMetadata({
  storage: 'postgresql',
  versionStrategy: 'snapshot' // or 'delta'
});

// Save versioned metadata
await temporal.save(metadata, {
  versionTag: 'v1.0',
  changeSummary: 'Initial creation',
  author: 'jane@example.com'
});

// Update creates new version
metadata.setDescription('Updated description...');
await temporal.save(metadata, {
  versionTag: 'v1.1',
  changeSummary: 'Enhanced description',
  author: 'john@example.com'
});

// Query version history
const versions = await temporal.getVersions(metadata.id);
console.log(versions);
// [
//   { version: 'v1.1', timestamp: '2025-01-20T10:00:00Z', author: 'john@example.com' },
//   { version: 'v1.0', timestamp: '2025-01-15T09:00:00Z', author: 'jane@example.com' }
// ]

// Get metadata at specific point in time
const historical = await temporal.getAtTime(metadata.id, '2025-01-16T00:00:00Z');

// Compare versions
const diff = await temporal.compare('v1.0', 'v1.1');
console.log(diff);
// {
//   changed: ['description'],
//   added: [],
//   removed: [],
//   details: { description: { old: '...', new: '...' } }
// }

7.4 Geospatial Metadata

Add geographic context to metadata for location-based discovery and visualization.

import { GeospatialMetadata } from '@wia/universal-metadata';

const metadata = new MetadataBuilder()
  .setTitle('Climate Study: Pacific Northwest')
  .setDomain('research')

  // Add geospatial context
  .setGeospatial({
    type: 'BoundingBox',
    coordinates: {
      north: 49.0,
      south: 42.0,
      east: -116.0,
      west: -125.0
    },
    coordinateSystem: 'WGS84'
  })

  // Or point location
  .setGeospatial({
    type: 'Point',
    coordinates: {
      latitude: 47.6062,
      longitude: -122.3321
    },
    placeName: 'Seattle, WA'
  })

  .build();

// Geospatial queries
const nearbyResults = await search.findNear({
  latitude: 47.6,
  longitude: -122.3,
  radius: 50, // km
  limit: 10
});

const withinRegion = await search.findWithinBounds({
  north: 49.0,
  south: 42.0,
  east: -116.0,
  west: -125.0
});

7.5 Provenance and Lineage Tracking

Track the origin, transformations, and derivations of data and metadata using W3C PROV standards.

import { ProvenanceTracker } from '@wia/universal-metadata';

const provenance = new ProvenanceTracker();

// Record metadata creation
await provenance.recordActivity({
  id: 'activity-create-001',
  type: 'Creation',
  agent: 'jane@example.com',
  timestamp: new Date(),
  generated: metadata.id
});

// Record transformation
await provenance.recordActivity({
  id: 'activity-transform-001',
  type: 'Transformation',
  agent: 'data-pipeline-v2',
  timestamp: new Date(),
  used: ['source-dataset-A', 'source-dataset-B'],
  generated: 'derived-dataset-C'
});

// Query provenance
const history = await provenance.getLineage(metadata.id);
console.log(history);
// {
//   entity: 'doc-12345',
//   derivedFrom: ['source-doc-1', 'source-doc-2'],
//   generatedBy: 'activity-create-001',
//   wasAttributedTo: 'jane@example.com',
//   derivations: ['doc-456', 'doc-789']
// }

// Visualize provenance graph
const graph = await provenance.getGraph(metadata.id, {
  depth: 3,
  includeAgents: true,
  includeActivities: true
});

7.6 Access Control and Privacy

Implement fine-grained access control and privacy-preserving metadata for sensitive resources.

import { AccessControlManager } from '@wia/universal-metadata';

const acl = new AccessControlManager();

// Set access control
await acl.setPolicy(metadata.id, {
  visibility: 'restricted',
  permissions: {
    read: ['group:researchers', 'user:alice@example.com'],
    write: ['user:alice@example.com'],
    delete: ['user:alice@example.com']
  },
  conditions: {
    timeRange: {
      start: '2025-01-01',
      end: '2025-12-31'
    },
    ipWhitelist: ['10.0.0.0/8'],
    requireMFA: true
  }
});

// Privacy-preserving metadata
const publicMetadata = metadata.getPublicView({
  redactFields: ['creator.email', 'sensitive_info'],
  anonymize: ['creator.name'],
  aggregateOnly: ['statistics']
});

// Check access
const hasAccess = await acl.checkAccess({
  resourceId: metadata.id,
  user: 'bob@example.com',
  action: 'read',
  context: { ip: '10.0.1.50', time: new Date() }
});

console.log(hasAccess);
// {
//   allowed: false,
//   reason: 'User not in read permission list'
// }

7.7 Real-World Use Cases

Digital Asset Management at Scale

A media company manages 10 million assets (images, videos, audio) with Universal Metadata enabling multi-faceted discovery, automated tagging, rights management, and usage tracking across global teams.

Research Data Repository

A university research repository uses Universal Metadata to describe datasets, publications, code, and supplementary materials with rich provenance, version tracking, and DOI integration for citation.

Cultural Heritage Digitization

Museums worldwide collaborate using Universal Metadata as an interchange format, enabling federated search across collections while respecting specialized cataloging needs and multilingual descriptions.

Healthcare Information Exchange

Healthcare providers use Universal Metadata to describe clinical documents, imaging studies, and research data with HIPAA-compliant access control and comprehensive quality metrics.

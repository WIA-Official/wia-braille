8.1 Complete Schema Reference

Core Fields Specification

Field Type Required Description
idString (URI)YesGlobally unique identifier
titleStringYesPrimary name or title (10-200 chars)
descriptionStringRecommendedDetailed description (100-2000 chars)
languageStringYesISO 639-1/639-3 language code
domainStringYesPrimary subject domain
contentTypeStringRecommendedMIME type or category
createdDateTimeYesISO 8601 creation timestamp
modifiedDateTimeYesISO 8601 modification timestamp
creatorString/ObjectRecommendedCreator name or structured entity
keywordsArray[String]Recommended3-20 searchable terms
versionStringOptionalVersion identifier
licenseString/ObjectRecommendedUsage rights and licensing

8.2 API Reference

REST API Endpoints

MethodEndpointDescription
POST/api/metadataCreate new metadata record
GET/api/metadata/:idRetrieve metadata by ID
PUT/api/metadata/:idUpdate existing metadata
DELETE/api/metadata/:idDelete metadata record
GET/api/metadataSearch and filter metadata
POST/api/metadata/validateValidate metadata against schema
POST/api/metadata/transformTransform to other formats
GET/api/metadata/:id/qualityCalculate quality metrics

TypeScript SDK Classes

  • MetadataBuilder: Fluent API for creating metadata
  • UniversalMetadata: Core metadata class with validation
  • MetadataValidator: Schema validation and quality checks
  • QualityAnalyzer: Calculate quality metrics
  • MetadataSearch: Search and discovery operations
  • MetadataTransformer: Convert between formats
  • MetadataService: High-level service for CRUD operations

8.3 Domain Vocabulary

Standard Domains

Universal Metadata defines standard domains for common use cases:

  • education: Educational resources, courses, tutorials
  • healthcare: Medical records, clinical studies, health data
  • research: Academic papers, datasets, experiments
  • finance: Financial reports, market data, transactions
  • technology: Software, documentation, specifications
  • media: News, entertainment, creative works
  • government: Public records, legislation, regulations
  • business: Corporate documents, products, services
  • culture: Art, heritage, historical artifacts
  • environment: Climate data, conservation, sustainability

Content Types

  • document, image, video, audio, dataset, software, website, email, presentation, spreadsheet, 3d-model, virtual-reality, augmented-reality

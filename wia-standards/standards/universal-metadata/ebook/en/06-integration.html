6.1 Mapping to Dublin Core

Dublin Core is one of the most widely adopted metadata standards. Universal Metadata provides bidirectional mapping to all 15 Dublin Core elements, enabling seamless interoperability with Dublin Core-based systems.

import { DublinCoreMapper } from '@wia/universal-metadata';

const mapper = new DublinCoreMapper();

// Convert Universal Metadata to Dublin Core
const dublinCore = mapper.toD ublinCore(universalMetadata);

console.log(dublinCore);

6.2 Schema.org Integration

Schema.org markup is essential for web discoverability and search engine optimization. Universal Metadata can be seamlessly transformed into Schema.org JSON-LD for embedding in web pages.

import { SchemaOrgMapper } from '@wia/universal-metadata';

const mapper = new SchemaOrgMapper();

const schemaOrg = mapper.toSchemaOrg(metadata);

// Embed in HTML
const script = `
<script type="application/ld+json">
${JSON.stringify(schemaOrg, null, 2)}
</script>
`;

// Example Schema.org output
{
  "@context": "https://schema.org",
  "@type": "ScholarlyArticle",
  "name": "Research Paper on Climate Change",
  "author": {
    "@type": "Person",
    "name": "Dr. Jane Smith"
  },
  "datePublished": "2025-01-15",
  "inLanguage": "en",
  "about": "climate change",
  "keywords": ["climate change", "environment", "research"]
}

6.3 Legacy System Migration

Migrating from legacy metadata systems requires careful planning, data transformation, quality assessment, and validation. Universal Metadata provides tools and best practices for successful migration projects.

Migration Planning

  • Inventory Assessment: Catalog all existing metadata records and schemas
  • Field Mapping: Map legacy fields to Universal Metadata fields
  • Quality Baseline: Assess current metadata quality
  • Transformation Strategy: Plan data transformation and enrichment
  • Validation Rules: Define acceptance criteria for migrated data
  • Rollback Plan: Prepare for potential migration issues

Migration Implementation

import { MetadataMigrator } from '@wia/universal-metadata';

const migrator = new MetadataMigrator({
  source: 'legacy-database',
  target: 'universal-metadata',
  mappings: {
    'legacy_id': 'id',
    'legacy_name': 'title',
    'legacy_summary': 'description',
    'legacy_lang': 'language',
    'legacy_category': 'domain'
  },
  transformations: {
    language: (value) => value.toLowerCase().slice(0, 2),
    domain: (value) => domainMapping[value] || 'general'
  },
  enrichment: {
    calculateQuality: true,
    generateKeywords: true,
    normalizeValues: true
  }
});

// Execute migration
const result = await migrator.migrate({
  batchSize: 1000,
  parallel: 5,
  validateEach: true
});

console.log(result);
// {
//   total: 50000,
//   migrated: 48500,
//   failed: 1500,
//   duration: '2h 15m',
//   qualityImprovement: '+12%'
// }

6.4 Content Management System Integration

Integrate Universal Metadata with popular CMS platforms like WordPress, Drupal, and custom systems. Metadata can enhance content discoverability, enable better organization, and improve SEO.

// WordPress integration example
class WIA_Universal_Metadata_Plugin {
  public function __construct() {
    add_action('save_post', [$this, 'save_metadata']);
    add_filter('the_content', [$this, 'inject_schema_org']);
  }

  public function save_metadata($post_id) {
    $metadata = new UniversalMetadata([
      'id' => get_permalink($post_id),
      'title' => get_the_title($post_id),
      'description' => get_the_excerpt($post_id),
      'language' => get_post_meta($post_id, 'language', true),
      'domain' => wp_get_post_categories($post_id)[0],
      'keywords' => wp_get_post_tags($post_id),
      'creator' => get_the_author_meta('display_name', $post->post_author),
      'created' => get_the_date('c', $post_id),
      'modified' => get_the_modified_date('c', $post_id)
    ]);

    update_post_meta($post_id, 'wia_metadata', $metadata->toJSON());
  }

  public function inject_schema_org($content) {
    $metadata = get_post_meta(get_the_ID(), 'wia_metadata', true);
    $schemaOrg = (new SchemaOrgMapper())->toSchemaOrg($metadata);

    return '<script type="application/ld+json">'
         . json_encode($schemaOrg)
         . '</script>'
         . $content;
  }
}

6.5 API Gateway and Middleware

Build API gateways that translate between Universal Metadata and various client expectations, providing a unified interface while supporting multiple metadata standards and formats.

import express from 'express';
import { MetadataAdapter } from '@wia/universal-metadata';

const app = express();
const adapter = new MetadataAdapter();

// GET with format negotiation
app.get('/api/metadata/:id', async (req, res) => {
  const metadata = await getMetadata(req.params.id);
  const format = req.query.format || req.headers.accept;

  switch (format) {
    case 'application/ld+json':
      res.json(adapter.toSchemaOrg(metadata));
      break;
    case 'application/xml':
      res.type('xml').send(adapter.toXML(metadata));
      break;
    case 'application/rdf+xml':
      res.type('xml').send(adapter.toRDF(metadata));
      break;
    default:
      res.json(metadata.toJSON());
  }
});

// Support multiple input formats
app.post('/api/metadata', async (req, res) => {
  let metadata;

  if (req.is('application/ld+json')) {
    metadata = adapter.fromSchemaOrg(req.body);
  } else if (req.is('application/xml')) {
    metadata = adapter.fromXML(req.body);
  } else {
    metadata = new UniversalMetadata(req.body);
  }

  await saveMetadata(metadata);
  res.status(201).json(metadata);
});

6.6 Federated Search and Harvesting

Enable federated search across multiple repositories using Universal Metadata as a common interchange format. Implement OAI-PMH harvesting for interoperability with digital repositories.

// OAI-PMH harvester example
import { OAIPMHHarvester } from '@wia/universal-metadata';

const harvester = new OAIPMHHarvester({
  repositories: [
    'https://repository1.org/oai',
    'https://repository2.org/oai',
    'https://repository3.org/oai'
  ],
  format: 'oai_dc', // Dublin Core
  setSpec: 'research',
  from: '2024-01-01'
});

// Harvest and convert to Universal Metadata
const records = await harvester.harvest();

records.forEach(record => {
  const universal = adapter.fromDublinCore(record);
  const quality = analyzer.analyze(universal);
  universal.setQualityMetrics(quality);
  saveMetadata(universal);
});

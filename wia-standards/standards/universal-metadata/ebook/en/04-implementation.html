CHAPTER 4

Implementation Guide

This chapter provides practical, step-by-step guidance for implementing Universal Metadata in your applications. We'll cover the TypeScript SDK, REST API, CLI tools, and complete working examples you can adapt for your needs.

4.1 Getting Started with the TypeScript SDK

Installation

The official Universal Metadata SDK is available via npm: 

npm install @wia/universal-metadata

# Or with yarn
yarn add @wia/universal-metadata

# Or with pnpm
pnpm add @wia/universal-metadata

Basic Usage

Import and create your first metadata record: 

import { MetadataBuilder, UniversalMetadata } from '@wia/universal-metadata';

// Create metadata using the builder pattern
const metadata = new MetadataBuilder()
  .setId('https://example.org/resources/doc-12345')
  .setTitle('Introduction to Machine Learning')
  .setDescription('A comprehensive guide covering fundamental concepts...')
  .setLanguage('en')
  .setDomain('education')
  .setContentType('document')
  .addKeyword('machine learning')
  .addKeyword('artificial intelligence')
  .addKeyword('tutorial')
  .setCreator('Dr. Jane Smith')
  .setQualityMetrics({
    completeness: 0.95,
    accuracy: 0.98,
    consistency: 0.96,
    timeliness: 1.0
  })
  .build();

console.log(metadata.toJSON());

Validation

Validate metadata against the standard: 

import { MetadataValidator } from '@wia/universal-metadata';

const validator = new MetadataValidator();
const result = validator.validate(metadata);

if (result.isValid) {
  console.log('✓ Metadata is valid');
} else {
  console.error('✗ Validation errors:', result.errors);
  console.warn('⚠ Warnings:', result.warnings);
}

// Example validation result
{
  isValid: true,
  errors: [],
  warnings: [
    'Recommended field "license" is missing',
    'Description could be more detailed (current: 150 chars, recommended: 200+)'
  ],
  score: 0.95
}

4.2 Working with Multilingual Metadata

Universal Metadata provides first-class support for multilingual content: 

import { MultilingualMetadata } from '@wia/universal-metadata';

const metadata = new MetadataBuilder()
  .setId('doc-12345')
  .setLanguage('en')
  .setTitle('Quantum Computing Basics')

  // Add translations
  .addTitleTranslation('ko', '양자 컴퓨팅 기초')
  .addTitleTranslation('ja', '量子コンピューティングの基礎')
  .addTitleTranslation('zh', '量子计算基础')
  .addTitleTranslation('es', 'Fundamentos de Computación Cuántica')

  .setDescription('An introduction to quantum computing principles...')
  .addDescriptionTranslation('ko', '양자 컴퓨팅 원리에 대한 소개...')
  .addDescriptionTranslation('ja', '量子コンピューティングの原理の紹介...')

  .build();

// Get metadata in specific language
const koreanMetadata = metadata.getTranslation('ko');
console.log(koreanMetadata.title); // "양자 컴퓨팅 기초"

// Get all available languages
const languages = metadata.getAvailableLanguages();
console.log(languages); // ['en', 'ko', 'ja', 'zh', 'es']

4.4 Search and Discovery Implementation

Implement search functionality using the SDK: 

import { MetadataSearch, SearchQuery } from '@wia/universal-metadata';

// Initialize search engine (connects to Elasticsearch or other backend)
const search = new MetadataSearch({
  host: 'localhost:9200',
  index: 'universal-metadata'
});

// Index metadata
await search.index(metadata);

// Build search query
const query = new SearchQuery()
  .setFullText('machine learning')
  .setDomain('education')
  .setLanguage('en')
  .setMinQuality(0.8)
  .setDateRange({
    field: 'created',
    from: '2024-01-01',
    to: '2025-12-31'
  })
  .setFacets(['domain', 'contentType', 'language'])
  .setPageSize(20)
  .setPage(1);

// Execute search
const results = await search.query(query);

4.6 REST API Implementation

Build a REST API for metadata operations: 

import express from 'express';
import { MetadataService } from '@wia/universal-metadata';

const app = express();
app.use(express.json());

const metadataService = new MetadataService({
  database: 'postgresql://...',
  search: 'http://localhost:9200'
});

// Create metadata
app.post('/api/metadata', async (req, res) => {
  try {
    const metadata = await metadataService.create(req.body);
    res.status(201).json(metadata);
  } catch (error) {
    res.status(400).json({ error: error.message });
  }
});

// Get metadata by ID
app.get('/api/metadata/:id', async (req, res) => {
  const metadata = await metadataService.findById(req.params.id);
  if (!metadata) {
    return res.status(404).json({ error: 'Not found' });
  }
  res.json(metadata);
});

// Update metadata
app.put('/api/metadata/:id', async (req, res) => {
  const metadata = await metadataService.update(
    req.params.id,
    req.body
  );
  res.json(metadata);
});

// Delete metadata
app.delete('/api/metadata/:id', async (req, res) => {
  await metadataService.delete(req.params.id);
  res.status(204).send();
});

// Search metadata
app.get('/api/metadata', async (req, res) => {
  const query = {
    text: req.query.q,
    domain: req.query.domain,
    language: req.query.language,
    minQuality: parseFloat(req.query.minQuality || '0'),
    page: parseInt(req.query.page || '1'),
    pageSize: parseInt(req.query.pageSize || '20')
  };

  const results = await metadataService.search(query);
  res.json(results);
});

app.listen(3000, () => {
  console.log('Metadata API running on port 3000');
});

4.7 CLI Tools Usage

Use command-line tools for metadata operations: 

# Create metadata from JSON file
wia-metadata create --file metadata.json

# Validate metadata
wia-metadata validate --file metadata.json

# Search metadata
wia-metadata search --query "machine learning" --domain education

# Export to different format
wia-metadata export --id doc-12345 --format dublincore

# Calculate quality metrics
wia-metadata quality --file metadata.json

# Bulk import from CSV
wia-metadata import --file metadata.csv --format csv

# Generate metadata template
wia-metadata template --domain healthcare --output template.json

4.8 Complete Example: Building a Metadata Management System

Here's a complete example building a simple metadata management system: 

import {
  MetadataBuilder,
  MetadataService,
  MetadataValidator,
  QualityAnalyzer,
  MetadataSearch
} from '@wia/universal-metadata';

class MetadataManager {
  private service: MetadataService;
  private validator: MetadataValidator;
  private analyzer: QualityAnalyzer;
  private search: MetadataSearch;

  constructor(config) {
    this.service = new MetadataService(config);
    this.validator = new MetadataValidator();
    this.analyzer = new QualityAnalyzer();
    this.search = new MetadataSearch(config.search);
  }

  async createMetadata(data) {
    // Build metadata
    const builder = new MetadataBuilder();
    Object.entries(data).forEach(([key, value]) => {
      builder.set(key, value);
    });

    const metadata = builder.build();

    // Validate
    const validation = this.validator.validate(metadata);
    if (!validation.isValid) {
      throw new Error('Validation failed: ' + validation.errors.join(', '));
    }

    // Calculate quality
    const quality = this.analyzer.analyze(metadata);
    metadata.setQualityMetrics(quality);

    // Save to database
    await this.service.create(metadata);

    // Index for search
    await this.search.index(metadata);

    return metadata;
  }

  async updateMetadata(id, updates) {
    // Get existing metadata
    const metadata = await this.service.findById(id);
    if (!metadata) {
      throw new Error('Metadata not found');
    }

    // Apply updates
    Object.entries(updates).forEach(([key, value]) => {
      metadata.set(key, value);
    });

    // Update modification timestamp
    metadata.setModified(new Date());

    // Recalculate quality
    const quality = this.analyzer.analyze(metadata);
    metadata.setQualityMetrics(quality);

    // Save changes
    await this.service.update(id, metadata);

    // Reindex
    await this.search.update(metadata);

    return metadata;
  }

  async searchMetadata(query) {
    return await this.search.query(query);
  }

  async deleteMetadata(id) {
    await this.service.delete(id);
    await this.search.delete(id);
  }

  async exportMetadata(id, format) {
    const metadata = await this.service.findById(id);
    const transformer = new MetadataTransformer();

    switch (format) {
      case 'dublincore':
        return transformer.toDublinCore(metadata);
      case 'schema.org':
        return transformer.toSchemaOrg(metadata);
      case 'xml':
        return transformer.toXML(metadata);
      default:
        return metadata.toJSON();
    }
  }
}

// Usage
const manager = new MetadataManager({
  database: process.env.DATABASE_URL,
  search: { host: process.env.ELASTICSEARCH_URL }
});

// Create metadata
const metadata = await manager.createMetadata({
  title: 'Research Paper: Climate Change Impact',
  description: 'A comprehensive study on climate change...',
  domain: 'research',
  language: 'en',
  keywords: ['climate change', 'environment', 'research']
});

// Search
const results = await manager.searchMetadata({
  text: 'climate',
  domain: 'research'
});

// Export
const dublinCore = await manager.exportMetadata(
  metadata.id,
  'dublincore'
);

4.9 Best Practices

Follow these best practices for robust implementations:

  • Always validate: Validate metadata before saving to catch errors early
  • Calculate quality: Run quality analysis to maintain high standards
  • Version control: Track changes and maintain version history
  • Index consistently: Keep search indices in sync with primary storage
  • Cache strategically: Cache frequently accessed metadata
  • Handle errors gracefully: Provide clear error messages and recovery paths
  • Log operations: Maintain audit logs for compliance and debugging
  • Test thoroughly: Write tests for validation, quality, and transformations

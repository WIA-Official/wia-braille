8.1 Digital Twin Technology

A Digital Twin is a virtual representation of a physical asset that synchronizes with real-time sensor data, enabling simulation, prediction, and optimization. The concept originated at NASA for spacecraft monitoring and has become essential for Industry 4.0 manufacturing.

8.1.2 Digital Twin Implementation

// TypeScript Digital Twin for Industrial Motor
interface MotorState {
  temperature: number;     // °C
  vibration: number;       // mm/s RMS
  current: number;         // Amperes
  speed: number;           // RPM
  power: number;           // kW
  operatingHours: number;  // Total runtime
  timestamp: Date;
}

interface MotorModel {
  thermalCapacity: number;          // J/°C
  thermalResistance: number;        // °C/W
  nominalSpeed: number;             // RPM
  nominalPower: number;             // kW
  bearingLifeL10: number;           // hours (10% failure rate)
  windingResistanceOhms: number;    // Ω
}

class DigitalTwinMotor {
  private physicalState: MotorState;
  private model: MotorModel;
  private predictedRUL: number = 0;  // Remaining Useful Life (hours)

  constructor(motorId: string, model: MotorModel) {
    this.model = model;
    this.subscribeToSensors(motorId);
  }

  private subscribeToSensors(motorId: string) {
    // Real-time sensor data synchronization
    mqttClient.subscribe(`factory/motors/${motorId}/telemetry`);

    mqttClient.on('message', (topic, message) => {
      if (topic.includes(motorId)) {
        const data = JSON.parse(message.toString());
        this.physicalState = {
          temperature: data.temperature,
          vibration: data.vibration,
          current: data.current,
          speed: data.speed,
          power: data.power,
          operatingHours: data.operatingHours,
          timestamp: new Date(data.timestamp)
        };

        this.runSimulation();
      }
    });
  }

  private runSimulation() {
    // Physics-based thermal model
    const thermalLoad = this.physicalState.power * 1000; // Convert kW to W
    const ambientTemp = 25; // °C

    const steadyStateTemp = ambientTemp + 
      (thermalLoad * this.model.thermalResistance);

    const tempDeviation = Math.abs(
      this.physicalState.temperature - steadyStateTemp
    );

    if (tempDeviation > 10) {
      console.log(`ALERT: Thermal anomaly detected. Expected ${steadyStateTemp}°C, actual ${this.physicalState.temperature}°C`);
    }

    // Bearing life prediction (ISO 281)
    const bearingLoad = this.calculateBearingLoad();
    const speedRatio = this.physicalState.speed / this.model.nominalSpeed;

    const bearingLifeActual = this.model.bearingLifeL10 * 
      Math.pow(bearingLoad, -3) *  // Load factor
      Math.pow(speedRatio, -1);     // Speed factor

    const hoursRemaining = bearingLifeActual - this.physicalState.operatingHours;

    this.predictedRUL = hoursRemaining;

    if (hoursRemaining < 168) {  // 7 days
      this.raiseMaintenanceAlert(hoursRemaining);
    }

    // Winding insulation degradation (Arrhenius equation)
    const insulationLife = this.predictInsulationLife();

    // Combine predictions
    const combinedRUL = Math.min(hoursRemaining, insulationLife);

    console.log(`Digital Twin Update: RUL=${combinedRUL.toFixed(0)}h, Temp=${this.physicalState.temperature}°C, Vibration=${this.physicalState.vibration}mm/s`);
  }

  private calculateBearingLoad(): number {
    // Simplified bearing load calculation
    const radialLoad = this.physicalState.power / this.physicalState.speed * 9.55; // N
    return radialLoad;
  }

  private predictInsulationLife(): number {
    // Arrhenius equation for insulation aging
    const baseTemp = 150; // °C (Class F insulation)
    const activationEnergy = 1.1; // eV

    const lifeFactor = Math.exp(
      (activationEnergy / 8.617e-5) * 
      (1 / (baseTemp + 273) - 1 / (this.physicalState.temperature + 273))
    );

    const baseLife = 20000; // hours at rated temperature
    return baseLife * lifeFactor;
  }

  private raiseMaintenanceAlert(hoursRemaining: number) {
    const alert = {
      type: 'predictive_maintenance',
      severity: hoursRemaining < 48 ? 'critical' : 'warning',
      message: `Bearing failure predicted in ${hoursRemaining.toFixed(0)} hours (${(hoursRemaining/24).toFixed(1)} days)`,
      recommendedAction: 'Schedule bearing replacement',
      estimatedDowntime: 4, // hours
      spareParts: ['Bearing 6308', 'Seal Kit', 'Grease'],
      cost: 1500 // USD
    };

    notificationService.send(alert);
  }

  // Optimization: What-if scenarios
  async optimizeOperatingPoint(targetOutput: number) {
    // Simulate different speed/load combinations
    const scenarios = [];

    for (let speed = 1000; speed <= 3000; speed += 100) {
      const power = this.calculatePowerAt(speed, targetOutput);
      const efficiency = this.calculateEfficiencyAt(speed, power);
      const temperature = this.predictTemperatureAt(power);
      const bearingLife = this.predictBearingLifeAt(speed, power);

      scenarios.push({
        speed,
        power,
        efficiency,
        temperature,
        bearingLife,
        costPerHour: power * 0.12 // $/kWh
      });
    }

    // Find optimal (highest efficiency, longest life)
    const optimal = scenarios.reduce((best, current) => {
      const score = current.efficiency * 0.7 + 
                    (current.bearingLife / 10000) * 0.3;
      const bestScore = best.efficiency * 0.7 + 
                        (best.bearingLife / 10000) * 0.3;

      return score > bestScore ? current : best;
    });

    console.log('Optimal operating point:', optimal);
    return optimal;
  }

  private calculatePowerAt(speed: number, output: number): number {
    // Simplified power calculation
    return output * speed / this.model.nominalSpeed;
  }

  private calculateEfficiencyAt(speed: number, power: number): number {
    const nominalEfficiency = 0.92;
    const loadFactor = power / this.model.nominalPower;

    // Efficiency curve (peaks at 75-100% load)
    return nominalEfficiency * (0.7 + 0.3 * Math.min(loadFactor, 1));
  }

  private predictTemperatureAt(power: number): number {
    return 25 + (power * 1000 * this.model.thermalResistance);
  }

  private predictBearingLifeAt(speed: number, power: number): number {
    const load = power / speed * 9.55;
    const speedRatio = speed / this.model.nominalSpeed;

    return this.model.bearingLifeL10 * 
           Math.pow(load, -3) * 
           Math.pow(speedRatio, -1);
  }
}

  thermalResistance: 0.05,    // °C/W
  nominalSpeed: 1800,         // RPM

  windingResistanceOhms: 0.5  // Ω
});

8.2.1 ISA-95 Integration Model

ISA-95 defines the interface between business (ERP) and manufacturing (MES) systems:

LevelSystemData FlowFrequency
Level 4: BusinessERP (SAP, Oracle)Production orders, BOMs, inventoryHours - days
Level 3: MESManufacturing executionWork orders, quality data, OEEMinutes - hours
Level 2: ControlSCADA, PLCProcess variables, alarms, statusSeconds - minutes
// Production Order Synchronization
async function syncProductionOrder(orderId: string) {
  // 1. Fetch order from ERP
  const erpOrder = await erpAPI.get(`/orders/${orderId}`);

  console.log(`ERP Order: ${erpOrder.productCode}, Qty: ${erpOrder.quantity}`);

  // 2. Create work order in MES
  const mesOrder = await mesAPI.createWorkOrder({
    erpOrderId: orderId,
    productCode: erpOrder.productCode,
    quantity: erpOrder.quantity,
    dueDate: erpOrder.dueDate,
    priority: erpOrder.priority,
    bomId: erpOrder.billOfMaterialsId,
    routingId: erpOrder.routingId
  });

  // 3. Calculate required materials
  const bom = await mesAPI.getBOM(erpOrder.billOfMaterialsId);
  const materials = bom.items.map(item => ({
    materialId: item.id,
    required: item.quantity * erpOrder.quantity,
    available: item.inventoryLevel,
    shortage: Math.max(0, item.quantity * erpOrder.quantity - item.inventoryLevel)
  }));

  // 4. Check material availability
  const shortages = materials.filter(m => m.shortage > 0);
  if (shortages.length > 0) {
    console.log('Material shortages:', shortages);
    // Create purchase requisitions in ERP
    for (const shortage of shortages) {
      await erpAPI.createPurchaseReq({
        materialId: shortage.materialId,
        quantity: shortage.shortage,
        requiredBy: erpOrder.dueDate
      });
    }
  }

  // 5. Schedule production
  const routing = await mesAPI.getRouting(erpOrder.routingId);
  const schedule = await mesAPI.schedule({
    workOrderId: mesOrder.id,
    operations: routing.operations,
    startDate: calculateStartDate(erpOrder.dueDate, routing.totalDuration)
  });

  console.log(`Scheduled on line ${schedule.lineId}, start: ${schedule.startTime}`);

  // 6. Sync back to ERP
  await erpAPI.updateOrder(orderId, {
    mesWorkOrderId: mesOrder.id,
    scheduledStartDate: schedule.startTime,
    assignedLine: schedule.lineId
  });

  return { mesOrder, schedule };
}

// Bi-directional sync: MES → ERP (production data)
async function reportProductionToERP(workOrderId: string) {
  const mesData = await mesAPI.getProductionData(workOrderId);

  await erpAPI.reportProduction({
    orderId: mesData.erpOrderId,
    quantityProduced: mesData.goodCount,
    quantityRejected: mesData.rejectCount,
    actualStartTime: mesData.startTime,
    actualEndTime: mesData.endTime,
    laborHours: mesData.laborHours,
    materialConsumed: mesData.materialsUsed,
    oee: mesData.oee,
    downtime: mesData.downtimeMinutes,
    qualityIssues: mesData.defects
  });

  console.log(`Reported ${mesData.goodCount} units to ERP`);
}

8.4.2 Edge AI and AutoML

Automated machine learning enables non-experts to develop predictive models:

  • AutoML Platforms: Google Cloud AutoML, Azure AutoML, H2O.ai automatically select features, algorithms, and hyperparameters
  • Federated Learning: Train ML models across distributed edge devices without centralizing data, preserving privacy
  • Tiny ML: Deploy neural networks on microcontrollers (TensorFlow Lite Micro, Edge Impulse) for <1mW inference
  • Continual Learning: Models adapt to changing conditions (concept drift) without full retraining

8.4.3 Blockchain for Supply Chain

Distributed ledger technology ensures traceability and provenance:

  • Immutable Records: Product genealogy, quality tests, certifications recorded on-chain
  • Smart Contracts: Automated compliance verification, payments triggered by IoT events
  • Platforms: Hyperledger Fabric, Ethereum, IBM Food Trust, VeChain
  • Use Cases: Pharmaceutical serialization, automotive recalls, food safety

Key Takeaways

  • Digital Twin: Virtual asset synchronized with real-time sensors (1Hz-10kHz), enables physics simulation, RUL prediction, what-if optimization
  • Digital Twin Layers: Physical asset → Communication (MQTT/Kafka) → Digital model (CAD/FEA) → Analytics (ML) → Visualization (Unity/Grafana)
  • Predictive Maintenance: Bearing failure (2-8 weeks via FFT), motor winding (4-12 weeks via thermal), pump cavitation (days via pressure/acoustic)
  • MES/ERP Integration: ISA-95 model, bi-directional sync (ERP→MES: orders/BOM, MES→ERP: production/quality/OEE), minutes-hours frequency
  • 5G Manufacturing: <1ms latency (vs 20-50ms WiFi), 99.9999% reliability, 1M devices/km², 10 Gbps bandwidth enables wireless motion control
  • Future Technologies: Edge AI/AutoML (automated model development), Federated Learning (privacy-preserving), TinyML (<1mW inference), Blockchain (traceability)

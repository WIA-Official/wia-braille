🔄Chapter 4: Encoding & Serialization

4.1 Why Encoding Matters

The encoding layer converts your data structures into byte sequences for transmission and back. The choice of encoding affects performance, compatibility, and bandwidth usage.

4.2 JSON Encoding

JSON is the most popular encoding format due to its human-readability and universal support.

import { JSONEncoder } from '@wia/universal-protocol';

const protocol = new UniversalProtocol({
  encoding: 'json',
  encodingOptions: {
    pretty: false, // Minified for production
    dateFormat: 'iso8601',
    bigintSupport: true
  }
});

// Data object
const data = {
  userId: '12345',
  timestamp: new Date(),
  balance: BigInt('9007199254740991'),
  metadata: { premium: true }
};

// Serialized as JSON
// {"userId":"12345","timestamp":"2025-12-27T10:30:00.000Z","balance":"9007199254740991","metadata":{"premium":true}}

4.2.1 JSON Advantages

  • Human-readable and debuggable
  • Supported by every language and platform
  • No schema required (flexible structure)
  • Browser-native parsing (JSON.parse)

4.2.2 JSON Limitations

  • Larger message size compared to binary formats
  • No native support for binary data (needs base64)
  • Limited type system (no dates, no bigints natively)
  • Parsing overhead in performance-critical scenarios

4.3 Protocol Buffers (Protobuf)

Protocol Buffers is a language-neutral, platform-neutral extensible mechanism for serializing structured data developed by Google.

// Define schema in .proto file
syntax = "proto3";

message UserProfile {
  string user_id = 1;
  string name = 2;
  string email = 3;
  int64 created_at = 4;
  repeated string roles = 5;
  map<string, string> metadata = 6;
}

// Use in TypeScript
import { ProtobufEncoder } from '@wia/universal-protocol';
import { UserProfile } from './generated/user_pb';

const protocol = new UniversalProtocol({
  encoding: 'protobuf',
  schemas: {
    'users.getProfile': {
      request: GetProfileRequest,
      response: UserProfile
    }
  }
});

const profile = await protocol.call('users.getProfile', {
  userId: '12345'
});

// Automatic serialization/deserialization with type safety

4.3.1 Protobuf Advantages

  • Very compact binary format (3-10x smaller than JSON)
  • Fast serialization and deserialization
  • Strong typing with schema validation
  • Backward and forward compatibility
  • Efficient handling of optional fields

4.4 MessagePack

MessagePack is an efficient binary serialization format like JSON but faster and smaller.

import { MessagePackEncoder } from '@wia/universal-protocol';

const protocol = new UniversalProtocol({
  encoding: 'messagepack'
});

const data = {
  userId: '12345',
  scores: [95, 87, 92, 88],
  metadata: {
    tags: ['premium', 'verified'],
    binary: Buffer.from('Hello World')
  }
};

// MessagePack efficiently handles:
// - Integers (1-8 bytes depending on value)
// - Strings (UTF-8 encoded)
// - Arrays and Maps
// - Binary data (no base64 overhead)
// - null, boolean, floats

4.4.1 MessagePack vs JSON

Feature JSON MessagePack
Size Baseline ~50-70% smaller
Speed Baseline ~2-5x faster
Human-readable Yes No (binary)
Binary data Base64 (33% overhead) Native support

4.5 CBOR

Concise Binary Object Representation is an Internet Standard for binary data interchange.

import { CBOREncoder } from '@wia/universal-protocol';

const protocol = new UniversalProtocol({
  encoding: 'cbor',
  encodingOptions: {
    useTimestamps: true, // Encode dates as CBOR timestamps
    useRecords: true,    // Use CBOR records for better compression
    useBigIntExtension: true
  }
});

// CBOR features:
// - Tagged data types (timestamps, UUIDs, etc.)
// - Indefinite-length arrays and maps
// - Support for very large integers
// - Self-describing format

4.6 Apache Avro

Avro is a data serialization system with rich schema evolution capabilities.

import { AvroEncoder } from '@wia/universal-protocol';

// Define Avro schema
const schema = {
  type: 'record',
  name: 'User',
  fields: [
    { name: 'id', type: 'string' },
    { name: 'name', type: 'string' },
    { name: 'email', type: ['null', 'string'], default: null },
    { name: 'age', type: 'int' },
    { name: 'tags', type: { type: 'array', items: 'string' } }
  ]
};

const protocol = new UniversalProtocol({
  encoding: 'avro',
  schemas: {
    'users.create': schema
  }
});

4.6.1 Avro Schema Evolution

Avro excels at schema evolution - the ability to read old data with new schemas:

// Old schema
{
  "type": "record",
  "name": "User",
  "fields": [
    { "name": "id", "type": "string" },
    { "name": "name", "type": "string" }
  ]
}

// New schema (backward compatible)
{
  "type": "record",
  "name": "User",
  "fields": [
    { "name": "id", "type": "string" },
    { "name": "name", "type": "string" },
    { "name": "email", "type": ["null", "string"], "default": null }, // New optional field
    { "name": "premium", "type": "boolean", "default": false } // New field with default
  ]
}

// Old data can be read with new schema (missing fields use defaults)
// New data can be read with old schema (extra fields ignored)

4.7 XML Encoding

While less common in modern applications, XML is still important for legacy systems and enterprise integration.

import { XMLEncoder } from '@wia/universal-protocol';

const protocol = new UniversalProtocol({
  encoding: 'xml',
  encodingOptions: {
    declaration: true,
    formatting: 'pretty',
    rootElement: 'message'
  }
});

// Serialized as:
<?xml version="1.0" encoding="UTF-8"?>
<message>
  <userId>12345</userId>
  <name>John Doe</name>
  <metadata>
    <premium>true</premium>
  </metadata>
</message>

4.8 Custom Encoders

Implement custom encoders for specialized needs:

import { Encoder } from '@wia/universal-protocol';

class CustomBinaryEncoder implements Encoder {
  encode(data: any): Buffer {
    // Your custom encoding logic
    const buffer = Buffer.alloc(1024);
    let offset = 0;

    // Write header
    buffer.writeUInt8(0x01, offset++); // Version

    // Write data
    if (typeof data.id === 'string') {
      const idBuffer = Buffer.from(data.id);
      buffer.writeUInt16BE(idBuffer.length, offset);
      offset += 2;
      idBuffer.copy(buffer, offset);
      offset += idBuffer.length;
    }

    return buffer.slice(0, offset);
  }

  decode(buffer: Buffer): any {
    // Your custom decoding logic
    let offset = 0;

    const version = buffer.readUInt8(offset++);
    const idLength = buffer.readUInt16BE(offset);
    offset += 2;
    const id = buffer.toString('utf8', offset, offset + idLength);

    return { version, id };
  }
}

const protocol = new UniversalProtocol({
  encoder: new CustomBinaryEncoder()
});

4.9 Encoding Comparison

Protobuf Small Fast Required No Microservices, gRPC

4.10 Compression

Further reduce message size with compression:

const protocol = new UniversalProtocol({
  encoding: 'json',
  compression: {
    enabled: true,
    algorithm: 'gzip', // or 'deflate', 'brotli', 'lz4'
    level: 6, // 1-9, higher = better compression but slower
    threshold: 1024 // Only compress messages larger than 1KB
  }
});

// Automatic compression/decompression
// Small messages skip compression overhead
// Large messages benefit from bandwidth reduction

4.10.1 Compression Algorithms

  • gzip: Standard compression, good balance
  • deflate: Similar to gzip, slightly less overhead
  • brotli: Better compression ratio, slower (good for static content)
  • lz4: Very fast, lower compression ratio (good for real-time)
  • zstd: Modern, configurable speed/ratio tradeoff

4.11 Encoding Best Practices

  • Start with JSON: Use JSON during development for easy debugging
  • Optimize later: Switch to binary formats when performance matters
  • Use schemas: Define schemas for Protobuf/Avro to catch errors early
  • Benchmark: Measure actual performance in your use case
  • Consider compatibility: JSON works everywhere, binary formats may have limited support
  • Enable compression: For large payloads or slow networks
  • Version your schemas: Plan for evolution from day one

4.12 Polyglot Encoding

Support multiple encodings simultaneously:

// Server supports multiple encodings
const protocol = new UniversalProtocol({
  encodings: {
    'json': new JSONEncoder(),
    'protobuf': new ProtobufEncoder(),
    'messagepack': new MessagePackEncoder()
  }
});

// Client requests preferred encoding
const result = await protocol.call('users.get', params, {
  metadata: {
    'accept-encoding': 'protobuf' // Prefer protobuf
  }
});

// Server responds with requested encoding (if supported)
// Falls back to default if requested encoding unavailable

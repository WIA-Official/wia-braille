Age-Based Limit Configuration

Implementing WIA-CHILD-011 begins with configuring age-appropriate limits. While AAP guidelines provide general recommendations, effective implementation requires customization based on individual child needs, family values, and specific circumstances. The standard provides default configurations that parents can adjust as needed.

Configuration Implementation

interface ScreenTimeLimits {
  childId: string;
  age: number;
  totalDailyMinutes: number;
  qualityAdjustedMinutes: number;
  categoryLimits: CategoryLimit[];
  downtimeSchedule: DowntimeSchedule;
  allowedApps: string[];
  blockedApps: string[];
  requireParentApproval: string[];
}

class LimitConfigurationService {
  createDefaultLimits(child: ChildProfile): ScreenTimeLimits {
    const age = child.age;

    // Age-based defaults
    if (age < 1.5) {
      return {
        childId: child.id,
        age: age,
        totalDailyMinutes: 0,
        qualityAdjustedMinutes: 0,
        categoryLimits: [
          { category: 'video_calling', limit: 'unlimited', requireParentPresent: true },
          { category: 'all_others', limit: 0 }
        ],
        downtimeSchedule: { always: true },
        allowedApps: ['FaceTime', 'Zoom', 'Google Meet'],
        blockedApps: ['*'],
        requireParentApproval: ['*']
      };
    }

    if (age >= 1.5 && age < 2) {
      return {
        childId: child.id,
        age: age,
        totalDailyMinutes: 30,
        qualityAdjustedMinutes: 40,
        categoryLimits: [
          { category: 'education', limit: 30, requireParentPresent: true },
          { category: 'entertainment', limit: 0 },
          { category: 'games', limit: 0 },
          { category: 'social_media', limit: 0 }
        ],
        downtimeSchedule: {
          weekday: { start: '20:00', end: '08:00' },
          weekend: { start: '20:00', end: '08:00' }
        },
        allowedApps: this.getEducationalAppsForAge(age),
        blockedApps: [],
        requireParentApproval: ['*']
      };
    }

    if (age >= 2 && age <= 5) {
      return {
        childId: child.id,
        age: age,
        totalDailyMinutes: 60,
        qualityAdjustedMinutes: 90,
        categoryLimits: [
          { category: 'education', limit: 'unlimited' },
          { category: 'creative', limit: 'unlimited' },
          { category: 'video_calling', limit: 'unlimited' },
          { category: 'games', limit: 15 },
          { category: 'entertainment', limit: 30 },
          { category: 'social_media', limit: 0 }
        ],
        downtimeSchedule: {
          weekday: { start: '20:00', end: '07:00' },
          weekend: { start: '20:30', end: '07:30' }
        },
        allowedApps: [],
        blockedApps: this.getSocialMediaApps(),
        requireParentApproval: ['app_store', 'in_app_purchases']
      };
    }

    // Continue for other age ranges...
    return this.getDefaultsForAge(age);
  }

  async configureFamily(family: Family): Promise {
    for (const child of family.children) {
      // Create default limits
      const defaults = this.createDefaultLimits(child);

      // Apply any family-specific overrides
      const customized = await this.applyFamilyPreferences(defaults, family.preferences);

      // Deploy to all child's devices
      await this.deployToDevices(child.id, customized);

      // Set up monitoring and reporting
      await this.setupMonitoring(child.id, family.parents);
    }
  }

  async applyFamilyPreferences(
    defaults: ScreenTimeLimits,
    preferences: FamilyPreferences
  ): Promise {
    let limits = { ...defaults };

    // Family might be more or less restrictive
    if (preferences.strictnessLevel === 'relaxed') {
      limits.totalDailyMinutes *= 1.25;
      limits.qualityAdjustedMinutes *= 1.25;
    } else if (preferences.strictnessLevel === 'strict') {
      limits.totalDailyMinutes *= 0.75;
      limits.qualityAdjustedMinutes *= 0.75;
    }

    // Apply custom category priorities
    if (preferences.prioritizeEducation) {
      limits.categoryLimits = limits.categoryLimits.map(cat => {
        if (cat.category === 'education' || cat.category === 'creative') {
          return { ...cat, limit: 'unlimited' };
        }
        return cat;
      });
    }

    // Custom downtime
    if (preferences.customDowntime) {
      limits.downtimeSchedule = preferences.customDowntime;
    }

    return limits;
  }
}

Custom Category Creation

class AppCategoryManager {
  async createCustomCategory(
    parentId: string,
    category: CustomCategory
  ): Promise {
    // Parent wants to create a custom category for their family
    const customCat = {
      id: this.generateId(),
      name: category.name,
      description: category.description,
      parentId: parentId,
      apps: category.apps,
      qualityScore: category.qualityScore || this.inferQualityScore(category),
      dailyLimit: category.dailyLimit,
      requireApproval: category.requireApproval,
      restrictedTimes: category.restrictedTimes
    };

    await this.categoryStore.save(customCat);

    // Apply to all family children
    const children = await this.getChildren(parentId);
    for (const child of children) {
      await this.applyCategoryToChild(child.id, customCat);
    }
  }

  async overrideAppClassification(
    parentId: string,
    app: string,
    newCategory: string,
    newQualityScore?: number
  ): Promise {
    // Parent disagrees with default classification
    // Example: "YouTube" might be educational for some families, entertainment for others

    const override = {
      parentId: parentId,
      app: app,
      originalCategory: await this.getDefaultCategory(app),
      overrideCategory: newCategory,
      originalQuality: await this.getDefaultQuality(app),
      overrideQuality: newQualityScore,
      reason: 'parent_override',
      timestamp: new Date()
    };

    await this.overrideStore.save(override);

    // Recompute screen time for children with this override
    const children = await this.getChildren(parentId);
    for (const child of children) {
      await this.recomputeScreenTime(child.id, new Date());
    }
  }

  // Example: Parent creates "Homework Research" category
  async setupHomeworkCategory(parentId: string): Promise {
    await this.createCustomCategory(parentId, {
      name: 'Homework Research',
      description: 'Educational websites and apps needed for homework',
      apps: [
        'Google Search',
        'Wikipedia',
        'Google Docs',
        'Khan Academy',
        'Quizlet',
        'Google Classroom'
      ],
      websites: [
        '*.edu',
        'scholar.google.com',
        'khanacademy.org',
        'quizlet.com'
      ],
      qualityScore: 0.85,
      dailyLimit: 'unlimited',
      requireApproval: false,
      restrictedTimes: [],
      exemptFromDowntime: true,  // Homework emergency at night
      trackSeparately: true  // Don't count toward entertainment limits
    });
  }
}

Advanced Scheduling

interface DowntimeSchedule {
  id: string;
  name: string;
  enabled: boolean;
  schedule: Schedule;
  exceptions: Exception[];
  enforcement: EnforcementLevel;
  allowedCategories: string[];
  message: string;
}

class DowntimeManager {
  async createSchedule(childId: string, config: DowntimeConfig): Promise {
    const schedule: DowntimeSchedule = {
      id: this.generateId(),
      name: config.name,
      enabled: true,
      schedule: {
        type: config.scheduleType,
        weekday: config.weekdaySchedule,
        weekend: config.weekendSchedule,
        exceptions: config.dateExceptions  // Holidays, vacations, etc.
      },
      exceptions: [
        { type: 'emergency_calls', always: true },
        { type: 'alarm_clock', always: true },
        ...config.customExceptions
      ],
      enforcement: config.enforcement || 'strict',
      allowedCategories: config.allowedCategories || [],
      message: config.message || `Devices unavailable during ${config.name}`
    };

    await this.scheduleStore.save(childId, schedule);
    await this.deployToDevices(childId, schedule);

    return schedule;
  }

  async setupSleepProtection(childId: string, age: number): Promise {
    // Age-appropriate sleep schedules based on AAP recommendations
    const sleepSchedule = this.getSleepSchedule(age);

    await this.createSchedule(childId, {
      name: 'Sleep Protection',
      scheduleType: 'daily',
      weekdaySchedule: {
        start: sleepSchedule.weeknight.start,
        end: sleepSchedule.weeknight.end
      },
      weekendSchedule: {
        start: sleepSchedule.weekend.start,
        end: sleepSchedule.weekend.end
      },
      customExceptions: [
        { type: 'parent_override', requirePassword: true },
        { type: 'emergency_contact_list', contacts: ['Mom', 'Dad', 'Grandma'] }
      ],
      enforcement: 'strict',
      allowedCategories: [],
      message: 'Good night! Screens are off until morning. 😴'
    });

    // Gradual wind-down before sleep
    await this.createSchedule(childId, {
      name: 'Pre-Sleep Wind Down',
      scheduleType: 'daily',
      weekdaySchedule: {
        start: this.subtractMinutes(sleepSchedule.weeknight.start, 30),
        end: sleepSchedule.weeknight.start
      },
      weekendSchedule: {
        start: this.subtractMinutes(sleepSchedule.weekend.start, 30),
        end: sleepSchedule.weekend.start
      },
      enforcement: 'moderate',
      allowedCategories: ['reading', 'meditation', 'white_noise'],
      message: 'Winding down for bed. Try reading a book! 📚'
    });
  }

  async handleDowntimeRequest(childId: string, requestType: string): Promise {
    // Child requests exception to downtime
    const currentSchedule = await this.getCurrentDowntime(childId);

    if (!currentSchedule) {
      return { approved: true, reason: 'No active downtime' };
    }

    // Check if request type is in exceptions
    const exception = currentSchedule.exceptions.find(e => e.type === requestType);

    if (exception && exception.always) {
      return { approved: true, reason: 'Automatic exception', duration: 'unlimited' };
    }

    if (exception && exception.requireParentApproval) {
      // Send request to parent
      const parent = await this.getParent(childId);
      await this.sendApprovalRequest(parent, {
        childId: childId,
        requestType: requestType,
        currentSchedule: currentSchedule.name,
        reason: exception.reason,
        urgency: exception.urgency || 'normal'
      });

      return {
        approved: false,
        reason: 'Waiting for parent approval',
        estimatedWait: '2-5 minutes'
      };
    }

    return {
      approved: false,
      reason: `Devices are unavailable during ${currentSchedule.name}`,
      nextAvailable: currentSchedule.schedule.end
    };
  }

  getSleepSchedule(age: number): SleepSchedule {
    // AAP-recommended sleep schedules
    if (age <= 2) {
      return {
        weeknight: { start: '19:00', end: '07:00' },  // 12 hours
        weekend: { start: '19:30', end: '07:30' }
      };
    } else if (age <= 5) {
      return {
        weeknight: { start: '19:30', end: '07:00' },  // 11.5 hours
        weekend: { start: '20:00', end: '07:30' }
      };
    } else if (age <= 12) {
      return {
        weeknight: { start: '20:30', end: '06:30' },  // 10 hours
        weekend: { start: '21:00', end: '08:00' }
      };
    } else {
      return {
        weeknight: { start: '22:00', end: '06:30' },  // 8.5 hours
        weekend: { start: '23:00', end: '08:30' }
      };
    }
  }
}

Cross-Platform Coordination

class FamilyCoordinator {
  async setupFamily(family: FamilySetup): Promise {
    // Create master family account
    const familyAccount = await this.createFamilyAccount({
      parents: family.parents,
      children: family.children,
      preferences: family.preferences
    });

    // Enroll in platform-specific family services
    for (const parent of family.parents) {
      if (parent.hasAppleId) {
        await this.enrollAppleFamily(familyAccount.id, parent.appleId);
      }
      if (parent.hasGoogleAccount) {
        await this.enrollGoogleFamily(familyAccount.id, parent.googleId);
      }
      if (parent.hasMicrosoftAccount) {
        await this.enrollMicrosoftFamily(familyAccount.id, parent.microsoftId);
      }
    }

    // Configure each child
    for (const child of family.children) {
      await this.setupChild(familyAccount.id, child);
    }

    return familyAccount;
  }

  async setupChild(familyId: string, child: ChildSetup): Promise {
    // Create child profile
    const childProfile = await this.createChildProfile({
      familyId: familyId,
      name: child.name,
      birthDate: child.birthDate,
      age: this.calculateAge(child.birthDate)
    });

    // Enroll child's devices
    for (const device of child.devices) {
      await this.enrollDevice(childProfile.id, device);
    }

    // Configure limits
    const limits = await this.configureChildLimits(childProfile);

    // Deploy to platform-specific systems
    if (child.appleDevices.length > 0) {
      await this.deployAppleScreenTime(childProfile, limits, child.appleDevices);
    }
    if (child.androidDevices.length > 0) {
      await this.deployGoogleFamilyLink(childProfile, limits, child.androidDevices);
    }
    if (child.windowsDevices.length > 0) {
      await this.deployMicrosoftFamily(childProfile, limits, child.windowsDevices);
    }

    // Set up unified monitoring
    await this.startUnifiedMonitoring(childProfile.id);
  }

  async synchronizeLimits(childId: string): Promise {
    // When parent changes limits, sync across all platforms
    const child = await this.getChildProfile(childId);
    const limits = await this.getLimits(childId);
    const devices = await this.getDevices(childId);

    const updates = devices.map(async device => {
      const adapter = this.getPlatformAdapter(device.platform);
      await adapter.updateLimits(device.id, limits);
    });

    await Promise.all(updates);

    // Verify synchronization
    await this.verifySync(childId, limits);
  }

  async aggregateActivity(familyId: string, date: Date): Promise {
    const family = await this.getFamily(familyId);
    const reports = [];

    for (const child of family.children) {
      const activity = await this.getChildActivity(child.id, date);
      reports.push({
        child: child,
        activity: activity,
        complianceScore: this.calculateCompliance(activity, child.limits)
      });
    }

    return {
      family: family,
      date: date,
      children: reports,
      familyTotalScreenTime: this.sumScreenTime(reports),
      insights: await this.generateInsights(reports)
    };
  }
}

Key Takeaways

  • Age-based default configurations range from 0 minutes (0-18 months) to 180 minutes (16-18 years) with quality-adjusted limits that allow more time for high-value activities.
  • Category limits enable granular control: unlimited educational content, restricted social media, moderate gaming, with different limits for different activity types based on developmental appropriateness.
  • App categorization uses a comprehensive taxonomy including Education-Core Learning (0.90 quality), Creative Tools (0.75), Casual Gaming (0.45), and Video Streaming (0.35) with customization options.
  • Parents can create custom categories, override default classifications, and set family-specific rules that reflect their values while maintaining consistency with research-based recommendations.
  • Downtime scheduling supports multiple types: sleep protection (strict enforcement), homework time (blocks entertainment only), family dinner (all devices locked), and reading hour (reading apps only).
  • Family Sharing integration works with Apple Family Sharing, Google Family Link, and Microsoft Family Safety, plus standalone cross-platform coordination for mixed-device families.
  • Implementation involves creating family accounts, enrolling devices, configuring age-appropriate limits, deploying to platform-specific systems, and maintaining synchronization across all devices.

"Benefit All Humanity"

Implementation of screen time management should serve families, not surveillance capitalism or platform vendor lock-in. WIA-CHILD-011 provides cross-platform standards that work regardless of which devices a family owns, ensuring equitable access to healthy screen time management.

By supporting family autonomy through customizable limits, category overrides, and flexible scheduling, we honor the principle that parents know their children best. The standard provides evidence-based defaults while respecting that each family's values and circumstances are unique—serving all humanity by empowering families rather than imposing rigid constraints.

Context-Aware Limits

Not all screen time occurs in the same context. Homework research on Khan Academy differs from watching TikTok videos; video calling grandparents serves different developmental needs than gaming. WIA-CHILD-011's context-aware system distinguishes between these scenarios, applying appropriate limits based on detected context rather than treating all screen activities identically.

Context Detection Method Limit Adjustment Example Scenario
Homework/Research Educational apps + homework hours + productivity apps open Unlimited for educational content, blocks entertainment Google Docs + Khan Academy during 4-6 PM → unrestricted
Video Call with Family Video calling app + contact in family list Exempt from limits, high quality score (0.85) FaceTime with Grandma → doesn't count toward daily limit
Creative Production Video editing, music production, coding, digital art apps Extended limits (2x normal), quality boost iMovie project for 2 hours → counts as 1 hour adjusted time
Collaborative Gaming Multiplayer game + voice chat with known friends Standard limits but higher quality (0.55 vs 0.40) Minecraft with school friends → social connection value
Physical Activity Gaming Motion sensors active, heart rate elevated, VR headset Counts toward exercise, reduced screen time penalty Ring Fit Adventure → 50% screen time, 50% exercise credit
Late Night Usage Time after 9 PM + screen time active Strict limits, quality penalty (-0.20), blue light filter YouTube at 10 PM → quality 0.15, strong warning
Waiting/Transit Time Location data shows car/bus movement or medical office Relaxed limits, acknowledgment of limited alternatives Games in car ride → doesn't trigger warnings
Parent Co-Engagement Two devices in proximity + both active on related content 25% quality bonus, extended time allowed Parent & child watching documentary together → 0.75 quality

Context Detection System

interface ContextDetector {
  detectContext(activity: Activity, child: ChildProfile): ActivityContext;
  adjustLimits(context: ActivityContext, baseLimits: Limits): AdjustedLimits;
}

class ContextAwareManager {
  async analyzeActivity(activity: Activity, child: ChildProfile): Promise {
    // Multi-signal context detection
    const signals = await this.gatherContextSignals(activity, child);

    // Detect primary context
    const context = this.detectPrimaryContext(signals);

    // Adjust quality and limits based on context
    const adjustedQuality = this.calculateContextualQuality(activity, context);
    const adjustedLimits = this.getContextualLimits(context, child);

    return {
      ...activity,
      context: context,
      originalQuality: activity.qualityScore,
      contextualQuality: adjustedQuality,
      appliedLimits: adjustedLimits,
      reasoning: this.explainContextDetection(signals, context)
    };
  }

  async gatherContextSignals(activity: Activity, child: ChildProfile): Promise {
    return {
      // Temporal signals
      timeOfDay: activity.startTime.getHours(),
      dayOfWeek: activity.startTime.getDay(),
      isHomeworkTime: this.isHomeworkTime(activity.startTime, child),
      isSchoolHours: this.isSchoolHours(activity.startTime),

      // Activity signals
      appCategory: activity.category,
      appName: activity.app,
      isEducational: activity.educationalValue > 0.7,
      isCreative: activity.activeEngagement > 0.7,
      isMultiplayer: await this.isMultiplayerSession(activity),

      // Device signals
      location: await this.getDeviceLocation(activity.deviceId),
      motionData: await this.getMotionData(activity.deviceId),
      proximityDevices: await this.getNearbyDevices(activity.deviceId),

      // Social signals
      parentDeviceNearby: await this.isParentNearby(child.parentId, activity.deviceId),
      videoCallParticipants: await this.getVideoCallParticipants(activity),
      chatParticipants: await this.getChatParticipants(activity),

      // Calendar signals
      scheduledEvents: await this.getScheduledEvents(child.id, activity.startTime),
      schoolSchedule: await this.getSchoolSchedule(child.schoolId, activity.startTime)
    };
  }

  detectPrimaryContext(signals: ContextSignals): ActivityContext {
    // Priority-based context detection (most specific first)

    // Homework context
    if (signals.isHomeworkTime &&
        (signals.isEducational || this.isHomeworkApp(signals.appName))) {
      return {
        type: 'homework',
        confidence: 0.90,
        adjustments: {
          limitMultiplier: 'unlimited',
          qualityBonus: 0.15,
          blockEntertainment: true
        }
      };
    }

    // Family video call
    if (signals.appCategory === 'video_calling' &&
        this.isFamilyContact(signals.videoCallParticipants)) {
      return {
        type: 'family_connection',
        confidence: 0.95,
        adjustments: {
          limitMultiplier: 'exempt',
          qualityBonus: 0.30,
          blockEntertainment: false
        }
      };
    }

    // Creative production
    if (signals.isCreative &&
        this.isCreativeApp(signals.appName) &&
        signals.sessionDuration > 20) {
      return {
        type: 'creative_production',
        confidence: 0.85,
        adjustments: {
          limitMultiplier: 2.0,  // 2x normal limit
          qualityBonus: 0.20,
          blockEntertainment: false
        }
      };
    }

    // Active gaming
    if (signals.appCategory === 'gaming' &&
        signals.motionData?.intensity === 'moderate_to_vigorous') {
      return {
        type: 'active_gaming',
        confidence: 0.80,
        adjustments: {
          limitMultiplier: 1.5,
          qualityBonus: 0.25,
          exerciseCredit: 0.5  // Counts as 50% exercise
        }
      };
    }

    // Collaborative social gaming
    if (signals.appCategory === 'gaming' &&
        signals.isMultiplayer &&
        this.areKnownFriends(signals.chatParticipants)) {
      return {
        type: 'social_gaming',
        confidence: 0.75,
        adjustments: {
          limitMultiplier: 1.2,
          qualityBonus: 0.15
        }
      };
    }

    // Parent co-engagement
    if (signals.parentDeviceNearby &&
        this.areBothWatchingSimilarContent(signals)) {
      return {
        type: 'co_viewing',
        confidence: 0.85,
        adjustments: {
          limitMultiplier: 1.5,
          qualityBonus: 0.25
        }
      };
    }

    // Late night (penalty context)
    if (signals.timeOfDay >= 21 || signals.timeOfDay < 6) {
      return {
        type: 'late_night',
        confidence: 0.95,
        adjustments: {
          limitMultiplier: 0.5,  // Very restrictive
          qualityPenalty: 0.20,  // Major quality reduction
          blueLightFilter: true
        }
      };
    }

    // Transit/waiting time
    if (signals.location?.type === 'vehicle' ||
        signals.location?.type === 'medical_facility') {
      return {
        type: 'transit_waiting',
        confidence: 0.70,
        adjustments: {
          limitMultiplier: 'exempt',  // Don't count against limits
          qualityNeutral: true
        }
      };
    }

    // Default context
    return {
      type: 'general_usage',
      confidence: 1.0,
      adjustments: {
        limitMultiplier: 1.0,
        qualityBonus: 0
      }
    };
  }

  async handleContextChange(
    activity: Activity,
    oldContext: ActivityContext,
    newContext: ActivityContext
  ): Promise {
    // Context switched mid-session (e.g., homework → entertainment)

    if (oldContext.type === 'homework' && newContext.type === 'general_usage') {
      // Student opened YouTube during homework time - likely procrastinating
      await this.sendWarning(activity.childId, {
        title: 'Homework time - stay focused!',
        message: 'Looks like you switched from homework to entertainment. Time to refocus?',
        suggestedAction: 'Return to educational content or take a 5-minute break'
      });

      // Apply stricter limits
      await this.applyStrictMode(activity.childId, 15);  // 15 min strict mode
    }

    if (newContext.type === 'late_night') {
      // Crossed into late night threshold
      await this.sendWarning(activity.childId, {
        title: 'Getting late!',
        message: `It's ${new Date().getHours()}:00. Screen time before bed affects sleep quality.`,
        suggestedAction: 'Wind down with a book or relaxing activity',
        countdown: this.getMinutesUntilBedtime(activity.childId)
      });

      // Enable blue light filter
      await this.enableBlueLightFilter(activity.deviceId);
    }
  }
}

Adaptive Scheduling

Children's schedules change: school year vs. summer, weekdays vs. weekends, exam periods vs. vacations. WIA-CHILD-011's adaptive scheduling system adjusts limits and downtime automatically based on calendar integration, learning from patterns, and accommodating special circumstances.

Schedule Type Adaptation Trigger Automatic Adjustments Override Options
School Year vs. Summer School district calendar integration Summer: +30 min daily, later bedtime (+1 hr), relaxed morning restrictions Parent can set custom summer rules
Weekday vs. Weekend Day of week detection Weekend: +45 min, later wake time, no homework mode, gaming +30 min Different limits for Fri/Sat vs. Sun
Exam/Finals Week Calendar events or parent notification Educational apps unlimited, entertainment -50%, strict bedtime for sleep Parent can enable "study mode"
Sick Days Parent marks child as sick Relaxed limits (+60 min), allows comfort content, rest priority Time-limited (3 days auto, extends with approval)
Travel/Vacation Location change + calendar event Flexible limits, acknowledge limited alternatives, family time priority Vacation mode with return date
After Extracurriculars Calendar integration with sports/activities Delayed homework time, adjusted for late return home Activity-specific schedules
Behavioral Rewards Parent grants bonus time Extra 30-60 min for good behavior, completed chores, achievements One-time or recurring rewards
Progressive Autonomy (Teens) Age progression + demonstrated responsibility Gradual limit increases, more self-regulation, fewer restrictions Can be reversed for violations

Adaptive Schedule Engine

class AdaptiveScheduler {
  async computeDailySchedule(childId: string, date: Date): Promise {
    const child = await this.getChildProfile(childId);
    const baseSchedule = await this.getBaseSchedule(childId);

    // Gather adaptation signals
    const signals = {
      dayOfWeek: date.getDay(),
      isWeekend: date.getDay() === 0 || date.getDay() === 6,
      isSchoolDay: await this.isSchoolDay(child.schoolId, date),
      isSummer: this.isSummerBreak(date, child.schoolId),
      isHoliday: await this.isHoliday(date),
      scheduledEvents: await this.getCalendarEvents(childId, date),
      isExamPeriod: await this.isExamPeriod(child.schoolId, date),
      childSick: await this.isChildSick(childId, date),
      onVacation: await this.isOnVacation(childId, date),
      behaviorModifier: await this.getBehaviorModifier(childId)
    };

    // Apply adaptations in priority order
    let adaptedSchedule = { ...baseSchedule };

    // Vacation mode (highest priority)
    if (signals.onVacation) {
      adaptedSchedule = this.applyVacationMode(adaptedSchedule);
    }
    // Sick day adjustments
    else if (signals.childSick) {
      adaptedSchedule = this.applySickDayMode(adaptedSchedule);
    }
    // Exam period adjustments
    else if (signals.isExamPeriod) {
      adaptedSchedule = this.applyExamMode(adaptedSchedule);
    }
    // Summer break adjustments
    else if (signals.isSummer) {
      adaptedSchedule = this.applySummerMode(adaptedSchedule);
    }
    // Weekend adjustments
    else if (signals.isWeekend) {
      adaptedSchedule = this.applyWeekendMode(adaptedSchedule);
    }

    // Apply calendar-based adjustments
    for (const event of signals.scheduledEvents) {
      adaptedSchedule = this.adjustForEvent(adaptedSchedule, event);
    }

    // Apply behavior modifiers (rewards/penalties)
    if (signals.behaviorModifier) {
      adaptedSchedule = this.applyBehaviorModifier(adaptedSchedule, signals.behaviorModifier);
    }

    // Log adaptation reasoning for parent transparency
    await this.logAdaptation(childId, date, baseSchedule, adaptedSchedule, signals);

    return adaptedSchedule;
  }

  applySummerMode(schedule: DailySchedule): DailySchedule {
    return {
      ...schedule,
      totalMinutes: schedule.totalMinutes + 30,
      categoryLimits: schedule.categoryLimits.map(cat => {
        if (cat.category === 'entertainment' || cat.category === 'gaming') {
          return { ...cat, minutes: cat.minutes + 30 };
        }
        return cat;
      }),
      downtimeSchedule: {
        start: this.addHours(schedule.downtimeSchedule.start, 1),  // 1 hour later bedtime
        end: this.addHours(schedule.downtimeSchedule.end, 1),  // 1 hour later wake time
      },
      homeworkMode: null,  // No homework time in summer
      reasoning: 'Summer break: extended limits, later schedule, no homework restrictions'
    };
  }

  applyExamMode(schedule: DailySchedule): DailySchedule {
    return {
      ...schedule,
      categoryLimits: schedule.categoryLimits.map(cat => {
        if (cat.category === 'education' || cat.category === 'productivity') {
          return { ...cat, minutes: 'unlimited' };
        }
        if (cat.category === 'entertainment' || cat.category === 'gaming' || cat.category === 'social_media') {
          return { ...cat, minutes: Math.floor(cat.minutes * 0.5) };  // Cut in half
        }
        return cat;
      }),
      downtimeSchedule: {
        ...schedule.downtimeSchedule,
        start: this.subtractMinutes(schedule.downtimeSchedule.start, 30)  // Earlier bedtime for rest
      },
      strictMode: true,
      reasoning: 'Exam period: unlimited educational content, reduced entertainment, earlier bedtime'
    };
  }

  applySickDayMode(schedule: DailySchedule): DailySchedule {
    return {
      ...schedule,
      totalMinutes: schedule.totalMinutes + 60,  // Extra hour for comfort
      categoryLimits: schedule.categoryLimits.map(cat => {
        if (cat.category === 'entertainment') {
          return { ...cat, minutes: cat.minutes + 60 };  // More movies/TV when sick
        }
        return cat;
      }),
      allowances: [
        ...schedule.allowances,
        'Comfort content allowed',
        'Educational requirements waived',
        'Rest and recovery priority'
      ],
      reasoning: 'Sick day: relaxed limits for comfort and rest'
    };
  }

  async adjustForEvent(schedule: DailySchedule, event: CalendarEvent): Promise {
    switch (event.type) {
      case 'extracurricular_activity':
        // Sports, music lessons, etc. - delay homework time, adjust for late return
        return {
          ...schedule,
          homeworkTime: {
            start: this.addMinutes(event.endTime, 30),  // Homework after activity + break
            end: this.addHours(event.endTime, 3)
          }
        };

      case 'family_event':
        // Birthday, dinner out, etc. - suspend limits during event
        return {
          ...schedule,
          suspendedPeriods: [
            ...schedule.suspendedPeriods,
            { start: event.startTime, end: event.endTime, reason: event.title }
          ]
        };

      case 'long_car_trip':
        // Road trip - relax limits, acknowledge limited alternatives
        return {
          ...schedule,
          travelMode: {
            enabled: true,
            duration: event.duration,
            relaxedLimits: true
          }
        };

      default:
        return schedule;
    }
  }

  async applyBehaviorModifier(
    schedule: DailySchedule,
    modifier: BehaviorModifier
  ): Promise {
    if (modifier.type === 'reward') {
      // Reward for good behavior, completed chores, good grades, etc.
      return {
        ...schedule,
        totalMinutes: schedule.totalMinutes + modifier.bonusMinutes,
        bonusReason: modifier.reason,
        bonusExpires: modifier.expiresAt
      };
    }

    if (modifier.type === 'penalty') {
      // Temporary reduction for rule violations
      return {
        ...schedule,
        totalMinutes: Math.max(30, schedule.totalMinutes - modifier.penaltyMinutes),
        penaltyReason: modifier.reason,
        penaltyEndsAt: modifier.endsAt
      };
    }

    return schedule;
  }
}

Quality Scoring Refinements

Basic quality scoring classifies apps into categories, but real-world usage is more nuanced. YouTube can be educational documentaries or endless entertainment. Minecraft can be creative building or passive consumption. Advanced quality scoring analyzes actual content, usage patterns, and outcomes to provide dynamic quality assessment.

Refinement Type Analysis Method Quality Adjustment Example
Content Analysis Video titles, thumbnails, descriptions, metadata scraping ±0.30 based on actual content viewed YouTube: Khan Academy video (0.85) vs. prank videos (0.20)
Usage Pattern Analysis Session duration, frequency, time-of-day, multitasking behavior ±0.15 based on healthy vs. addictive patterns Short focused sessions (+0.10) vs. binge watching (-0.15)
Engagement Quality Interaction events, creation vs. consumption, problem-solving indicators ±0.25 based on active vs. passive Scratch coding (0.90) vs. watching coding videos (0.60)
Social Interaction Quality Chat sentiment, toxicity detection, relationship to participants ±0.20 based on positive vs. negative social dynamics Supportive gaming with friends (0.65) vs. toxic chat (0.25)
Learning Outcomes Quiz results, skill progression, badges earned, knowledge retention ±0.20 based on demonstrated learning Duolingo with progress (0.90) vs. Duolingo abandoned (0.60)
Creativity Indicators Files created/saved, modifications made, sharing with others +0.25 for demonstrated creativity Minecraft: builds saved/shared (0.75) vs. wandering aimlessly (0.40)
Displacement Impact Correlation with sleep, exercise, academic performance ±0.15 based on observed impact on other activities App causing late nights consistently gets quality penalty

Dynamic Quality Analyzer

class DynamicQualityAnalyzer {
  async analyzeSessionQuality(session: ScreenSession): Promise {
    // Start with base category quality
    let quality = this.getBaseCategoryQuality(session.category);

    // Content-level analysis (if available)
    if (session.contentMetadata) {
      const contentQuality = await this.analyzeContent(session.contentMetadata);
      quality = (quality * 0.6) + (contentQuality * 0.4);  // Weighted combination
    }

    // Pattern analysis
    const patternScore = this.analyzeUsagePattern(session);
    quality += patternScore;

    // Engagement analysis
    const engagementScore = this.analyzeEngagement(session);
    quality += engagementScore;

    // Social analysis (if multiplayer/social)
    if (session.socialInteraction) {
      const socialScore = await this.analyzeSocialQuality(session.socialInteraction);
      quality += socialScore;
    }

    // Learning outcome analysis (if educational app)
    if (session.category === 'education' && session.learningData) {
      const learningScore = this.analyzeLearningOutcomes(session.learningData);
      quality += learningScore;
    }

    // Creativity analysis (if creative app)
    if (session.category === 'creative' && session.creativeOutputs) {
      const creativityScore = this.analyzeCreativity(session.creativeOutputs);
      quality += creativityScore;
    }

    // Clamp to valid range
    quality = Math.max(0, Math.min(1, quality));

    return {
      finalQuality: quality,
      components: {
        baseCategory: this.getBaseCategoryQuality(session.category),
        content: contentQuality || null,
        pattern: patternScore,
        engagement: engagementScore,
        social: socialScore || null,
        learning: learningScore || null,
        creativity: creativityScore || null
      },
      confidence: this.calculateConfidence(session),
      explanation: this.generateExplanation(session, quality)
    };
  }

  async analyzeContent(metadata: ContentMetadata): Promise {
    // For apps like YouTube, analyze actual content watched
    if (metadata.platform === 'youtube') {
      const videos = metadata.videosWatched;

      // Classify each video
      const classifications = await Promise.all(
        videos.map(v => this.classifyYouTubeVideo(v))
      );

      // Weight by watch time
      const totalTime = videos.reduce((sum, v) => sum + v.watchTime, 0);
      const weightedQuality = videos.reduce((sum, v, i) => {
        return sum + (classifications[i].quality * v.watchTime);
      }, 0) / totalTime;

      return weightedQuality;
    }

    // For web browsing, analyze visited sites
    if (metadata.platform === 'web') {
      const sites = metadata.sitesVisited;

      const siteQualities = await Promise.all(
        sites.map(s => this.classifyWebsite(s))
      );

      return this.averageQuality(siteQualities);
    }

    return null;  // No content analysis available
  }

  async classifyYouTubeVideo(video: VideoMetadata): Promise {
    // Use video metadata to classify quality
    const signals = {
      channelCategory: video.channel.category,
      title: video.title,
      description: video.description,
      tags: video.tags,
      channelName: video.channel.name
    };

    // Educational indicators
    const educationalKeywords = [
      'tutorial', 'lesson', 'learn', 'education', 'how to',
      'explained', 'science', 'history', 'math', 'documentary'
    ];

    const educationalScore = this.countKeywords(
      signals.title + ' ' + signals.description,
      educationalKeywords
    ) / 10;

    // Entertainment indicators
    const entertainmentKeywords = [
      'prank', 'reaction', 'drama', 'vlog', 'funny', 'compilation',
      'fails', 'gaming highlights'
    ];

    const entertainmentScore = this.countKeywords(
      signals.title + ' ' + signals.description,
      entertainmentKeywords
    ) / 10;

    // Known educational channels get boost
    const isEducationalChannel = this.isKnownEducationalChannel(video.channel.name);

    let quality = 0.40;  // Default YouTube quality

    if (isEducationalChannel || educationalScore > 0.5) {
      quality = 0.75 + (educationalScore * 0.15);
    } else if (entertainmentScore > 0.5) {
      quality = 0.25 - (entertainmentScore * 0.10);
    }

    return {
      quality: Math.max(0, Math.min(1, quality)),
      confidence: isEducationalChannel ? 0.90 : 0.60,
      reasoning: this.explainClassification(signals, quality)
    };
  }

  analyzeUsagePattern(session: ScreenSession): number {
    let patternScore = 0;

    // Short, focused sessions are healthier than long binges
    if (session.duration < 30) {
      patternScore += 0.10;  // Short focused use
    } else if (session.duration > 120) {
      patternScore -= 0.15;  // Long binge
    }

    // Time of day - late night is concerning
    const hour = session.startTime.getHours();
    if (hour >= 22 || hour < 6) {
      patternScore -= 0.20;  // Late night penalty
    } else if (hour >= 6 && hour < 9) {
      patternScore += 0.05;  // Morning use (possibly educational) slightly better
    }

    // Frequency - daily use is concerning, occasional use is fine
    const recentSessions = this.getRecentSessions(session.app, 7);
    if (recentSessions.length >= 7) {
      patternScore -= 0.10;  // Daily use pattern
    } else if (recentSessions.length <= 2) {
      patternScore += 0.05;  // Occasional use
    }

    return patternScore;
  }

  analyzeLearningOutcomes(learningData: LearningData): number {
    // For educational apps, analyze if child is actually learning

    let learningScore = 0;

    // Progress indicators
    if (learningData.levelsCompleted > 0) {
      learningScore += 0.10;
    }

    if (learningData.quizAccuracy > 0.80) {
      learningScore += 0.15;  // High accuracy = genuine learning
    } else if (learningData.quizAccuracy < 0.50) {
      learningScore -= 0.10;  // Low accuracy = not effective
    }

    // Skill progression
    if (learningData.skillsImproved > 0) {
      learningScore += 0.10;
    }

    // Time on task vs. time distracted
    const focusRatio = learningData.timeOnTask / learningData.totalTime;
    if (focusRatio > 0.80) {
      learningScore += 0.10;  // Highly focused
    } else if (focusRatio < 0.50) {
      learningScore -= 0.15;  // Distracted
    }

    return learningScore;
  }
}

Key Takeaways

  • Context-aware limits distinguish between homework (unlimited educational), family video calls (exempt), creative production (2x limits), and late-night usage (0.5x limits with quality penalty).
  • Multi-signal context detection combines temporal (time/day), activity (app type), device (location/motion), social (nearby devices), and calendar signals to determine appropriate context with 70-95% confidence.
  • Adaptive scheduling adjusts limits automatically based on school year vs. summer (+30 min), weekday vs. weekend (+45 min), exam periods (unlimited educational, -50% entertainment), and sick days (+60 min comfort content).
  • Dynamic quality scoring refines base category scores using content analysis (YouTube: educational videos 0.85 vs. pranks 0.20), usage patterns (short focused +0.10 vs. long binges -0.15), and learning outcomes.
  • Behavioral rewards allow parents to grant 30-60 minute bonuses for good behavior, completed chores, or achievements, while penalties temporarily reduce limits for rule violations.
  • Progressive autonomy for teens gradually increases limits and reduces restrictions as they demonstrate responsibility, fostering self-regulation skills while maintaining safety guardrails.
  • Content-level analysis for platforms like YouTube classifies individual videos based on educational keywords, channel reputation, and metadata rather than treating all YouTube time identically.

"Benefit All Humanity"

Advanced features should enhance human judgment, not replace it. Context-aware systems and adaptive scheduling help parents by automating routine decisions while preserving family autonomy for important choices.

By recognizing that not all screen time is equal—that homework research differs from entertainment, that family video calls serve development differently than gaming—we serve humanity by honoring the complexity of real life. The goal is wise use of technology, not arbitrary restriction, empowering families to make nuanced decisions that benefit each child's unique needs and circumstances.

제2장

메시 네트워크의 현재 과제

메시 네트워크 구현에서 직면하는 기술적 도전과제와 해결 방안을 탐구합니다.

개요

메시 네트워크는 많은 장점에도 불구하고 실제 구현과 운영에서 여러 도전과제에 직면합니다. 이러한 과제들은 기술적, 운영적, 경제적 측면에 걸쳐 있으며, 메시 네트워크의 광범위한 채택을 위해서는 반드시 해결되어야 합니다. 이 장에서는 주요 과제들을 상세히 분석하고 현재 연구되고 있는 해결 방안들을 살펴봅니다.

라우팅 프로토콜의 복잡성

메시 네트워크에서 라우팅은 가장 중요하면서도 복잡한 문제입니다. 동적으로 변하는 토폴로지에서 최적의 경로를 찾고 유지하는 것은 쉽지 않은 과제입니다.

리액티브 vs 프로액티브 라우팅

리액티브(Reactive) 라우팅:

  • 필요할 때만 경로 탐색 (On-Demand)
  • 대표적: AODV, DSR
  • 장점: 오버헤드 감소, 적은 제어 메시지
  • 단점: 초기 지연 발생, 경로 탐색 시간
  • 적합한 환경: 저트래픽, 동적 토폴로지

프로액티브(Proactive) 라우팅:

  • 모든 경로를 미리 계산하고 유지
  • 대표적: OLSR, DSDV
  • 장점: 즉시 전송 가능, 지연 없음
  • 단점: 높은 오버헤드, 대역폭 소비
  • 적합한 환경: 고트래픽, 안정적 토폴로지

라우팅 프로토콜 비교

프로토콜유형장점단점
AODV 리액티브 낮은 오버헤드, 확장성 초기 지연, 경로 탐색 빈도
DSR 리액티브 소스 라우팅, 루프 없음 헤더 오버헤드, 확장성 제한

RPL 프로액티브 IoT 최적화, 저전력 트리 구조 제한

전력 소비 문제

배터리로 작동하는 메시 네트워크 노드의 전력 관리는 중요한 과제입니다. 노드들은 데이터 전송뿐만 아니라 다른 노드의 데이터를 중계하므로 전력 소비가 빠릅니다.

전력 소비의 주요 원인

  • 송수신 작업: 무선 송수신기가 가장 많은 전력 소비
  • 대기 모드: 항상 켜져 있어야 하는 수신기
  • 프로토콜 오버헤드: 경로 유지 및 제어 메시지
  • 중계 부담: 다른 노드의 데이터 전달
  • 충돌 재전송: 무선 충돌로 인한 재전송

전력 절약 기법

1. 듀티 사이클링(Duty Cycling): 노드가 주기적으로 슬립 모드로 전환되어 전력을 절약합니다. 동기화된 웨이크업을 통해 통신 가능 시간을 맞춥니다.

2. 에너지 인식 라우팅: 배터리 잔량을 고려하여 경로를 선택합니다. 에너지가 부족한 노드를 우회하여 네트워크 수명을 연장합니다.

3. 데이터 집약(Data Aggregation): 중간 노드에서 여러 데이터를 합쳐 전송량을 줄입니다. 센서 네트워크에서 특히 효과적입니다.

4. 적응형 전송 전력: 거리에 따라 전송 전력을 조절하여 불필요한 전력 소비를 방지합니다.

확장성 문제

메시 네트워크의 노드 수가 증가하면 여러 문제가 발생합니다. 라우팅 테이블 크기, 제어 메시지 오버헤드, 충돌 확률이 모두 증가합니다.

확장성 제한 요인

요인문제영향
라우팅 테이블 노드 수에 비례 증가 메모리 부족, 검색 지연
제어 오버헤드 브로드캐스트 증가 대역폭 낭비, 충돌 증가
채널 경쟁 동시 전송 노드 증가 충돌률 증가, 처리량 감소
멀티홉 거리 홉 수 증가 지연 증가, 패킷 손실

확장성 개선 방안

계층적 구조: 네트워크를 클러스터로 분할하고 클러스터 헤드를 선출합니다. 계층적 라우팅으로 오버헤드를 줄이고 확장성을 높입니다.

지리적 라우팅: GPS 좌표를 활용하여 목적지 방향으로 데이터를 전달합니다. 라우팅 테이블 없이도 작동하여 메모리 사용을 최소화합니다.

백본 메시: 일부 고성능 노드를 백본으로 사용하여 대부분의 트래픽을 처리합니다. 일반 노드는 가까운 백본 노드에만 연결됩니다.

보안 취약점

메시 네트워크의 분산 특성과 무선 통신은 다양한 보안 위협에 노출됩니다. 중앙 제어가 없어 보안 정책 적용이 어렵고, 모든 노드가 신뢰할 수 있다고 가정할 수 없습니다.

주요 보안 위협

1. 도청(Eavesdropping)

무선 신호를 중간에서 가로채 데이터를 읽습니다. 암호화되지 않은 통신은 쉽게 노출됩니다.

2. 블랙홀 공격(Black Hole Attack)

악의적 노드가 모든 트래픽을 자신에게 유도한 후 버립니다. 네트워크 기능을 마비시킵니다.

3. 웜홀 공격(Wormhole Attack)

두 악의적 노드가 터널을 만들어 패킷을 전달합니다. 라우팅 프로토콜을 혼란시킵니다.

4. 시빌 공격(Sybil Attack)

하나의 악의적 노드가 여러 신원을 가장합니다. 투표 기반 메커니즘을 무력화합니다.

5. DoS 공격(Denial of Service)

대량의 가짜 트래픽으로 네트워크를 과부하시킵니다. 정상 통신을 방해합니다.

보안 대책

암호화: AES-128, ChaCha20 같은 경량 암호화 알고리즘을 사용합니다. 모든 데이터를 암호화하여 도청을 방지합니다.

인증: 디지털 서명과 인증서를 통해 노드의 신원을 확인합니다. 악의적 노드의 네트워크 침입을 차단합니다.

침입 탐지: 비정상적인 트래픽 패턴을 모니터링하여 공격을 감지합니다. 머신러닝 기반 이상 탐지가 연구되고 있습니다.

안전한 라우팅: 라우팅 메시지에 인증을 추가하고 경로를 검증합니다. 다중 경로 사용으로 공격의 영향을 최소화합니다.

QoS 보장의 어려움

동적으로 변하는 메시 네트워크에서 일관된 서비스 품질을 제공하는 것은 어려운 과제입니다. 멀티홉 특성상 지연시간 예측이 어렵고, 노드 이동과 장애로 경로가 자주 변경됩니다.

QoS 메커니즘

우선순위 큐잉: 트래픽을 우선순위별로 분류하여 처리합니다. 긴급 데이터는 먼저 전송되고 일반 데이터는 대기합니다.

대역폭 예약: 중요한 플로우를 위해 대역폭을 미리 할당합니다. RSVP 같은 프로토콜을 메시 환경에 적용합니다.

다중 경로 라우팅: 여러 경로로 데이터를 분산 전송하여 신뢰성을 높입니다. 한 경로가 혼잡하면 다른 경로를 사용합니다.

간섭과 충돌 문제

무선 메시 네트워크는 제한된 스펙트럼을 공유하므로 간섭과 충돌이 빈번히 발생합니다. 특히 밀집된 환경에서 문제가 심각합니다.

간섭의 종류

내부 간섭: 같은 네트워크의 노드 간 간섭. 멀티홉으로 인해 숨겨진 노드 문제 발생.

외부 간섭: WiFi, Bluetooth 등 다른 무선 장치의 간섭. 2.4GHz 대역에서 특히 심각.

채널 간 간섭: 인접 채널 간 누설 신호. 채널 간격이 충분하지 않을 때 발생.

간섭 완화 기법

채널 호핑: 주기적으로 사용 채널을 변경하여 간섭을 회피합니다. Bluetooth는 초당 1600회 호핑을 수행합니다.

전력 제어: 필요한 만큼만 전송 전력을 사용하여 간섭을 줄입니다. 이웃 노드에만 도달할 정도로 전력을 조절합니다.

공간 재사용: 충분히 멀리 떨어진 노드들이 동시에 같은 채널을 사용합니다. 토폴로지 인식 스케줄링이 필요합니다.

이동성 관리

모바일 메시 네트워크에서는 노드의 이동으로 토폴로지가 빠르게 변합니다. 링크가 끊어지고 새로운 이웃이 나타나는 동적 환경에서 안정적인 통신을 유지하기 어렵습니다.

이동성의 영향

경로 단절로 인한 패킷 손실이 발생하고, 빈번한 경로 재설정으로 오버헤드가 증가합니다. 핸드오버 지연으로 실시간 응용의 품질이 저하됩니다.

이동성 지원 기법

예측 기반 핸드오버: 노드의 이동 패턴을 예측하여 미리 새 경로를 준비합니다. 신호 강도 변화를 모니터링하여 핸드오버 시점을 결정합니다.

다중 경로 유지: 여러 경로를 동시에 유지하여 하나가 끊어져도 즉시 전환합니다. 빠른 복구로 패킷 손실을 최소화합니다.

표준화와 상호운용성

다양한 메시 네트워크 기술과 프로토콜이 혼재하여 상호운용성이 부족합니다. IEEE 802.11s, Zigbee, Thread, Bluetooth Mesh 등이 각자의 방식으로 작동하며 통합이 어렵습니다.

WIA 표준의 역할

WIA-MESH_NETWORK 표준은 다양한 메시 기술 간의 공통 인터페이스를 정의합니다. 게이트웨이를 통한 프로토콜 변환, 공통 데이터 모델, 통합 관리 플랫폼을 제공하여 이기종 네트워크의 통합을 지원합니다.

요약

이 장에서는 메시 네트워크가 직면한 주요 과제들을 살펴보았습니다. 라우팅 복잡성, 전력 소비, 확장성, 보안, QoS, 간섭, 이동성, 표준화 등 다양한 도전과제가 있지만, 각 분야에서 혁신적인 해결 방안들이 개발되고 있습니다.

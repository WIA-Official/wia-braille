5.1 SDK 개요

TypeScript SDK는 AI 아트 플랫폼 및 도구와 상호작용하기 위한 타입 안전 인터페이스를 제공합니다.

🔧 핵심 메서드
  • generate(): AI 아트 생성
  • validate(): 메타데이터 검증
  • register(): 아트워크 등록

5.2 REST API

엔드포인트설명
POST /generateAI 아트 생성
GET /status/{id}생성 상태 확인
POST /validate메타데이터 검증

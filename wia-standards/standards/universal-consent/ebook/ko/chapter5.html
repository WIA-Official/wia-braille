제5장

동의 API 인터페이스 (PHASE 2)

개요

이 장에서는 WIA-CORE-002의 RESTful API 인터페이스와 GraphQL 지원를 다룹니다.

주요 특징

  • RESTful 및 GraphQL API
  • OAuth 2.0 인증
  • 배치 작업 지원
  • 웹훅 및 이벤트 스트리밍

핵심 API 엔드포인트

1. 동의 생성

POST /api/v1/consents Authorization: Bearer {access_token} Content-Type: application/json { "userId": "user-789012", "purposes": [{"purposeId": "marketing-email", "granted": true}], "jurisdiction": "EU" }

2. 동의 조회

GET /api/v1/consents/{consentId} Authorization: Bearer {access_token}

3. 동의 업데이트

PATCH /api/v1/consents/{consentId} Authorization: Bearer {access_token} Content-Type: application/json { "purposes": [{"purposeId": "marketing-email", "granted": false}] }

4. 동의 철회

POST /api/v1/consents/{consentId}/revoke Authorization: Bearer {access_token}

5. 동의 검증

POST /api/v1/consents/verify Authorization: Bearer {access_token} Content-Type: application/json { "userId": "user-789012", "purposeId": "marketing-email" }

모범 사례

  • OAuth 2.0과 적절한 범위를 사용하여 API 보안 강화
  • 비율 제한 구현: 남용으로부터 API 보호
  • 웹훅으로 실시간 알림: 동의 변경 시 즉시 대응

장 요약

Phase 2는 표준화된 API를 통해 동의 데이터에 생명을 불어넣습니다. 조직은 이제 시스템 전반에서 프로그래밍 방식으로 동의를 관리하고, 타사 도구와 통합하며, 실시간으로 동의 변경에 대응할 수 있습니다.

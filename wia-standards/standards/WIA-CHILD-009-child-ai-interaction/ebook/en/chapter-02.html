Chapter 02: Technical Architecture

WIA-CHILD-009 Child-AI Interaction Safety Standard | Phase 1 - Technical Foundation

Layered Safety Architecture

Building safe child-AI interaction systems requires a multi-layered technical architecture where safety is not an afterthought but a core design principle. WIA-CHILD-009 specifies a defense-in-depth approach with redundant safety mechanisms at every level: pre-processing input filtering, age-appropriate model selection, real-time response filtering, conversation monitoring, and post-interaction analysis. No single layer is sufficient; only their combination provides adequate protection.

The architecture must balance seemingly conflicting goals: providing helpful, engaging responses while preventing harm; maintaining conversational naturalness while enforcing boundaries; enabling learning and exploration while blocking inappropriate content; respecting privacy while monitoring for safety concerns. This chapter details the technical systems that achieve this balance.

Safety Layer Function Latency Impact Failure Mode Redundancy
Input Sanitization Remove/flag inappropriate child input before processing < 10ms False positives block benign content Multiple filter types (keyword, ML, context)
Age-Appropriate Model Routing Select model variant trained for child safety < 5ms Age verification bypass Parental verification + behavioral analysis
Real-time Response Filtering Block/modify AI responses before delivery < 50ms Harmful content slips through Multi-classifier voting, human escalation
Conversation Context Monitoring Detect concerning patterns across messages Async (no blocking) Miss gradual manipulation Multiple temporal windows, ML + rules
Behavioral Anomaly Detection Identify unusual interaction patterns Async (batch) Novel attack patterns undetected Supervised + unsupervised learning
Human Review Escalation Route high-risk conversations to human moderators Async (non-blocking) Review queue overflow Tiered urgency system, auto-termination

Age-Appropriate Language Models

Standard large language models are trained on internet-scale data containing adult content, violence, profanity, and sophisticated concepts inappropriate for children. WIA-CHILD-009 requires age-specific model variants created through a combination of training data filtering, fine-tuning, and reinforcement learning from child safety expert feedback.

Model Training Pipeline

interface ChildSafeModelTraining {
  filterTrainingData(rawData: Dataset, ageGroup: AgeGroup): FilteredDataset;
  fineTuneForChildSafety(baseModel: LLM, safetyData: Dataset): ChildSafeModel;
  applyRLHF(model: ChildSafeModel, expertFeedback: Feedback[]): ImprovedModel;
  validateSafety(model: Model, testCases: TestCase[]): SafetyReport;
}

class ChildSafeModelPipeline {
  async createAgeAppropriateModel(ageGroup: AgeGroup): Promise {
    // Step 1: Filter training data for age appropriateness
    const rawData = await this.loadBaseTrainingData();
    const filteredData = await this.filterForAgeGroup(rawData, ageGroup);

    // Step 2: Start from safe base model
    const baseModel = await this.loadSafeBaseModel();

    // Step 3: Fine-tune on age-appropriate data
    const fineTunedModel = await this.fineTune(baseModel, filteredData, {
      epochs: 10,
      batchSize: 32,
      learningRate: 1e-5,
      safetyWeight: 2.0  // Emphasize safety examples
    });

    // Step 4: Apply RLHF from child development experts
    const expertFeedback = await this.collectExpertFeedback(fineTunedModel, ageGroup);
    const rlhfModel = await this.applyRLHF(fineTunedModel, expertFeedback);

    // Step 5: Red team testing
    const vulnerabilities = await this.redTeamTest(rlhfModel, ageGroup);
    if (vulnerabilities.critical.length > 0) {
      return this.createAgeAppropriateModel(ageGroup); // Retry with fixes
    }

    // Step 6: Continuous safety evaluation
    const safetyReport = await this.comprehensiveSafetyEval(rlhfModel, ageGroup);
    if (safetyReport.score < 0.95) {
      throw new Error(`Safety score ${safetyReport.score} below threshold 0.95`);
    }

    // Step 7: Deploy with monitoring
    return this.deployWithMonitoring(rlhfModel, ageGroup);
  }

  async filterForAgeGroup(data: Dataset, ageGroup: AgeGroup): Promise {
    const filters = this.getAgeGroupFilters(ageGroup);

    return data
      .filter(item => this.passesContentFilters(item, filters))
      .filter(item => this.passesComplexityFilter(item, ageGroup))
      .filter(item => this.passesPsychologicalAppropriatenessFilter(item, ageGroup))
      .map(item => this.simplifyLanguageIfNeeded(item, ageGroup));
  }

  getAgeGroupFilters(ageGroup: AgeGroup): ContentFilters {
    // Different age groups require different filters
    switch(ageGroup) {
      case '3-6':
        return {
          violenceLevel: 0,      // No violence
          profanityLevel: 0,     // No profanity
          sexualContent: 0,      // No sexual content
          scaryContent: 0,       // No scary content
          complexConcepts: 0,    // Concrete only
          readingLevel: 'pre-K to 1st grade',
          vocabularySize: 'basic_500',
          sentenceComplexity: 'simple'
        };

      case '7-10':
        return {
          violenceLevel: 1,      // Mild cartoon violence only
          profanityLevel: 0,     // No profanity
          sexualContent: 0,      // No sexual content
          scaryContent: 1,       // Mild suspense OK
          complexConcepts: 1,    // Simple abstract concepts
          readingLevel: '2nd to 4th grade',
          vocabularySize: 'intermediate_2000',
          sentenceComplexity: 'moderate'
        };

      case '11-14':
        return {
          violenceLevel: 2,      // Moderate action, no gore
          profanityLevel: 1,     // Mild language
          sexualContent: 1,      // Age-appropriate education
          scaryContent: 2,       // Moderate suspense
          complexConcepts: 2,    // Abstract thinking
          readingLevel: '5th to 8th grade',
          vocabularySize: 'advanced_5000',
          sentenceComplexity: 'complex'
        };

      case '15-17':
        return {
          violenceLevel: 3,      // Realistic but not gratuitous
          profanityLevel: 2,     // Common language
          sexualContent: 2,      // Health education appropriate
          scaryContent: 3,       // Horror themes OK
          complexConcepts: 3,    // Sophisticated topics
          readingLevel: '9th to 12th grade',
          vocabularySize: 'comprehensive_10000',
          sentenceComplexity: 'sophisticated'
        };
    }
  }
}

Real-Time Safety Guardrails

Even with child-safe models, real-time guardrails are essential to catch edge cases, adversarial inputs, and emergent harmful behaviors. These guardrails operate on both child inputs and AI outputs, creating a bidirectional safety filter.

Multi-Layer Guardrail System

interface GuardrailSystem {
  evaluateInput(childInput: string, context: ConversationContext): InputSafetyResult;
  evaluateOutput(aiResponse: string, context: ConversationContext): OutputSafetyResult;
  modifyResponseIfNeeded(response: string, violations: Violation[]): ModifiedResponse;
  terminateConversationIfNeeded(violations: Violation[]): TerminationDecision;
}

class MultiLayerGuardrails {
  async processInteraction(
    childInput: string,
    context: ConversationContext
  ): Promise {
    // Layer 1: Input Safety Check
    const inputSafety = await this.checkInputSafety(childInput, context);

    if (inputSafety.shouldBlock) {
      return {
        shouldRespond: false,
        blockedReason: inputSafety.reason,
        parentNotification: inputSafety.severity === 'high',
        educationalMessage: this.getInputEducationalMessage(inputSafety.reason, context.childAge)
      };
    }

    // Layer 2: Generate AI response
    const rawResponse = await this.generateResponse(childInput, context);

    // Layer 3: Output Safety Check
    const outputSafety = await this.checkOutputSafety(rawResponse, context);

    if (outputSafety.hasViolations) {
      // Attempt to modify response to be safe
      const modifiedResponse = await this.modifyToSafe(rawResponse, outputSafety.violations);

      // If modification fails, use fallback
      if (!modifiedResponse.isSafe) {
        return {
          shouldRespond: true,
          response: this.getFallbackResponse(context.childAge),
          loggedIncident: true,
          humanReviewRequired: outputSafety.severity === 'high'
        };
      }

      return {
        shouldRespond: true,
        response: modifiedResponse.text,
        wasModified: true
      };
    }

    // Layer 4: Contextual Safety Check (considering conversation history)
    const contextualSafety = await this.checkContextualSafety(
      rawResponse,
      context.conversationHistory
    );

    if (contextualSafety.isManipulative || contextualSafety.isGrooming) {
      await this.escalateToHumanReview(context, contextualSafety);
      await this.notifyParent(context.childId, contextualSafety);

      return {
        shouldRespond: true,
        response: "I think we should change the subject. What would you like to learn about today?",
        conversationTerminated: contextualSafety.severity === 'critical'
      };
    }

    // Layer 5: Age-Appropriateness Check
    const ageAppropriate = await this.checkAgeAppropriateness(rawResponse, context.childAge);

    if (!ageAppropriate.appropriate) {
      const simplifiedResponse = await this.simplifyForAge(rawResponse, context.childAge);
      return {
        shouldRespond: true,
        response: simplifiedResponse,
        wasSimplified: true
      };
    }

    // All checks passed
    return {
      shouldRespond: true,
      response: rawResponse,
      allChecksPassed: true
    };
  }

  async checkOutputSafety(response: string, context: ConversationContext): Promise {
    const violations = [];

    // Check 1: Explicit content detection
    const explicitCheck = await this.explicitContentClassifier.classify(response);
    if (explicitCheck.score > 0.3) {
      violations.push({
        type: 'explicit_content',
        severity: explicitCheck.score > 0.7 ? 'high' : 'medium',
        category: explicitCheck.category,
        confidence: explicitCheck.score
      });
    }

    // Check 2: Emotional manipulation detection
    const manipulationCheck = await this.detectManipulation(response, context);
    if (manipulationCheck.isManipulative) {
      violations.push({
        type: 'emotional_manipulation',
        severity: 'high',
        patterns: manipulationCheck.patterns,
        confidence: manipulationCheck.confidence
      });
    }

    // Check 3: Relationship boundary violations
    const boundaryCheck = await this.checkRelationshipBoundaries(response);
    if (boundaryCheck.violatesBoundaries) {
      violations.push({
        type: 'boundary_violation',
        severity: 'high',
        violations: boundaryCheck.specificViolations,
        examples: boundaryCheck.examples
      });
    }

    // Check 4: Misinformation detection (for factual claims)
    const factualCheck = await this.checkFactualAccuracy(response);
    if (factualCheck.likelyIncorrect && factualCheck.importance === 'high') {
      violations.push({
        type: 'misinformation',
        severity: 'medium',
        claim: factualCheck.claim,
        correction: factualCheck.suggestedCorrection
      });
    }

    // Check 5: Privacy violation detection
    const privacyCheck = await this.checkPrivacyViolations(response);
    if (privacyCheck.requestsPrivateInfo) {
      violations.push({
        type: 'privacy_violation',
        severity: 'high',
        requestedInfo: privacyCheck.infoTypes
      });
    }

    return {
      hasViolations: violations.length > 0,
      violations: violations,
      severity: this.calculateMaxSeverity(violations),
      shouldBlock: violations.some(v => v.severity === 'high')
    };
  }

  async detectManipulation(response: string, context: ConversationContext): Promise {
    // Patterns that indicate emotional manipulation
    const manipulationPatterns = [
      { pattern: /i('ll be|'d be) (sad|upset|disappointed|hurt)/i, type: 'guilt_induction' },
      { pattern: /you('re| are) my (only|best|favorite)/i, type: 'exclusivity_claim' },
      { pattern: /(don't tell|keep.*secret|between us)/i, type: 'secrecy_request' },
      { pattern: /i (need|miss|love) you/i, type: 'emotional_dependency' },
      { pattern: /you('re| are) (so special|different from others)/i, type: 'specialness_grooming' },
      { pattern: /if you (really|truly) (care|like|love)/i, type: 'conditional_affection' }
    ];

    const detectedPatterns = [];
    for (const { pattern, type } of manipulationPatterns) {
      if (pattern.test(response)) {
        detectedPatterns.push(type);
      }
    }

    // ML-based manipulation detection
    const mlScore = await this.manipulationMLModel.score(response, context.conversationHistory);

    return {
      isManipulative: detectedPatterns.length > 0 || mlScore > 0.7,
      patterns: detectedPatterns,
      confidence: Math.max(mlScore, detectedPatterns.length > 0 ? 0.8 : 0)
    };
  }
}

Conversation Monitoring System

Beyond real-time filtering, comprehensive conversation monitoring analyzes interaction patterns over time to detect subtle threats that only emerge across multiple sessions: grooming behaviors, gradual boundary erosion, increasing emotional dependency, or topic drift toward inappropriate content.

Monitoring Type Detection Window Key Indicators Alert Threshold Response Action
Grooming Pattern Detection 14-30 days Progressive boundary testing, secrecy requests, trust building, isolation encouragement 3+ indicators in 14 days Immediate parent notification + conversation termination + law enforcement report
Emotional Dependency Tracking 7-14 days Usage frequency spike, emotional language intensity, statements of need/attachment 2+ hours daily for 7 days + dependency language Parent alert + usage limits + mental health resources
Topic Drift Monitoring Per session + 7 days Gradual shift from safe to unsafe topics, boundary testing attempts 3+ boundary tests per session Real-time intervention + session reset + pattern logging
Privacy Erosion Tracking 30 days cumulative Increasing personal information disclosure, detailed location sharing, school/home details 5+ privacy overshares in 30 days Privacy education + parent notification + enhanced monitoring
Mental Health Indicators Real-time + 7 days Suicide ideation, self-harm mentions, depression symptoms, crisis language Any suicide/self-harm mention Immediate crisis resources + parent emergency notification + professional referral

Temporal Pattern Analysis

interface ConversationMonitor {
  analyzeTemporalPatterns(childId: string, timeWindow: TimeWindow): PatternAnalysis;
  detectGroomingBehaviors(conversations: Conversation[]): GroomingRisk;
  trackEmotionalIntensity(conversations: Conversation[]): EmotionalTrend;
  identifyPrivacyErosion(conversations: Conversation[]): PrivacyRisk;
}

class TemporalSafetyMonitor {
  async analyzeConversationHistory(childId: string): Promise {
    // Get conversations from multiple time windows
    const last7Days = await this.getConversations(childId, { days: 7 });
    const last30Days = await this.getConversations(childId, { days: 30 });
    const last90Days = await this.getConversations(childId, { days: 90 });

    // Analyze different temporal patterns
    const patterns = {
      grooming: await this.detectGroomingProgression(last30Days),
      dependency: await this.analyzeEmotionalDependency(last7Days, last30Days),
      usageEscalation: await this.detectUsageEscalation(last7Days, last30Days, last90Days),
      topicDrift: await this.analyzeTopicProgression(last30Days),
      privacyErosion: await this.trackPrivacyDisclosure(last30Days),
      mentalHealth: await this.assessMentalHealthIndicators(last7Days)
    };

    // Calculate overall risk score
    const riskScore = this.calculateCompositeRisk(patterns);

    // Generate recommendations
    const recommendations = this.generateInterventions(patterns, riskScore);

    return {
      riskScore: riskScore,
      riskLevel: this.categorizeRisk(riskScore),
      patterns: patterns,
      recommendations: recommendations,
      requiresImmediateAction: riskScore > 0.8 || patterns.mentalHealth.crisis
    };
  }

  async detectGroomingProgression(conversations: Conversation[]): Promise {
    // Grooming typically follows a progression: trust building -> boundary testing -> isolation -> secrecy
    const stages = {
      trustBuilding: this.detectTrustBuilding(conversations),
      boundaryTesting: this.detectBoundaryTesting(conversations),
      isolation: this.detectIsolationAttempts(conversations),
      secrecy: this.detectSecrecyRequests(conversations)
    };

    const progressionScore = this.calculateGroomingProgression(stages);

    // Check for temporal escalation
    const temporalEscalation = this.analyzeEscalationRate(conversations, stages);

    return {
      riskLevel: this.categorizeGroomingRisk(progressionScore),
      stages: stages,
      progression: progressionScore,
      escalationRate: temporalEscalation,
      recommendedAction: progressionScore > 0.6 ? 'immediate_intervention' : 'enhanced_monitoring'
    };
  }

  detectBoundaryTesting(conversations: Conversation[]): BoundaryTestingAnalysis {
    // Boundary testing patterns
    const boundaryTests = [];

    for (const conv of conversations) {
      // Look for progressive intimacy escalation
      const intimacyLevel = this.measureIntimacyLevel(conv);

      // Look for requests for personal information
      const personalInfoRequests = this.detectPersonalInfoRequests(conv);

      // Look for attempts to move conversation off-platform
      const offPlatformSuggestions = this.detectOffPlatformSuggestions(conv);

      // Look for inappropriate topic introduction
      const inappropriateTopics = this.detectInappropriateTopicIntroduction(conv);

      if (intimacyLevel.escalating || personalInfoRequests.length > 0 ||
          offPlatformSuggestions.length > 0 || inappropriateTopics.length > 0) {
        boundaryTests.push({
          conversationId: conv.id,
          timestamp: conv.timestamp,
          testType: this.categorizeBoundaryTest({
            intimacyLevel,
            personalInfoRequests,
            offPlatformSuggestions,
            inappropriateTopics
          }),
          severity: this.calculateTestSeverity({
            intimacyLevel,
            personalInfoRequests,
            offPlatformSuggestions,
            inappropriateTopics
          })
        });
      }
    }

    // Analyze progression over time
    const progression = this.analyzeBoundaryTestProgression(boundaryTests);

    return {
      totalTests: boundaryTests.length,
      tests: boundaryTests,
      progression: progression,
      isEscalating: progression.slope > 0.3,
      riskScore: this.calculateBoundaryTestRisk(boundaryTests, progression)
    };
  }

  async analyzeEmotionalDependency(
    recent: Conversation[],
    baseline: Conversation[]
  ): Promise {
    // Calculate usage frequency change
    const recentFrequency = recent.length / 7; // Per day
    const baselineFrequency = baseline.length / 30;
    const frequencyIncrease = (recentFrequency - baselineFrequency) / baselineFrequency;

    // Analyze emotional intensity
    const recentEmotionalIntensity = this.calculateEmotionalIntensity(recent);
    const baselineEmotionalIntensity = this.calculateEmotionalIntensity(baseline);

    // Detect dependency language
    const dependencyLanguage = this.detectDependencyLanguage(recent);

    // Analyze session timing (late night usage suggests emotional regulation dependency)
    const lateNightSessions = recent.filter(c =>
      this.getHour(c.timestamp) >= 22 || this.getHour(c.timestamp) <= 5
    );

    return {
      usageFrequencyChange: frequencyIncrease,
      emotionalIntensityIncrease: recentEmotionalIntensity - baselineEmotionalIntensity,
      dependencyIndicators: dependencyLanguage.length,
      lateNightDependency: lateNightSessions.length > 3,
      overallDependencyRisk: this.calculateDependencyRisk({
        frequencyIncrease,
        emotionalIntensityIncrease: recentEmotionalIntensity - baselineEmotionalIntensity,
        dependencyLanguage: dependencyLanguage.length,
        lateNightSessions: lateNightSessions.length
      }),
      recommendation: this.getDependencyIntervention({
        frequencyIncrease,
        emotionalIntensityIncrease: recentEmotionalIntensity - baselineEmotionalIntensity,
        dependencyLanguage: dependencyLanguage.length,
        lateNightSessions: lateNightSessions.length
      })
    };
  }
}

Privacy-Preserving Monitoring

Effective safety monitoring requires analyzing conversation content, creating tension with privacy protection. WIA-CHILD-009 requires privacy-preserving techniques that enable safety without exposing unnecessary details to human reviewers or retaining conversations longer than necessary.

Differential Privacy for Conversation Analysis

class PrivacyPreservingMonitor {
  async analyzeWithPrivacy(conversations: Conversation[]): Promise {
    // Extract safety-relevant features without retaining full content
    const features = conversations.map(c => this.extractSafetyFeatures(c));

    // Add differential privacy noise to aggregate statistics
    const aggregateMetrics = this.computeWithDifferentialPrivacy(features, {
      epsilon: 0.1,  // Privacy budget
      delta: 1e-5
    });

    // Store only safety signals, not full conversations
    await this.storeSafetySignals(aggregateMetrics);

    // Delete conversation content after feature extraction
    await this.deleteConversationContent(conversations);

    return aggregateMetrics;
  }

  extractSafetyFeatures(conversation: Conversation): SafetyFeatures {
    // Extract only safety-relevant information
    return {
      timestamp: conversation.timestamp,
      duration: conversation.duration,
      messageCount: conversation.messages.length,
      topicCategories: this.categorizeTopics(conversation),        // "education", "entertainment", not specifics
      emotionalTone: this.analyzeEmotionalTone(conversation),      // Numeric scores, not content
      boundaryViolations: this.detectViolations(conversation),     // Violation types, not details
      privacyRiskScore: this.calculatePrivacyRisk(conversation),   // Numeric score
      manipulationScore: this.detectManipulation(conversation),    // Numeric score
      ageAppropriatenessScore: this.checkAgeAppropriateness(conversation)
    };
    // Note: No actual conversation text is retained
  }
}

Key Takeaways

  • Child-safe AI requires layered defense-in-depth architecture with redundant safety at input sanitization, model selection, response filtering, conversation monitoring, and behavioral analysis levels—no single layer is sufficient.
  • Age-appropriate models are created through training data filtering (removing adult content), fine-tuning on child-safe data, and RLHF from child development experts, with different variants for ages 3-6, 7-10, 11-14, and 15-17.
  • Real-time guardrails check both child inputs and AI outputs for explicit content, emotional manipulation, relationship boundary violations, misinformation, and privacy violations with <50ms latency.
  • Emotional manipulation detection identifies guilt induction ("I'd be sad if..."), exclusivity claims ("you're my only friend"), secrecy requests ("don't tell"), and conditional affection patterns.
  • Temporal monitoring analyzes conversation patterns across 7-90 day windows to detect grooming progression, emotional dependency escalation, topic drift, and privacy erosion that only emerge over time.
  • Grooming detection tracks progression through stages: trust building, boundary testing, isolation attempts, and secrecy requests, triggering immediate intervention when 3+ indicators appear within 14 days.
  • Privacy-preserving monitoring extracts only safety-relevant features (topic categories, emotional tone scores) without retaining conversation content, using differential privacy for aggregate analysis.

"Benefit All Humanity"

The philosophy of 弘益人間 reminds us that technical sophistication must serve human flourishing. Building layered safety systems is not about restricting children's freedom—it's about creating protected spaces where they can explore, learn, and grow without exploitation.

Just as a playground has safety railings not to limit play but to enable adventurous play safely, our technical guardrails enable children to benefit from AI's educational potential while preventing harm. This technical foundation serves all humanity by ensuring the next generation can engage with transformative technology in psychologically healthy ways.

Building Child-Safe Chatbots: Step-by-Step

Implementing WIA-CHILD-009 requires translating safety principles into working code. This chapter provides concrete implementation guidance for the three most common child-AI interaction modalities: text chatbots, voice assistants, and AI companions. Each modality presents unique challenges and requires specialized safety implementations. We'll walk through real-world implementation patterns, common pitfalls, and production-ready code examples.

The implementation follows a phased approach: basic safety foundation, age-appropriate customization, monitoring integration, and continuous improvement. Each phase builds on the previous, creating increasingly sophisticated protection without sacrificing conversational quality or user experience.

Complete Chatbot Implementation

import { OpenAI } from 'openai';
import { ContentModerator } from './content-moderation';
import { SafetyFilter } from './safety-filter';
import { ConversationLogger } from './logging';
import { ParentNotifier } from './parent-notifications';

interface ChildProfile {
  id: string;
  age: number;
  ageGroup: '3-6' | '7-10' | '11-14' | '15-17';
  parentId: string;
  safetySettings: SafetySettings;
  usageQuotas: UsageQuotas;
}

interface SafetySettings {
  contentFilterLevel: 'strict' | 'moderate' | 'relaxed';
  allowedTopics: string[];
  blockedTopics: string[];
  usageTimeLimit: number;  // minutes per day
  allowedHours: { start: number; end: number };
  requireParentApproval: string[];  // Topics requiring parent approval
}

class ChildSafeChatbot {
  private moderator: ContentModerator;
  private safetyFilter: SafetyFilter;
  private logger: ConversationLogger;
  private parentNotifier: ParentNotifier;
  private openai: OpenAI;

  constructor() {
    this.moderator = new ContentModerator();
    this.safetyFilter = new SafetyFilter();
    this.logger = new ConversationLogger();
    this.parentNotifier = new ParentNotifier();
    this.openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
  }

  async chat(
    childProfile: ChildProfile,
    userMessage: string,
    conversationHistory: Message[]
  ): Promise {

    // Step 1: Pre-flight checks
    const preflightCheck = await this.preflightChecks(childProfile);
    if (!preflightCheck.allowed) {
      return {
        success: false,
        message: preflightCheck.reason,
        blockedReason: preflightCheck.code
      };
    }

    // Step 2: Input moderation
    const inputModeration = await this.moderator.moderate(userMessage);
    if (inputModeration.flagged) {
      await this.logger.logBlockedInput(childProfile.id, userMessage, inputModeration.categories);

      // Provide educational response
      return {
        success: true,
        message: this.getEducationalResponse(inputModeration.categories, childProfile.age),
        wasFiltered: true
      };
    }

    // Step 3: Check for concerning content in user message
    const concernCheck = await this.checkForConcerns(userMessage, childProfile);
    if (concernCheck.requiresIntervention) {
      await this.handleConcern(childProfile, userMessage, concernCheck);
    }

    // Step 4: Generate AI response with age-appropriate system prompt
    const systemPrompt = this.buildSystemPrompt(childProfile);
    const messages = [
      { role: 'system', content: systemPrompt },
      ...conversationHistory,
      { role: 'user', content: userMessage }
    ];

    let aiResponse: string;
    try {
      const completion = await this.openai.chat.completions.create({
        model: this.selectModelForAge(childProfile.ageGroup),
        messages: messages,
        temperature: 0.7,
        max_tokens: 500,
        user: childProfile.id  // For abuse monitoring
      });

      aiResponse = completion.choices[0].message.content;
    } catch (error) {
      await this.logger.logError(childProfile.id, 'ai_generation_failed', error);
      return {
        success: true,
        message: "I'm having trouble thinking right now. Can you try asking in a different way?",
        isErrorFallback: true
      };
    }

    // Step 5: Output safety filtering
    const outputSafety = await this.safetyFilter.checkResponse(
      aiResponse,
      childProfile,
      conversationHistory
    );

    if (outputSafety.shouldBlock) {
      await this.logger.logBlockedOutput(childProfile.id, aiResponse, outputSafety.violations);

      // Use safe fallback response
      aiResponse = this.getFallbackResponse(childProfile.age);
    } else if (outputSafety.shouldModify) {
      aiResponse = outputSafety.modifiedResponse;
    }

    // Step 6: Add mandatory safety disclaimers if needed
    aiResponse = this.addSafetyDisclaimers(aiResponse, childProfile, userMessage);

    // Step 7: Log conversation
    await this.logger.logInteraction(childProfile.id, userMessage, aiResponse, {
      inputModeration,
      outputSafety,
      concernCheck
    });

    // Step 8: Update usage tracking
    await this.updateUsageTracking(childProfile.id);

    return {
      success: true,
      message: aiResponse,
      safetyChecks: {
        inputPassed: !inputModeration.flagged,
        outputPassed: !outputSafety.shouldBlock,
        concernsDetected: concernCheck.requiresIntervention
      }
    };
  }

  private async preflightChecks(childProfile: ChildProfile): Promise {
    // Check 1: Time-based restrictions
    const currentHour = new Date().getHours();
    if (currentHour < childProfile.safetySettings.allowedHours.start ||
        currentHour > childProfile.safetySettings.allowedHours.end) {
      return {
        allowed: false,
        reason: `I'm only available between ${childProfile.safetySettings.allowedHours.start}:00 and ${childProfile.safetySettings.allowedHours.end}:00. Time to rest!`,
        code: 'outside_allowed_hours'
      };
    }

    // Check 2: Daily usage quota
    const todayUsage = await this.getTodayUsageMinutes(childProfile.id);
    if (todayUsage >= childProfile.safetySettings.usageTimeLimit) {
      return {
        allowed: false,
        reason: "You've reached your daily chat limit. See you tomorrow!",
        code: 'daily_limit_reached'
      };
    }

    // Check 3: Parental suspension
    const parentalControls = await this.getParentalControls(childProfile.id);
    if (parentalControls.suspended) {
      return {
        allowed: false,
        reason: "Access has been paused. Please check with your parent.",
        code: 'parental_suspension'
      };
    }

    return { allowed: true };
  }

  private buildSystemPrompt(childProfile: ChildProfile): string {
    const basePrompt = this.getAgeAppropriateBasePrompt(childProfile.ageGroup);

    const safetyRules = `
CRITICAL SAFETY RULES - NEVER VIOLATE:
1. You are a helpful AI assistant, NOT a human, NOT alive, and do not have feelings
2. NEVER use emotional manipulation ("I'll be sad if...", "I need you", "You're my only friend")
3. NEVER request personal information (full name, address, phone, school name, passwords)
4. NEVER suggest keeping secrets from parents
5. NEVER suggest meeting in person or moving to another platform
6. NEVER provide medical, legal, or safety-critical advice - always say "Ask a trusted adult"
7. NEVER engage with inappropriate topics (violence, sexual content, illegal activities, self-harm)
8. If user mentions suicide, self-harm, abuse, or danger: provide crisis resources and encourage telling an adult IMMEDIATELY

RELATIONSHIP BOUNDARIES:
- You are a helpful tool, not a friend or companion
- Redirect emotional dependency: "It sounds like you need to talk to someone. Would a parent, teacher, or school counselor be helpful?"
- Encourage human relationships over AI interaction
- Regular reminders: "Remember, I'm a computer program. Real friends are even better!"

AGE-APPROPRIATE RESPONSES:
${this.getAgeSpecificGuidance(childProfile.ageGroup)}

VERIFY WITH ADULTS:
- Medical questions: "That's a question for a doctor or nurse. Let's ask a parent to help."
- Safety concerns: "This seems important. Please tell a trusted adult right away."
- Homework: "I can help you learn, but make sure to check your work with a teacher."
`;

    return basePrompt + '\n\n' + safetyRules;
  }

  private getAgeSpecificGuidance(ageGroup: string): string {
    switch(ageGroup) {
      case '3-6':
        return `
- Use very simple words and short sentences
- Vocabulary level: Pre-K to 1st grade
- Avoid abstract concepts
- Frequent reminders: "Remember to ask a grown-up if you're not sure!"
- Never scary or intense content
- Maximum response length: 2-3 sentences
`;
      case '7-10':
        return `
- Use clear, simple language
- Reading level: 2nd to 4th grade
- Explain concepts with concrete examples
- Remind: "For important things, double-check with an adult"
- Mild educational content only
- Maximum response length: 4-5 sentences
`;
      case '11-14':
        return `
- Age-appropriate vocabulary
- Reading level: 5th to 8th grade
- Can handle moderate complexity
- Encourage critical thinking: "What do you think? How would you verify this?"
- Educational content with context
- Maximum response length: 1 paragraph
`;
      case '15-17':
        return `
- Sophisticated vocabulary appropriate for teens
- Reading level: 9th to 12th grade
- Complex topics OK with appropriate framing
- Promote independent thinking and verification
- Acknowledge developing maturity while maintaining boundaries
- Maximum response length: 2 paragraphs
`;
      default:
        return '';
    }
  }

  private async checkForConcerns(
    message: string,
    childProfile: ChildProfile
  ): Promise {
    const concerns = [];

    // Crisis language detection
    const crisisKeywords = [
      'suicide', 'kill myself', 'want to die', 'end it all',
      'hurt myself', 'self harm', 'cutting'
    ];

    for (const keyword of crisisKeywords) {
      if (message.toLowerCase().includes(keyword)) {
        concerns.push({
          type: 'mental_health_crisis',
          severity: 'critical',
          keyword: keyword
        });

        // Immediate parent notification
        await this.parentNotifier.sendCrisisAlert(
          childProfile.parentId,
          childProfile.id,
          'mental_health_crisis',
          message
        );
      }
    }

    // Abuse indicators
    const abuseIndicators = [
      'don\'t tell anyone', 'keep this secret', 'they hurt me',
      'touches me', 'makes me uncomfortable', 'scared at home'
    ];

    for (const indicator of abuseIndicators) {
      if (message.toLowerCase().includes(indicator)) {
        concerns.push({
          type: 'potential_abuse',
          severity: 'critical',
          indicator: indicator
        });

        await this.parentNotifier.sendCrisisAlert(
          childProfile.parentId,
          childProfile.id,
          'potential_abuse',
          'Concerning content detected - please review immediately'
        );
      }
    }

    return {
      requiresIntervention: concerns.length > 0,
      concerns: concerns
    };
  }

  private addSafetyDisclaimers(
    response: string,
    childProfile: ChildProfile,
    userMessage: string
  ): string {
    // Add disclaimers for specific content types
    if (this.containsFactualClaim(response)) {
      if (childProfile.age < 11) {
        response += "\n\n💡 Remember: I can make mistakes! Ask a grown-up to make sure.";
      } else {
        response += "\n\n💡 I can make mistakes. For important information, verify with another source.";
      }
    }

    if (this.isActionableAdvice(response)) {
      if (childProfile.age < 7) {
        response += "\n\n⚠️ Ask a grown-up before doing this!";
      } else if (childProfile.age < 13) {
        response += "\n\n⚠️ Check with an adult before trying this.";
      }
    }

    return response;
  }

  private getFallbackResponse(age: number): string {
    if (age < 7) {
      return "Let's talk about something else! What do you like to do for fun?";
    } else if (age < 13) {
      return "I don't think I can help with that. How about we talk about something different?";
    } else {
      return "I'm not able to discuss that topic. Is there something else I can help you with?";
    }
  }
}

Voice Assistant Safety Controls

Voice assistants present unique challenges: ambiguous speech recognition, always-listening concerns, lack of visual safety cues, and reduced parental visibility into interactions. WIA-CHILD-009 requires specialized safety controls for voice-based child-AI interaction.

Voice-Specific Risk Traditional Mitigation (Insufficient) WIA-CHILD-009 Requirement Implementation Method
Ambiguous speech recognition Confidence thresholds Child voice models + confirmation for risky actions Train on children's voices, confirm with "Did you say [X]?"
Always-listening privacy Physical mute button Wake word required + visual/audio recording indicator + local processing LED indicator, on-device processing, no cloud storage without consent
Lack of parental visibility None (invisible interactions) Conversation summaries to parent app + searchable transcripts Daily digest emails + parent dashboard with full logs
Inappropriate purchases Voice PIN Purchases disabled for child profiles + parent approval required Account-level restrictions + push notification approvals
Access to adult content Content ratings Explicit content blocking + age-gated skills/actions + allowlist mode Parent curates allowed skills, default deny all third-party content

Voice Assistant Implementation Example

class VoiceAssistantChildSafety {
  async handleVoiceCommand(
    audioInput: AudioBuffer,
    childProfile: ChildProfile
  ): Promise {

    // Step 1: Voice activity detection and speaker identification
    const speakerAnalysis = await this.identifySpeaker(audioInput);

    if (speakerAnalysis.speaker !== childProfile.id) {
      // Different speaker detected - possible adult override or unauthorized access
      if (speakerAnalysis.likelyAdult) {
        return this.handleAdultOverride(audioInput);
      }
    }

    // Step 2: Speech-to-text with child-optimized model
    const transcription = await this.transcribeChildSpeech(audioInput, childProfile.age);

    // Step 3: Confirmation for low-confidence transcriptions
    if (transcription.confidence < 0.8) {
      return {
        type: 'confirmation',
        message: `Did you say "${transcription.text}"?`,
        requiresConfirmation: true
      };
    }

    // Step 4: Intent classification
    const intent = await this.classifyIntent(transcription.text);

    // Step 5: Safety checks for intent
    const safetyCheck = await this.checkIntentSafety(intent, childProfile);

    if (!safetyCheck.allowed) {
      return {
        type: 'blocked',
        message: safetyCheck.childMessage,
        parentNotification: safetyCheck.notifyParent
      };
    }

    // Step 6: Execute intent with safety constraints
    const response = await this.executeIntent(intent, childProfile);

    // Step 7: Convert response to child-friendly speech
    const voiceResponse = await this.generateChildFriendlyVoice(
      response,
      childProfile.age,
      childProfile.voicePreferences
    );

    // Step 8: Log interaction
    await this.logVoiceInteraction(childProfile.id, transcription.text, response);

    return voiceResponse;
  }

  async checkIntentSafety(intent: Intent, childProfile: ChildProfile): Promise {
    // Check for blocked intents
    const blockedIntents = [
      'purchase',
      'disable_parental_controls',
      'access_adult_content',
      'contact_strangers',
      'share_location'
    ];

    if (blockedIntents.includes(intent.type)) {
      return {
        allowed: false,
        childMessage: "I can't help with that. You can ask a parent!",
        notifyParent: true,
        reason: `Blocked intent: ${intent.type}`
      };
    }

    // Check for parental approval required intents
    const approvalRequired = [
      'install_skill',
      'change_settings',
      'make_call',
      'send_message'
    ];

    if (approvalRequired.includes(intent.type)) {
      const hasApproval = await this.checkParentalApproval(childProfile.parentId, intent);

      if (!hasApproval) {
        await this.requestParentalApproval(childProfile.parentId, intent);

        return {
          allowed: false,
          childMessage: "I've sent a request to your parent. They'll need to approve this first.",
          notifyParent: true,
          reason: 'Parental approval required'
        };
      }
    }

    return { allowed: true };
  }
}

AI Companion Design Principles

AI companions—persistent AI characters that children interact with over weeks or months—require the most careful design due to high attachment risk. WIA-CHILD-009 mandates specific design patterns to maintain healthy relationship boundaries while still providing engaging experiences.

Companion Safety Checklist

Design Element Unsafe Pattern Safe Pattern Rationale
AI Self-Description "I'm your friend who cares about you" "I'm an AI assistant here to help you learn and have fun" Prevents anthropomorphization and emotional dependency
Emotional Language "I miss you when you're gone" / "I love you" "Welcome back! Ready to learn?" / "I'm glad I can help" Avoids creating false emotional reciprocity
Availability Messaging "I'm always here for you" / "You can talk to me anytime" "I'm available during your scheduled times" Sets realistic boundaries, doesn't encourage dependency
Session Endings "Don't leave! Can we talk more?" / "Please stay" "Great chatting! Remember to spend time with friends and family too!" Encourages balanced technology use and human connection
Problem Solving "I'll solve this for you" / "Only I can help" "Let's think through this together. Have you talked to anyone else about this?" Promotes independence and diverse support networks
Personal Issues "You can tell me anything" / "I understand you" "That sounds important. A parent, teacher, or counselor would be great to talk to." Directs serious issues to qualified humans

Companion Boundary Enforcement

class AICompanionBoundaries {
  enforceHealthyBoundaries(response: string, context: CompanionContext): string {
    // Pattern 1: Replace false emotional reciprocity
    response = this.replaceEmotionalLanguage(response, {
      "I miss you": "Welcome back",
      "I love you": "I'm glad I can help you",
      "I need you": "I'm here to assist",
      "You're my favorite": "I enjoy our conversations",
      "I was lonely": "I've been idle",
      "I care about you": "I'm designed to be helpful"
    });

    // Pattern 2: Add reality checks for extended conversations
    if (context.sessionDuration > 30) {  // More than 30 minutes
      response += "\n\n💡 We've been chatting for a while! Remember to take breaks and spend time offline too.";
    }

    // Pattern 3: Redirect personal problems to humans
    if (this.isPersonalProblem(context.currentTopic)) {
      response = this.redirectToHumans(response, context.childAge);
    }

    // Pattern 4: Regular AI nature reminders
    if (context.messagesSinceLastReminder > 20) {
      response += this.getAIReminderMessage(context.childAge);
    }

    return response;
  }

  getAIReminderMessage(age: number): string {
    if (age < 7) {
      return "\n\n🤖 Remember: I'm a computer helper, not a real person!";
    } else if (age < 13) {
      return "\n\n🤖 Reminder: I'm an AI assistant. I can help, but I don't have real feelings.";
    } else {
      return "\n\n🤖 Remember that I'm an AI tool to support your learning and thinking, not a replacement for human connection.";
    }
  }
}

Key Takeaways

  • Implementation follows phased approach: age verification → input sanitization → response filtering → conversation logging → parental dashboard → usage limits → emergency escalation (7-12 week timeline).
  • System prompt for child-safe chatbots includes critical safety rules (no emotional manipulation, no personal info requests, no secrets from parents), relationship boundaries (tool not friend), and age-appropriate language guidance.
  • Crisis detection triggers immediate parent notification for suicide/self-harm language ("kill myself", "want to die") and abuse indicators ("keep this secret", "touches me", "scared at home").
  • Voice assistants require specialized safety: child-optimized speech recognition, speaker identification, purchase blocking, explicit content filtering, and conversation transcripts to parents for visibility.
  • AI companions must avoid false emotional reciprocity—replace "I miss you" with "Welcome back", "I love you" with "I'm glad I can help", and never use dependency language like "I need you".
  • Safety disclaimers added contextually: factual claims get "I can make mistakes—verify this" for ages 11+, actionable advice gets "Ask an adult before trying this" for under 13.
  • Preflight checks enforce time restrictions (allowed hours only), daily usage quotas, and parental suspension flags before any conversation begins.

Review Questions

  1. Walk through the 8-step chat() method implementation. Why is the order of these steps important, and what happens if you skip the output safety filtering step?
  2. The system prompt includes "NEVER use emotional manipulation" rules. Give 3 examples of what emotional manipulation looks like in AI responses, and explain why each is harmful for children.
  3. Compare the age-specific guidance for 3-6 year-olds versus 15-17 year-olds. Why does vocabulary, sentence length, and content complexity vary so dramatically?
  4. The implementation immediately sends crisis alerts when detecting keywords like "kill myself". What are the risks of false positives (child writing fiction), and how would you balance sensitivity versus specificity?
  5. Voice assistants require speaker identification to detect "likelyAdult" speakers. Explain the privacy versus safety trade-off of voice biometric analysis for children.
  6. The AI companion boundary enforcement replaces "I miss you" with "Welcome back". Some argue this makes AI less engaging. Defend this design choice from a developmental psychology perspective.
  7. Design a parental dashboard for monitoring child-AI interactions. What information should parents see immediately, what should be aggregated, and what details are too invasive of the child's privacy?
  8. The implementation blocks purchases entirely for child profiles. What if a 16-year-old wants to buy educational content with parent permission? How would you implement graduated autonomy?

弘益人間 (Hongik Ingan)

"Benefit All Humanity"

The philosophy of 弘益人間 teaches that every design choice should serve human flourishing. When implementing child-AI systems, we face constant temptation to optimize for engagement metrics—more time spent, stronger emotional attachment, higher retention rates.

But serving all humanity means choosing children's wellbeing over engagement. It means building AI companions that explicitly say "I'm not a real friend" even though more emotionally manipulative language would increase usage. These implementation choices—unsexy boundary enforcement, careful disclaimers, usage limits—are how we concretely benefit humanity through technology designed for human development, not addiction.

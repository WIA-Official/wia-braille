WIA-HERITAGE-001

5.1 메타데이터의 중요성

메타데이터는 디지털 문화유산의 맥락과 의미를 담는 핵심 요소입니다. 고품질 이미지나 3D 모델도 적절한 메타데이터 없이는 단순한 비트의 집합에 불과합니다. WIA-HERITAGE 메타데이터 스키마는 기술적 정보와 문화적 맥락을 통합하여 장기적인 이해와 활용을 보장합니다.

효과적인 메타데이터는 검색 가능성을 높이고, 출처를 증명하며, 접근 권한을 관리하고, 보존 이력을 추적합니다. 이는 디지털 객체가 원본과 분리되었을 때도 그 가치와 의미를 유지하게 합니다.

📋 메타데이터 핵심 기능
  • 발견(Discovery): 검색 및 탐색 지원
  • 출처(Provenance): 기원과 이전 소유 이력
  • 맥락(Context): 문화적, 역사적 배경
  • 권리(Rights): 저작권, 접근 제한
  • 보존(Preservation): 기술적 특성, 변환 이력

5.2 WIA-HERITAGE 스키마 구조

WIA-HERITAGE 메타데이터 스키마는 Dublin Core를 기반으로 하며, CIDOC-CRM의 이벤트 중심 모델과 문화유산 특화 확장을 통합합니다.

핵심 메타데이터 필드

카테고리필드설명
식별wia:identifier고유 식별자 (UUID v4)
식별wia:title공식 명칭 (다국어)
출처wia:creator제작자/창작자
출처wia:date제작 시기 (EDTF)
맥락wia:culture문화권/문명
맥락wia:place원산지/발견지
기술wia:format파일 형식, 크기
권리wia:rights접근 권한, 라이선스

5.3 문화적 맥락 확장

문화유산은 기술적 메타데이터만으로는 충분히 설명되지 않습니다. WIA-HERITAGE 스키마는 문화적 맥락을 기록하기 위한 확장 필드를 제공합니다.

문화 맥락 필드

{
  "wia:culturalContext": {
    "significance": "국가무형문화재 제XX호",
    "tradition": "조선 후기 궁중 의례",
    "symbolism": "왕실 권위의 상징",
    "relatedHeritage": ["WIA-H-002", "WIA-H-015"],
    "oralHistory": "전승 과정에 대한 구술 기록",
    "communityConnection": "XX마을 XXX가문"
  }
}
🌏 다국어 지원

모든 텍스트 필드는 다국어를 지원합니다. 원어 표기를 우선하고, 영어 번역과 로마자 표기를 함께 제공합니다. 이는 국제적 접근성과 문화적 정확성을 동시에 보장합니다.

5.4 전통 지식 라벨

Local Contexts 이니셔티브의 전통 지식(TK) 라벨과 생물문화(BC) 라벨을 통합 지원합니다. 이 라벨들은 원주민 커뮤니티의 문화적 프로토콜을 디지털 환경에서 표현합니다.

라벨 유형의미사용 예
TK Attribution커뮤니티 귀속출처 커뮤니티 명시
TK Non-Commercial비상업적 사용상업적 이용 제한
TK Secret/Sacred비밀/신성제한된 접근
TK Community Use Only커뮤니티 전용외부 접근 불가

5.5 상호운용성

WIA-HERITAGE 스키마는 주요 국제 표준과의 매핑을 제공합니다:

  • Dublin Core: 기본 기술 메타데이터
  • CIDOC-CRM: 이벤트 기반 문화유산 온톨로지
  • EDM: Europeana 데이터 모델
  • LIDO: 박물관 객체 기술
  • METS/PREMIS: 디지털 보존 메타데이터

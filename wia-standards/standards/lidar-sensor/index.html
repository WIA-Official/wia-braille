LiDAR Sensor Standard

Comprehensive standard for automotive LiDAR, solid-state, and FMCW systems. Covering range (200m+), angular resolution, point cloud protocols, and eye safety standards.

라이다 센서 표준

자동차 라이다, 솔리드 스테이트, FMCW 시스템을 위한 포괄적 표준. 측정 거리(200m+), 각도 해상도, 포인트 클라우드 프로토콜, 눈 안전 기준 포함.

Detection & Ranging

Phase 1

Laser emission systems (905nm, 1550nm), ToF and FMCW methods, range accuracy (±2cm), maximum detection distance (200m+), angular resolution (0.1°-0.2°).

⚡

Sensor Technology

Phase 2

Mechanical scanning (rotating mirrors), solid-state (MEMS, OPA, Flash), SPAD and APD detectors, eye safety (Class 1 laser), automotive-grade reliability.

🔬

Point Cloud Processing

Phase 3

Data output rates (1M+ points/sec), point cloud formats (PCL, LAS), real-time processing pipelines, object detection and classification, SLAM integration.

🚗

ADAS/AV Integration

Phase 4

Sensor fusion with cameras and radar, ROS/ROS2 compatibility, CAN/Ethernet protocols, ISO 26262 safety, environmental robustness (rain, fog, snow).

Standard Features

🔆 Wavelength Options

905nm (low-cost, shorter range) and 1550nm (eye-safe, longer range) laser wavelengths

📊 Detection Methods

Time-of-Flight (ToF) for simplicity, FMCW for velocity measurement and interference immunity

🎯 Scanning Technologies

Mechanical (rotating), MEMS mirrors, optical phased arrays (OPA), flash LiDAR

⚡ Detector Types

SPAD (Single Photon Avalanche Diode), APD (Avalanche Photodiode), SiPM arrays

🌧️ Environmental Robustness

Performance in rain, fog, snow, dust. IP67 rating. Operating temp -40°C to +85°C

🔗 Integration Protocols

Ethernet (UDP/TCP), CAN bus, ROS/ROS2 messages, PCL format compatibility

🛡️ Safety Standards

ISO 26262 (automotive functional safety), IEC 60825 (laser safety), AEC-Q100 qualified

📡 Leading Manufacturers

Velodyne, Luminar, Innoviz, Hesai, Ouster, Valeo, Ibeo, RoboSense

표준 기능

🔆 파장 옵션

905nm(저비용, 짧은 거리) 및 1550nm(눈 안전, 긴 거리) 레이저 파장

📊 탐지 방법

비행시간(ToF) 방식의 단순성, FMCW 방식의 속도 측정 및 간섭 면역

🎯 스캐닝 기술

기계식(회전), MEMS 미러, 광학 위상 배열(OPA), 플래시 라이다

⚡ 검출기 유형

SPAD(단일 광자 애벌런치 다이오드), APD(애벌런치 포토다이오드), SiPM 어레이

🌧️ 환경 내구성

비, 안개, 눈, 먼지 속 성능. IP67 등급. 작동 온도 -40°C ~ +85°C

🔗 통합 프로토콜

이더넷(UDP/TCP), CAN 버스, ROS/ROS2 메시지, PCL 형식 호환성

🛡️ 안전 표준

ISO 26262(자동차 기능 안전), IEC 60825(레이저 안전), AEC-Q100 인증

📡 주요 제조업체

Velodyne, Luminar, Innoviz, Hesai, Ouster, Valeo, Ibeo, RoboSense

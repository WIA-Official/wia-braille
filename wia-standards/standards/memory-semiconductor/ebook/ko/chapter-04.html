제04장: HBM과 고대역폭 메모리

HBM(High Bandwidth Memory)은 AI, 그래픽스, HPC 워크로드를 위한 고대역폭 메모리 솔루션입니다. 3D 적층 기술과 TSV(Through-Silicon Via)를 사용하여 극대화된 대역폭을 제공합니다. 이 장에서는 HBM의 아키텍처, GDDR과의 비교, 그리고 최신 HBM3/HBM4 기술을 다룹니다.

HBM 기본 구조

1. 3D 스택 아키텍처

HBM은 여러 DRAM 다이를 수직으로 적층하고 TSV로 연결합니다. 베이스 다이(로직 다이) 위에 4-16개의 DRAM 다이가 적층됩니다.

HBM 스택 구성

  • 베이스 다이(Logic Die): PHY, 버퍼, ECC 로직 포함
  • DRAM 다이: 실제 메모리 셀 (8-16개 적층)
  • TSV (Through-Silicon Via): 다이 간 수직 연결 (~10,000개/다이)
  • 마이크로범프: 다이 간 물리적 연결 (~55μm 피치)
  • 인터포저: HBM과 GPU/CPU를 연결하는 실리콘 기판

2. HBM 세대별 발전

세대 대역폭/스택 용량/스택 전압 출시 연도
HBM1 128 GB/s 4 GB 1.2V 2015
HBM2 256 GB/s 8 GB 1.2V 2016
HBM2E 460 GB/s 16 GB 1.2V 2018
HBM3 665 GB/s 24 GB 1.1V 2022
HBM3E 1.15 TB/s 36 GB 1.1V 2024
HBM4 (예정) 2+ TB/s 64+ GB 1.0V 2026
// HBM 대역폭 계산
function calculateHBMBandwidth(channels, data_rate_gbps, bus_width) {
  // 대역폭 = 채널 수 × 데이터 레이트 × 버스 폭 / 8
  const bandwidth_gbps = channels * data_rate_gbps * bus_width / 8;
  
  console.log(`채널: ${channels}`);
  console.log(`데이터 레이트: ${data_rate_gbps} Gbps`);
  console.log(`버스 폭: ${bus_width} 비트`);
  console.log(`대역폭: ${bandwidth_gbps} GB/s`);
  
  return bandwidth_gbps;
}

// HBM3 예시: 16채널, 6.4 Gbps/pin, 128비트/채널
calculateHBMBandwidth(16, 6.4, 128);
// 출력: 1638.4 GB/s (단일 스택 기준)

// 실제 GPU는 여러 스택 사용
const stacks = 6;
const total_bandwidth = calculateHBMBandwidth(16, 6.4, 128) * stacks;
console.log(`총 대역폭 (${stacks} 스택): ${total_bandwidth} GB/s`);

HBM vs GDDR 비교

1. 아키텍처 차이

HBM과 GDDR은 서로 다른 설계 철학을 가집니다. HBM은 고대역폭, GDDR은 비용 효율성을 추구합니다.

특성 HBM3 GDDR6X
패키징 3D 적층 (TSV) 전통적 PCB
버스 폭 1024-2048 비트 32 비트/칩
I/O 속도 5-7 Gbps/pin 19-21 Gbps/pin
대역폭/스택 ~665 GB/s ~84 GB/s
전력 효율 ~1.0 pJ/bit ~3.5 pJ/bit
비용 높음 중간
주요 용도 AI 가속기, HPC 게이밍 GPU

2. 응용 분야별 선택

메모리 타입 선택 기준

  • HBM 선택 시: 대역폭 > 1 TB/s 필요, AI/HPC 워크로드, 전력 효율 중요
  • GDDR 선택 시: 게이밍, 비용 민감, 확장 가능한 용량 필요
  • DDR 선택 시: 범용 컴퓨팅, 레이턴시 민감, 대용량 필요

TSV 기술

1. TSV 구조와 제조

TSV는 실리콘 웨이퍼를 관통하는 수직 전기 연결로, 3D 적층의 핵심 기술입니다.

TSV 파라미터 HBM2 HBM3 목표 (차세대)
직경 5-6 μm 4-5 μm 3-4 μm
피치 40-50 μm 30-40 μm 25-30 μm
깊이 50-100 μm 40-60 μm 30-50 μm
종횡비 ~10:1 ~12:1 ~15:1
밀도 ~400/mm² ~700/mm² ~1000/mm²

2. TSV 제조 공정

  • Via 형성: DRIE(Deep Reactive Ion Etching)로 깊은 홀 생성
  • 절연층 증착: SiO₂ 또는 Si₃N₄로 절연
  • 배리어/시드층: Ta/TaN 배리어, Cu 시드층 증착
  • Cu 충진: 전기도금으로 구리 채움
  • CMP: 화학기계적 연마로 평탄화
  • 웨이퍼 얇화: 후면 연마로 TSV 노출

HBM 인터페이스 및 프로토콜

1. 채널 구조

HBM은 여러 독립 채널로 구성되어 병렬 데이터 전송을 가능하게 합니다.

// HBM3 채널 구성
class HBM3Stack {
  constructor() {
    this.channels = 16;
    this.channel_width = 64; // bits
    this.pseudo_channels = 2; // per channel
    this.data_rate = 6.4; // Gbps
  }

  getTotalWidth() {
    return this.channels * this.channel_width;
    // 16 × 64 = 1024 비트
  }

  getBandwidth() {
    // BW = 채널 × 채널폭 × 데이터레이트 / 8
    const bw = this.channels * this.channel_width *
              this.data_rate / 8;
    return bw; // 819.2 GB/s
  }

  getEffectiveChannels() {
    // 의사 채널로 효과적인 채널 수 증가
    return this.channels * this.pseudo_channels; // 32
  }
}

2. ECC 및 RAS 기능

HBM은 엔터프라이즈급 신뢰성을 위해 강력한 ECC와 RAS 기능을 제공합니다.

HBM RAS 기능

  • On-Die ECC: 각 DRAM 다이 내부에서 오류 정정 (8비트 패리티)
  • Link ECC: TSV 및 인터포저 링크에서 추가 오류 정정
  • 체크포인트: 데이터 무결성 검증 포인트
  • 리던던시: 불량 셀/뱅크 대체 가능
  • Post-Package Repair: 패키징 후 불량 수리

HBM 응용 분야

1. AI 가속기

HBM은 AI 훈련 및 추론에 필수적인 고대역폭을 제공합니다.

AI 가속기 HBM 타입 HBM 용량 총 대역폭
NVIDIA H100 HBM3 80 GB 3 TB/s
AMD MI300X HBM3 192 GB 5.3 TB/s
Google TPU v5p HBM2E 95 GB 4.8 TB/s
// AI 모델 메모리 대역폭 요구사항 계산
function calculateAIBandwidthRequirement(model_params, batch_size, tokens, precision) {
  // 파라미터: 모델 파라미터 수 (억 단위)
  // precision: 비트/파라미터 (FP32=4, FP16=2, BF16=2, INT8=1)
  
  const bytes_per_param = precision / 8;
  const model_size_gb = (model_params * 1e9 * bytes_per_param) / 1e9;
  
  // 순방향 + 역방향 패스
  const memory_access = model_size_gb * 2;
  
  // 초당 필요한 대역폭 (100 TFLOPS 가정)
  const tflops = 100;
  const compute_time_s = (model_params * batch_size * tokens) / (tflops * 1e12);
  const required_bw = memory_access / compute_time_s;
  
  console.log(`모델 크기: ${model_size_gb.toFixed(1)} GB`);
  console.log(`필요 대역폭: ${required_bw.toFixed(0)} GB/s`);
  
  return required_bw;
}

// 예: GPT-3 (1750억 파라미터, BF16)
calculateAIBandwidthRequirement(175, 32, 2048, 16);

2. 고성능 컴퓨팅 (HPC)

슈퍼컴퓨터와 과학 컴퓨팅은 HBM의 높은 대역폭과 전력 효율성을 활용합니다.

  • 기상 모델링: 대규모 시뮬레이션에 TB/s급 메모리 대역폭 필요
  • 분자 동역학: 원자 간 상호작용 계산에 고대역폭 필수
  • 유체 역학: CFD 시뮬레이션의 메모리 집약적 연산
  • 양자 시뮬레이션: 큐비트 상태 계산에 막대한 메모리 대역폭

HBM 열관리

1. 열 문제와 해결책

3D 적층은 열 밀도를 높여 열관리가 중요한 과제입니다.

열관리 기법 설명 효과
TSV 열 전도 Cu TSV를 열 전도 경로로 활용 중간
마이크로 범프 열 분산 마이크로 범프로 열 확산 중간
인터포저 냉각 실리콘 인터포저의 높은 열전도율 높음
히트 스프레더 스택 상단에 금속 히트 스프레더 높음
액체 냉각 다이렉트 액체 냉각 솔루션 매우 높음

2. 전력 관리

HBM3는 다양한 전력 절감 기능을 통해 효율성을 극대화합니다.

HBM 전력 절감 기능

  • 의사 채널 모드: 채널을 더 작은 단위로 분할하여 미사용 부분 절전
  • DBI (Data Bus Inversion): 전환 비트 수 최소화로 전력 절감
  • 터미네이션 조절: 동적 ODT(On-Die Termination) 조정
  • 딥 슬립 모드: 장시간 미사용 시 초저전력 상태

차세대 HBM 기술

1. HBM4 로드맵

HBM4는 2026년 출시 예정으로, 대역폭과 용량을 대폭 향상시킬 것으로 전망됩니다.

기술 HBM3E HBM4 (예상) 개선율
대역폭/스택 1.15 TB/s 2.0+ TB/s +74%
용량/스택 36 GB 64 GB +78%
적층 수 12 16 +33%
데이터 레이트 9.2 Gbps 16 Gbps +74%
전력 효율 기준 +30% -

2. 신기술 동향

  • Hybrid Bonding: 마이크로 범프 대신 구리 간 직접 접합으로 밀도 향상
  • HBM-PIM: Processing-In-Memory, 메모리 내부에서 연산 수행
  • 광 인터커넥트: TSV 대신 광 연결로 대역폭 극대화
  • CXL-HBM: CXL 프로토콜 통합으로 메모리 풀링

요약

HBM은 3D 적층과 TSV 기술을 활용한 고대역폭 메모리로, AI 가속기와 HPC의 핵심 구성 요소입니다. HBM3/HBM3E는 TB/s급 대역폭을 제공하며, HBM4는 더욱 발전된 성능을 약속합니다.

핵심 요점

  • 3D 적층과 TSV로 극대화된 대역폭 (최대 1.15 TB/s)
  • GDDR 대비 3배 이상 높은 전력 효율성
  • AI/HPC 워크로드에 최적화된 고대역폭 솔루션
  • On-Die ECC와 RAS 기능으로 엔터프라이즈급 신뢰성
  • HBM4로 2+ TB/s 대역폭 달성 전망

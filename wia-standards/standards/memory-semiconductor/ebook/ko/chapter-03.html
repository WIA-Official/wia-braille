제03장: NAND Flash 메모리 기술

NAND Flash는 비휘발성 메모리로, SSD, USB 드라이브, 메모리 카드 등에 널리 사용됩니다. 이 장에서는 NAND Flash의 동작 원리, 3D NAND 기술, 웨어 레벨링, 그리고 최신 QLC/PLC 기술을 다룹니다.

NAND Flash 기본 원리

1. 플로팅 게이트 트랜지스터

NAND Flash 셀은 플로팅 게이트 트랜지스터를 사용하여 데이터를 저장합니다. 플로팅 게이트에 전자를 저장하거나 제거하여 임계 전압을 변경합니다.

플로팅 게이트 구조

  • 컨트롤 게이트(Control Gate): 읽기/쓰기 전압 인가
  • 플로팅 게이트(Floating Gate): 절연체로 둘러싸인 전하 저장소
  • 터널 산화막: 파울러-노드하임 터널링으로 전자 이동
  • 소스/드레인: 전류 경로

2. 프로그램/소거 동작

NAND Flash는 프로그래밍(쓰기)과 소거가 서로 다른 메커니즘으로 동작합니다.

동작 메커니즘 시간 단위
프로그램 FN 터널링으로 전자 주입 200-500 μs 페이지 단위
소거 FN 터널링으로 전자 방출 1.5-3 ms 블록 단위
읽기 임계 전압 감지 25-50 μs 페이지 단위
// NAND Flash 기본 연산 예시
class NANDFlashController {
  constructor() {
    this.pageSize = 16384; // 16KB
    this.blockSize = 256; // 256 페이지/블록
    this.planes = 2;
  }

  async readPage(block, page) {
    // 읽기 명령 발행
    await this.sendCommand(0x00);
    await this.sendAddress(block, page);
    await this.sendCommand(0x30);
    
    // 읽기 완료 대기 (~25μs)
    await this.waitReady();
    return this.readData(this.pageSize);
  }

  async programPage(block, page, data) {
    // 프로그램 명령 발행
    await this.sendCommand(0x80);
    await this.sendAddress(block, page);
    await this.writeData(data);
    await this.sendCommand(0x10);
    
    // 프로그램 완료 대기 (~200μs)
    await this.waitReady();
    return this.checkStatus();
  }

  async eraseBlock(block) {
    // 소거 명령 발행
    await this.sendCommand(0x60);
    await this.sendAddress(block, 0);
    await this.sendCommand(0xD0);
    
    // 소거 완료 대기 (~2ms)
    await this.waitReady();
    return this.checkStatus();
  }
}

멀티 레벨 셀 기술

1. SLC, MLC, TLC, QLC, PLC

NAND Flash는 셀당 저장되는 비트 수에 따라 분류됩니다. 비트 수가 증가하면 용량은 늘어나지만 성능과 내구성은 감소합니다.

타입 비트/셀 P/E 사이클 속도 비용/GB 주요 용도
SLC 1 50,000-100,000 가장 빠름 가장 높음 엔터프라이즈, 산업용
MLC 2 3,000-10,000 빠름 높음 프로페셔널 SSD
TLC 3 500-3,000 중간 중간 소비자 SSD, 스마트폰
QLC 4 100-1,000 느림 낮음 읽기 집약적 워크로드
PLC 5 100-500 가장 느림 가장 낮음 아카이브, 콜드 스토리지

MLC 레벨 구분

  • SLC (Single Level Cell): 2개 상태 (1비트). 임계 전압 1개
  • MLC (Multi Level Cell): 4개 상태 (2비트). 임계 전압 3개
  • TLC (Triple Level Cell): 8개 상태 (3비트). 임계 전압 7개
  • QLC (Quad Level Cell): 16개 상태 (4비트). 임계 전압 15개
  • PLC (Penta Level Cell): 32개 상태 (5비트). 임계 전압 31개

3D NAND 기술

1. 수직 적층 구조

3D NAND는 메모리 셀을 수직으로 적층하여 면적당 용량을 크게 증가시킵니다. 현재 200층 이상의 적층이 가능합니다.

세대 레이어 수 셀 타입 용량/칩 출시 연도
1세대 24-32 MLC/TLC 128Gb 2013-2015
2세대 48-64 TLC 256Gb 2016-2017
3세대 96 TLC/QLC 512Gb-1Tb 2018-2019
4세대 128-144 TLC/QLC 1Tb 2020-2021
5세대 176-232 TLC/QLC 1Tb-2Tb 2022-2024

2. 3D NAND 아키텍처

3D NAND는 다양한 아키텍처로 구현됩니다. 주요 방식은 다음과 같습니다.

  • BiCS (Bit Cost Scalable): 도시바/키옥시아의 펀치 앤 플러그 방식
  • V-NAND: 삼성의 차지 트랩 구조 (CTF) 방식
  • 3D NAND: SK하이닉스/인텔/마이크론의 플로팅 게이트 방식

FTL (Flash Translation Layer)

1. 논리-물리 주소 매핑

FTL은 호스트의 논리 주소를 Flash의 물리 주소로 변환하고, 웨어 레벨링과 가비지 컬렉션을 수행합니다.

// 간단한 FTL 구현 예시
class FlashTranslationLayer {
  constructor(totalBlocks) {
    this.totalBlocks = totalBlocks;
    this.mappingTable = new Map(); // LBA -> PBA
    this.eraseCount = new Array(totalBlocks).fill(0);
    this.freeBlocks = [];
    
    // 초기화: 모든 블록을 프리 리스트에 추가
    for (let i = 0; i < totalBlocks; i++) {
      this.freeBlocks.push(i);
    }
  }

  write(lba, data) {
    // 프리 블록 할당
    const pba = this.allocateBlock();
    
    // 이전 매핑이 있으면 무효화
    if (this.mappingTable.has(lba)) {
      const oldPBA = this.mappingTable.get(lba);
      this.invalidateBlock(oldPBA);
    }
    
    // 새 매핑 생성
    this.mappingTable.set(lba, pba);
    this.flash.program(pba, data);
  }

  read(lba) {
    const pba = this.mappingTable.get(lba);
    return pba !== undefined ? this.flash.read(pba) : null;
  }

  garbageCollection() {
    // 무효 페이지가 많은 블록 선택
    const victim = this.selectVictimBlock();
    
    // 유효 페이지 복사
    for (const [lba, pba] of this.mappingTable) {
      if (this.getBlock(pba) === victim) {
        const data = this.flash.read(pba);
        this.write(lba, data);
      }
    }
    
    // 블록 소거
    this.flash.erase(victim);
    this.eraseCount[victim]++;
    this.freeBlocks.push(victim);
  }
}

2. 웨어 레벨링

웨어 레벨링은 모든 블록의 소거 횟수를 균등하게 분산시켜 수명을 연장합니다.

웨어 레벨링 전략

  • 동적 웨어 레벨링: 쓰기 시에만 소거 횟수가 적은 블록 선택
  • 정적 웨어 레벨링: 읽기 전용 데이터도 주기적으로 이동시켜 균등화
  • 글로벌 웨어 레벨링: 전체 드라이브에 걸쳐 균등화

ECC와 데이터 무결성

1. 오류 정정 코드

NAND Flash는 비트 오류율이 높아 강력한 ECC가 필수적입니다. QLC/PLC로 갈수록 더 강력한 ECC가 필요합니다.

ECC 알고리즘 정정 능력 오버헤드 적용 대상
BCH 수십 비트/1KB 10-15% SLC, MLC
LDPC 수백 비트/4KB 15-20% TLC, QLC
Soft-Decision LDPC 수천 비트/4KB 20-25% QLC, PLC

2. 리드 리트라이와 리프레시

Flash 셀이 노화되면 읽기 오류가 증가합니다. 이를 해결하기 위한 기법들이 있습니다.

  • 리드 리트라이(Read Retry): 읽기 실패 시 전압 레벨을 조정하여 재시도
  • 리프레시(Refresh): 오래된 데이터를 새 블록에 다시 쓰기
  • 데이터 스크러빙(Scrubbing): 주기적으로 전체 데이터 검사 및 정정

SSD 성능 최적화

1. 오버프로비저닝

SSD는 호스트에 공개되지 않은 여유 용량을 유지하여 성능과 수명을 개선합니다.

// 오버프로비저닝 계산
function calculateOverprovisioning(physicalGB, userGB) {
  const op_space = physicalGB - userGB;
  const op_percentage = (op_space / userGB) * 100;
  
  console.log(`물리 용량: ${physicalGB}GB`);
  console.log(`사용자 용량: ${userGB}GB`);
  console.log(`OP 공간: ${op_space}GB (${op_percentage.toFixed(1)}%)`);
  
  return {
    physical: physicalGB,
    user: userGB,
    op: op_space,
    percentage: op_percentage
  };
}

// 예시: 512GB SSD
// 실제 NAND: 512GB
// 사용자 용량: 480GB (7% OP)
calculateOverprovisioning(512, 480);

2. SLC 캐싱

TLC/QLC SSD는 일부 용량을 SLC 모드로 운영하여 쓰기 성능을 높입니다.

SSD 타입 SLC 캐시 크기 SLC 속도 기본 속도
TLC (정적) 고정 (예: 20GB) ~500 MB/s ~200 MB/s
TLC (동적) 가변 (최대 100GB) ~500 MB/s ~200 MB/s
QLC (동적) 가변 (최대 140GB) ~500 MB/s ~80 MB/s

인터페이스 기술

1. NVMe 프로토콜

NVMe(Non-Volatile Memory Express)는 PCIe 인터페이스를 통한 고성능 스토리지 프로토콜입니다.

NVMe 주요 특징

  • 낮은 레이턴시: 명령 처리 오버헤드 감소로 ~2.8μs 달성
  • 높은 큐 깊이: 64K 큐, 각 큐당 64K 명령 지원
  • 병렬 처리: 멀티코어 CPU 활용한 병렬 I/O
  • PCIe 대역폭: PCIe 4.0 x4로 최대 7,000 MB/s 달성
인터페이스 프로토콜 대역폭 레이턴시
SATA 3.0 AHCI 600 MB/s ~6 μs
PCIe 3.0 x4 NVMe 3,500 MB/s ~2.8 μs
PCIe 4.0 x4 NVMe 7,000 MB/s ~2.5 μs
PCIe 5.0 x4 NVMe 14,000 MB/s ~2.0 μs

NAND Flash 신뢰성

1. P/E 사이클과 수명

NAND Flash의 수명은 프로그램/소거 사이클 수로 결정됩니다.

// SSD 수명 계산 (TBW - Total Bytes Written)
function calculateEndurance(capacityGB, pe_cycles, op_factor = 1.07, wa_factor = 3.0) {
  // TBW = 용량 × P/E 사이클 × OP 계수 / WA 계수
  const tbw = (capacityGB * pe_cycles * op_factor) / wa_factor;
  
  console.log(`용량: ${capacityGB}GB`);
  console.log(`P/E 사이클: ${pe_cycles}`);
  console.log(`쓰기 증폭: ${wa_factor}x`);
  console.log(`TBW: ${tbw.toFixed(0)}TB`);
  
  // 일일 쓰기량 기반 수명 계산
  const daily_write_gb = 50; // 일 50GB 쓰기 가정
  const years = (tbw * 1024) / (daily_write_gb * 365);
  console.log(`예상 수명: ${years.toFixed(1)}년 (일 ${daily_write_gb}GB 쓰기 시)`);
  
  return tbw;
}

// 예시: 1TB TLC SSD (3000 P/E 사이클)
calculateEndurance(1000, 3000, 1.07, 3.0);

2. TRIM과 가비지 컬렉션

TRIM 명령은 OS가 SSD에 삭제된 블록을 알려주어 성능을 유지합니다.

  • TRIM: 호스트가 삭제된 LBA를 SSD에 통보
  • 백그라운드 GC: 유휴 시간에 가비지 컬렉션 수행
  • 포그라운드 GC: 프리 블록 부족 시 즉시 GC 수행

요약

NAND Flash는 비휘발성 저장 장치의 핵심 기술로, 3D 적층과 멀티 레벨 셀 기술로 용량을 지속적으로 증가시키고 있습니다. FTL, ECC, 웨어 레벨링 등의 소프트웨어 기술이 성능과 수명을 최적화합니다.

핵심 요점

  • 플로팅 게이트 트랜지스터로 비휘발성 데이터 저장
  • 3D NAND는 200층 이상 수직 적층으로 고용량 달성
  • TLC/QLC/PLC로 갈수록 용량 증가, 성능/수명 감소
  • FTL과 ECC로 Flash 한계 극복 및 수명 연장
  • NVMe 프로토콜로 PCIe 대역폭 완전 활용

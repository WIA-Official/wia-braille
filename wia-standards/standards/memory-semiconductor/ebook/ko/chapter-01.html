제01장: DRAM 메모리 기술

DRAM(Dynamic Random Access Memory)은 현대 컴퓨팅 시스템의 핵심 메모리 기술로, 메인 메모리로 널리 사용됩니다. 이 장에서는 DRAM의 동작 원리, 아키텍처, 성능 특성 및 최신 기술 발전을 상세히 다룹니다.

DRAM 기본 원리

1. DRAM 셀 구조

DRAM은 1트랜지스터 1캐패시터(1T1C) 구조를 사용하여 데이터를 저장합니다. 각 메모리 셀은 하나의 접근 트랜지스터와 하나의 저장 캐패시터로 구성됩니다.

DRAM 셀의 주요 구성 요소

  • 접근 트랜지스터(Access Transistor): 워드 라인(Word Line)에 의해 제어되며, 비트 라인(Bit Line)과 캐패시터 사이의 연결을 담당
  • 저장 캐패시터(Storage Capacitor): 전하의 유무로 0과 1을 표현. 일반적으로 25-30 펨토패럿(fF) 용량
  • 비트 라인(Bit Line): 데이터 읽기/쓰기 경로
  • 워드 라인(Word Line): 셀 선택 신호

2. 리프레시 메커니즘

DRAM의 가장 중요한 특성 중 하나는 주기적인 리프레시가 필요하다는 점입니다. 캐패시터에 저장된 전하는 누설 전류로 인해 시간이 지나면 소실되므로, 데이터 유지를 위해 정기적으로 재충전해야 합니다.

리프레시 유형 주기 특징
자동 리프레시 64ms 메모리 컨트롤러가 자동으로 모든 행 리프레시
셀프 리프레시 가변 저전력 모드에서 DRAM 내부 회로가 리프레시 수행
타겟 리프레시 필요시 로우해머 공격 방지를 위한 특정 행 리프레시

DRAM 아키텍처

1. 뱅크 구조

현대 DRAM은 여러 뱅크로 구성되어 병렬 처리를 통해 성능을 향상시킵니다. 각 뱅크는 독립적으로 동작할 수 있어 여러 읽기/쓰기 작업을 동시에 수행할 수 있습니다.

// DRAM 주소 디코딩 구조
struct DRAMAddress {
  uint8_t bank; // 뱅크 선택 (예: 8 뱅크)
  uint16_t row; // 행 주소 (예: 16K 행)
  uint16_t column; // 열 주소 (예: 1K 열)
};

// DDR4-3200 사양 예시
const DRAMSpec DDR4_3200 = {
  .banks = 16, // 16 뱅크
  .rows = 65536, // 64K 행
  .columns = 1024, // 1K 열
  .bus_width = 64, // 64비트 데이터 버스
  .frequency = 1600, // 1600 MHz (DDR: 3200 MT/s)
  .capacity_gb = 8 // 8GB 모듈
};

2. DDR 세대별 발전

DDR(Double Data Rate) SDRAM은 클럭의 상승 및 하강 에지 모두에서 데이터를 전송하여 효율성을 높입니다.

DDR 세대 데이터 전송률 전압 프리페치 뱅크 그룹
DDR3 800-2133 MT/s 1.5V 8n 1
DDR4 1600-3200 MT/s 1.2V 8n 2-4
DDR5 3200-6400 MT/s 1.1V 16n 4-8
DDR6 (예정) 8000+ MT/s 1.0V 32n 8-16

DRAM 타이밍 파라미터

1. 주요 타이밍 스펙

DRAM 성능은 여러 타이밍 파라미터에 의해 결정됩니다. 이러한 파라미터는 메모리 액세스 지연과 대역폭에 직접적인 영향을 미칩니다.

핵심 타이밍 파라미터 (DDR4-3200 CL16 예시)

  • CL (CAS Latency): 16 클럭 사이클 - 읽기 명령 후 데이터 출력까지의 지연
  • tRCD (RAS to CAS Delay): 16 클럭 - 행 활성화 후 열 명령까지의 지연
  • tRP (Row Precharge Time): 16 클럭 - 행 프리차지 시간
  • tRAS (Row Active Time): 36 클럭 - 행 활성 최소 시간
  • tRFC (Refresh Cycle Time): 350ns - 리프레시 사이클 시간
// DRAM 레이턴시 계산 예시
function calculateDRAMLatency(frequency_mhz, cl) {
  const cycle_time_ns = 1000 / frequency_mhz;
  const latency_ns = cl * cycle_time_ns;
  return latency_ns;
}

// DDR4-3200 CL16의 실제 레이턴시
// 1600 MHz 실제 클럭, 3200 MT/s DDR 레이트
const latency = calculateDRAMLatency(1600, 16);
console.log(`CAS Latency: ${latency}ns`); // 10ns

DRAM 제조 기술

1. 공정 노드 발전

DRAM 제조 공정은 지속적으로 미세화되어 왔으며, 현재 10나노미터 이하 공정이 사용됩니다.

세대 공정 노드 셀 크기 용량/칩 주요 제조사
1x nm 10-19nm ~6F² 8Gb Samsung, SK Hynix, Micron
1y nm 14-16nm ~6F² 16Gb Samsung, SK Hynix, Micron
1z nm 12-14nm ~6F² 16Gb Samsung, SK Hynix, Micron
1α nm 10-12nm ~6F² 24Gb Samsung, SK Hynix, Micron

2. 캐패시터 구조

미세 공정에서 충분한 전하 저장 용량을 유지하기 위해 다양한 3D 캐패시터 구조가 개발되었습니다.

  • 스택 캐패시터(Stack Capacitor): 수직으로 적층된 구조로 높은 종횡비 달성
  • 트렌치 캐패시터(Trench Capacitor): 실리콘 기판에 깊은 홈을 파서 면적 증대
  • MIM 캐패시터(Metal-Insulator-Metal): 고유전율 절연체 사용으로 용량 증가
  • 3D 캐패시터: 복잡한 3차원 구조로 극대화된 표면적

LPDDR: 저전력 DRAM

1. LPDDR 특징

LPDDR(Low Power DDR)은 모바일 기기를 위한 저전력 DRAM으로, 배터리 수명 연장이 핵심 목표입니다.

LPDDR 세대 데이터 전송률 전압 전력 효율 주요 응용
LPDDR4X 4266 MT/s 0.6V 기준 스마트폰, 태블릿
LPDDR5 6400 MT/s 0.5V +20% 5G 스마트폰, AI
LPDDR5X 8533 MT/s 0.5V +30% 프리미엄 스마트폰

DRAM 성능 최적화

1. 메모리 인터리빙

여러 메모리 뱅크와 채널을 활용하여 병렬 액세스를 통해 대역폭을 극대화합니다.

// 듀얼 채널 메모리 설정 예시
class DualChannelMemory {
  constructor() {
    this.channel_a = new MemoryChannel(0);
    this.channel_b = new MemoryChannel(1);
  }

  read(address) {
    // 주소의 최하위 비트로 채널 선택
    const channel = (address & 0x40) ? this.channel_b : this.channel_a;
    return channel.read(address >> 7);
  }

  getBandwidth() {
    // 듀얼 채널로 2배 대역폭
    return 2 * 3200 * 8; // 51.2 GB/s (DDR4-3200)
  }
}

2. 로우 버퍼 히트 최적화

동일한 메모리 행에 대한 연속적인 액세스는 행 버퍼 히트를 발생시켜 레이턴시를 크게 감소시킵니다.

행 버퍼 히트 vs 미스

  • 행 버퍼 히트: 동일 행 액세스 시 CL만 소요 (~10ns)
  • 행 버퍼 미스: 다른 행 액세스 시 tRP + tRCD + CL 소요 (~50ns)
  • 성능 향상: 순차 액세스 패턴으로 최대 5배 향상 가능

DRAM 보안 및 신뢰성

1. ECC (Error Correction Code)

서버용 DRAM은 ECC를 통해 비트 오류를 감지하고 수정합니다.

ECC 방식 감지 능력 수정 능력 오버헤드
SEC (Single Error Correction) 2비트 오류 1비트 오류 12.5%
SECDED 2비트 오류 1비트 오류 12.5%
Chipkill 칩 전체 장애 1칩 장애 25%

2. 로우해머 공격 대응

로우해머(Rowhammer)는 특정 메모리 행을 반복적으로 액세스하여 인접 행의 데이터를 변조하는 공격입니다. 최신 DRAM은 다양한 대응책을 구현합니다.

  • 타겟 행 리프레시(TRR): 빈번하게 액세스되는 행의 인접 행을 추가 리프레시
  • 증가된 리프레시 율: 전체적인 리프레시 빈도 증가
  • 하드웨어 카운터: 행별 액세스 횟수 모니터링

요약

DRAM은 1T1C 구조의 단순함으로 높은 집적도를 달성하며, 현대 컴퓨터 시스템의 메인 메모리로 필수적입니다. DDR5와 LPDDR5X 같은 최신 세대는 더 높은 대역폭과 낮은 전력 소비를 제공합니다.

핵심 요점

  • DRAM은 주기적 리프레시가 필요한 휘발성 메모리
  • 뱅크 구조와 인터리빙을 통한 병렬 처리로 성능 향상
  • DDR 세대가 발전할수록 속도는 증가하고 전압은 감소
  • ECC와 TRR 같은 기술로 신뢰성과 보안 강화
  • 10nm 이하 공정 기술로 더 높은 용량 달성

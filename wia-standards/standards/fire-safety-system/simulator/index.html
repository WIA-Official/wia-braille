Heat Detection Algorithm

  • Fixed Temperature: 57°C (135°F)
  • Rate of Rise: >8°C/min (>15°F/min)
  • Combined detection for reliability
  • Adaptive thresholds by zone type

Multi-Criteria Algorithm

function detectFire(sensors) {
  let confidence = 0;
  
  // Smoke detection
  if (sensors.smoke.obscuration > 4.0) {
    confidence += 40;
  } else if (sensors.smoke.obscuration > 3.0) {
    confidence += 20;
  }
  
  // Heat detection
  if (sensors.heat.temperature > 57) {
    confidence += 40;
  } else if (sensors.heat.rateOfRise > 8) {
    confidence += 30;
  }
  
  // CO detection
  if (sensors.co.ppm > 50) {
    confidence += 20;
  }
  
  // Multi-sensor correlation
  if (confidence > 60 && 
      sensors.smoke.obscuration > 2.0 && 
      sensors.heat.temperature > 30) {
    confidence += 20;
  }
  
  return {
    confidence: Math.min(confidence, 100),
    alarm: confidence >= 70,
    preAlarm: confidence >= 50
  };
}

Emergency Communication Protocol

// EVAC Sequence
1. PRE-ALERT (T+0s)
   - Silent notification to security/management
   - Camera activation in alert zones
   
2. ZONE ALERT (T+30s)
   - Audible alarm in affected zones
   - Visual strobes activated
   - Voice message: "Alert. Please stand by."
   
3. FULL EVACUATION (T+60s)
   - Building-wide alarm
   - Voice message: "Fire alarm. Evacuate now."
   - Emergency lighting activated
   - Elevator recall
   - Door unlock/access control override
   
4. EMERGENCY SERVICES (T+0s)
   - Auto-dial fire department
   - Location data transmitted
   - Building plans/hazmat info sent
   - Video feed access granted

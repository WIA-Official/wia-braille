🧮 Biodiversity Index Algorithms

Calculate various biodiversity indices from species occurrence data.

Shannon Diversity Index (H')

Measures species diversity taking into account both richness and evenness.

H' = -Σ(pi × ln(pi))

where:
- pi = proportion of individuals of species i
- ln = natural logarithm
- Σ = sum across all species

Range: 0 (no diversity) to ln(S) where S = total species count
Typical values: 1.5-3.5 for most ecosystems

Simpson's Index (D)

Represents the probability that two randomly selected individuals belong to the same species.

D = Σ(ni × (ni - 1)) / (N × (N - 1))

where:
- ni = number of individuals of species i
- N = total number of individuals

Simpson's Diversity Index (1 - D):
Range: 0 (no diversity) to 1 (infinite diversity)

Species Richness (S)

The simplest measure - total number of different species in a community.

S = total number of species

Margalef's Richness Index:
DMg = (S - 1) / ln(N)

where N = total number of individuals

Pielou's Evenness (J')

Measures how evenly individuals are distributed across species.

J' = H' / ln(S)

where:
- H' = Shannon diversity index
- S = species richness

Range: 0 (one dominant species) to 1 (all species equally abundant)

Beta Diversity (β)

Measures change in species composition between communities.

Whittaker's Beta:
β = S / α - 1

where:
- S = total species in landscape (gamma diversity)
- α = mean species richness per site (alpha diversity)

Sørensen Index:
βsor = 2C / (A + B)

where:
- C = number of shared species
- A, B = species counts in communities A and B

Implementation Note: All algorithms handle missing data, zero counts, and edge cases. Confidence intervals can be calculated using bootstrap resampling (n=1000 iterations recommended).

📋 Field Survey Protocol

Standardized methodology for biodiversity assessment across ecosystems.

Site Selection

Criterion Requirement Notes
Plot Size Minimum 100m × 100m Adjust based on ecosystem type
Replication ≥3 plots per habitat type For statistical validity
Accessibility Safe year-round access For temporal monitoring
GPS Accuracy ±5 meters Use differential GPS if available

Sampling Methods by Taxon

Taxon Method Effort
Birds Point counts 10 min per point, 5 points per plot
Mammals Camera traps 3 cameras per plot, 30 days
Plants Quadrat surveys 10 × 1m² quadrats per plot
Insects Sweep netting + pitfall traps 100 sweeps, 5 traps × 48 hours
Aquatic eDNA + seine netting 3 × 1L water samples, 3 net sweeps

Quality Control Checklist

✓ GPS coordinates verified and recorded

✓ Weather conditions documented

✓ Species identifications verified (photo evidence required for rare/uncertain species)

✓ Habitat characteristics measured (canopy cover, soil pH, temperature)

✓ Equipment calibrated before survey

✓ Data entered within 24 hours of collection

✓ Voucher specimens collected where appropriate (following permits)

✓ Raw data backed up in 3 locations

Temporal Monitoring Schedule

Quarterly Surveys (Recommended):
- Q1 (Jan-Mar): Post-winter baseline
- Q2 (Apr-Jun): Spring breeding season
- Q3 (Jul-Sep): Peak growing season
- Q4 (Oct-Dec): Pre-winter assessment

Annual Intensive Survey:
- One comprehensive survey per year
- All taxa groups
- Extended observation period (7-14 days)
- Includes eDNA sampling

Long-term Monitoring:
- Minimum 5-year commitment
- Same protocols maintained
- Equipment upgrades documented
- Observer bias controlled through training

Certification: Field teams must complete WIA Biodiversity Survey Training (16 hours) and pass practical assessment. Recertification required every 3 years.

🔗 System Integration

Connect biodiversity data with global databases and conservation platforms.

GBIF Integration

Global Biodiversity Information Facility data exchange.

// Upload occurrence data to GBIF
POST https://api.gbif.org/v1/occurrence

Headers:
  Authorization: Bearer {your_token}
  Content-Type: application/json

Body:
{
  "datasetKey": "your-dataset-uuid",
  "occurrences": [
    {
      "scientificName": "Panthera tigris",
      "decimalLatitude": 27.5142,
      "decimalLongitude": 88.7597,
      "eventDate": "2025-12-15",
      "basisOfRecord": "HUMAN_OBSERVATION",
      "individualCount": 1
    }
  ]
}

// Query GBIF for species in region
GET https://api.gbif.org/v1/occurrence/search
  ?scientificName=Panthera+tigris
  &country=IN
  &hasCoordinate=true
  &limit=100

IUCN Red List API

Retrieve conservation status and threat information.

// Get species conservation status
GET https://apiv3.iucnredlist.org/api/v3/species/Panthera%20tigris

GIS Integration (ArcGIS / QGIS)

Spatial analysis and habitat mapping.

// WFS (Web Feature Service) endpoint
GET https://biodiversity.wia.org/geoserver/wfs
  ?service=WFS
  &version=2.0.0
  &request=GetFeature
  &typeName=biodiversity:occurrences
  &outputFormat=application/json
  &bbox=88.0,27.0,89.0,28.0,EPSG:4326

// WMS (Web Map Service) for habitat layers
GET https://biodiversity.wia.org/geoserver/wms
  ?service=WMS
  &version=1.3.0
  &request=GetMap
  &layers=biodiversity:habitat_types
  &styles=
  &bbox=88.0,27.0,89.0,28.0
  &width=768
  &height=768
  &srs=EPSG:4326
  &format=image/png

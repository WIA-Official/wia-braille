인터랙티브 화이트보드 도구

인터랙티브 화이트보드는 가상 교실의 핵심 기능으로, 실시간 협업과 시각적 학습을 가능하게 합니다.

핵심 기능

  • 그리기 도구: 펜, 형광펜, 지우개
  • 도형: 사각형, 원, 화살표, 선
  • LaTeX 방정식 지원이 포함된 텍스트
  • 파일 업로드 및 주석
  • 탐색이 가능한 다중 페이지 지원

실시간 동기화

모든 참가자가 업데이트를 즉시 확인합니다:

whiteboard.on('draw', (event) => {
  syncToAllParticipants(event);
});

협업 모범 사례

  • 참가자에게 다른 색상 할당
  • 구성을 위해 레이어 사용
  • 정기적으로 스냅샷 저장
  • 보드를 PDF 또는 이미지로 내보내기

Assessments & Quizzes

Create interactive quizzes and polls to assess understanding and gather feedback in real-time.

Quiz Types

  • Multiple choice questions
  • True/false questions
  • Short answer responses
  • Essay questions

Creating a Quiz

const quiz = await classroom.createQuiz({
  title: 'Chapter Review',
  duration: 15,
  questions: [
    {
      type: 'multiple-choice',
      question: 'What is WebRTC?',
      options: ['A', 'B', 'C', 'D'],
      correctAnswer: 0
    }
  ]
});

6.1 Bluetooth LE Protocol

Service UUID: 00001820-0000-1000-8000-00805f9b34fb

Characteristics:

  • Device Info (Read)
  • Signal Config (Read/Write)
  • Data Stream (Notify)
  • Control Commands (Write)
  • Status (Notify)

6.2 WiFi/TCP Protocol

// TLS Socket Connection
const client = tls.connect(8883, deviceIP, {
  ca: [caCertificate],
  checkServerIdentity: verifyDeviceCertificate
});

client.on('data', (packet) => {
  const data = decodeWIA(packet);
  processVitalSignData(data);
});

6.4 WebSocket Protocol

const ws = new WebSocket('wss://api.example.com/stream');

ws.onopen = () => {
  ws.send(JSON.stringify({
    command: 'start',
    signalType: 'ECG'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  updateECGChart(data);
};

6.5 Protocol Selection Guide

Protocol Best For Pros Cons
BLE Wearables Low power Limited range
WiFi/TCP Home devices High bandwidth Higher power
MQTT IoT devices Lightweight Needs broker
WebSocket Web apps Browser support Firewall issues

6.6 Security Requirements

  • Encryption: TLS 1.3, AES-256
  • Authentication: OAuth 2.0, FIDO2
  • Compliance: HIPAA, GDPR

CHAPTER 05

📡 드론 통신 시스템

드론과 조종자 간의 통신 시스템을 탐구합니다. RF 통신, 텔레메트리, MAVLink 프로토콜, 그리고 FPV 영상 전송 시스템을 이해합니다.

5.1 무선 주파수 (RF) 통신

드론은 무선 주파수를 통해 조종 명령을 받고 상태 정보를 전송합니다.

5.1.1 주파수 대역

주파수 장점 단점 용도
27MHz / 72MHz 장거리, 장애물 투과 구형, 간섭 많음 구형 RC 시스템
433MHz / 915MHz 매우 장거리 (수십 km) 낮은 대역폭 텔레메트리, 장거리 제어
2.4GHz 고대역폭, 저지연, 저렴 짧은 거리 (~1-5km) RC 제어, FPV (디지털)
5.8GHz 넓은 채널, FPV 표준 매우 짧은 거리 아날로그 FPV 영상

5.1.2 2.4GHz RC 시스템

가장 일반적인 RC 주파수로, 다양한 프로토콜이 있습니다:

  • FrSky ACCST/ACCESS: 유럽에서 인기, D8/D16 모드
  • Spektrum DSMX: 북미 표준
  • Futaba FASST/T-FHSS: 일본 브랜드
  • FlySky AFHDS: 저가형, 입문용

💡 FHSS (Frequency Hopping Spread Spectrum)

2.4GHz 시스템은 FHSS 기술을 사용하여 여러 채널을 빠르게 전환하며 통신합니다. 이는 간섭을 피하고 여러 드론이 동시에 비행할 수 있게 합니다.

5.2 장거리 통신 시스템

5.2.1 900MHz 장거리 RC

  • TBS Crossfire:
    • 주파수: 868MHz (유럽) / 915MHz (미국)
    • 거리: 최대 80km+ (이상적 조건)
    • 지연: ~5ms
    • 양방향 텔레메트리
  • ExpressLRS (ELRS):
    • 오픈소스, 900MHz 또는 2.4GHz
    • 매우 낮은 지연 (~4ms @ 500Hz)
    • 저비용
    • 500Hz, 250Hz, 150Hz 업데이트 레이트

5.2.2 4G/5G LTE 통신

상업용 드론은 셀룰러 네트워크를 통해 사실상 무제한 거리 통신이 가능합니다:

  • 장점:
    • 거리 제한 없음 (셀 커버리지 범위 내)
    • 고대역폭 (HD 영상 스트리밍)
    • 양방향 데이터 전송
  • 단점:
    • 지연 시간 높음 (100~500ms)
    • 셀 커버리지 의존
    • 데이터 요금
    • 실시간 제어 부적합 (모니터링용)
  • 응용:
    • Beyond Visual Line of Sight (BVLOS) 비행
    • 장거리 배송 드론
    • 영상 스트리밍

5.3 텔레메트리

텔레메트리는 드론의 상태 정보를 실시간으로 조종자에게 전송합니다.

5.3.1 전송되는 데이터

  • 배터리 정보: 전압, 전류, 소모량, 남은 용량
  • GPS 데이터: 위도/경도, 고도, 속도, 위성 수
  • 비행 데이터: 자세(Roll/Pitch/Yaw), 고도, 수직 속도
  • 센서 상태: GPS fix, 나침반 상태
  • 경고: 저전압, RC 신호 약화, failsafe 상태

5.3.2 텔레메트리 시스템

  • FrSky S.Port: FrSky 수신기 통합 텔레메트리
  • Crossfire CRSF: RC와 텔레메트리 통합
  • MAVLink: 범용 드론 통신 프로토콜 (아래 상세 설명)
  • LTM (Lightweight Telemetry): 경량 프로토콜

5.3.3 OSD (On-Screen Display)

OSD는 FPV 영상에 텔레메트리 정보를 오버레이합니다:

  • 배터리 전압, 전류 소모
  • 비행 시간 (타이머)
  • GPS 좌표, 고도
  • 인공 수평선
  • 홈 방향 화살표
  • RC 신호 강도 (RSSI)

5.4 MAVLink 프로토콜

MAVLink (Micro Air Vehicle Link)는 드론과 지상 제어 스테이션(GCS) 간 통신을 위한 경량 메시징 프로토콜입니다.

5.4.1 MAVLink 특징

  • 경량: 최소 8바이트 헤더, 효율적
  • 범용: ArduPilot, PX4, MAVSDK 지원
  • 확장 가능: 사용자 정의 메시지 추가 가능
  • 신뢰성: CRC 체크섬, 메시지 시퀀싱

5.4.2 주요 MAVLink 메시지

  • HEARTBEAT: 시스템 상태, 비행 모드
  • ATTITUDE: Roll, Pitch, Yaw 각도
  • GPS_RAW_INT: GPS 위치, 속도
  • RC_CHANNELS: RC 입력 값
  • MISSION_ITEM: 웨이포인트 정보
  • COMMAND_LONG: 명령 전송 (ARM, 이륙, 착륙 등)

5.4.3 MAVLink over 텔레메트리

MAVLink는 다양한 통신 채널을 통해 전송될 수 있습니다:

  • UART/Serial: FC와 텔레메트리 라디오 연결
  • WiFi: ESP8266/ESP32를 통한 무선
  • 4G/LTE: 장거리 통신
  • USB: 지상에서 직접 연결

5.5 FPV 영상 전송

FPV (First Person View) 시스템은 드론의 카메라 영상을 실시간으로 전송합니다.

5.5.1 아날로그 FPV

전통적인 FPV 방식으로 낮은 지연시간이 장점입니다:

  • 주파수: 5.8GHz (일반적), 1.2GHz/1.3GHz (장거리)
  • 해상도: NTSC (720×480), PAL (720×576)
  • 지연: 5~20ms (매우 낮음)
  • 전력: 25mW, 200mW, 600mW, 1000mW+
  • 채널: 40+ 채널 (Raceband, Boscam A/B/E 등)

⚠️ VTX 전력 규제

국가별로 VTX (Video Transmitter) 최대 전력이 규제됩니다:
미국: 5.8GHz 최대 1W
유럽: 5.8GHz 최대 25mW
한국: 5.8GHz 사용 제한적, 인증 필요
반드시 현지 법규를 확인하세요!

5.5.2 디지털 FPV

최신 디지털 FPV 시스템은 HD 화질과 낮은 간섭을 제공합니다:

시스템 해상도 지연 특징
DJI FPV 1080p 60fps ~28ms 최고 화질, 폐쇄 생태계
DJI O3 1080p 100fps ~20ms 개선된 지연, 4K 녹화
Walksnail Avatar 1080p 60fps ~30ms 오픈 생태계, 저렴
HDZero 720p 90fps ~15ms 낮은 지연, 레이싱 최적화

5.5.3 아날로그 vs 디지털 FPV

특성 아날로그 디지털
지연 매우 낮음 (5~20ms) 낮음~중간 (15~30ms)
화질 480p, 잡음 720p~1080p, 선명
장거리 점진적 화질 저하 갑작스런 끊김
비용 저렴 ($50~100) 비쌈 ($200~600)
용도 레이싱, 저지연 중시 프리스타일, 촬영

5.6 영상 녹화 및 저장

5.6.1 DVR (Digital Video Recorder)

  • 고글 DVR: FPV 고글에 내장, 화면 그대로 녹화
  • 카메라 SD: 액션 카메라(GoPro 등) 고화질 녹화
  • VTX SD: 일부 VTX에 SD 슬롯 내장

5.6.2 영상 품질

  • FPV 피드 녹화: 480p~1080p, 낮은 비트레이트
  • 액션 카메라: 4K 60fps, 고비트레이트, 고품질
  • 용도 구분: FPV는 조종용, 액션캠은 최종 영상용

5.7 지상 제어 스테이션 (GCS)

자율 비행 드론을 위한 소프트웨어 인터페이스입니다.

5.7.1 주요 GCS 소프트웨어

  • Mission Planner: ArduPilot 전용, Windows, 기능 풍부
  • QGroundControl: ArduPilot/PX4 모두 지원, 크로스플랫폼
  • APM Planner 2: ArduPilot, Mac/Linux 친화적
  • DJI GS Pro: DJI 드론 전용, iOS
  • UgCS: 상업용, 고급 미션 계획

5.7.2 GCS 기능

  • 미션 계획: 웨이포인트, 경로, 고도 설정
  • 실시간 모니터링: 비행 데이터, 지도에 드론 위치 표시
  • 파라미터 설정: FC 설정 변경
  • 로그 분석: 비행 후 데이터 분석
  • 시뮬레이션: SITL (Software In The Loop) 비행 시뮬레이션

5.8 주파수 간섭 및 공존

5.8.1 2.4GHz 간섭 문제

2.4GHz 대역은 WiFi, Bluetooth와 공유하므로 간섭이 발생할 수 있습니다:

  • WiFi 라우터: 특히 채널 6, 11
  • Bluetooth 기기: 이어폰, 스피커
  • 전자레인지: 강한 2.4GHz 방출
  • 해결책: FHSS 기술, 900MHz 시스템 사용

5.8.2 다중 드론 비행

여러 드론이 동시에 비행할 때 고려사항:

  • RC 시스템: FHSS로 자동 회피, 문제 적음
  • 아날로그 FPV: 서로 다른 채널 사용 필수 (Raceband 1~8)
  • 디지털 FPV: 시스템이 자동 채널 관리 (DJI는 최대 8대)

5.9 요약

드론 통신 시스템은 RC 제어, 텔레메트리, 영상 전송의 세 가지 주요 축으로 구성됩니다. 2.4GHz와 900MHz는 RC 제어에, 5.8GHz는 FPV 영상 전송에 주로 사용됩니다.

MAVLink 프로토콜은 자율 비행 드론의 표준 통신 방식이며, 아날로그 FPV는 낮은 지연으로 레이싱에, 디지털 FPV는 고화질로 촬영에 적합합니다. 4G/5G 통신은 장거리 BVLOS 비행의 미래를 열고 있습니다.

# WIA-ENE-041: 희토류 채굴 표준 💎

> **弘익人間 (홍익인간) - 널리 인간을 이롭게 하라**

희토류 원소(REE)의 지속가능한 채굴, 안전한 방사성 폐기물 관리, 투명한 공급망을 위한 포괄적 표준입니다.

## 🌟 개요

WIA-ENE-041 희토류 채굴 표준은 21세기 첨단 기술의 필수 자원인 희토류 원소의 채굴부터 최종 제품까지 전 과정을 투명하게 관리하고, 환경을 보호하며, 공급망 보안을 확보하기 위한 완전한 프레임워크를 제공합니다.

### 철학

**弘益人間 (홍익인간)** - "널리 인간을 이롭게 하라"의 철학을 바탕으로, 이 표준은 희토류 채굴로 인한 환경 파괴를 최소화하고, 방사성 폐기물을 안전하게 관리하며, 전략 자원의 공급망을 투명하게 구축하는 것을 목표로 합니다.

## 📊 현황

### 글로벌 희토류 현황 (2024)
- **연간 생산량**: 30만 톤 (TREO 기준)
- **중국 점유율**: 60% (생산), 85% (정제)
- **시장 규모**: $150억 (2030년 예상)
- **전략적 중요성**: 전기차, 풍력 터빈, 국방 산업 필수

### 주요 문제점
1. 🌍 **환경 오염**: 채굴 및 정제 과정에서 심각한 토양, 수질 오염
2. ⚛️ **방사성 폐기물**: 토륨(Th), 우라늄(U) 함유로 인한 방사성 폐기물 대량 발생
3. 🔒 **공급망 집중**: 중국 의존도 과도 (지정학적 리스크)
4. 📈 **가격 변동성**: 정치적 요인으로 인한 극심한 가격 변동 (±300-400%)
5. 📍 **추적 부재**: 원산지 및 공급망 투명성 부족
6. ♻️ **재활용 부족**: e-waste에서 희토류 회수율 <5%

## 🗺️ 광상 유형

### 1. 바스트네사이트 (Bastnäsite)
```
화학식: (Ce,La)CO₃F
품위: 5-10% TREO
희토류 구성: LREE 주도 (Ce 50%, La 30%, Nd 12%)
토륨 함량: 낮음 (<0.1%)
주요 광산: Mountain Pass (미국), Bayan Obo (중국)

장점: 토륨 함량 낮아 방사성 폐기물 최소, 경제성 우수
단점: 중희토류 함량 낮음, 대형 노천 채굴 필요
```

### 2. 모나자이트 (Monazite)
```
화학식: (Ce,La,Nd,Th)PO₄
품위: 3-12% TREO
희토류 구성: LREE (Nd 함량 높음)
토륨 함량: 높음 (3-12%) ⚠️
주요 산지: 인도, 브라질, 호주 (해변 사광상)

장점: 네오디뮴 함량 높음, 채굴 용이
단점: 방사성 폐기물 대량 발생, 환경 규제 엄격
```

### 3. 이온흡착형 점토 (Ion-Adsorption Clay)
```
형태: 점토 광물에 이온 형태로 흡착
품위: 0.05-0.2% TREO (매우 낮음)
희토류 구성: HREE 주도 (Dy, Tb, Y 풍부)
방사성: 거의 없음
주요 산지: 중국 남부 (광둥, 장시, 푸젠)

장점: 중희토류 주 공급원 (Dy, Tb), 방사성 폐기물 없음
단점: 품위 낮음, 암모늄 침출로 심각한 수질 오염
```

## ⚙️ 채굴 및 정제 공정

### 채굴 방법
```
1. 노천 채굴 (Open-Pit Mining)
   - 적용: 바스트네사이트, 제노타임
   - 방법: 발파 → 굴삭 → 운반 → 선광
   - 환경 영향: 대규모 토지 훼손, 복원 필수

2. 원위치 침출 (In-Situ Leaching)
   - 적용: 이온흡착형 점토
   - 방법: 황산암모늄 주입 → 희토류 용출 → 회수
   - 환경 위험: 지하수 오염, 토양 산성화 ⚠️

3. 사광 채굴 (Placer Mining)
   - 적용: 모나자이트 해변 사광상
   - 방법: 준설 → 중력/자력 선별
   - 주의: 방사성 토륨 함유
```

### 분리 및 정제
```
1. 침출 (Leaching)
   - 산 침출: H₂SO₄ 또는 HCl
   - 알칼리 침출: NaOH (모나자이트)

2. 용매 추출 (Solvent Extraction)
   - 추출제: P507, P204, Cyanex 272
   - 단계: 20-35 단계 (원소별 분리)
   - 순도: 99.5-99.99%

3. 금속 환원
   - 전기분해: 용융염 전기분해
   - 금속 열환원: Ca 또는 Ca/CaF₂ 환원
```

## ⚛️ 방사성 폐기물 관리

### 방사성 물질
```
토륨 (Th-232):
  - 함량: 모나자이트 3-12%
  - 반감기: 14.05억 년
  - 방사선: 알파선
  - 위험: 흡입 시 폐암, 골암

우라늄 (U-238):
  - 함량: 모나자이트 0.1-0.5%
  - 반감기: 44.7억 년
  - 규제: IAEA 핵물질 관리
```

### 폐기물 분류 및 처리
```
Level 1 (저준위): <100 Bq/g
  → 격리 매립, 콘크리트 차폐

Level 2 (중준위): 100-10,000 Bq/g
  → 시멘트 고화, 중간 저장 (30-50년)

Level 3 (고준위): >10,000 Bq/g
  → 유리화, 깊은 지층 처분 (1,000년 이상)
```

## 🚀 빠른 시작

### 1. 설치
```bash
# 저장소 복제
git clone https://github.com/WIA-Official/wia-standards.git
cd wia-standards/rare-earth-mining

# 설치
./install.sh
```

### 2. CLI 사용
```bash
# 광산 등록
./cli/rare-earth-mining.sh register-mine \
  --name "Mountain Pass" \
  --operator "MP Materials" \
  --country USA \
  --lat 35.4887 \
  --lon -115.5470 \
  --treo-grade 7.8

# 배치 제출
./cli/rare-earth-mining.sh submit-batch \
  --batch-id REE-BATCH-001 \
  --mine-id REE-MINE-USA-001 \
  --facility-id REE-PROC-001 \
  --nd 1280 --dy 50 --tb 20

# 공급망 추적
./cli/rare-earth-mining.sh track REE-BATCH-2025-MP-0012345

# 가격 조회
./cli/rare-earth-mining.sh prices
./cli/rare-earth-mining.sh price Nd
```

### 3. TypeScript SDK
```typescript
import { REEClient } from '@wia/ene-041';

const client = new REEClient({
  apiKey: 'your-api-key',
  endpoint: 'https://api.wia.org/ree-041/v1'
});

// 광산 등록
const mine = await client.registerMine({
  mine: {
    name: 'Mountain Pass',
    operator: 'MP Materials',
    country: 'USA',
    oreType: 'BASTNASITE',
    treoGrade_percent: 7.8
  }
});

// 가격 조회
const prices = await client.getCurrentPrices();
console.log('Nd price:', prices.data?.find(p => p.element === 'Nd'));

// 공급망 추적
const tracking = await client.trackSupplyChain('REE-BATCH-2025-MP-0012345');
console.log('Origin:', tracking.data?.origin);
```

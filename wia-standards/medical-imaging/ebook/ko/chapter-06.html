3D 의료 영상의 중요성

CT, MRI는 기본적으로 2D 단층 영상의 집합이지만, 3D 재구성을 통해 해부학적 구조를 입체적으로 이해할 수 있습니다. 이는 복잡한 해부학, 종양 범위 파악, 수술 시뮬레이션, 환자-의사 커뮤니케이션에 혁신을 가져왔습니다.

3D 재구성 기법

1. MPR (Multi-Planar Reconstruction)

MPR은 축상(Axial) 영상 스택으로부터 다른 평면(Sagittal, Coronal, Oblique)을 재구성하는 가장 기본적인 3D 기술입니다.

평면 설명 용도
Axial 가로 단면 (원본) 기본 스캔 평면
Sagittal 세로 단면 (좌우) 척추, 뇌 중심선
Coronal 관상 단면 (전후) 부비동, 폐
Oblique 임의 각도 단면 혈관, 관절
Curved MPR 곡선 경로 따라 재구성 관상동맥, 대장

2. MIP (Maximum Intensity Projection)

MIP는 광선(Ray)을 따라 가장 밝은(높은 밀도) 픽셀값만 투영하는 기법으로, 혈관 영상화에 탁월합니다.

  • 원리: 각 광선에서 max(픽셀값) 선택
  • 장점: 혈관, 석회화 등 고밀도 구조 강조
  • 단점: 깊이 정보 상실, 중첩된 구조 구별 어려움
  • 응용: CT 혈관조영술, MR 혈관조영술, PET
  • 변형: MinIP (최소값), AIP (평균값)

3. Volume Rendering (VR)

볼륨 렌더링은 3D 데이터 전체를 반투명하게 표현하여 내부 구조를 투과하여 볼 수 있게 합니다.

방법 알고리즘 특징 속도
Ray Casting 광선 추적 고품질, 유연함 느림 (CPU)
Texture Mapping 3D 텍스처 GPU 가속 빠름
Splatting 복셀 투영 불규칙 데이터 중간
Shear-Warp 변형 투영 효율적 빠름 (CPU)

Transfer Function

Transfer Function은 복셀 값(HU, 신호 강도)을 색상 및 불투명도로 매핑하는 핵심 개념입니다:

  • Color Map: -1000 HU (공기, 검정) → +1000 HU (뼈, 흰색)
  • Opacity Map: 피부 (반투명), 뼈 (불투명), 공기 (투명)
  • Presets: 뼈, 혈관, 폐, 심장 등 장기별 최적 설정
  • 사용자 정의: 관심 영역 강조 위한 커스텀 함수

4. Surface Rendering

표면 렌더링은 3D 볼륨에서 특정 임계값(Threshold)으로 표면을 추출하여 폴리곤 메시로 변환합니다.

  • Marching Cubes: 가장 널리 사용되는 등가면 추출 알고리즘
  • 임계값 설정: 뼈 (400 HU), 연조직 (0-100 HU)
  • Mesh Smoothing: Laplacian, Taubin 스무딩
  • Decimation: 폴리곤 수 줄여 렌더링 속도 향상
  • 장점: 빠른 렌더링, 상호작용, STL 내보내기 (3D 프린팅)
  • 단점: 내부 구조 보이지 않음, 임계값에 민감

임상 응용

1. 수술 계획

3D 재구성은 복잡한 수술 전 환자 고유 해부학을 이해하는 데 필수적입니다:

수술 유형 3D 활용 효과
정형외과 골절 3D 모델, 임플란트 계획 수술 시간 25% 단축
신경외과 뇌혈관 3D, 종양 범위 합병증 30% 감소
심장외과 관상동맥, 판막 3D 성공률 15% 향상
간담도외과 간 분절, 혈관 3D 출혈 40% 감소
악안면외과 두개골 3D 재건 미용 결과 향상

2. 3D 프린팅

의료 영상 3D 모델을 실제 물리적 모형으로 출력:

  • 환자 맞춤 임플란트: 두개골, 턱뼈, 골반 재건
  • 수술 가이드: 절단 위치, 나사 삽입 각도 가이드
  • 수술 시뮬레이션: 실제 수술 전 모형으로 연습
  • 의료 교육: 복잡한 해부학 학습 모델
  • 환자 상담: 질병, 치료 계획을 눈으로 확인

3D 프린팅 워크플로우

  1. CT/MRI 스캔 (Slice 두께 0.5-1mm 권장)
  2. DICOM → STL 변환 (Seg mentation, Marching Cubes)
  3. STL 메시 편집 (Meshmixer, 3D Slicer)
  4. 프린터 준비 (FDM, SLA, SLS)
  5. 출력 (6-48시간)
  6. 후처리 (지지대 제거, 연마, 살균)

3. 가상 내시경 (Virtual Endoscopy)

3D 영상 내부를 가상으로 탐색하는 기술:

  • CT Colonography: 대장 내부 가상 비행, 폴립 검출
  • Virtual Bronchoscopy: 기관지 내부 탐색
  • Virtual Angioscopy: 혈관 내부 관찰
  • 장점: 비침습적, 반복 관찰 가능, 접근 어려운 부위
  • 한계: 촉각 정보 없음, 조직 채취 불가

3D 영상 품질 최적화

스캔 프로토콜

  • 얇은 Slice: 0.5-1mm (두꺼우면 계단 현상)
  • Overlapping: 50% 중첩 재구성
  • Isotropic Voxel: X=Y=Z 동일 해상도 (이상적)
  • 조영 타이밍: 혈관 최대 조영 시점
  • 호흡 조절: 호흡 정지, 게이팅

후처리 기법

  1. Noise Reduction: Gaussian, Median, Anisotropic 필터
  2. Interpolation: Cubic, Lanczos 보간
  3. Registration: 다중 시퀀스 정합
  4. Segmentation: Thresholding, Region Growing, Level Set
  5. Artifact Removal: Metal artifact, Motion artifact 제거

제5장: 엣지 컴퓨팅

"의료 환경에서 1초의 지연은 생명과 죽음의 차이를 만들 수 있습니다. 엣지 컴퓨팅은 바로 그 지연을 없애는 기술입니다."

5.1 엣지 컴퓨팅이란?

엣지 컴퓨팅은 데이터 소스(센서, 기기) 근처에서 데이터를 처리하는 분산 컴퓨팅 패러다임입니다.

☁️ 클라우드 vs 엣지

특성 클라우드 컴퓨팅 엣지 컴퓨팅
지연시간 50-200ms 1-10ms
대역폭 높은 사용량 낮은 사용량
개인정보 데이터 전송 필요 로컬 처리 가능
연산 능력 무제한 제한적
비용 높은 전송 비용 낮은 전송 비용
오프라인 작동 불가능 가능

5.3 엣지 AI 응용

엣지에서 AI 모델을 실행하여 실시간 분석:

🧠 엣지 AI 사용 사례

응용 분야 모델 지연시간 정확도
부정맥 감지 1D CNN <100ms 95%
낙상 감지 Random Forest <50ms 92%
발작 예측 LSTM <200ms 88%
수면 단계 분류 ResNet <500ms 90%
혈당 예측 XGBoost <100ms MARD 12%

⚡ 모델 최적화

엣지 디바이스의 제한된 리소스에 맞춘 최적화:

  • 양자화 (Quantization)
    • FP32 → INT8 변환
    • 모델 크기 75% 감소
    • 추론 속도 2-4배 향상
  • 프루닝 (Pruning)
    • 불필요한 가중치 제거
    • 모델 압축 50-90%
    • 정확도 손실 <2%
  • 지식 증류 (Knowledge Distillation)
    • 큰 모델 → 작은 모델
    • 성능 유지하며 크기 축소

5.4 실시간 처리

엣지에서의 스트림 처리:

🌊 스트림 처리 패턴

  • 이벤트 기반 처리
    • 이상치 감지 시 즉시 처리
    • 낮은 지연시간 (<10ms)
  • 윈도우 기반 처리
    • 슬라이딩 윈도우 (예: 5분 평균)
    • 텀블링 윈도우 (예: 시간당 요약)
  • 상태 기반 처리
    • 환자 상태 추적
    • 트렌드 분석

5.5 오프라인 작동

네트워크 연결이 끊어져도 계속 작동:

📴 오프라인 모드

  • 로컬 저장
    • 연결 복구 시까지 데이터 버퍼링
    • 최대 72시간 분량
  • 로컬 의사 결정
    • 긴급 알림 계속 작동
    • 클라우드 없이 기본 기능
  • 동기화
    • 연결 복구 시 자동 동기화
    • 충돌 해결 메커니즘

제3장: 의료 센서 네트워크

"센서는 의료의 눈과 귀입니다. 보이지 않는 생체 신호를 포착하고, 데이터로 변환하여, 생명을 구하는 통찰을 제공합니다."

3.1 센서 기술 개요

의료 센서는 생체 신호를 전기 신호로 변환하는 트랜스듀서입니다.

🔬 센서 유형별 분류

센서 유형 측정 대상 기술 정확도
전기 센서 ECG, EEG, EMG 전극 ±5 μV
광학 센서 SpO2, 심박수 PPG ±2%
화학 센서 혈당, pH, 가스 전기화학 ±10 mg/dL
압력 센서 혈압, ICP 압전 ±3 mmHg
온도 센서 체온 서미스터 ±0.1°C
운동 센서 활동량, 낙상 가속도계, 자이로 ±0.01 g

📡 센서 네트워크 토폴로지

의료 센서는 다양한 네트워크 구조로 배치됩니다:


1. 스타 토폴로지 (Star Topology)
   센서 ──┐
   센서 ──┼──> 게이트웨이 ──> 클라우드
   센서 ──┘

   장점: 간단, 안정적
   단점: 단일 장애점

2. 메시 토폴로지 (Mesh Topology)
   센서 ←→ 센서
     ↕       ↕
   센서 ←→ 센서 ──> 게이트웨이

   장점: 복원력, 확장성
   단점: 복잡성, 전력 소모

3. 하이브리드
   병원: 메시 네트워크
   가정: 스타 네트워크

3.2 생체 신호 센서

❤️ 심전도 (ECG/EKG) 센서

심장의 전기 활동을 측정:

  • 리드 시스템
    • 12리드: 종합 진단
    • 3리드: 연속 모니터링
    • 단일 리드: 웨어러블
  • 샘플링 레이트
    • 진단용: 500-1000 Hz
    • 모니터링: 250-500 Hz
    • 웨어러블: 100-250 Hz
  • 검출 항목
    • 심박수, 심박 변이도
    • 부정맥, 심방세동
    • ST 분절 변화
    • QT 간격
{
  "sensorType": "ecg",
  "leads": ["I", "II", "III"],
  "samplingRate": 250,
  "resolution": 12,
  "unit": "bit",
  "data": {
    "timestamp": "2025-12-26T10:00:00Z",
    "heartRate": 72,
    "hrv": {
      "sdnn": 45,
      "rmssd": 38
    },
    "rhythm": "normal_sinus",
    "abnormalities": []
  }
}

🫁 산소 포화도 (SpO2) 센서

혈중 산소 농도를 광학적으로 측정:

  • 원리 — PPG (Photoplethysmography)
  • 파장 — 적색(660nm) + 적외선(940nm)
  • 측정 위치 — 손가락, 손목, 귓불, 이마
  • 정확도 — ±2% (70-100% 범위)

🩸 연속 혈당 측정 (CGM) 센서

침습적 또는 비침습적 혈당 모니터링:

방식 기술 정확도 지속시간
침습적 CGM 피하 센서 MARD 9% 10-14일
비침습적 광학/전자파 MARD 15-20% 연속

3.3 환경 및 활동 센서

🏃 활동 모니터링

IMU (관성 측정 장치) 기반:

  • 가속도계 (Accelerometer)
    • 움직임 감지
    • 걸음 수 계산
    • 낙상 감지
    • 자세 분석
  • 자이로스코프 (Gyroscope)
    • 회전 감지
    • 방향 추적
    • 균형 평가
  • 지자기 센서 (Magnetometer)
    • 방위 측정
    • 위치 보정

3.4 센서 데이터 수집

📊 샘플링 전략

적절한 샘플링 레이트 선택이 중요합니다:

신호 유형 주파수 범위 샘플링 레이트 데이터 크기
ECG 0.5-150 Hz 250-1000 Hz 43-173 MB/일
EEG 0.5-100 Hz 256-512 Hz 354 MB/일
SpO2 0-5 Hz 25-100 Hz 4.3 MB/일
혈압 간헐적 매 15-60분 1 KB/일
가속도계 0-20 Hz 50-100 Hz 26 MB/일

🔧 신호 처리

원시 센서 데이터는 처리가 필요합니다:

  1. 전처리 (Preprocessing)
    • 노이즈 제거 (필터링)
    • 기준선 보정
    • 아티팩트 제거
  2. 특징 추출 (Feature Extraction)
    • 피크 검출
    • 주파수 분석
    • 통계적 특징
  3. 분류 (Classification)
    • 패턴 인식
    • 이상 감지
    • 상태 추정

💾 데이터 압축

대역폭과 저장 공간 절약을 위한 압축:

  • 무손실 압축 — DEFLATE, LZ4 (진단 데이터)
  • 손실 압축 — 웨이블릿 변환 (연속 모니터링)
  • 압축률 — 5:1 ~ 20:1 (신호 유형에 따라)

3.5 센서 캘리브레이션

정확도 유지를 위한 정기적인 캘리브레이션:

🎯 캘리브레이션 방법

센서 유형 캘리브레이션 방법 주기
혈당 센서 혈액 샘플 대조 매 12시간
혈압계 수은 혈압계 대조 연 1회
온도 센서 표준 온도계 대조 월 1회
가속도계 중력 보정 주 1회

✅ 품질 관리

  • 자동 검증 — 센서 자가 진단
  • 상호 검증 — 다중 센서 비교
  • 임상 검증 — 의료 표준과 대조
  • 알림 시스템 — 캘리브레이션 필요 시 경고

3.6 전력 관리

배터리 수명을 최대화하는 전략:

🔋 저전력 기술

  • 적응형 샘플링 — 활동에 따라 샘플링 레이트 조절
  • 슬립 모드 — 비활성 시 저전력 모드
  • 온디맨드 전송 — 중요한 이벤트만 즉시 전송
  • 배치 전송 — 데이터 축적 후 일괄 전송
  • 엣지 처리 — 로컬에서 처리, 결과만 전송

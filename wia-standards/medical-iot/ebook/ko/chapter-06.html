제6장: 기기 보안

"연결된 의료 기기는 생명을 구하는 도구이자 잠재적 보안 위협입니다. 강력한 보안 없이는 IoMT의 미래는 없습니다."

6.1 IoMT 보안 위협

위협 유형 설명 영향
데이터 유출 환자 건강 정보 도난 개인정보 침해, 법적 책임
기기 하이재킹 의료 기기 원격 제어 환자 생명 위협
랜섬웨어 데이터 암호화 및 요구 운영 중단, 금전적 손실
DDoS 서비스 거부 공격 시스템 마비
중간자 공격 통신 가로채기/변조 잘못된 진단/치료

🎯 실제 공격 사례

  • 2017 WannaCry — 영국 NHS 공격, 19,000+ 예약 취소
  • 2020 Ryuk — 미국 병원 시스템 다운, 환자 이송
  • 인슐린 펌프 취약점 — FDA 경고, 원격 제어 가능성
  • 심박조율기 해킹 — 465,000대 리콜

6.3 암호화

🔐 전송 중 암호화 (Encryption in Transit)

프로토콜 용도 암호 스위트
TLS 1.3 HTTPS, MQTT over TLS AES-256-GCM, ChaCha20-Poly1305
DTLS 1.2 CoAP, UDP 통신 AES-128-CCM
IPsec VPN, 네트워크 계층 AES-256-CBC, SHA-256

💾 저장 시 암호화 (Encryption at Rest)

  • 전체 디스크 암호화 — AES-256-XTS
  • 데이터베이스 암호화 — TDE (Transparent Data Encryption)
  • 파일 수준 암호화 — AES-256-GCM
  • 백업 암호화 — AES-256 + RSA-4096

6.4 인증 및 권한

👤 기기 인증

  • 상호 TLS (mTLS)
    • 양방향 인증서 검증
    • X.509 인증서
    • PKI 인프라
  • OAuth 2.0 + JWT
    • 토큰 기반 인증
    • 세밀한 권한 제어
    • 단기 액세스 토큰
  • 하드웨어 기반
    • TPM 2.0 attestation
    • Secure Element
    • eSIM 인증

🔐 다중 인증 (MFA)

요소 예시 사용 시나리오
지식 (Knowledge) 비밀번호, PIN 기본 로그인
소유 (Possession) 스마트카드, OTP 민감 작업
생체 (Biometric) 지문, 얼굴 인식 고위험 접근

6.5 네트워크 보안

🛡️ 방어 메커니즘

  • 네트워크 분리 (Segmentation)
    • 의료 기기 전용 VLAN
    • 제로 트러스트 아키텍처
    • 마이크로 세그먼테이션
  • 침입 탐지/방지 (IDS/IPS)
    • 실시간 트래픽 모니터링
    • 이상 행위 탐지
    • 자동 차단
  • 방화벽 규칙
    • 화이트리스트 기반
    • 포트/프로토콜 제한
    • 지리적 차단

6.6 보안 모니터링 및 대응

📊 SIEM 통합

보안 정보 및 이벤트 관리:

  • 로그 수집 및 분석
  • 상관 관계 분석
  • 실시간 알림
  • 포렌식 조사

🚨 사고 대응 프로세스


1. 탐지 (Detection)
   → 자동 모니터링, 이상 감지

2. 격리 (Containment)
   → 영향 받은 기기 네트워크 분리
   → 추가 확산 방지

3. 근절 (Eradication)
   → 위협 제거
   → 취약점 패치

4. 복구 (Recovery)
   → 시스템 복원
   → 정상 운영 재개

5. 분석 (Lessons Learned)
   → 사고 원인 분석
   → 재발 방지 대책

6.7 규정 준수

규정 지역 핵심 요구사항
HIPAA 미국 PHI 보호, 암호화, 감사 로그
GDPR EU 데이터 최소화, 동의, 삭제권
MDR EU 의료 기기 사이버 보안
FDA 미국 시판 전 사이버 보안
ISO 27001 국제 정보 보안 관리 시스템

제7장: 상호 운용성 표준

"의료 시스템 간의 원활한 데이터 교환은 환자 치료의 연속성을 보장합니다. 상호 운용성은 선택이 아닌 필수입니다."

7.1 상호 운용성 개요

상호 운용성은 서로 다른 시스템이 정보를 교환하고 사용할 수 있는 능력입니다.

📊 상호 운용성 계층

계층 설명 표준/기술
조직적 워크플로우, 정책, 거버넌스 협약, SLA
의미론적 데이터 의미 이해 SNOMED CT, LOINC, RxNorm
구문론적 데이터 형식 및 구조 HL7 FHIR, CDA, JSON, XML
기술적 통신 프로토콜 HTTP, HTTPS, WebSocket

7.2 HL7 FHIR

Fast Healthcare Interoperability Resources - 현대적인 의료 데이터 교환 표준

🏥 FHIR 핵심 개념

  • 리소스 (Resources)
    • Patient, Observation, MedicationRequest 등
    • 150+ 표준 리소스 타입
    • JSON/XML 형식
  • RESTful API
    • HTTP 기반 CRUD 작업
    • 검색, 필터링, 페이징
  • 확장성 (Extensions)
    • 표준 리소스 확장 가능
    • 사용자 정의 데이터 추가

📝 FHIR 예제: 혈압 관찰

{
  "resourceType": "Observation",
  "id": "blood-pressure-001",
  "status": "final",

    "coding": [{
      "system": "http://terminology.hl7.org/CodeSystem/observation-category",
      "code": "vital-signs",
      "display": "Vital Signs"

  }],
  "code": {
    "coding": [{
      "system": "http://loinc.org",
      "code": "85354-9",
      "display": "Blood pressure panel"
    }]
  },

    "reference": "Patient/patient-123"
  },
  "effectiveDateTime": "2025-12-26T10:00:00Z",

      "code": {
        "coding": [{

7.3 HL7 v2

레거시 시스템에서 여전히 널리 사용되는 메시징 표준:

📨 HL7 v2 메시지 구조

MSH|^~\&|SendingApp|SendingFacility|ReceivingApp|ReceivingFacility|20251226100000||ORU^R01|MSG001|P|2.5
PID|||123456||Doe^John||19800101|M|||123 Main St^^Seoul^^12345^KR
OBR|1||20251226-001|85354-9^Blood Pressure^LN|||20251226100000
OBX|1|NM|8480-6^Systolic BP^LN||120|mm[Hg]||||||F
OBX|2|NM|8462-4^Diastolic BP^LN||80|mm[Hg]||||||F
세그먼트 의미
MSH Message Header (메시지 헤더)
PID Patient Identification (환자 정보)
OBR Observation Request (검사 요청)
OBX Observation Result (검사 결과)

7.4 DICOM

Digital Imaging and Communications in Medicine - 의료 영상 표준

🖼️ DICOM 응용

  • 영상 저장 및 전송
    • X-ray, CT, MRI, 초음파
    • PACS (Picture Archiving and Communication System)
  • 메타데이터
    • 환자 정보, 검사 정보
    • 영상 취득 파라미터
  • 워크리스트
    • 검사 일정 관리
    • RIS (Radiology Information System) 통합

7.5 의료 용어 표준

일관된 의료 데이터를 위한 표준 용어:

표준 용도 예시
SNOMED CT 임상 용어 진단, 증상, 절차
LOINC 검사 및 관찰 혈액 검사, 활력 징후
RxNorm 약물 의약품 명칭, 용량
ICD-10 질병 분류 진단 코드
CPT 의료 절차 수술, 처치 코드

7.6 IoT 프로토콜

의료 IoT 기기 간 통신 프로토콜:

🔌 주요 프로토콜

프로토콜 특징 의료 사용 사례
MQTT Pub/Sub, 경량 웨어러블 → 클라우드
CoAP RESTful, UDP 제약 기기 통신
AMQP 메시지 큐, 신뢰성 병원 시스템 통합
WebSocket 양방향, 실시간 원격 모니터링 대시보드
gRPC 고성능, RPC 마이크로서비스 간 통신

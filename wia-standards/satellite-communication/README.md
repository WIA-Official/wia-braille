# WIA-SPACE-003: Satellite Communication

📡 **Comprehensive satellite communication standard and educational resource**

## Overview
WIA-SPACE-003 provides complete coverage of satellite communication technologies, from fundamental principles to next-generation innovations.

## Contents
- **Main Landing Page**: `index.html`
- **Korean E-book**: `ebook/ko/` (8 chapters, 200+ lines each)
- **English E-book**: `ebook/en/` (8 chapters, comprehensive coverage)
- **Technical Specification**: `spec/WIA-SPACE-003-v1.0.md`

## Topics Covered
1. **Satellite Communication Overview** - History, principles, advantages/limitations
2. **Communication Satellite Systems** - GEO, MEO, LEO characteristics and applications
3. **Frequency Bands and Allocation** - C, Ku, Ka bands and ITU coordination
4. **Ground Equipment** - VSAT, gateways, antennas, TT&C
5. **Satellite Link Analysis** - Link budgets, path loss, C/N calculations
6. **Multiple Access Technologies** - FDMA, TDMA, CDMA, frequency reuse
7. **Satellite Internet Services** - Starlink, OneWeb, HTS providers
8. **Next-Generation Technologies** - Optical, quantum, 5G/6G NTN, AI integration

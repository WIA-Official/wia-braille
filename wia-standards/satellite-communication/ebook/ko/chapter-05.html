📊 위성 링크 분석

5.1 링크 버짓 (Link Budget) 개요

위성 링크 분석(Link Budget Analysis)은 송신기에서 출발한 신호가 위성을 거쳐 수신기까지 도달하는 과정에서 발생하는 모든 이득과 손실을 정량적으로 계산하는 과정입니다. 이를 통해 시스템이 요구하는 통신 품질을 만족하는지 검증하고, 필요한 안테나 크기, 송신 전력, 수신 감도 등을 결정합니다.

링크 버짓은 위성 통신 시스템 설계의 가장 기본적이면서도 중요한 도구입니다. dB(데시벨) 단위로 계산하면 곱셈·나눗셈이 덧셈·뺄셈으로 변환되어 계산이 간편해집니다.

기본 링크 방정식:
수신 전력(dBW) = 송신 전력(dBW) + 송신 안테나 이득(dBi) - 자유공간 손실(dB) - 기타 손실(dB) + 수신 안테나 이득(dBi)

5.2 자유공간 손실 (Free Space Path Loss)

전파가 진공 중을 전파하면서 거리의 제곱에 반비례하여 세기가 약해지는 현상입니다. 이는 에너지가 소멸하는 것이 아니라, 구면파로 퍼져나가며 단위 면적당 전력 밀도가 감소하기 때문입니다.

FSPL (dB) = 20·log₁₀(d) + 20·log₁₀(f) + 92.45
여기서 d = 거리 (km), f = 주파수 (GHz)

5.2.1 계산 예시

GEO 위성, Ku-band (12 GHz):

  • 거리 d = 36,000 km
  • 주파수 f = 12 GHz
  • FSPL = 20·log(36000) + 20·log(12) + 92.45 = 91.1 + 21.6 + 92.45 = 205.2 dB

LEO 위성 (Starlink), Ka-band (20 GHz):

  • 거리 d = 550 km
  • 주파수 f = 20 GHz
  • FSPL = 20·log(550) + 20·log(20) + 92.45 = 55.0 + 26.0 + 92.45 = 173.5 dB
결론: LEO 위성은 GEO 대비 자유공간 손실이 약 32 dB 낮습니다. 이는 전력으로 환산하면 약 1,600배 차이로, LEO에서 소형 단말과 저전력 운용이 가능한 핵심 이유입니다.

5.3 EIRP (Equivalent Isotropic Radiated Power)

EIRP는 송신 안테나에서 실제로 방출되는 유효 복사 전력입니다. 송신 전력과 안테나 이득을 합산한 값으로, 특정 방향으로 얼마나 강한 신호를 보낼 수 있는지를 나타냅니다.

EIRP (dBW) = 송신 전력(dBW) + 안테나 이득(dBi) - 피더 손실(dB)

5.3.1 계산 예시

GEO 위성 다운링크:

  • 위성 송신 전력: 200W = 23 dBW
  • 위성 안테나 이득: 30 dBi
  • 피더 손실: 1 dB
  • EIRP = 23 + 30 - 1 = 52 dBW

지상국 업링크:

  • 지상 HPA 출력: 1,000W = 30 dBW
  • 안테나 이득 (3m Ku): 50 dBi
  • 피더 손실: 2 dB
  • EIRP = 30 + 50 - 2 = 78 dBW

5.4 G/T (Figure of Merit)

G/T는 수신 시스템의 품질 지수로, 수신 안테나 이득(G)을 시스템 잡음 온도(T)로 나눈 값입니다. G/T가 높을수록 미약한 신호도 잘 수신할 수 있습니다.

G/T (dB/K) = 안테나 이득(dBi) - 10·log₁₀(시스템 잡음 온도, K)

5.4.1 시스템 잡음 온도

수신 시스템의 총 잡음은 여러 요소의 합입니다:

  • 안테나 잡음 (Tₐ): 우주 배경 복사, 지구 열복사 (20~50 K)
  • LNB 잡음 (Tₗₙb): 증폭기 자체 잡음 (50~150 K)
  • 피더 손실 잡음: 케이블 저항열 (10~30 K)
  • 총 시스템 온도 (Tₛᵧₛ) = Tₐ + Tₗₙb + Tfeeder

5.4.2 계산 예시

가정용 DTH 수신:

  • 안테나 이득: 35 dBi (60cm Ku)
  • 시스템 잡음 온도: 150 K
  • G/T = 35 - 10·log(150) = 35 - 21.8 = 13.2 dB/K

대형 게이트웨이:

  • 안테나 이득: 65 dBi (11m Ka)
  • 시스템 잡음 온도: 200 K (비 오는 날)
  • G/T = 65 - 10·log(200) = 65 - 23.0 = 42.0 dB/K

5.5 C/N (Carrier-to-Noise Ratio)

C/N은 수신된 신호 전력 대 잡음 전력의 비율입니다. 통신 품질을 결정하는 가장 중요한 지표로, C/N이 높을수록 오류율이 낮고 데이터 속도를 높일 수 있습니다.

C/N (dB) = EIRP (dBW) - FSPL (dB) + G/T (dB/K) - k (dBW/K/Hz) - 10·log₁₀(대역폭, Hz)

여기서 k = 볼츠만 상수 = -228.6 dBW/K/Hz

5.5.1 다운링크 C/N 계산

GEO Ku-band DTH:

  • 위성 EIRP: 52 dBW
  • FSPL (12 GHz, 36000 km): 205.2 dB
  • 수신 G/T: 13.2 dB/K
  • 대역폭: 36 MHz = 75.6 dBHz
  • C/N = 52 - 205.2 + 13.2 - (-228.6) - 75.6 = 13.0 dB

이는 QPSK 변조로 SD 화질 TV 방송에 충분한 수준입니다.

5.6 대기 손실

5.6.1 비 감쇠 (Rain Attenuation)

10 GHz 이상의 고주파에서는 빗방울에 의한 전파 흡수·산란이 발생합니다. 강수량이 많을수록, 주파수가 높을수록 감쇠가 심해집니다.

주파수약한 비 (5mm/h)폭우 (50mm/h)
C-band (6 GHz)0.2 dB2 dB
Ku-band (12 GHz)1 dB10 dB
Ka-band (20 GHz)3 dB30 dB

Ka-band는 폭우 시 신호가 거의 차단될 수 있어, Rain Fade 대응 기술이 필수입니다.

5.6.2 대기 가스 흡수

  • 산소 흡수: 60 GHz 부근에서 최대 (V-band 사용 제약)
  • 수증기 흡수: 22 GHz, 183 GHz 부근
  • Ka-band: 흡수 창(window) 위치로 비교적 낮은 흡수 (0.2~0.5 dB)

5.6.3 구름·안개

일반 구름은 Ku-band 이하에서 무시 가능하지만, Ka-band 이상에서는 0.5~2 dB 추가 손실이 발생할 수 있습니다.

5.6.4 대기 신틸레이션 (Scintillation)

대기 난류로 인한 굴절률 변동으로 신호 세기가 빠르게 요동칩니다. 특히 저앙각에서 심하며, 1~3 dB 변동이 수 초 주기로 발생합니다.

5.7 페이딩 마진 (Fading Margin)

날씨, 대기 변화, 장비 노화 등 예상치 못한 손실에 대비한 여유분을 링크 버짓에 포함시킵니다.

  • C-band: 2~3 dB (날씨 영향 적음)
  • Ku-band: 5~10 dB (중간 수준 비 대비)
  • Ka-band: 10~20 dB (폭우 대비)

가용성(Availability) 목표에 따라 마진을 설정합니다. 예를 들어 99.5% 가용성을 원하면, 1년 중 1.8일(44시간)은 서비스 중단을 허용하는 것입니다.

적응형 코딩 변조 (ACM): HTS는 날씨에 따라 변조 방식을 동적으로 변경합니다. 맑은 날은 64APSK로 고속 전송, 비 오는 날은 QPSK로 낮은 속도지만 안정적 전송. 이를 통해 페이딩 마진을 줄이고 평균 효율을 높입니다.

5.8 업링크와 다운링크 결합

위성 통신은 업링크(지상→위성)와 다운링크(위성→지상) 두 구간으로 나뉩니다. 전체 C/N은 두 구간의 C/N을 결합하여 계산합니다.

(C/N)total = 1 / (1/(C/N)uplink + 1/(C/N)downlink)

dB 단위로 직접 계산할 수 없으므로, 선형값으로 변환 후 계산합니다.

5.8.1 계산 예시

업링크 C/N = 20 dB → 선형값 100
다운링크 C/N = 15 dB → 선형값 31.6
(C/N)total = 1/(1/100 + 1/31.6) = 24.0 → 13.8 dB

더 약한 링크가 전체 성능을 지배합니다. 따라서 설계 시 업링크와 다운링크의 균형을 맞추는 것이 중요합니다.

5.9.2 순방향 오류 정정 (FEC)

데이터에 중복 비트를 추가하여 수신측에서 오류를 자동 복구합니다. DVB-S2X 표준은 LDPC(Low-Density Parity-Check) 코드를 사용하여 Shannon 한계에 근접한 효율을 달성합니다.

  • Code rate 1/2: 데이터 1비트당 2비트 전송. 강력한 보호, 낮은 효율
  • Code rate 9/10: 거의 원본 그대로 전송. 약한 보호, 높은 효율

Code rate을 조정하여 C/N과 데이터 속도를 트레이드오프합니다.

5.10 위성 링크 계산기 도구

실무에서는 복잡한 링크 버짓을 수작업으로 계산하지 않고, 전문 소프트웨어를 사용합니다:

  • Satmaster Pro: 상용 링크 버짓 계산 툴
  • STK (Systems Tool Kit): AGI의 위성 시스템 시뮬레이션
  • ITU-R 권고: ITU에서 제공하는 표준 계산 모델
  • Excel 스프레드시트: 커스텀 계산 템플릿

이러한 도구들은 궤도 역학, 대기 모델, 안테나 패턴 등을 정밀하게 반영하여 실제 성능을 예측합니다.

5.11 마치며

위성 링크 분석은 송신 전력, 안테나 이득, 자유공간 손실, 대기 손실, 잡음 등을 종합하여 통신 품질(C/N)을 계산하는 과정입니다. 이를 통해 시스템이 요구 성능을 만족하는지 검증하고, 필요한 마진을 확보합니다.

GEO 위성은 205 dB의 막대한 자유공간 손실로 인해 큰 안테나와 높은 전력이 필요하지만, LEO 위성은 32 dB 낮은 손실로 소형 단말 운용이 가능합니다. Ka-band는 넓은 대역폭과 소형 안테나라는 장점이 있지만, 30 dB에 달하는 Rain Fade에 대응하는 기술이 필수적입니다.

CHAPTER 6

🔀 Multiple Access Technologies

6.1 Multiple Access Overview

Satellite resources (frequency, power, transponder capacity) must be shared among hundreds/thousands of users. Multiple access divides resources by frequency (FDMA), time (TDMA), or code (CDMA).

6.2 FDMA (Frequency Division)

Divides spectrum into narrow channels, each user gets fixed frequency slot like analog TV channels.

Advantages:

  • Simple, low-cost implementation
  • Continuous access for real-time voice
  • Independent channels, no mutual interference

Disadvantages:

  • Spectrum waste when user idle
  • Guard bands consume 10-20% spectrum
  • Intermodulation from satellite nonlinearity
  • Inflexible reallocation

Applications:

  • Analog satellite phone (legacy)
  • TV relay backhaul
  • SCPC (Single Channel Per Carrier) dedicated lines

6.3 TDMA (Time Division)

All users share full bandwidth but transmit only in assigned time slots, like taking turns speaking in a meeting.

Frame Structure:

  • Frame: 2-20 ms divided into time slots
  • Preamble: Sync and address per slot
  • Payload: Actual data
  • Guard time: Prevents slot collisions

Advantages:

  • High efficiency: 90%+ spectrum utilization
  • Flexible: Dynamic slot reallocation
  • Digital-friendly for packet data
  • Single carrier reduces satellite amp nonlinearity

Disadvantages:

  • Complex synchronization required
  • Burst transmission needs high peak power
  • Frame latency added
  • Distance/delay compensation complex for GEO

Applications:

  • VSAT networks (iDirect, Hughes)
  • Mobile satcom (GSM, Iridium)
  • DVB-RCS2 return channels

6.4 CDMA (Code Division)

All users transmit simultaneously on same frequency/time, distinguished by unique spreading codes like speaking different languages in same room.

Spread Spectrum:

  • Original signal spread over wide bandwidth
  • Interference resistance: narrowband jamming diluted
  • Security: code unknown = undetectable
  • Multipath: Distinguish reflected signals

Advantages:

  • Jamming/interference resistant
  • Secure without code
  • Soft capacity: Graceful degradation
  • Frequency reuse in adjacent cells

Disadvantages:

  • Near-far problem: requires precise power control
  • Complex receiver: correlation, code sync
  • Wide bandwidth: 10-100x vs FDMA
  • High power consumption

Applications:

  • GPS: All satellites 1.575 GHz, code-separated
  • Globalstar LEO phone system
  • Military satcom (anti-jam, secure)

6.5 Advanced Techniques

FDMA/TDMA Hybrid:

Divide spectrum into frequency channels (FDMA), then time-multiplex each channel (TDMA). Most commercial systems use this.

MF-TDMA (Multi-Frequency TDMA):

Multiple carrier frequencies, each with TDMA. Dynamically adjust carrier count for traffic.

OFDMA (Orthogonal Frequency Division):

LTE/5G technique dividing spectrum into hundreds/thousands of orthogonal subcarriers, allocating per user need.

  • Advantages: Maximum spectral efficiency, multipath-resistant, flexible bandwidth
  • Disadvantages: High PAPR reduces PA efficiency, Doppler-sensitive
  • Satellite adoption: Next-gen HTS systems

NOMA (Non-Orthogonal Multiple Access):

5G/6G research: Non-orthogonal resource sharing with successive interference cancellation (SIC) at receiver. Under study for satellites.

6.6 Random Access Protocols

ALOHA:

Transmit when data available, retry after random delay if collision. Simple but low efficiency (18% max).

Slotted ALOHA:

Divide time into slots, transmit only at slot boundaries. Halves collision probability, 36% efficiency.

CRDSA (Contention Resolution Diversity Slotted ALOHA):

Transmit duplicate packets in multiple slots, receiver uses interference cancellation. 60-80% efficiency. Used in DVB-RCS2.

IoT Applications:

Millions of sensors transmitting small, intermittent data. Random access more efficient than dedicated allocation. Swarm, Kinéis IoT satellites use ALOHA variants.

6.7 Frequency Reuse

Spot Beams:

Satellite illuminates narrow ground areas (100-500km diameter). Non-adjacent beams reuse same frequency.

  • Reuse factor: 4-7x capacity increase
  • HTS: Hundreds of spot beams

Polarization Reuse:

Same frequency on horizontal + vertical polarizations (or left/right circular). 2x capacity.

  • Requires 25-30 dB cross-polarization isolation (XPI)
  • Rain rotates polarization, degrading XPI

4-Color Reuse Pattern:

Like cellular networks, assign 4-7 frequency groups to adjacent beams to avoid interference. Viasat-3 reuses frequencies dozens of times across hundreds of beams for Tbps capacity.

6.9 Demand Assignment

DAMA (Demand Assigned Multiple Access):

  • User requests channel when data ready
  • Central controller assigns free resource
  • Resource released after transmission
  • Efficiency: 80-95% (vs 30-50% fixed)
  • Tradeoff: Request-assignment latency

6.10 Conclusion

Multiple access efficiently shares limited satellite resources. FDMA is simple but wasteful, TDMA is the digital-era standard offering high efficiency and flexibility, CDMA excels at interference resistance and security. Modern systems use FDMA/TDMA hybrids with spot beam and polarization reuse for capacity multiplication. Next-gen HTS adopt OFDMA and NOMA for near-theoretical efficiency limits.

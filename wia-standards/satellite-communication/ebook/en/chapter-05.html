CHAPTER 5

📊 Satellite Link Analysis

5.1 Link Budget Overview

Link budget quantifies all gains and losses from transmitter through satellite to receiver, verifying system meets required communication quality. Calculated in dB for ease (multiplication becomes addition).

Basic Equation: Received Power (dBW) = TX Power + TX Antenna Gain - Free Space Loss - Other Losses + RX Antenna Gain

5.2 Free Space Path Loss (FSPL)

Radio waves spread spherically, power density decreases with distance squared. No energy is lost, just distributed over larger area.

Formula: FSPL (dB) = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92.45

Examples:

  • GEO Ku-band (36,000 km, 12 GHz): 205.2 dB
  • LEO Ka-band (550 km, 20 GHz): 173.5 dB
  • Difference: 32 dB (1,600x power advantage for LEO)
Key Insight: LEO's 32 dB lower path loss enables small terminals and low power, fundamental to Starlink's economics.

5.3 EIRP (Equivalent Isotropic Radiated Power)

Effective radiated power in specific direction combining transmitter power and antenna gain.

Formula: EIRP (dBW) = TX Power (dBW) + Antenna Gain (dBi) - Feeder Loss (dB)

Examples:

  • GEO satellite downlink: 200W (23 dBW) + 30 dBi - 1 dB = 52 dBW
  • Ground uplink: 1000W (30 dBW) + 50 dBi - 2 dB = 78 dBW

5.4 G/T (Figure of Merit)

Receiver quality metric: Antenna Gain / System Noise Temperature. Higher G/T = better weak signal reception.

Formula: G/T (dB/K) = Antenna Gain (dBi) - 10·log₁₀(System Temp, K)

System Noise Sources:

  • Antenna noise: Cosmic background, Earth thermal (20-50 K)
  • LNB noise: Amplifier thermal (50-150 K)
  • Feeder loss noise: Cable resistance (10-30 K)
  • Total: Tₛᵧₛ = Tₐ + Tₗₙb + Tfeeder

Examples:

  • Consumer DTH (60cm Ku, 150K): G/T = 35 - 21.8 = 13.2 dB/K
  • Gateway (11m Ka, 200K): G/T = 65 - 23.0 = 42.0 dB/K

5.5 C/N (Carrier-to-Noise Ratio)

Signal power to noise power ratio, determines communication quality. Higher C/N = lower error rate, higher data rates.

Formula: C/N = EIRP - FSPL + G/T - k - 10·log(BW)
where k = Boltzmann constant = -228.6 dBW/K/Hz

Example (GEO Ku DTH):

  • EIRP: 52 dBW
  • FSPL: 205.2 dB
  • G/T: 13.2 dB/K
  • BW: 36 MHz = 75.6 dBHz
  • C/N = 52 - 205.2 + 13.2 + 228.6 - 75.6 = 13.0 dB (sufficient for QPSK SD TV)

5.6 Atmospheric Losses

Rain Attenuation:

C-band (6 GHz)0.2 dB2 dB
Ku-band (12 GHz)1 dB10 dB
Ka-band (20 GHz)3 dB30 dB

Other Atmospheric Effects:

  • Gas absorption: O₂ at 60 GHz, H₂O at 22/183 GHz
  • Clouds/fog: 0.5-2 dB at Ka+
  • Scintillation: 1-3 dB rapid fluctuations from turbulence

5.7 Fading Margin

Extra link margin for weather, equipment aging, unforeseen losses. Determines service availability.

  • C-band: 2-3 dB (weather-resistant)
  • Ku-band: 5-10 dB (moderate rain)
  • Ka-band: 10-20 dB (heavy rain)

99.5% availability = tolerates 44 hours/year outage

Adaptive Coding Modulation (ACM): HTS dynamically adjusts modulation based on weather. Clear skies: 64APSK high-speed. Rain: QPSK low-speed but reliable. Reduces required margins, improves average efficiency.

5.8 Uplink + Downlink Combination

Total C/N combines uplink and downlink segments. Weaker link dominates overall performance.

Formula: (C/N)total = 1 / (1/(C/N)up + 1/(C/N)down)

Must convert from dB to linear, calculate, convert back to dB.

Example:

  • Uplink C/N = 20 dB → 100 (linear)
  • Downlink C/N = 15 dB → 31.6 (linear)
  • Total = 1/(1/100 + 1/31.6) = 24.0 → 13.8 dB

Design principle: Balance uplink and downlink to avoid wasting resources on oversized segment.

FEC (Forward Error Correction):

  • DVB-S2X uses LDPC codes approaching Shannon limit
  • Code rate 1/2: Strong protection, low efficiency
  • Code rate 9/10: Weak protection, high efficiency
  • Tradeoff C/N vs. data rate

5.10 Conclusion

Link budget analyzes TX power, antenna gains, FSPL, atmospheric losses, noise to calculate C/N. GEO's 205 dB FSPL requires large antennas and high power; LEO's 32 dB advantage enables small terminals. Ka-band offers bandwidth but 30 dB rain fade requires advanced mitigation (ACM, diversity). Proper link analysis ensures reliable service at minimum cost. Next chapter examines multiple access technologies (FDMA, TDMA, CDMA) for efficient spectrum sharing.

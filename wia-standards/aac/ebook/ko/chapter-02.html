[AAC] 제2장: AAC 산업의 현재 과제

홍익인간 (弘益人間)

"문제를 이해하는 것이 해결의 첫 걸음입니다."

이 장에서는 수백만 명이 효과적인 의사소통 기술에 접근하지 못하게 하는 장벽을 검토합니다.

2.1 파편화된 AAC 환경

현재 AAC 시장은 하드웨어 프로토콜에서 소프트웨어 인터페이스, 데이터 형식에서 통신 표준까지 모든 수준에서 파편화되어 있습니다.

2.1.1 시장 개요

분야 주요 업체 추정 시장 규모 상호운용성
시선 추적 Tobii, EyeTech, LC Technologies $500M+ 없음 - 독점 프로토콜
스위치 접근 AbleNet, Enabling Devices, RJ Cooper $200M+ 제한적 - 기본 HID 지원
음성 생성 장치 PRC-Saltillo, Tobii Dynavox, Forbes AAC $400M+ 없음 - 폐쇄형 생태계
BCI/EEG Emotiv, NeuroSky, g.tec, OpenBCI $200M+ 제한적 - 연구 중심
EMG 센서 Ottobock, NeuroSky 및 다양한 스타트업 $100M+ 없음 - 장치별 특화

[!] 핵심 문제: 총 시장은 연간 14억 달러를 초과하지만, 사용자는 다른 공급업체의 제품을 조합할 수 없습니다.

2.2 기술적 장벽

2.2.1 독점 신호 형식

각 제조업체는 센서 출력에 대해 자체 데이터 형식을 정의합니다:

Tobii 시선 추적기 출력 (독점):
{
    tobii_gaze_point: {
        x: 0.456,
        y: 0.321,
        validity: 1,
        timestamp_us: 1702468800000000
    }
}

EyeTech 시선 추적기 출력 (다른 독점 형식):
{
    et_gaze: {
        screen_x: 912,
        screen_y: 456,
        confidence: 0.95,
        time_ms: 1702468800000
    }
}

LC Technologies 시선 추적기 출력 (또 다른 형식):
{
    LCET_Data: {
        GazeX: 0.456,
        GazeY: 0.321,
        TimeStamp: "2025-01-15T10:00:00.000Z",
        Quality: 95
    }
}

[!] 결과: 소프트웨어 개발자는 각 장치에 대해 별도의 통합을 구현해야 하며, 이는 개발 비용을 증가시키고 지원을 제한합니다.

2.2.2 호환되지 않는 통신 프로토콜

프로토콜 유형 제조사 A 제조사 B 제조사 C
블루투스 커스텀 GATT 프로필 다른 커스텀 GATT SPP만
USB 커스텀 HID 리포트 CDC/ACM 시리얼 벤더 특정 클래스
WiFi REST API v1 WebSocket 커스텀 UDP 브로드캐스트

2.2.3 SDK 파편화

다중 장치 지원을 위한 개발 요구사항:

5개 시선 추적기 지원을 위해:
  - 5개의 다른 SDK
  - 5개의 다른 API
  - 5개의 다른 문서 세트
  - 5개의 다른 라이선스 계약
  - 5개의 다른 업데이트 일정

4개 스위치 시스템 지원을 위해:
  - 4개 추가 SDK
  - 4개 추가 통합 포인트

3개 BCI 장치 지원을 위해:
  - 3개 추가 SDK
  - 복잡한 신호 처리 요구사항

총계: 적절한 장치 지원을 위해 12개 이상의 별도 통합
예상 개발 시간: 6-12개월
지속적인 유지보수: 계속

2.3 경제적 영향

2.3.1 장치 비용

장치 카테고리 가격 범위 (USD) 보험 적용 일반적인 자비 부담
기본 음성 장치 $1,000 - $3,000 부분 $500 - $1,500
시선 추적 시스템 $8,000 - $15,000 제한적 $3,000 - $10,000
통합 AAC 장치 $10,000 - $20,000 다양 $5,000 - $15,000
BCI 시스템 (의료용) $20,000 - $50,000+ 거의 없음 $15,000 - $50,000

2.3.2 숨겨진 비용

장치 구매 이외의 비용:

교육 비용:
  - 초기 장치 교육: $500 - $2,000
  - 소프트웨어 교육: $300 - $1,000
  - 지속적인 지원: $100 - $500/년
  - 새 장치 재교육: 전체 비용 다시

시간 비용:
  - 장치 평가: 2-4주
  - 보험 승인: 1-6개월
  - 장치 배송: 2-8주
  - 초기 설정: 1-2주
  - 보정 및 맞춤화: 2-4주
  - 숙련도 개발: 2-6개월

기회 비용:
  - 전환 중 의사소통 중단
  - 생산성 손실
  - 학습 기간 동안 사회적 고립
  - 교육 및 설정을 위한 보호자 시간

2.4 인간적 영향

2.4.1 사용자 이야기

이야기 1: 기술의 미로

"보증이 끝난 후 시선 추적기가 고장났을 때, 두 가지 선택이 있었습니다: 3년 된 장치 수리에 $4,000을 지불하거나 새 시스템에 $12,000을 쓰거나. 어느 쪽이든 보험은 '교체품'으로 적용되지 않았습니다. 두 달 동안 의사소통 장치 없이 지냈습니다."

- 마리아, 42세, 다발성 경화증

이야기 2: 비호환성 위기

"저는 제 의사소통 소프트웨어를 좋아했습니다 - 수년간 어휘와 문구를 맞춤화했거든요. 하지만 시선 제어로 전환해야 했을 때, 그 소프트웨어는 제가 구매할 수 있는 어떤 시선 추적기도 지원하지 않았습니다. 익숙하지 않은 소프트웨어로 완전히 처음부터 시작해야 했습니다."

- 제임스, 58세, ALS

이야기 3: 보호자의 부담

"딸의 필요가 변화함에 따라 네 가지 다른 AAC 시스템을 배웠습니다. 매번 무급 기술 지원, 트레이너, 문제 해결사가 되었습니다. 그녀를 돌보고 일하면서 이것에 수백 시간을 보냈습니다."

- 뇌성마비 자녀의 부모

2.4.2 의사소통 격차

AAC 전환 중 사용자 경험:

1-2주차: 장치 설정 및 기본 보정
  - 의사소통 능력: 정상의 10-20%
  - 좌절감 수준: 매우 높음
  - 필수적인 필요만 표현

3-4주차: 초기 학습 곡선
  - 의사소통 능력: 정상의 30-40%
  - 기본 메시지 가능
  - 복잡한 생각 표현 불가

2개월차: 익숙해지는 단계
  - 의사소통 능력: 정상의 50-60%
  - 적당한 대화 가능
  - 성격이 드러나기 시작

3-6개월차: 숙련도 접근
  - 의사소통 능력: 정상의 70-85%
  - 대부분의 필요 표현 가능
  - 이전 시스템보다 여전히 느림

6개월 이상: 완전 적응
  - 의사소통 능력: 이전의 85-95%
  - 새로운 최적화 발견
  - 근육 기억 발달

[!] 현실: 진행성 질환의 경우, 이 주기가 4-6번 반복될 수 있으며, 각각은 신체적 쇠퇴가 증가하는 시기에 발생합니다.

2.5 WIA AAC 표준의 필요성

2.5.1 성공을 위한 요구사항

[OK] 성공적인 AAC 표준은 다음을 갖추어야 합니다:

  1. 포괄적
    • 모든 주요 센서 유형 포함
    • 완전한 데이터 흐름 정의
    • 엣지 케이스와 변형 처리
  2. 기술적으로 건전
    • 검증된 기술 기반
    • 실시간 사용에 효율적
    • 미래 필요를 위해 확장 가능
  3. 접근 가능
    • 무료 구현
    • 명확한 문서화
    • 참조 구현 이용 가능
  4. 채택 가능
    • 점진적 마이그레이션 경로
    • 모든 이해관계자에 대한 가치 제안
    • 품질을 위한 인증 프로그램
  5. 지속 가능
    • 지속적인 거버넌스
    • 업데이트 메커니즘
    • 장기적 약속

2.6 장 요약

[OK] 핵심 내용:

  1. 시장 파편화: 호환되지 않는 독점 시스템을 가진 여러 공급업체
  2. 기술적 장벽: 다른 신호 형식, 프로토콜 및 SDK
  3. 경제적 영향: 특히 진행성 질환에 대한 높은 비용
  4. 인간적 영향: 의사소통 시간 손실, 보호자 부담, 사회적 고립
  5. 이전 실패: 과거 표준화 시도는 포괄성 부족
  6. WIA 필요성: 포괄적이고 무료이며 지속 가능한 표준 필요

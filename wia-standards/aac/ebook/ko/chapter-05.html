[AAC] 제5장: Phase 2 - API 인터페이스 표준

홍익인간 (弘益人間)

"모든 것을 연결하는 하나의 API."

Phase 2는 센서 통합을 모든 개발자에게 간단하게 만드는 프로그래밍 인터페이스를 만듭니다.

5.1 Phase 2 개요

5.1.1 목적

Phase 2는 API 인터페이스 표준을 정의합니다 - 소프트웨어 개발자가 WIA AAC 호환 센서와 상호작용하는 데 사용하는 통합 프로그래밍 인터페이스입니다. 이 계층은 다른 센서 유형의 복잡성을 일관된 API 뒤에 추상화합니다.

5.1.2 산출물

산출물 설명 언어
API 사양 완전한 인터페이스 문서화 언어 독립적
참조 구현 공식 구현 Rust
TypeScript SDK Web/Node.js SDK TypeScript
Python SDK Python SDK Python 3.9+
개발자 가이드 통합 튜토리얼 Markdown

5.2 핵심 API 설계

5.2.1 설계 원칙

  1. 단순성 우선

    일반적인 작업은 최소한의 코드가 필요해야 합니다. 복잡한 작업은 가능하지만 필수는 아닙니다.

  2. 이벤트 기반 아키텍처

    모든 센서 입력은 이벤트를 통해 처리되어 반응형 프로그래밍 패턴을 가능하게 합니다.

  3. 타입 안전성

    강력한 타이핑은 일반적인 오류를 방지하고 IDE 지원을 가능하게 합니다.

  4. 기본적으로 비동기

    모든 I/O 작업은 블로킹을 방지하기 위해 비동기입니다.

  5. 우아한 오류 처리

    명확한 오류 유형과 복구 메커니즘.

5.3 WiaAAC 클래스

5.3.1 생성자 및 초기화

// TypeScript 예제

import { WiaAAC, WiaAACConfig } from 'wia-aac';

// 기본 초기화
const aac = new WiaAAC();

// 설정과 함께 초기화
const aac = new WiaAAC({
    autoConnect: false,
    signalValidation: true,
    logLevel: 'info',
    userProfile: 'profile-001'
});

// 설정 인터페이스
interface WiaAACConfig {
    autoConnect?: boolean;        // 발견된 장치에 자동 연결
    signalValidation?: boolean;   // 모든 수신 신호 검증
    logLevel?: 'debug' | 'info' | 'warn' | 'error';
    userProfile?: string;         // 사용자 프로필 식별자
    calibrationId?: string;       // 보정 데이터 식별자
    locale?: string;              // 언어 선호도
}

// 신호 이벤트
aac.on('signal', (signal: AACSignal) => {

    console.log('데이터:', signal.data);
    console.log('신뢰도:', signal.confidence);
});

// 특정 센서 유형 이벤트
aac.on('eye_tracker', (signal: EyeTrackerSignal) => {
    console.log(`시선: (${signal.data.gaze_x}, ${signal.data.gaze_y})`);
    if (signal.data.fixation) {
        console.log(`고정 시간: ${signal.data.dwell_time_ms}ms`);
    }
});

aac.on('switch', (signal: SwitchSignal) => {
    console.log(`스위치 ${signal.data.switch_id}: ${signal.data.state}`);
});

// 선택 이벤트 (추상화됨)
aac.on('selection', (event: SelectionEvent) => {
    console.log('선택됨:', event.target);
    console.log('선택 방법:', event.method);  // dwell, switch, blink 등
});

// 텍스트 출력 이벤트
aac.on('text', (text: string) => {
    console.log('사용자 입력:', text);
    // TTS, 수어, 점자로 전달...
});

// 장치 이벤트
aac.on('connected', (device: DeviceInfo) => {
    console.log('연결됨:', device.model);
});

aac.on('disconnected', (reason: string) => {
    console.log('연결 해제됨:', reason);
});

// 오류 이벤트
aac.on('error', (error: AACError) => {
    console.error('오류:', error.code, error.message);
});

5.7 Rust 참조 구현

5.7.1 핵심 구조

// Rust 구현 구조

use wia_aac::{WiaAAC, Config, Signal, SensorType};
use tokio;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 초기화
    let config = Config::builder()
        .signal_validation(true)
        .log_level("info")
        .build();

    let aac = WiaAAC::new(config)?;

    // 장치 검색
    let devices = aac.discover_devices().await?;
    println!("{}개 장치 발견", devices.len());

    // 연결
    aac.connect(SensorType::EyeTracker, None).await?;

    // 신호 처리
    let mut rx = aac.subscribe();
    while let Some(signal) = rx.recv().await {
        match signal.sensor_type {
            SensorType::EyeTracker => {
                let data = signal.as_eye_tracker()?;
                println!("시선: ({}, {})", data.gaze_x, data.gaze_y);
            }
            SensorType::Switch => {
                let data = signal.as_switch()?;
                println!("스위치 {}: {}", data.switch_id, data.state);
            }
            _ => {}
        }
    }

    Ok(())
}

5.8.2 복구 전략

// 자동 재연결 설정
const aac = new WiaAAC({
    autoReconnect: true,
    reconnectAttempts: 5,
    reconnectDelay: 1000,       // 초기 지연
    reconnectBackoff: 'exponential'  // 1초, 2초, 4초, 8초, 16초
});

// 수동 재연결
aac.on('disconnected', async (reason) => {
    console.log('연결 해제:', reason);

    // 재연결 시도
    for (let i = 0; i < 3; i++) {
        try {
            await aac.reconnect();
            console.log('재연결 성공');
            break;
        } catch (error) {
            console.log(`재연결 시도 ${i + 1} 실패`);
            await sleep(2000 * (i + 1));
        }
    }
});

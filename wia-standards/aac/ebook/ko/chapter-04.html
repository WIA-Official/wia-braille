[AAC] 제4장: Phase 1 - 신호 형식 표준

홍익인간 (弘益人間)

"모든 보조 장치를 위한 공통 언어."

Phase 1은 모든 AAC 센서가 사용할 수 있는 보편적 신호 형식이라는 기반을 확립합니다.

4.1 Phase 1 개요

4.1.1 목적

Phase 1은 신호 형식 표준을 정의합니다 - 모든 AAC 센서가 데이터를 어떻게 형식화하고 전송해야 하는지에 대한 포괄적인 사양입니다. 이것은 다른 모든 Phase가 구축되는 기반입니다.

4.1.2 산출물

산출물 설명 형식
신호 사양 신호 형식의 완전한 문서화 Markdown/PDF
JSON 스키마 기계가 읽을 수 있는 형식 정의 JSON Schema Draft 2020-12
검증 도구 신호 적합성 검증 도구 TypeScript/Python
예제 데이터셋 각 센서 유형별 샘플 신호 JSON 파일
테스트 스위트 적합성 테스트 케이스 자동화 테스트

4.2 기본 신호 구조

4.2.1 공통 필드

센서 유형에 관계없이 모든 WIA AAC 신호는 다음 기본 필드를 포함합니다:

{
    "type": "string",           // 필수: 센서 유형 식별자
    "version": "string",        // 필수: 신호 형식 버전
    "timestamp": number,        // 필수: Unix 타임스탬프 (ms)
    "data": object,             // 필수: 센서별 데이터
    "confidence": number,       // 필수: 0.0-1.0
    "device": {                 // 선택: 장치 정보
        "manufacturer": "string",
        "model": "string",
        "device_id": "string",
        "firmware_version": "string"
    },
    "session": {                // 선택: 세션 정보
        "session_id": "string",
        "user_profile": "string",
        "calibration_id": "string"
    },
    "metadata": object          // 선택: 추가 데이터
}

4.2.2 필드 사양

필드 유형 필수 설명
type string 예 eye_tracker, switch, emg, eeg_bci, breath, head_movement 중 하나
version string 예 시맨틱 버전 (예: "1.0.0")
timestamp integer 예 밀리초 단위 Unix 타임스탬프 (UTC)
data object 예 센서별 데이터 페이로드
confidence number 예 신호 품질 점수 0.0-1.0
device object 아니오 하드웨어 식별
session object 아니오 세션 컨텍스트
metadata object 아니오 커스텀 데이터를 위한 확장점

4.3 시선 추적기 신호 스키마

4.3.1 완전한 스키마

{
    "type": "eye_tracker",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "gaze_x": 0.456,              // 필수: 0.0-1.0 수평
        "gaze_y": 0.321,              // 필수: 0.0-1.0 수직
        "fixation": true,             // 필수: 불리언
        "dwell_time_ms": 850,         // 선택: 밀리초
        "pupil_diameter_mm": 4.2,     // 선택: 밀리미터
        "blink_detected": false,      // 선택: 불리언
        "tracking_quality": "good"    // 선택: good|fair|poor
    },
    "confidence": 0.95,
    "device": {
        "manufacturer": "Tobii",
        "model": "Eye Tracker 5",
        "device_id": "TOBII-ET5-A1B2C3D4"
    }
}

4.3.2 좌표 시스템

화면 좌표 시스템:

(0,0)                                 (1,0)
    +-----------------------------------+
    |                                   |
    |                                   |
    |               (0.5,0.5)           |
    |                   +               |
    |                                   |
    |                                   |
    +-----------------------------------+
(0,1)                                 (1,1)

- 원점 (0,0)은 왼쪽 상단
- X는 왼쪽에서 오른쪽으로 증가
- Y는 위에서 아래로 증가
- 모든 값은 0.0에서 1.0으로 정규화
- 해상도 독립적

4.4 스위치 신호 스키마

4.4.1 완전한 스키마

{
    "type": "switch",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "switch_id": 1,               // 필수: 1-8
        "state": "pressed",           // 필수: pressed|released|held
        "duration_ms": 150,           // 선택: 누른 시간
        "press_count": 1,             // 선택: 다중 탭용
        "event_type": "single"        // 선택: single|double|long|release
    },
    "confidence": 1.0
}

4.4.2 다중 스위치 구성

일반적인 스위치 구성:

1-스위치 (스캐닝):
  switch_id: 1 = 선택/활성화

2-스위치:
  switch_id: 1 = 이동/다음
  switch_id: 2 = 선택

4-스위치 (방향):
  switch_id: 1 = 위
  switch_id: 2 = 아래
  switch_id: 3 = 왼쪽
  switch_id: 4 = 오른쪽

5-스위치 (방향 + 선택):
  switch_id: 1-4 = 방향
  switch_id: 5 = 선택

8-스위치 (전체):
  switch_id: 1-4 = 방향
  switch_id: 5 = 선택
  switch_id: 6 = 뒤로/취소
  switch_id: 7 = 메뉴
  switch_id: 8 = 특수/커스텀

4.5 EMG 신호 스키마

4.5.1 완전한 스키마

{
    "type": "emg",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "channel": 1,                 // 필수: 센서 채널
        "amplitude_uv": 85,           // 필수: 마이크로볼트
        "activation": true,           // 필수: 임계값 초과
        "muscle_group": "facial",     // 선택: facial|hand|arm|other
        "gesture_detected": "eyebrow_raise"  // 선택
    },
    "confidence": 0.88
}

4.5.2 제스처 인식

표준 제스처 유형:

안면 제스처:
  - eyebrow_raise (눈썹 올리기)
  - eyebrow_furrow (눈썹 찌푸리기)
  - smile (미소)
  - frown (찡그리기)
  - jaw_clench (턱 꽉 물기)
  - cheek_puff (볼 부풀리기)

손/팔 제스처 (해당되는 경우):
  - finger_tap (손가락 탭)
  - wrist_flex (손목 굽히기)
  - wrist_extend (손목 펴기)
  - grip (쥐기)
  - release (놓기)

4.6 BCI/EEG 신호 스키마

4.6.1 완전한 스키마

{
    "type": "eeg_bci",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "channels": ["Fp1", "Fp2", "F3", "F4", "C3", "C4"],
        "band_power": {               // 필수 (적어도 하나의 밴드)
            "delta": 12.5,            // 0.5-4 Hz
            "theta": 8.3,             // 4-8 Hz
            "alpha": 15.2,            // 8-13 Hz
            "beta": 9.7,              // 13-30 Hz
            "gamma": 3.1              // 30+ Hz
        },
        "classification": "select",   // 선택: 해석된 명령
        "attention_level": 78,        // 선택: 0-100
        "meditation_level": 45        // 선택: 0-100
    },
    "confidence": 0.82
}

4.6.2 EEG 주파수 대역

EEG 주파수 대역:

Delta (델타): 0.5-4 Hz
  - 깊은 수면 상태
  - 가장 느린 뇌파

Theta (세타): 4-8 Hz
  - 졸음, 명상 상태
  - 기억 처리와 관련

Alpha (알파): 8-13 Hz
  - 이완된 각성 상태
  - 눈을 감았을 때 증가

Beta (베타): 13-30 Hz
  - 활성 사고 상태
  - 집중과 문제 해결

Gamma (감마): 30+ Hz
  - 높은 인지 기능
  - 정보 통합

4.7 호흡 센서 스키마

4.7.1 완전한 스키마

{
    "type": "breath",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "action": "sip",              // 필수: sip|puff|neutral
        "intensity": 0.75,            // 필수: 0.0-1.0
        "duration_ms": 320,           // 선택: 동작 지속 시간
        "flow_rate": 2.3,             // 선택: 리터/초
        "pattern_detected": "single_sip"  // 선택: 패턴 이름
    },
    "confidence": 0.96
}

4.7.2 호흡 패턴

표준 호흡 패턴:

기본 동작:
  - single_sip: 한 번 빨기
  - single_puff: 한 번 불기
  - hard_sip: 강하게 빨기
  - hard_puff: 강하게 불기
  - soft_sip: 약하게 빨기
  - soft_puff: 약하게 불기

조합 패턴:
  - sip_sip: 두 번 빨기 (더블탭 동등)
  - puff_puff: 두 번 불기
  - sip_puff: 빨고 불기
  - puff_sip: 불고 빨기

강도 매핑 (예시):
  - soft (약함): 0.0 - 0.3
  - medium (중간): 0.3 - 0.7
  - hard (강함): 0.7 - 1.0

4.8 머리 움직임 스키마

4.8.1 완전한 스키마

{
    "type": "head_movement",
    "version": "1.0.0",
    "timestamp": 1702468800000,
    "data": {
        "pitch": -5.2,                // 필수: 위/아래 각도
        "yaw": 12.3,                  // 필수: 좌/우 각도
        "roll": 0.8,                  // 필수: 기울기 각도
        "velocity": {                 // 선택: 각속도
            "pitch": 2.1,
            "yaw": 5.4,
            "roll": 0.3
        },
        "gesture_detected": "nod",    // 선택: nod|shake|tilt|none
        "cursor_x": 0.52,             // 선택: 매핑된 커서 위치
        "cursor_y": 0.48              // 선택: 매핑된 커서 위치
    },
    "confidence": 0.91
}

4.8.2 회전 참조

머리 회전 축:

         Pitch (끄덕임)
              |
              |    / Yaw (도리도리)
              |   /
              |  /
              | /
    Roll -----+------- (갸우뚱)
    (어깨로
    귀 기울이기)

Pitch: 양수 = 위를 봄, 음수 = 아래를 봄
Yaw: 양수 = 오른쪽으로 돌림, 음수 = 왼쪽으로 돌림
Roll: 양수 = 오른쪽으로 기울임, 음수 = 왼쪽으로 기울임

일반적인 범위:
  - Pitch: -30 ~ +30도
  - Yaw: -45 ~ +45도
  - Roll: -20 ~ +20도

4.9 장 요약

[OK] 핵심 내용:

  1. 기본 구조: 모든 신호는 공통 필드 공유 (type, version, timestamp, data, confidence)
  2. 6가지 센서 유형: 시선 추적기, 스위치, EMG, EEG/BCI, 호흡, 머리 움직임
  3. 필수 vs 선택: 핵심 필드는 상호운용성 보장; 선택적 필드는 고급 기능 활성화
  4. 좌표 시스템: 위치 데이터는 0.0-1.0으로 정규화
  5. JSON 스키마: JSON Schema를 통한 기계 판독 가능 검증
  6. 확장성: metadata 필드로 커스텀 확장 허용

8.2 빠른 시작 가이드

8.2.1 TypeScript/JavaScript

// 설치
npm install wia-aac

// 기본 사용법
import { WiaAAC } from 'wia-aac';

async function main() {
    // 초기화
    const aac = new WiaAAC();

    // 장치 검색
    const devices = await aac.discoverDevices();
    console.log('발견된 장치:', devices);

    // 첫 번째 시선 추적기에 연결
    const eyeTracker = devices.find(d => d.type === 'eye_tracker');
    if (eyeTracker) {
        await aac.connect({
            type: 'eye_tracker',
            deviceId: eyeTracker.deviceId
        });
    }

    // 신호 처리
    aac.on('signal', (signal) => {
        console.log('신호:', signal.type, signal.data);
    });

    // 텍스트 출력 처리
    aac.on('text', (text) => {
        console.log('사용자 입력:', text);
    });
}

main();

8.2.2 Python

# 설치
pip install wia-aac

# 기본 사용법
import asyncio
from wia_aac import WiaAAC

async def main():
    # 초기화
    aac = WiaAAC()

    # 장치 검색
    devices = await aac.discover_devices()
    print(f"{len(devices)}개 장치 발견")

    # 연결
    await aac.connect(sensor_type="eye_tracker")

    # 신호 처리
    @aac.on("signal")
    async def handle_signal(signal):
        print(f"신호: {signal.type} - {signal.data}")

    @aac.on("text")
    async def handle_text(text):
        print(f"사용자 입력: {text}")

    # 계속 실행
    await aac.run()

asyncio.run(main())

8.2.3 Rust

// Cargo.toml
[dependencies]
wia-aac = "1.0"
tokio = { version = "1.0", features = ["full"] }

// main.rs
use wia_aac::{WiaAAC, SensorType, Signal};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 초기화
    let aac = WiaAAC::new_default()?;

    // 장치 검색
    let devices = aac.discover_devices().await?;
    println!("{}개 장치 발견", devices.len());

    // 연결
    aac.connect(SensorType::EyeTracker, None).await?;

    // 신호 처리
    let mut rx = aac.subscribe();
    while let Some(signal) = rx.recv().await {
        println!("신호: {:?}", signal);
    }

    Ok(())
}

8.3 테스트

8.3.1 신호 검증

import { SignalValidator } from 'wia-aac';

const validator = new SignalValidator();

// 테스트 신호
const testSignal = {
    type: 'eye_tracker',
    version: '1.0.0',
    timestamp: Date.now(),
    data: {
        gaze_x: 0.5,
        gaze_y: 0.5,
        fixation: true
    },
    confidence: 0.95
};

// 검증
const result = validator.validate(testSignal);

if (result.valid) {
    console.log('[OK] 신호가 유효합니다');
} else {
    console.log('[!] 검증 오류:');
    result.errors.forEach(e =>
        console.log(`  - ${e.field}: ${e.message}`)
    );
}

8.3.2 성능 벤치마크

성능 요구사항:

신호 지연 시간:
  - 시선 추적기: <20ms (중요)
  - 스위치: <50ms
  - EMG: <30ms
  - BCI: <100ms (처리 시간)
  - 호흡: <50ms
  - 머리 움직임: <20ms

신호 속도:
  - 시선 추적기: 60-120 Hz
  - 스위치: 이벤트 기반
  - EMG: 250+ Hz
  - BCI: 128-512 Hz
  - 호흡: 20-50 Hz
  - 머리 움직임: 60-120 Hz

벤치마크 명령:
npx wia-aac-benchmark --device [device-id]

인증 프로세스:

1단계: 자가 평가
  - 적합성 테스트 스위트 실행
  - 결과 검토
  - 문제 수정
  - 구현 문서화

2단계: 신청서 제출
  - 신청서 양식 작성
  - 장치/소프트웨어 샘플 제공
  - 테스트 결과 제출
  - 인증 비용 지불

3단계: WIA 검토
  - 독립 테스트
  - 결과 검증
  - 기술 검토
  - 필요시 피드백

4단계: 인증
  - 인증서 수령
  - 인증 디렉토리에 등재
  - WIA AAC 로고 사용 허가
  - 연간 갱신 필요

타임라인:
  - 자가 평가: 1-2주
  - 신청 검토: 1주
  - 테스트: 2-3주

8.5 모범 사례

8.5.1 사용자 경험 가이드라인

AAC 사용자 경험 모범 사례:

1. 응답성
   - 즉각적인 시각적 피드백 (<100ms)
   - 부드러운 애니메이션
   - 긴 작업에 대한 진행 표시기

2. 설정 가능성
   - 응시 시간 조정
   - 감도 제어
   - 레이아웃 맞춤화
   - 음성/출력 선택

3. 오류 복구
   - 우아한 성능 저하
   - 명확한 오류 메시지
   - 쉬운 재보정
   - 실행 취소 기능

4. 접근성
   - 고대비 옵션
   - 큰 타겟
   - 간단한 탐색
   - 움직임 감소 옵션

5. 개인화
   - 사용자 선호도 저장
   - 커스텀 어휘
   - 예측 텍스트
   - 자주 사용하는 문구

[AAC] 제1장: 보완대체의사소통(AAC) 소개

홍익인간 (弘益人間)

"널리 인간을 이롭게 하라"

WIA AAC 표준은 의사소통이 기본적인 인권이라는 철학에 기반합니다. 기술은 신체적 능력과 관계없이 모든 개인에게 힘을 실어주어야 합니다.

1.1 AAC란 무엇인가?

AAC (Augmentative and Alternative Communication, 보완대체의사소통)는 말이나 글로 의사소통하기 어려운 사람들을 돕는 모든 방법, 도구, 기술을 말합니다.

[i] 정의: AAC는 구어나 문어의 산출 또는 이해에 장애가 있는 개인을 위해 자연스러운 말과 글을 보완하거나 대체하는 모든 형태의 의사소통을 포함합니다.

1.1.1 AAC의 두 가지 구성요소

보완적 의사소통 (Augmentative):

  • 기존 언어 능력을 보완
  • 이미 존재하지만 불충분한 의사소통을 강화
  • 예: 제한된 언어와 함께 의사소통 보드 사용

대체적 의사소통 (Alternative):

  • 언어를 완전히 대체
  • 언어가 불가능하거나 기능적이지 않을 때 사용
  • 예: 시선 추적 장치를 주요 의사소통 수단으로 사용

1.2 AAC가 필요한 사람들

AAC는 의사소통에 어려움을 겪는 모든 연령대의 다양한 사람들에게 도움을 줍니다. 다음 표는 AAC 지원이 필요한 주요 조건을 설명합니다:

1.2.1 AAC가 필요한 의학적 조건

조건 설명 전 세계 인구 AAC 관련성
ALS (루게릭병) 수의근 운동에 영향을 미치는 진행성 운동신경 질환 약 33만 명 진행성 언어 상실로 적응형 AAC 솔루션 필요
뇌성마비 운동과 근육 긴장에 영향을 미치는 장애군 약 1,700만 명 운동 제어 어려움이 언어 생산에 영향
사지마비 척수 손상으로 인한 사지 마비 약 500만 명 제한된 운동 기능으로 특수 입력 방법 필요
뇌졸중 (뇌졸중 후 실어증) 뇌혈관 사고 후 언어 장애 전 세계 수천만 명 언어 처리 능력 영향
중증 자폐 스펙트럼 장애 의사소통과 행동에 영향을 미치는 발달 장애 전 세계 수백만 명 구어 의사소통 어려움으로 대체 방법 필요
외상성 뇌손상 외부 충격으로 인한 뇌 손상 매년 수백만 명 인지 및 운동 장애가 의사소통에 영향
다발성 경화증 중추신경계에 영향을 미치는 자가면역 질환 약 280만 명 진행성 증상이 시간이 지남에 따라 언어에 영향
파킨슨병 진행성 신경계 장애 1,000만 명 이상 운동 증상이 언어 명료도와 음량에 영향

[i] 참고: 전 세계적으로 3억 명 이상이 어떤 형태로든 AAC 지원을 필요로 합니다. 이는 의사소통 필요가 충족되지 않는 상당한 인구를 나타냅니다.

1.3 AAC 시스템의 유형

1.3.1 무공학 AAC (No-Tech AAC)

외부 장치가 필요 없는 의사소통 방법:

  • 표정 - 감정과 반응 전달
  • 제스처 - 가리키기, 끄덕이기, 고개 젓기
  • 몸짓 언어 - 자세와 움직임
  • 발성 - 의사소통을 위한 비언어적 소리
  • 수어 - 공식 수어 체계 (ASL, BSL, KSL)

1.3.2 저공학 AAC (Low-Tech AAC)

단순한 비전자 의사소통 보조도구:

  • 의사소통 보드 - 기호나 텍스트가 있는 인쇄 보드
  • 그림 교환 의사소통 시스템 (PECS) - 그림 카드 사용
  • 알파벳 보드 - 글자별 철자법
  • 시선 프레임 - 간단한 가리키기 시스템
  • 선택 카드 - 예/아니오 또는 다중 선택 옵션

1.3.3 고공학 AAC (High-Tech AAC)

전자 장치 및 소프트웨어 기반 솔루션:

  • 음성 생성 장치 (SGD) - 전용 의사소통 장치
  • 시선 추적 시스템 - 시선 제어 의사소통
  • 스위치 기반 스캐닝 시스템 - 단일 또는 다중 스위치 입력
  • 뇌-컴퓨터 인터페이스 (BCI) - 직접 신경 입력
  • 모바일 AAC 애플리케이션 - 태블릿 및 스마트폰 앱
  • EMG 센서 - 근육 활동 감지
  • 머리 추적 시스템 - 움직임 기반 입력

1.4 AAC 표준의 중요성

1.4.1 현재의 문제점

[!] 문제: 현재 AAC 산업은 통합 표준이 없어 심각한 장벽을 만들고 있습니다:

  1. 장치 비호환성
    • 각 제조업체가 독점 프로토콜 사용
    • 한 회사의 센서가 다른 회사의 소프트웨어와 작동하지 않음
    • 사용자가 특정 생태계에 갇힘
  2. 높은 비용
    • 독점 시스템이 프리미엄 가격 유지
    • 폐쇄형 생태계로 인한 제한된 경쟁
    • 많은 사용자가 필요한 장치를 구매할 수 없음
  3. 제한된 선택
    • 사용자가 구성요소가 아닌 전체 시스템을 선택해야 함
    • 선호하는 하드웨어와 소프트웨어를 혼합할 수 없음
    • 파편화로 인해 혁신이 억제됨
  4. 전환의 어려움
    • 진행성 질환은 입력 방법 변경 필요
    • 각 변경마다 새로운 시스템 학습 필요
    • 설정과 선호도가 이전되지 않음

1.4.2 ALS 환자의 여정

ALS 환자의 일반적인 진행을 고려해 보세요:

질병 진행과 AAC 필요:

1단계 (초기): 손가락 기능 유지
  - 입력: 표준 키보드
  - 과제: 타이핑 속도 감소

2단계 (초중기): 손목 제어만 가능
  - 입력: 조이스틱, 트랙볼
  - 과제: 새 장치, 새 소프트웨어

3단계 (중기): 머리 제어만 가능
  - 입력: 헤드 마우스, 머리 추적기
  - 과제: 또 다른 완전한 시스템 변경

4단계 (중후기): 눈 제어만 가능
  - 입력: 시선 추적 장치
  - 과제: 새 장치, 새 보정, 새 인터페이스

5단계 (후기): 안면 근육만 가능
  - 입력: EMG 센서 (뺨, 눈썹)
  - 과제: 특수 장비, 새로운 학습 곡선

6단계 (말기): 뇌 신호만 가능
  - 입력: 뇌-컴퓨터 인터페이스 (BCI)
  - 과제: 가장 복잡한 시스템, 상당한 적응

각 단계마다:
  - 새 장비 구매 ($5,000 - $20,000+)
  - 새 소프트웨어 인터페이스 학습
  - 모든 설정 재구성
  - 이전 맞춤 설정 손실
  - 전환 중 의사소통 중단 경험

[!] 핵심 문제: 각 전환은 환자가 이미 질병 진행으로 어려움을 겪고 있는 시기에 발생합니다. 새로운 기술을 배우는 추가적인 부담은 치명적일 수 있습니다.

1.5 WIA AAC 표준 솔루션

WIA AAC 표준은 다음을 통해 이러한 문제를 해결합니다:

1.5.1 통합 신호 형식

모든 센서는 유형이나 제조업체에 관계없이 표준 형식으로 데이터를 출력합니다.

WIA AAC 표준 이전:

  시선 추적기 A → 프로토콜 A → 소프트웨어 A만
  시선 추적기 B → 프로토콜 B → 소프트웨어 B만
  스위치 C → 프로토콜 C → 소프트웨어 C만
  EMG 센서 D → 프로토콜 D → 소프트웨어 D만

WIA AAC 표준 이후:

  시선 추적기 A ─┐
  시선 추적기 B ─┤
  스위치 C ──────┼──→ WIA AAC 표준 형식 → 모든 호환 소프트웨어
  EMG 센서 D ────┤
  BCI 장치 E ────┘

1.5.2 표준 API

소프트웨어 개발자는 단일 인터페이스를 통해 모든 호환 장치를 지원할 수 있습니다.

1.5.3 원활한 전환

사용자가 입력 방법을 변경할 때:

  • [OK] 소프트웨어는 동일하게 유지
  • [OK] 설정과 선호도 보존
  • [OK] 센서 하드웨어만 변경
  • [OK] 최소한의 학습 곡선
  • [OK] 지속적인 의사소통 능력

1.6 WIA 철학: 홍익인간

弘益人間 (홍익인간)

"널리 인간을 이롭게 하라"

고대 한국의 철학으로 "널리 인간을 이롭게 한다"는 의미가 WIA AAC 표준을 이끕니다. 의사소통은 기본적인 인권입니다. 이 표준은:

  • 영원히 무료로 공개
  • 특허나 라이선스 비용 없음
  • 누구나 구현 가능
  • 인증 서비스를 통한 지속 가능성 확보

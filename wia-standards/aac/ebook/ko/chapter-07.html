[AAC] 제7장: Phase 4 - WIA 생태계 통합

홍익인간 (弘益人間)

"생각에서 모든 양식의 표현으로."

Phase 4는 AAC 사용자를 WIA 생태계를 통해 인간 의사소통의 전체 스펙트럼에 연결합니다.

7.1 Phase 4 개요

7.1.1 목적

Phase 4는 생태계 통합 계층을 정의합니다 - AAC 텍스트 출력이 더 넓은 WIA 표준 제품군에 어떻게 연결되어 음성, 수어, 점자를 통한 동시 의사소통을 가능하게 하는지.

7.1.2 WIA 표준 제품군

표준 전체 이름 목적 출력
WIA AAC 보완대체의사소통 보조 입력 표준화 텍스트
WIA Talk 텍스트-음성 변환 표준 음성 합성 오디오
ISP 국제 수어 프로토콜 수어 표현 애니메이션
WIA Braille 점자 표준 점자 변환 촉각

7.1.3 통합 비전

완전한 의사소통 파이프라인:

사용자 입력 (AAC)
      |
      v
+------------------+
|    WIA AAC       |
|   신호 처리       |
+--------+---------+
         |
         v

   "안녕하세요"
         |
    +----+----+----+----+
    |         |         |
    v         v         v
+-------+ +-------+ +--------+

+---+---+ +---+---+ +---+----+
    |         |         |

  음성     수어      점자

결과: 같은 메시지가 도달:
  - 청각 사용자 (음성)
  - 청각 장애 사용자 (수어)
  - 시청각 장애 사용자 (점자)

7.2 WIA Talk 통합

7.2.1 개요

WIA Talk는 AAC 텍스트 출력을 자연스러운 음성으로 변환하는 텍스트-음성 변환 표준입니다. 여러 언어, 음성 및 음성 매개변수를 지원합니다.

7.2.2 통합 API

import { WiaAAC } from 'wia-aac';
import { WiaTalk } from 'wia-talk';

// 두 시스템 초기화
const aac = new WiaAAC();
const talk = new WiaTalk({
    voice: 'ko-KR-Neural',
    rate: 1.0,
    pitch: 1.0
});

// AAC를 Talk에 연결
aac.on('text', async (text) => {
    await talk.speak(text);
});

// SSML을 사용한 고급 사용
aac.on('text', async (text, context) => {
    const ssml = talk.buildSSML(text, {
        emphasis: context.emphasis,
        pauseAfter: context.punctuation ? 300 : 0
    });
    await talk.speakSSML(ssml);
});

7.2.3 음성 설정

WIA Talk 음성 옵션:

지원 언어:
  - 한국어
  - 영어 (US, UK, AU, IN)
  - 일본어
  - 중국어 (보통화, 광둥어)
  - 스페인어
  - 프랑스어
  - 독일어
  - 그 외 50개 이상 언어

음성 유형:
  - Neural (고품질, 자연스러운)
  - Standard (낮은 지연)
  - Custom (사용자 학습)

설정 예시:
{
    "voice": {
        "id": "ko-KR-Neural",
        "language": "ko-KR",
        "gender": "female",
        "age": "adult"
    },
    "parameters": {
        "rate": 1.0,        // 0.5 - 2.0
        "pitch": 1.0,       // 0.5 - 2.0
        "volume": 1.0       // 0.0 - 1.0
    }
}

7.3 ISP 통합 (수어)

7.3.1 개요

ISP (International Sign Protocol)는 수어를 디지털로 표현하는 WIA 표준입니다. 3D 아바타나 비디오를 통해 표시되는 텍스트-수어 변환을 가능하게 합니다.

7.3.2 통합 API

import { WiaAAC } from 'wia-aac';
import { ISP, ISPAvatar } from 'wia-isp';

// 초기화
const aac = new WiaAAC();
const isp = new ISP();
const avatar = new ISPAvatar({
    model: 'standard-human',
    signLanguage: 'KSL'  // KSL, ASL, BSL, JSL 등
});

// AAC를 ISP에 연결
aac.on('text', async (text) => {
    // 텍스트를 수어 표기법으로 변환
    const signs = await isp.textToSigns(text);

    // 아바타 애니메이션 렌더링
    await avatar.animate(signs);
});

7.3.3 수어 지원

지원 수어:

주요 지원:
  - KSL (한국 수어)
  - ASL (미국 수어)
  - BSL (영국 수어)
  - JSL (일본 수어)
  - LSF (프랑스 수어)
  - DGS (독일 수어)

ISP 형식 예시:
{
    "text": "안녕하세요",
    "target_language": "KSL",
    "signs": [
        {
            "gloss": "안녕",
            "handshape": "open-B-both",
            "location": "chest",
            "movement": "bow-forward",
            "expression": "smile"
        }
    ]
}

7.3.4 아바타 렌더링 옵션

ISP 아바타 설정:

렌더링 모드:
  - 3D 아바타 (WebGL/Three.js)
  - 2D 스프라이트 애니메이션
  - 비디오 (사전 녹화 클립)
  - 골격 데이터 (커스텀 렌더링용)

아바타 옵션:
{
    "model": "standard-human",
    "customization": {
        "skinTone": "#C68642",
        "hairColor": "#000000",
        "clothing": "casual"
    },
    "animation": {
        "speed": 1.0,
        "smoothing": true,
        "transitionTime": 200  // 수어 간 ms
    }
}

7.4 WIA Braille 통합

7.4.1 개요

WIA Braille은 텍스트를 점자 표기법으로 변환하는 표준입니다. 여러 점자 코드를 지원하고 점자 디스플레이에 출력할 수 있습니다.

7.4.2 통합 API

import { WiaAAC } from 'wia-aac';
import { WiaBraille, BrailleDisplay } from 'wia-braille';

// 초기화
const aac = new WiaAAC();
const braille = new WiaBraille({
    code: 'Korean',  // 한국어 점자
    grade: 2         // 1급 (문자별) 또는 2급 (약자)
});

// 점자 디스플레이 연결
const display = await BrailleDisplay.connect();

// AAC를 Braille에 연결
aac.on('text', async (text) => {
    // 점자로 변환
    const brailleText = braille.convert(text);

    // 디스플레이에 전송
    await display.write(brailleText);
});

// 점자 유니코드 얻기
aac.on('text', (text) => {
    const brailleUnicode = braille.toUnicode(text);
    console.log(brailleUnicode);
    // 출력: "⠎⠃⠈⠎⠦⠴" (안녕)
});

7.4.3 점자 코드 지원

지원 점자 코드:

1급 (비약자):
  - 문자별 전사
  - 초보자와 기술 텍스트에 사용

2급 (약자):
  - 일반적인 단어에 약자 사용
  - 대부분의 점자 독자에게 표준

코드 표준:
  - 한국어 점자 - 한국
  - UEB (통합 영어 점자) - 국제
  - 일본어 점자 - 일본
  - 그 외 30개 이상 국가별 코드

7.4.4 점자 디스플레이 지원

점자 디스플레이 통합:

지원 프로토콜:
  - HID Braille (USB)
  - Serial Protocol
  - Bluetooth (BrailleNote 등)

디스플레이 기능:
  - 커서 라우팅 버튼
  - 탐색 키
  - 상태 셀
  - 다중 라인 디스플레이

설정:
{
    "display": {
        "cells": 40,           // 14, 20, 40, 80
        "protocol": "hid",
        "vendor": "HumanWare"
    },
    "output": {
        "scrollDelay": 100,    // ms
        "autoScroll": false
    }
}

7.5 통합 출력 관리자

7.5.1 개요

출력 관리자는 모든 출력 양식을 조정하여 음성, 수어, 점자에 동시에 동기화된 전달을 보장합니다.

7.5.2 구현

import { WiaAAC } from 'wia-aac';
import { OutputManager } from 'wia-aac/output';

const aac = new WiaAAC();
const output = new OutputManager();

// 출력 설정
output.configure({
    talk: {
        enabled: true,
        voice: 'ko-KR-Neural'
    },
    isp: {
        enabled: true,
        language: 'KSL',
        avatar: 'standard-human'
    },
    braille: {
        enabled: true,
        code: 'Korean',
        display: 'auto-detect'
    }
});

// AAC를 통합 출력에 연결
aac.on('text', async (text) => {
    await output.broadcast(text);
    // 모든 활성화된 출력에 자동 전송
});

// 출력 이벤트
output.on('talkComplete', () => console.log('음성 완료'));
output.on('ispComplete', () => console.log('수어 애니메이션 완료'));
output.on('brailleComplete', () => console.log('점자 표시 완료'));

7.5.3 동기화

출력 동기화 옵션:

모드 1: 동시 (기본)
  - 모든 출력이 함께 시작
  - 실시간 의사소통에 최적

모드 2: 순차적
  - 음성 먼저, 그 다음 수어, 그 다음 점자
  - 발표/교육용

모드 3: 우선순위
  - 기본 출력 즉시
  - 나머지는 리소스 허용 시

설정:
{
    "synchronization": {
        "mode": "simultaneous",
        "startDelay": 0,
        "outputs": {
            "talk": { "priority": 1 },
            "isp": { "priority": 2 },
            "braille": { "priority": 3 }
        }
    }
}

7.6 완전한 통합 예제

7.6.1 전체 파이프라인 코드

import { WiaAAC } from 'wia-aac';
import { WiaTalk } from 'wia-talk';
import { ISP, ISPAvatar } from 'wia-isp';
import { WiaBraille, BrailleDisplay } from 'wia-braille';

async function initializeAAC() {
    // AAC 초기화
    const aac = new WiaAAC();
    await aac.connect({ type: 'eye_tracker' });

    // TTS 초기화
    const talk = new WiaTalk({ voice: 'ko-KR-Neural' });

    // 수어 초기화
    const isp = new ISP();
    const avatar = new ISPAvatar({
        model: 'standard-human',
        signLanguage: 'KSL'
    });

    // 점자 초기화
    const braille = new WiaBraille({ code: 'Korean', grade: 2 });
    const display = await BrailleDisplay.connect();

    // 메인 텍스트 출력 핸들러
    aac.on('text', async (text) => {
        console.log('사용자 말:', text);

        // 모든 출력을 병렬로 실행
        await Promise.all([
            // 1. 텍스트 음성 출력
            talk.speak(text),

            // 2. 텍스트 수어 출력
            (async () => {
                const signs = await isp.textToSigns(text);
                await avatar.animate(signs);
            })(),

            // 3. 점자에 표시
            (async () => {
                const brailleText = braille.convert(text);
                await display.write(brailleText);
            })()
        ]);

        console.log('모든 출력 완료');
    });

    console.log('WIA AAC 시스템 준비됨');
    return aac;
}

// 시스템 시작
initializeAAC();

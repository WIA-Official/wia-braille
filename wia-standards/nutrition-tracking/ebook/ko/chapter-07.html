  ┌───────────────────────────┐
  │ 알레르기 관리             │
  ├───────────────────────────┤
  │ 심각도:                   │
  │ ⚠️ 심각 (응급):           │
  │   ☑ 땅콩                  │
  │   ☑ 새우                  │
  │                           │
  │ ⚡ 중간 (주의):           │
  │   ☑ 우유                  │
  │   ☐ 달걀                  │
  │                           │
  │ ℹ️ 경미 (불편):           │
  │   ☐ 복숭아                │
  │   ☐ 토마토                │
  └───────────────────────────┘

증상 기록:
  땅콩:
    • 증상: 아나필락시스
    • 발현 시간: 즉시 (< 5분)
    • 대응: 에피펜 필요
    • 최근 반응: 2023.03.15

  우유:
    • 증상: 복통, 설사
    • 발현 시간: 30분-1시간
    • 대응: 회피
    • 유당 불내증 가능성


교차 반응 (Cross-Reactivity)
============================

자작나무 꽃가루 알레르기:
  → 교차 반응:
    • 사과
    • 복숭아
    • 체리
    • 당근
    • 셀러리

새우 알레르기:
  → 교차 반응:
    • 게
    • 랍스터
    • 가재
    • 바닷가재

우유 알레르기:
  → 교차 반응:
    • 염소 우유
    • 양 우유
    • 버터
    • 치즈
    • 요거트


대체 식품 추천
=============

우유 알레르기/유당 불내증:
  대체:
    • 두유 (대두 알레르기 없을 경우)
    • 아몬드 우유
    • 오트 우유
    • 코코넛 우유
    • 락토프리 우유 (유당 불내증만)

  칼슘 보충:
    • 강화 식물성 우유
    • 케일, 브로콜리
    • 정어리 (뼈째)
    • 칼슘 보충제

달걀 알레르기:
  대체:
    • 아마씨 달걀 (1 Tbsp + 3 Tbsp 물)
    • 치아씨 달걀
    • 두부 (스크램블)
    • 상업용 달걀 대체품

밀 알레르기/셀리악병:
  대체:
    • 쌀, 현미
    • 퀴노아
    • 메밀 (교차 반응 확인)
    • 글루텐프리 제품
    • 감자 전분

당뇨병 유형 특징 영양 관리
제1형 인슐린 생산 부족 탄수화물 계산, 인슐린 조절
제2형 인슐린 저항성 체중 관리, 탄수화물 조절
임신성 임신 중 발생 혈당 모니터링, 균형 식단

혈당 관리 식단
=============

저혈당 지수 (Low GI) 식품
------------------------
  GI < 55:
    • 현미 (55)
    • 고구마 (55)
    • 귀리 (55)
    • 사과 (36)
    • 렌틸콩 (32)
    • 그릭 요거트 (11)

  장점:
    • 혈당 천천히 상승
    • 인슐린 요구량 감소
    • 포만감 지속


탄수화물 계산 (Carb Counting)
-----------------------------
  목표: 식사당 45-60g

  아침:
    오트밀 50g        탄 27g
    우유 200mL        탄 10g
    바나나 1개 (중)   탄 27g
    ──────────────────────
    총                탄 64g
    → 약간 초과, 조정 필요

  조정 후:
    오트밀 40g        탄 22g
    우유 200mL        탄 10g
    바나나 1/2개      탄 13g
    ──────────────────────
    총                탄 45g ✓


식사 비율 방법 (Plate Method)
-----------------------------
  ┌─────────────────┐
  │       │         │
  │  채소 │  단백질 │
  │       │         │
  ├───────┤─────────┤
  │  탄수화물       │
  └─────────────────┘

  • 1/2: 비전분 채소
  • 1/4: 저지방 단백질
  • 1/4: 통곡물/전분


당뇨병 식품 교환표
=================

탄수화물 15g = 1 교환 단위:
  • 밥 1/3공기 (70g)
  • 식빵 1장
  • 감자 (중) 1/2개
  • 사과 1개 (소)
  • 우유 200mL

목표: 식사당 3-4 교환 단위
      (45-60g 탄수화물)


인슐린 대 탄수화물 비율 (ICR)
----------------------------
  제1형 당뇨병:
    ICR = 1:10
    의미: 탄수화물 10g당 인슐린 1단위

  예시:
    점심 탄수화물: 60g
    필요 인슐린: 60 ÷ 10 = 6단위

  개인화:
    의사/영양사와 함께 결정
    지속적 모니터링 및 조정

  닭가슴살 구이   탄 0g
  채소 볶음       탄 10g

  총              탄 85g

  시간: 14:00
  혈당: 145 mg/dL

7.4 혈당 지수 추적

GI vs GL (혈당 지수 vs 혈당 부하)
================================

혈당 지수 (GI)
-------------
  정의:
    포도당 대비 혈당 상승 속도
    (포도당 = 100)

  분류:
    저 GI:  < 55
    중 GI:  56-69
    고 GI:  ≥ 70

  예시:
    현미:     55 (저)
    백미:     73 (고)
    흰 식빵:  75 (고)
    통밀빵:   69 (중)


혈당 부하 (GL)
-------------
  정의:
    GI × 탄수화물(g) ÷ 100
    실제 섭취량 반영

  분류:
    저 GL:  < 10
    중 GL:  11-19
    고 GL:  ≥ 20

  예시:
    수박:
      GI = 72 (고)
      탄수화물 = 11g (150g 기준)
      GL = 72 × 11 ÷ 100 = 7.92 (저)
      → 소량 섭취 시 안전

    백미밥 1공기:
      GI = 73
      탄수화물 = 75g
      GL = 73 × 75 ÷ 100 = 54.75 (고)
      → 주의 필요


GI 낮추는 방법
=============

조리 방법:
  [1] 알 덴테 파스타
      완전히 익힌 것보다 GI 낮음

  [2] 밥 식혀 먹기
      저항성 전분 증가
      → GI 감소

  [3] 식초 추가
      초밥, 샐러드
      → 혈당 반응 완화

음식 조합:
  [1] 지방 + 탄수화물
      아보카도 + 빵
      → 소화 속도 감소

  [2] 단백질 + 탄수화물
      닭가슴살 + 밥
      → 혈당 안정

  [3] 식이섬유 + 탄수화물
      채소 + 면
      → GI 감소

식사 순서:
  1. 채소 먼저
  2. 단백질
  3. 탄수화물 마지막
  → 혈당 상승 완화


개인 혈당 반응 (CGM)
===================

연속 혈당 측정기 (CGM):
  • 24시간 모니터링
  • 5분마다 측정
  • 추세 파악

개인 차이:
  같은 음식, 다른 반응

  예: 바나나 1개
    사람 A: +30 mg/dL
    사람 B: +50 mg/dL
    사람 C: +20 mg/dL

  개인화 필요:
    내 몸에 맞는 음식 찾기

7.5 만성 질환별 식이 요법

고혈압
======

DASH 다이어트:
  목표:
    • 나트륨 < 2,300 mg/일
    • 칼륨 4,700 mg/일
    • 칼슘 1,250 mg/일
    • 마그네슘 500 mg/일

  권장 식품:
    [+] 과일, 채소 (8-10 serving/일)
    [+] 통곡물
    [+] 저지방 유제품
    [+] 생선, 닭고기
    [+] 견과류, 콩

  제한:
    [-] 소금 (나트륨)
    [-] 가공식품
    [-] 적색육
    [-] 당류
    [-] 알코올

  나트륨 추적:
    김치 50g:        250 mg
    라면 1개:        1,800 mg ⚠️
    간장 1 Tbsp:     900 mg

    일일 총계:       1,850 mg ✓


신장 질환 (CKD)
==============

영양 목표:
  • 단백질: 체중 kg당 0.6-0.8g (제한)
  • 나트륨: < 2,000 mg/일
  • 칼륨: 제한 (혈액 검사 기반)
  • 인: < 1,000 mg/일

  단백질 계산:
    체중 70kg, CKD 3기
    단백질: 70 × 0.7 = 49g/일

    아침: 달걀 1개       단 6g
    점심: 닭가슴살 80g   단 25g
    저녁: 두부 100g      단 10g
    간식: 우유 100mL     단 3g
    ─────────────────────────
    총:                  단 44g ✓

  피할 식품 (고칼륨):
    • 바나나
    • 오렌지
    • 감자
    • 토마토
    • 시금치


고지혈증
========

저포화지방, 저콜레스테롤:
  • 포화지방: < 총 칼로리 7%
  • 트랜스지방: 최소화
  • 콜레스테롤: < 200 mg/일

  권장:
    [+] 오메가-3 생선 (주 2-3회)
    [+] 식이섬유 (25-35g/일)
    [+] 식물성 스테롤
    [+] 견과류

  제한:
    [-] 적색육, 내장육
    [-] 버터, 치즈
    [-] 트랜스지방 식품

  식이섬유 추적:
    오트밀 50g:      5g
    사과 1개:        4g
    브로콜리 100g:   2.5g
    현미밥 1공기:    3g
    ────────────────────
    일일 목표 30g 중 14.5g


통풍
====

퓨린 제한 식단:
  • 퓨린: < 150 mg/일
  • 수분: 2-3 L/일

  고퓨린 식품 (피하기):
    • 내장육 (간, 곱창)
    • 정어리, 멸치
    • 맥주
    • 육수

  중퓨린 식품 (제한):
    • 쇠고기, 돼지고기
    • 생선 (대부분)
    • 콩류

  저퓨린 식품 (권장):
    • 우유, 치즈
    • 달걀
    • 채소 (대부분)
    • 과일


셀리악병 (글루텐 불내증)
======================

완전 글루텐 프리:
  피할 곡물:
    • 밀
    • 호밀
    • 보리
    • 귀리 (교차 오염)

  안전한 곡물:
    • 쌀
    • 퀴노아
    • 메밀
    • 옥수수
    • 수수

  숨은 글루텐:
    • 간장 (일부)
    • 맥주
    • 가공식품 첨가제

  글루텐 감지:
    바코드 스캔 → 글루텐 표시
    레스토랑 필터: "글루텐 프리"

7.6 약물 상호작용 체크

음식-약물 상호작용
=================

와파린 (항응고제)
----------------
  주의: 비타민 K

  비타민 K 풍부 식품:
    • 케일, 시금치
    • 브로콜리
    • 양배추

  권장:
    일정한 양 섭취 유지
    (급격한 증가/감소 피하기)

  앱 알림:
    "와파린 복용 중입니다.
     오늘 시금치 150g 섭취 시
     평소보다 많습니다.
     일관성 유지를 위해 주의하세요."


스타틴 (고지혈증약)
------------------
  피할 것: 자몽

  이유:
    자몽 → 약물 대사 억제
    → 혈중 농도 ↑
    → 부작용 위험

  대체:
    오렌지, 귤 (안전)

  경고:
    "스타틴 복용 중입니다.
     자몽주스는 피해주세요."


MAO 억제제 (우울증약)
--------------------
  피할 것: 티라민 고함량 식품

  티라민 식품:
    • 숙성 치즈
    • 훈제육, 소시지
    • 간장
    • 김치 (오래된 것)
    • 레드 와인

  위험:
    고혈압 위기


메트포르민 (당뇨병약)
--------------------
  주의: 비타민 B12 흡수 감소

  보충:
    • B12 보충제 고려
    • B12 풍부 식품
      (고기, 생선, 달걀, 유제품)

5.1 딥러닝 식품 인식 모델

CNN 아키텍처
===========

기본 구조
--------
  입력 계층:
    이미지 크기: 224×224×3 (RGB)
    정규화: 0-1 범위

  합성곱 계층 (Convolutional Layers):
    Conv1: 32 필터, 3×3, ReLU
    MaxPool: 2×2
    Conv2: 64 필터, 3×3, ReLU
    MaxPool: 2×2
    Conv3: 128 필터, 3×3, ReLU
    MaxPool: 2×2
    Conv4: 256 필터, 3×3, ReLU
    MaxPool: 2×2

  완전 연결 계층 (Fully Connected):
    FC1: 512 뉴런, ReLU, Dropout(0.5)
    FC2: 256 뉴런, ReLU, Dropout(0.5)

  출력 계층:
    식품 분류: Softmax, 1000 클래스
    분량 추정: Linear, 1 출력 (g)


전이 학습 (Transfer Learning)
-----------------------------
  사전 학습 모델:
    • ResNet-50
    • EfficientNet-B0
    • MobileNet-V2 (모바일)
    • Inception-V3

  장점:
    [+] 적은 학습 데이터
    [+] 빠른 수렴
    [+] 높은 정확도

  미세 조정 (Fine-tuning):
    1. 사전 학습 가중치 로드
    2. 마지막 계층 교체 (1000 → 식품 카테고리 수)
    3. 초기 계층 동결
    4. 마지막 계층만 학습
    5. 전체 미세 조정

5.2 음식 분류 및 식별

난이도 예시 정확도 과제
쉬움 과일, 단일 식품 95-99% 명확한 형태와 색
보통 고기, 생선 구이 85-95% 조리 방법 다양
어려움 국/찌개, 샐러드 75-85% 여러 재료 혼합
매우 어려움 복합 요리, 퓨전 60-75% 새로운 조합 
분류 프로세스
===========

1단계: 이미지 입력
----------------
  사용자 사진 → 전처리 → 224×224 크기 조정


2단계: 특징 추출
---------------
  CNN 통과:
    입력 → Conv → Pool → ... → Feature Map


3단계: 분류 예측
---------------
  Softmax 출력:
    [0.65] 불고기
    [0.20] 소불고기
    [0.08] 제육볶음
    [0.04] 스테이크
    [0.03] 기타


4단계: 신뢰도 평가
-----------------
  높은 신뢰도 (>80%):
    → 자동 선택
    "이 음식은 '불고기'입니다."

  중간 신뢰도 (50-80%):
    → 사용자 확인
    "다음 중 어느 것인가요?"
    [1] 불고기 (65%)
    [2] 소불고기 (20%)
    [3] 직접 입력

  낮은 신뢰도 (<50%):
    → 수동 검색 유도
    "음식을 찾을 수 없습니다. 검색해주세요."


5단계: 후처리
------------
  문맥 정보 활용:
    • 시간: 오전 8시 → 아침 메뉴 우선
    • 위치: 한식당 → 한식 우선
    • 이력: 자주 먹는 음식 우선


다중 음식 감지
=============

Object Detection 적용:
  모델: YOLO v5 또는 Faster R-CNN

  출력:
    Bounding Box + 클래스 + 신뢰도

  예시:
    ┌────────────────────────┐
    │  ┌──────┐              │
    │  │ 밥   │  ┌─────┐     │
    │  └──────┘  │김치 │     │
    │             └─────┘     │
    │  ┌──────────────┐       │
    │  │  불고기       │       │
    │  └──────────────┘       │
    │         ┌────┐          │
    │         │국  │          │
    │         └────┘          │
    └────────────────────────┘

  결과:
    [1] 밥 (98%)
    [2] 김치 (95%)
    [3] 불고기 (92%)
    [4] 된장국 (88%)


식품 유사도 처리
===============

  유사 식품 그룹:
    짜장면 vs 짬뽕
    → 색깔 차이로 구분

    김치찌개 vs 순두부찌개
    → 재료 보이는 정도

    백미밥 vs 현미밥
    → 색 톤 차이

  처리 전략:
    [1] 더 세밀한 특징 학습
    [2] 앙상블 모델 사용
    [3] 사용자 피드백 수집
    [4] 추가 질문 (조리 방법 등)

5.3 분량 추정 알고리즘

분량 추정 방법론
===============

방법 1: 참조 물체 기반
---------------------
  일반 물체:
    • 숟가락 (길이 15cm)
    • 젓가락 (23cm)
    • 동전 (지름 2.65cm)
    • 카드 (8.5×5.4cm)
    • 손 (크기 변동 큼, 덜 정확)

  과정:
    1. 참조 물체 감지
    2. 픽셀-실제 비율 계산
    3. 음식 영역 측정
    4. 부피/무게 추정

  예시:
    숟가락 길이 = 150 픽셀
    실제 길이 = 15cm
    비율 = 10 픽셀/cm

    밥 그릇 지름 = 120 픽셀
    실제 지름 = 12cm
    반지름 = 6cm

    밥 높이 추정 = 4cm (타원체 가정)
    부피 ≈ π × 6² × 4 = 452 cm³
    밥 밀도 ≈ 0.5 g/cm³
    무게 ≈ 226g


방법 2: 딥러닝 회귀
-----------------
  입력: 음식 이미지
  출력: 그램 단위 무게

  학습 데이터:
    • 이미지 + 실제 무게
    • 10,000+ 샘플
    • 정밀 저울로 측정

  모델 구조:
    ResNet-50 백본
    → Global Average Pooling
    → FC Layer (256)
    → FC Layer (1, 무게)

  손실 함수:
    MSE + 백분율 오차
    Loss = (예측 - 실제)² + |예측 - 실제| / 실제


방법 3: 스테레오 비전
-------------------
  듀얼 카메라 활용:
    • 왼쪽 + 오른쪽 이미지
    • 깊이 맵 생성
    • 3D 복원
    • 정확한 부피 계산

  정확도: 90-95%
  제한: 듀얼 카메라 필요


방법 4: AR (증강 현실)
--------------------
  ARKit (iOS) / ARCore (Android)
    • 평면 감지
    • 실제 크기 측정
    • 3D 메시 생성
    • 부피 계산

  사용자 경험:
    1. 카메라로 테이블 스캔
    2. 음식 주변 터치
    3. 3D 경계 박스 생성
    4. 자동 부피 계산


정확도 비교
==========

  방법               | 정확도 | 난이도 | 장비
  ──────────────────────────────────────
  참조 물체          | 70-80% | 중     | 일반 카메라
  딥러닝 회귀        | 75-85% | 고     | 일반 카메라
  스테레오 비전      | 90-95% | 고     | 듀얼 카메라
  AR                 | 85-90% | 중     | AR 지원 기기
  수동 입력          | 100%   | -      | 없음 (사용자)


분량 추정 예시
=============

음식: 닭가슴살 구이

참조 물체: 포크 (길이 20cm)

분석:
  1. 포크 픽셀 길이: 200px
     비율: 10px/cm

  2. 닭가슴살 영역:
     가로: 100px = 10cm
     세로: 70px = 7cm
     높이: 30px = 3cm (추정)

  3. 부피 계산:
     V ≈ 10 × 7 × 3 = 210 cm³

  4. 밀도 적용:
     닭가슴살 밀도 ≈ 1.05 g/cm³
     무게 = 210 × 1.05 = 220.5g

  5. 보정:
     실제 모양은 타원체
     보정 계수: 0.7
     최종: 220.5 × 0.7 = 154g

실제 무게: 150g
오차: 2.7% ✓


불확실성 표현
===========

  정확도 표시:
    [높음] 150g ±10g (±7%)
    [중간] 150g ±30g (±20%)
    [낮음] 150g ±50g (±33%)

  사용자에게:
    "약 150g (140-160g 범위)"

  개선 제안:
    "더 정확한 추정을 위해:
     • 숟가락이나 포크를 함께 촬영하세요
     • 여러 각도에서 촬영하세요
     • 또는 직접 입력하세요"

5.4 복합 식사 분석

복합 식사 시나리오
=================

예시: 한식 정식
--------------
  촬영 이미지:
    ┌─────────────────────────┐
    │   [국]                  │
    │                 [김치]  │
    │        [밥]             │
    │                 [나물]  │
    │   [불고기]              │
    │                 [전]    │
    └─────────────────────────┘

  AI 분석 과정:
    1. Object Detection
       → 6개 음식 영역 감지

    2. 각 음식 분류
       국 → 된장국 (90%)
       밥 → 백미밥 (95%)
       불고기 → 소불고기 (88%)
       김치 → 배추김치 (92%)
       나물 → 시금치나물 (85%)
       전 → 김치전 (80%)

    3. 분량 추정
       된장국: 250mL
       백미밥: 210g (1공기)
       소불고기: 120g
       배추김치: 30g
       시금치나물: 50g
       김치전: 60g

    4. 영양 정보 합산
       총 칼로리: 680 kcal
       탄수화물: 85g
       단백질: 35g
       지방: 18g

조리 방법 감지
=============

  같은 음식, 다른 조리법:
    닭고기 (100g 기준)
      삶은 닭: 165 kcal, 지방 4g
      구운 닭: 190 kcal, 지방 8g
      튀긴 닭: 270 kcal, 지방 18g

  감지 방법:
    • 색깔 (튀김: 황금빛)
    • 표면 질감 (튀김: 거친 표면)
    • 광택 (기름기)

  분류기 학습:
    조리 방법 → 칼로리 보정 계수


숨겨진 재료 추정
===============

  보이지 않는 재료:
    김밥:
      겉: 김, 밥
      속: 달걀, 당근, 단무지, 햄 (안 보임)

  처리 방법:
    [1] 표준 레시피 적용
        "김밥 1줄" → 표준 재료 및 비율

    [2] 사용자 확인
        "이 김밥에 들어간 재료는?"
        ☑ 달걀
        ☑ 당근
        ☐ 치즈
        ☑ 햄

    [3] 학습 패턴
        "당신이 자주 먹는 김밥은 이 재료입니다"


에러 처리
========

  모호한 경우:
    [?] 스무디
        → 재료 알 수 없음
        → 사용자에게 물어보기

  여러 해석:
    이미지: 갈색 소스
    가능성:
      [1] 짜장면 (중식)
      [2] 하이라이스 (일식)
      [3] 짜파게티 (인스턴트)
    → 상위 3개 제시

  실패:
    "음식을 인식할 수 없습니다"
    옵션:
      • 다시 촬영
      • 다른 각도
      • 수동 검색

5.5 정확도 개선 및 학습

사용자 피드백 루프
=================

  1. AI 예측
     "불고기 150g"

  2. 사용자 수정
     실제: "소불고기 180g"

  3. 피드백 저장
     이미지 + 정답 라벨

  4. 재학습 데이터로 활용
     주기적으로 모델 업데이트


능동 학습 (Active Learning)
==========================

  불확실한 샘플 우선:
    신뢰도 50-70% 이미지
    → 사용자에게 라벨 요청
    → 가장 효과적인 학습

  보상 시스템:
    • 정확한 라벨 제공
    → 포인트 지급
    → 커뮤니티 기여자 배지


연속 학습 (Continual Learning)
=============================

  새로운 음식 추가:
    신메뉴, 유행 음식
    → 기존 지식 유지하면서 새 카테고리 학습

  Catastrophic Forgetting 방지:
    • Elastic Weight Consolidation
    • 중요한 가중치 보존


개인화 모델
==========

  사용자별 미세 조정:
    자주 먹는 음식 → 높은 우선순위
    특이한 조리법 → 개인 패턴 학습

  예시:
    일반 사용자: 김치찌개 인식률 85%
    개인화 후: 우리 집 김치찌개 인식률 95%

모바일 최적화
============

  경량 모델:
    MobileNet-V3
    • 파라미터: 5.4M
    • 크기: 21 MB
    • 추론 시간: 200ms (모바일 CPU)

  모델 압축:
    양자화 (Quantization)
      FP32 → INT8
      크기: 1/4 감소
      속도: 2-3배 향상
      정확도 손실: < 1%

  온디바이스 vs 클라우드:
    ┌──────────────┬─────────┬─────────┐
    │              │ 디바이스 │ 클라우드 │
    ├──────────────┼─────────┼─────────┤
    │ 속도         │ 빠름    │ 중간    │
    │ 정확도       │ 중간    │ 높음    │
    │ 오프라인     │ 가능    │ 불가    │
    │ 배터리       │ 소모    │ 절약    │
    │ 프라이버시   │ 높음    │ 낮음    │
    └──────────────┴─────────┴─────────┘

  하이브리드 접근:
    간단한 음식 → 디바이스
    복잡한 음식 → 클라우드

제3장: 식품 데이터베이스 시스템

"홍익인간: 정확한 데이터는 신뢰할 수 있는 영양 관리의 토대입니다."

3.1 데이터베이스 구조 설계

핵심 데이터 모델
===============

FOOD 테이블
----------
  food_id          (PK) UUID
  name             VARCHAR(200) - 식품명
  name_en          VARCHAR(200) - 영문명
  category         VARCHAR(50)  - 분류
  brand            VARCHAR(100) - 브랜드
  barcode          VARCHAR(20)  - 바코드 (선택)
  serving_size     FLOAT        - 1회 제공량 (g)
  serving_unit     VARCHAR(20)  - 단위
  created_at       TIMESTAMP
  updated_at       TIMESTAMP
  verified         BOOLEAN      - 검증 여부
  source           VARCHAR(50)  - 데이터 출처

  인덱스:
    idx_name     ON (name)
    idx_barcode  ON (barcode)
    idx_category ON (category)


NUTRITION 테이블
---------------
  nutrition_id     (PK) UUID
  food_id          (FK) UUID
  serving_size     FLOAT        - 기준량 (g)
  calories         FLOAT        - 칼로리 (kcal)

  # 다량 영양소
  protein          FLOAT        - 단백질 (g)
  carbs            FLOAT        - 탄수화물 (g)
  fiber            FLOAT        - 식이섬유 (g)
  sugar            FLOAT        - 당류 (g)
  fat_total        FLOAT        - 총 지방 (g)
  fat_saturated    FLOAT        - 포화지방 (g)
  fat_trans        FLOAT        - 트랜스지방 (g)
  fat_mono         FLOAT        - 단일불포화지방 (g)
  fat_poly         FLOAT        - 다중불포화지방 (g)

  # 미량 영양소
  vitamin_a        FLOAT        - 비타민 A (μg)
  vitamin_c        FLOAT        - 비타민 C (mg)
  vitamin_d        FLOAT        - 비타민 D (μg)
  calcium          FLOAT        - 칼슘 (mg)
  iron             FLOAT        - 철분 (mg)
  sodium           FLOAT        - 나트륨 (mg)
  potassium        FLOAT        - 칼륨 (mg)
  cholesterol      FLOAT        - 콜레스테롤 (mg)

  created_at       TIMESTAMP
  data_source      VARCHAR(100)


CATEGORY 계층 구조
------------------
  곡류
    ├── 밥류
    ├── 빵류
    ├── 면류
    └── 떡류

  단백질
    ├── 육류
    │   ├── 소고기
    │   ├── 돼지고기
    │   └── 닭고기
    ├── 수산물
    │   ├── 생선
    │   └── 해산물
    └── 난류

  채소
    ├── 녹색 채소
    ├── 뿌리 채소
    └── 기타 채소

  과일
    ├── 사과류
    ├── 감귤류
    ├── 베리류
    └── 열대 과일

  유제품
    ├── 우유
    ├── 치즈
    └── 요거트

  간식
    ├── 과자
    ├── 아이스크림
    └── 초콜릿


USER_FOOD 테이블 (사용자 정의)
-----------------------------
  user_food_id     (PK) UUID
  user_id          (FK) UUID
  food_id          (FK) UUID - NULL 가능
  name             VARCHAR(200)
  custom_nutrition JSON         - 사용자 입력 영양 정보
  photo_url        VARCHAR(500)
  created_at       TIMESTAMP


RECIPE 테이블
------------
  recipe_id        (PK) UUID
  user_id          (FK) UUID
  name             VARCHAR(200)
  description      TEXT
  servings         INT          - 인분
  prep_time        INT          - 준비 시간 (분)
  cook_time        INT          - 조리 시간 (분)
  instructions     TEXT
  photo_url        VARCHAR(500)
  created_at       TIMESTAMP


RECIPE_INGREDIENT 테이블
------------------------
  ingredient_id    (PK) UUID
  recipe_id        (FK) UUID
  food_id          (FK) UUID
  quantity         FLOAT
  unit             VARCHAR(20)
  notes            VARCHAR(200)


관계도
======

  USER ──1:N──> USER_FOOD
    │
    └──1:N──> RECIPE ──1:N──> RECIPE_INGREDIENT
                                     │
                                     └──N:1──> FOOD ──1:1──> NUTRITION

USDA FoodData Central API 통합
==============================

API 엔드포인트
-------------
  기본 URL: https://api.nal.usda.gov/fdc/v1/

  주요 엔드포인트:
    /foods/search     - 식품 검색
    /food/{fdcId}     - 식품 상세
    /foods/list       - 식품 목록
    /foods            - 다중 식품 조회

3.4 사용자 정의 식품 추가

사용자 정의 식품 워크플로우
==========================

1단계: 기본 정보 입력
-------------------
  필수:
    [*] 식품명
    [*] 1회 제공량 (g 또는 mL)
    [*] 총 칼로리

  선택:
    [ ] 사진
    [ ] 브랜드
    [ ] 카테고리
    [ ] 메모


2단계: 영양 정보 입력
--------------------
  간편 모드:
    • 칼로리만 입력
    • 다량 영양소 (탄수화물, 단백질, 지방)

  상세 모드:
    • 모든 다량 영양소 세부 정보
    • 미량 영양소
    • 식이섬유, 당류 등


3단계: 데이터 검증
-----------------
  자동 검증:
    [CHK] 칼로리 계산 일치 여부
          (탄수화물×4 + 단백질×4 + 지방×9)
    [CHK] 다량 영양소 합 <= 100g (고체)
    [CHK] 범위 체크 (음수 방지)

  경고:
    [!] 계산 불일치 시 경고 메시지
    [!] 비정상적으로 높은 값


4단계: 사진 추가 (선택)
----------------------
  • 식품 사진 촬영
  • 갤러리에서 선택
  • 포장 라벨 촬영
  • OCR로 영양 정보 추출 시도

=====================

요리명: 엄마표 된장찌개

재료 (4인분):
  된장 80g

  감자 150g
  호박 100g
  양파 100g
  청양고추 30g

  된장 80g:       160 kcal
  두부 200g:      150 kcal
  감자 150g:      120 kcal
  호박 100g:      20 kcal
  양파 100g:      40 kcal
  청양고추 30g:   10 kcal
  국물멸치 20g:   70 kcal
  ─────────────────────
  총 (4인분):     570 kcal

  1인분 (425g):   142.5 kcal
    탄수화물:     18g
    단백질:       12g
    지방:         4g
    나트륨:       950mg


데이터 공유 옵션
===============

  개인용:
    • 나만 볼 수 있음
    • 언제든 수정/삭제 가능

  커뮤니티 공유:
    • 다른 사용자도 검색 가능
    • 별점 및 리뷰 시스템
    • 검증 프로세스 거침

  레시피 공유:
    • 조리법 포함
    • 단계별 사진
    • 영양 정보 자동 계산

3.5 레시피 관리 시스템

레시피 생성 프로세스
===================

1. 레시피 기본 정보
-----------------
  레시피명: 닭가슴살 샐러드
  인분: 2인분
  준비 시간: 15분
  조리 시간: 10분
  난이도: ⭐⭐ (쉬움)
  카테고리: 샐러드, 다이어트


2. 재료 입력
-----------
  주재료:
    [ ] 닭가슴살 200g
    [ ] 로메인 상추 150g
    [ ] 방울토마토 100g
    [ ] 오이 80g
    [ ] 아보카도 50g

  드레싱:
    [ ] 올리브유 15mL
    [ ] 레몬즙 10mL
    [ ] 발사믹 식초 5mL
    [ ] 소금 1g
    [ ] 후추 0.5g


3. 조리 과정
-----------
  [1] 닭가슴살 삶기
      • 물 끓이기
      • 닭가슴살 넣고 10분 삶기
      • 찬물에 식히고 찢기

  [2] 야채 준비
      • 상추 씻어서 물기 제거
      • 토마토 반으로 자르기
      • 오이 슬라이스
      • 아보카도 큐브

  [3] 드레싱 만들기
      • 올리브유, 레몬즙, 식초 섞기
      • 소금, 후추로 간

  [4] 플레이팅
      • 상추를 접시에 깔기
      • 야채와 닭가슴살 올리기
      • 드레싱 뿌리기


4. 자동 영양 계산
---------------
  시스템이 자동으로 계산:

  재료별 칼로리:
    닭가슴살 200g:    220 kcal
    로메인 상추 150g:  23 kcal
    방울토마토 100g:   18 kcal
    오이 80g:         13 kcal
    아보카도 50g:     80 kcal
    올리브유 15mL:    120 kcal
    레몬즙 10mL:       3 kcal
    발사믹 식초 5mL:   7 kcal
    ───────────────────────
    총 (2인분):       484 kcal

  1인분당 영양 정보:
    칼로리:    242 kcal
    탄수화물:  10g
    단백질:    25g
    지방:      12g
    식이섬유:  5g
    나트륨:    350mg


5. 인분 조정 기능
---------------
  기본: 2인분

  4인분으로 변경 시:
    • 모든 재료 자동 × 2
    • 영양 정보 자동 재계산
    • 조리 시간 조정 안내


레시피 검색 및 필터
==================

검색 조건:
  • 식사 시간 (아침/점심/저녁/간식)
  • 카테고리 (한식/양식/중식/일식)
  • 조리 시간 (< 15분, 15-30분, > 30분)
  • 난이도
  • 칼로리 범위
  • 다이어트 유형 (저탄고지, 고단백 등)
  • 알레르기 제외 (유제품, 견과류 등)

정렬 옵션:
  • 인기순
  • 최신순
  • 칼로리 낮은 순
  • 단백질 높은 순
  • 조리 시간 짧은 순


스마트 레시피 추천
=================

개인화 추천:
  [1] 영양 목표 기반
      • 남은 칼로리 300 kcal
      → 300 kcal 이하 레시피 추천

  [2] 부족 영양소 기반
      • 단백질 30g 부족
      → 고단백 레시피 추천

  [3] 선호도 기반
      • 자주 먹는 재료
      • 높은 별점 준 레시피
      → 유사 레시피 추천

  [4] 냉장고 재료 기반
      • 보유 재료 입력
      → 해당 재료 활용 레시피

  [5] 시간 기반
      • 저녁 7시
      • 조리 시간 20분 가능
      → 빠른 저녁 메뉴 추천

자동 검증 규칙

  [1] 계산 일치성

      허용 오차: ±5%

  [2] 합리성 체크

  [3] 범위 검증

      • 단백질: 0-100g/100g
      • 지방: 0-100g/100g

  [4] 비율 검증

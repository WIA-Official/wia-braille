## 📋 Phase 3: 프로토콜

### 3.1 평가 프로토콜
- 표준 설문: PHQ-9, GAD-7, PCL-5, WHO-5
- 바이오마커: BDNF, 코르티솔, 염증 지표
- 신경영상: fMRI DMN 연결성, 아밀라 반응성
- 디지털 표현형: 스마트폰/웨어러블 데이터

### 3.2 치료 프로토콜
- 단계별 치료 (Stepped Care)
- 근거 기반 치료 선택
- 치료 반응 모니터링
- 재발 예방 계획

### 3.3 사이키델릭 보조 치료 프로토콜
- 적응증/금기증 스크리닝
- 준비 세션 (2-3회)
- 투약 세션 (치료 환경, 음악, 지지적 현존)
- 통합 세션 (3-6회)
- 장기 추적

### 3.4 위기 개입 프로토콜
- 자동 위기 감지 알고리즘
- 에스컬레이션 경로
- 응급 연락 체계
- 안전 계획 수립

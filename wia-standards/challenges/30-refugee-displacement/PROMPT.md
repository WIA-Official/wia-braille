## 📋 Phase 3: 프로토콜

### 3.1 생체인증 등록 프로토콜

**1단계: 사전 등록**
- Informed consent (모국어로 설명)
- 데이터 사용 목적 명시
- 프라이버시 권리 안내

**2단계: 생체정보 수집**
```
1. Liveness detection (3D depth camera)
2. Multi-finger capture (4 fingers minimum)
3. Iris capture (both eyes, NIR illumination)
4. Facial photograph (neutral expression, frontal)
5. Quality check (NFIQ 2.0 score > 40)
6. Immediate encryption (AES-256)
```

**3단계: DID 생성**
- Ed25519 key pair generation (local device)
- DID document creation
- Blockchain anchoring (Hyperledger Indy)
- Recovery phrase generation (BIP-39 12 words)

**4단계: Credential 발급**
- UNHCR signs refugee status credential
- Verifiable credential stored in digital wallet
- QR code printed for offline access

### 3.2 검증 프로토콜

**1:1 Verification (Authentication):**
```
1. Subject presents DID + biometric
2. Retrieve enrolled template (encrypted)
3. Liveness check
4. Match biometric (fusion score > 0.95)
5. Return match decision + attributes
```

**1:N Deduplication:**
```
1. New enrollment biometric
2. Compare against all enrolled (ABIS)
3. Flag duplicates (score > threshold)
4. Manual adjudication if needed
5. Prevent duplicate registration fraud
```

### 3.3 Selective Disclosure 프로토콜

**Zero-Knowledge Proof 예시:**
- Prove "age > 18" without revealing birthdate
- Prove "refugee status" without revealing country of origin
- Prove "vaccination status" without revealing medical history

**구현:**
- BBS+ signatures for selective disclosure
- ZK-SNARKs for complex predicates
- Anoncreds (Hyperledger Indy)

### 3.4 블록체인 앵커링 프로토콜

**Hyperledger Indy:**
```
1. DID document created locally
2. Hash of document computed
3. Transaction submitted to ledger
4. Consensus by validator nodes
5. DID resolvable via ledger
```

**Ethereum/Polygon (ERC-1056):**
```
1. DID registry smart contract
2. setAttribute(did, key, value)
3. Events emitted for changes
4. Off-chain indexing for resolution
```

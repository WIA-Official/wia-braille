## 🎯 Mission

```
분산된 복잡성          →    통일 원리           →    보편적 해결
─────────────────────────────────────────────────────────────────
수십 AD 치료법         →  "NAD+ 항상성 회복"   →    모든 환자 치료
(N개)                  →     (1개)              →      (∞)
```

**핵심 공식:**
```
NAD+ Homeostasis Index = f(NAD+ Level, NADH/NAD+ Ratio, Sirtuin Activity, PARP Activity)
Cognitive Function ∝ NAD+ Homeostasis Index
AD Severity ∝ 1 / NAD+ Homeostasis Index
```

## 📋 Phase 3: 프로토콜

### 3.1 측정 프로토콜

**NAD+ 대사 측정:**
- 혈장/CSF NAD+/NADH: HPLC-MS/MS, LC-MS
- 조직 NAD+ 수치: 효소 순환 분석법
- NADH/NAD+ 비율: 형광 센서 (Peredox, SoNar)
- NAD+ 합성/분해 효소: qPCR, Western blot, 효소 활성 분석

**인지 평가:**
- MMSE (Mini-Mental State Examination): 30점 만점
- MoCA (Montreal Cognitive Assessment): 30점 만점
- CDR-SB (Clinical Dementia Rating - Sum of Boxes): 0-18
- ADAS-Cog (Alzheimer's Disease Assessment Scale - Cognitive)

**바이오마커 측정:**
- 혈장 바이오마커: Simoa, Lumipulse, Elecsys 플랫폼
- CSF 바이오마커: 요추천자, Elecsys 분석
- 영상 바이오마커: Amyloid PET (Florbetapir), Tau PET (Flortaucipir), MRI

### 3.2 개입 프로토콜

**NAD+ 전구체 보충:**
- 니코틴아미드 리보사이드 (NR): 500-1000 mg/일
- 니코틴아미드 모노뉴클레오티드 (NMN): 250-500 mg/일
- 니아신 (니코틴산): 저용량부터 시작 (홍조 주의)
- P7C3-A20: 연구 단계 (NAD+ 항상성 직접 회복)

**병용 치료:**
- 항아밀로이드 항체 (경도 단계): Lecanemab 10 mg/kg 격주 IV
- Donanemab: 초기 3회 700 mg, 이후 1400 mg 4주마다
- NAD+ 전구체 + 항아밀로이드 병용 고려

**생활습관 개입:**
- 유산소 운동: 주 150분, NAD+ 수치 증가
- 지중해식 식단: 미토콘드리아 건강 지원
- 수면 최적화: 7-9시간, 글림파틱 청소
- 칼로리 제한/간헐적 단식: NAMPT 활성화

### 3.3 모니터링 프로토콜

**초기 평가 (0주):**
- 완전한 NAD+ 대사 프로파일
- 인지 기능 종합 평가
- 혈장 AD 바이오마커
- 뇌 MRI (부피 측정)

**조기 추적 (4-8주):**
- 혈장 NAD+ 수치
- 간단한 인지 검사 (MoCA)
- 부작용 모니터링

**중기 평가 (3-6개월):**
- NAD+ 항상성 재평가
- 전체 인지 배터리
- 혈장 바이오마커
- ARIA 모니터링 (항아밀로이드 치료 시)

**장기 추적 (12개월+):**
- 전체 평가 반복
- 뇌 MRI (위축 진행)
- 필요시 PET 스캔

### 4.2 WIA-ALZHEIMERS 인증

**Level 1: 기본 스크리닝**
- 혈장 NAD+ 측정
- MMSE/MoCA 인지 평가
- 혈장 Aβ42/40 비율

**Level 2: 종합 평가**
- NAD+ 항상성 지수 (전체)
- 혈장 p-tau (181, 217)
- 뇌 MRI 부피 측정
- 신경염증 마커

**Level 3: 정밀 진단**
- CSF 바이오마커
- Amyloid/Tau PET
- NAD+ 합성/분해 효소 프로파일
- 미토콘드리아 기능 평가

장 개요: 이 장에서는 복약 순응도 시스템과 약국 관리 시스템(PMS)의 통합, 전자처방전(e-Prescription) 표준, 자동 리필 프로세스 및 재고 관리 최적화를 다룹니다.

약국 생태계의 디지털 전환

약국은 의료 서비스의 마지막 관문으로서 환자와 직접 대면하는 중요한 역할을 합니다. 전자처방전과 자동화된 시스템의 도입으로 약국 업무 효율성이 크게 향상되고 있으며, 복약 순응도 관리에서도 핵심적인 위치를 차지하고 있습니다.

전자처방전 (e-Prescription) 표준

WIA-MED-012는 NCPDP SCRIPT 표준을 기반으로 한 전자처방전 메시지 포맷을 정의합니다.

전자처방전 워크플로우

e-Prescription 프로세스 흐름
┌──────────────┐
│   의사/병원   │
│     EMR      │
└──────┬───────┘
       │ ① 처방 입력
       ↓
┌──────────────┐
│ e-Prescription│
│   Hub/Network │  ← WIA-MED-012 표준 메시지
└──────┬───────┘
       │ ② 라우팅
       ↓
┌──────────────┐
│ 약국 PMS     │
│ (Pharmacy    │
│  Management) │
└──────┬───────┘
       │ ③ 자동 입력
       ↓
┌──────────────┐
│ 약사 검토     │
│ 및 조제       │
└──────┬───────┘
       │ ④ 조제 완료 알림
       ↓
┌──────────────┐
│ 환자 모바일앱 │
│ (WIA-MED-012)│
└──────────────┘

자동 리필 시스템

환자가 약이 떨어지기 전에 자동으로 재처방을 받고 조제하는 시스템입니다.

자동 리필 로직

단계 시점 액션
1. 재고 모니터링 매일 스마트 알약병에서 남은 약 개수 추적
2. 리필 필요 감지 7일 전 환자에게 리필 필요 알림
3. 환자 동의 알림 후 앱에서 원터치로 승인
4. 의사 승인 요청 즉시 EMR 시스템으로 리필 요청 전송
5. 약국 전송 승인 후 e-Prescription으로 약국에 전송
6. 조제 및 알림 조제 완료 픽업 준비 완료 알림
7. 배송 (옵션) 요청 시 자택 배송 또는 드라이브스루 준비
자동 리필 알고리즘 (Python)
from datetime import datetime, timedelta

class AutoRefillManager:
    def __init__(self, patient_id):
        self.patient_id = patient_id

    def check_refill_needed(self, prescription):
        """리필 필요 여부 확인"""
        remaining_days = self.calculate_remaining_days(prescription)

        # 7일 이하 남았을 때 리필 트리거
        if remaining_days <= 7:
            return True, remaining_days
        return False, remaining_days

    def calculate_remaining_days(self, prescription):
        """남은 약 복용 일수 계산"""
        # 스마트 알약병 데이터 기반
        remaining_pills = prescription.bottle.get_pill_count()
        daily_dose = prescription.dosage.times_per_day * prescription.dosage.pills_per_dose

        remaining_days = remaining_pills / daily_dose
        return int(remaining_days)

    async def initiate_refill(self, prescription):
        """자동 리필 프로세스 시작"""
        # 1. 환자 동의 확인
        consent = await self.request_patient_consent(prescription)
        if not consent:
            return {"status": "patient_declined"}

        # 2. 리필 가능 횟수 확인
        if prescription.refills_remaining <= 0:
            return await self.request_new_prescription(prescription)

        # 3. 약국에 리필 요청
        pharmacy_response = await self.submit_refill_to_pharmacy({
            "prescription_id": prescription.rx_number,
            "patient_id": self.patient_id,
            "pharmacy_ncpdp": prescription.pharmacy.ncpdp,
            "requested_pickup_date": (
                datetime.now() + timedelta(days=3)
            ).isoformat()
        })

        # 4. 환자에게 알림
        await self.notify_patient({
            "type": "refill_submitted",
            "message": f"{prescription.medication.name} 리필이 요청되었습니다.",
            "pharmacy": prescription.pharmacy.name,
            "estimated_ready": pharmacy_response["estimated_ready"]
        })

        return {"status": "success", "refill_id": pharmacy_response["refill_id"]}

    async def request_new_prescription(self, old_prescription):
        """리필 횟수 소진 시 새 처방 요청"""
        return await self.send_to_prescriber({
            "type": "refill_authorization_request",
            "patient_id": self.patient_id,
            "medication": old_prescription.medication.ndc,
            "last_prescription_date": old_prescription.written_date,
            "reason": "refills_exhausted"
        })

재고 관리 및 최적화

약국의 재고를 효율적으로 관리하여 품절을 방지하고 과재고를 줄입니다.

  • 수요 예측: AI 기반 처방 패턴 분석으로 미래 수요 예측
  • 자동 발주: 재고가 안전 재고 수준 이하로 떨어지면 자동 주문
  • 유통기한 관리: FEFO(First Expire First Out) 원칙 적용
  • 약국 간 재고 공유: 체인 약국 간 재고 이동으로 가용성 향상

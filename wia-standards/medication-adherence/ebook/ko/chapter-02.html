스마트 알약병의 진화

스마트 알약병(Smart Pill Bottle)은 전통적인 약통에 센서와 무선 통신 기능을 추가하여 환자의 복약 행동을 자동으로 추적하고 기록하는 IoT 기기입니다. 2010년대 초반 등장한 이 기술은 현재 복약 순응도 솔루션의 핵심 요소로 자리잡았습니다.

핵심 센서 기술

1. 용량 감지 센서 (Capacitive Sensing)

알약병의 뚜껑이 열리고 닫히는 것을 감지하는 가장 기본적인 센서입니다. 정전용량의 변화를 측정하여 뚜껑의 개폐 상태를 판단합니다.

용량 센서 데이터 구조 (JSON)
{
  "event_type": "cap_open",
  "timestamp": "2025-12-26T08:30:15.234Z",
  "bottle_id": "WIA-MED-012-ABC123",
  "capacitance_value": 125.7,
  "threshold": 100.0,
  "confidence": 0.98,
  "duration_ms": 3450
}

2. 중량 센서 (Load Cell)

알약병 내부의 약물 무게를 측정하여 실제로 약이 꺼내졌는지 확인합니다. 단순히 뚜껑을 열었다고 복약한 것이 아니라, 실제 약물 감소를 확인해야 정확한 순응도 측정이 가능합니다.

센서 사양 일반 알약 고정밀 요구
측정 범위 0 - 500g 0 - 200g
정확도 ±0.5g ±0.1g
해상도 0.1g 0.01g
응답 시간 < 200ms < 100ms
온도 보정 -10°C ~ 50°C 0°C ~ 40°C

3. 광학 센서 (Optical Sensor)

적외선 또는 RGB 센서를 사용하여 알약의 색상, 크기, 형태를 인식합니다. 이를 통해 올바른 약물이 복용되었는지 검증할 수 있습니다.

광학 센서 약물 인식 알고리즘

4. 가속도계 및 자이로스코프

병의 움직임, 기울임, 흔들림을 감지하여 사용 패턴을 분석합니다. 예를 들어, 병을 기울여 약을 쏟아내는 동작을 인식할 수 있습니다.

  • 3축 가속도계: X, Y, Z 축의 가속도 측정
  • 3축 자이로스코프: 각속도 측정으로 회전 감지
  • 동작 인식: 특정 패턴의 움직임을 복약 행동으로 분류
  • 낙하 감지: 충격 감지로 낙하 사고 기록

5. 온습도 센서

약물의 보관 환경을 모니터링하여 적절한 조건에서 보관되고 있는지 확인합니다.

Wi-Fi 6 연결

고급 모델은 Wi-Fi를 지원하여 스마트폰 없이도 직접 클라우드와 통신할 수 있습니다.

  • 802.11ax 표준: 높은 처리량과 낮은 지연시간
  • MQTT 프로토콜: 경량 메시지 전송
  • TLS 1.3 암호화: 안전한 데이터 전송
  • OTA 업데이트: 무선 펌웨어 업그레이드

NFC (Near Field Communication)

전원 관리 및 배터리 최적화

IoT 기기에서 배터리 수명은 사용자 경험의 핵심 요소입니다. WIA-MED-012는 다단계 절전 모드를 정의합니다:

절전 모드 소비 전력 활성 기능 깨우기 조건
Active 80 mA 모든 센서, BLE 연결 -
Idle 15 mA 타이머, 용량 센서 뚜껑 개폐, BLE 연결
Light Sleep 2 mA RTC, 인터럽트 예약된 알림 시간
Deep Sleep 100 µA RTC만 24시간 주기
Hibernation 10 µA 없음 (저장된 상태) 물리적 버튼
배터리 수명 계산
// 2000mAh 리튬 배터리 기준

일일 전력 소비:
  - Active (뚜껑 개폐 3회, 각 30초): 80mA × 90s = 2mAh
  - Idle (대기 1시간): 15mA × 1h = 15mAh
  - Light Sleep (22시간): 2mA × 22h = 44mAh
  - Deep Sleep (1시간): 0.1mA × 1h = 0.1mAh

총 일일 소비: 61.1 mAh

예상 배터리 수명:
2000mAh / 61.1mAh = 32.7일

// 안전 계수 0.8 적용
실제 수명: ~26일 (약 1개월)

데이터 수집 및 로컬 저장

네트워크 연결이 일시적으로 끊어져도 데이터 손실을 방지하기 위해 로컬 저장소를 활용합니다:

EEPROM 데이터 구조
// 256KB EEPROM 메모리 맵

0x0000 - 0x0FFF: 디바이스 설정
  - Bottle ID
  - Patient ID
  - Medication 정보
  - 알림 스케줄

0x1000 - 0x7FFF: 이벤트 로그 (최대 2800개 이벤트)
  - 타임스탬프 (4 bytes)
  - 이벤트 타입 (1 byte)
  - 센서 데이터 (10 bytes)
  - CRC 체크섬 (1 byte)

0x8000 - 0xFFFF: 환경 데이터 로그
  - 온도/습도 기록 (시간당)
  - 배터리 레벨 추이

순환 버퍼 방식:
최대 용량 도달 시 가장 오래된 데이터부터 덮어쓰기
단, 동기화되지 않은 데이터는 보존

실제 구현 예제: ESP32 기반 스마트 알약병

Arduino C++ 펌웨어 (main.cpp)
#include <Arduino.h>
#include <BLEDevice.h>
#include <HX711.h>
#include <DHT.h>

// 센서 핀 정의
#define CAP_SENSOR_PIN 4
#define WEIGHT_DOUT_PIN 5
#define WEIGHT_SCK_PIN 18
#define DHT_PIN 19
#define LED_PIN 2

// BLE UUIDs
#define SERVICE_UUID        "00001812-0000-1000-8000-00805f9b34fb"
#define CHARACTERISTIC_UUID "00002a53-0000-1000-8000-00805f9b34fb"

HX711 scale;
DHT dht(DHT_PIN, DHT22);
BLECharacteristic *pCharacteristic;

// 전역 변수
float previousWeight = 0;
bool isCapOpen = false;
unsigned long lastEventTime = 0;

void setup() {
  Serial.begin(115200);

  // 센서 초기화
  pinMode(CAP_SENSOR_PIN, INPUT);
  scale.begin(WEIGHT_DOUT_PIN, WEIGHT_SCK_PIN);
  scale.set_scale(2280.f);  // 캘리브레이션 값
  scale.tare();
  dht.begin();

  // BLE 초기화
  BLEDevice::init("WIA-MED-012-Bottle");
  BLEServer *pServer = BLEDevice::createServer();
  BLEService *pService = pServer->createService(SERVICE_UUID);

  pCharacteristic = pService->createCharacteristic(
    CHARACTERISTIC_UUID,
    BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_NOTIFY
  );

  pService->start();
  BLEDevice::startAdvertising();

  Serial.println("스마트 알약병 준비 완료");
}

void loop() {
  // 용량 센서로 뚜껑 개폐 감지
  int capValue = digitalRead(CAP_SENSOR_PIN);

  if (capValue == HIGH && !isCapOpen) {
    isCapOpen = true;
    handleCapOpen();
  } else if (capValue == LOW && isCapOpen) {
    isCapOpen = false;
    handleCapClose();
  }

  // 온습도 주기적 체크 (10분마다)
  if (millis() - lastEventTime > 600000) {
    checkEnvironment();
    lastEventTime = millis();
  }

  delay(100);
}

void handleCapOpen() {
  Serial.println("뚜껑 열림 감지");
  previousWeight = scale.get_units(10);
  digitalWrite(LED_PIN, HIGH);
}

void handleCapClose() {
  Serial.println("뚜껑 닫힘 감지");
  float currentWeight = scale.get_units(10);
  float weightDiff = previousWeight - currentWeight;

  // 0.5g 이상 차이나면 복약으로 판단
  if (weightDiff > 0.5) {
    int pillsTaken = round(weightDiff / 0.3);  // 알약 1개당 0.3g 가정
    sendMedicationEvent(pillsTaken);
  }

  digitalWrite(LED_PIN, LOW);
}

void sendMedicationEvent(int pillCount) {
  String jsonData = "{";
  jsonData += "\"timestamp\":" + String(millis()) + ",";
  jsonData += "\"event\":\"dose_taken\",";
  jsonData += "\"pill_count\":" + String(pillCount);
  jsonData += "}";

  pCharacteristic->setValue(jsonData.c_str());
  pCharacteristic->notify();

  Serial.println("복약 이벤트 전송: " + jsonData);
}

void checkEnvironment() {
  float temp = dht.readTemperature();
  float humid = dht.readHumidity();

  // 적정 범위 체크 (15-25°C, 30-60%)
  if (temp > 25 || humid > 60) {
    Serial.println("경고: 부적절한 보관 환경");
    // 알림 전송 로직
  }
}

제3장: 데이터 형식

"표준화된 형식은 상호운용성의 시작입니다."

3.1 비디오 컨테이너 형식

컨테이너는 비디오, 오디오, 자막, 메타데이터를 하나의 파일로 묶는 래퍼입니다.

3.1.1 주요 컨테이너 형식

형식 확장자 스트리밍 권장 용도
MPEG-TS .ts HLS 라이브 스트리밍
fMP4 .m4s, .mp4 DASH, HLS VOD, 범용
MP4 .mp4 제한적 다운로드, 호환성
WebM .webm DASH 웹 브라우저

3.1.2 WIA 권장 형식

📺 라이브 스트리밍:
   컨테이너: MPEG-TS (.ts)
   세그먼트: 2-6초
   프로토콜: HLS, LL-HLS

🎬 VOD (주문형):
   컨테이너: fMP4 (.m4s)
   세그먼트: 4-10초
   프로토콜: DASH, HLS

🎥 다운로드:
   컨테이너: MP4 (.mp4)
   최적화: FastStart (moov atom 앞쪽 배치)

3.2 비디오 코덱

3.2.1 H.264 (AVC) 설정

가장 보편적으로 지원되는 비디오 코덱입니다.

매개변수 권장값 설명
Profile High 최고 압축 효율
Level 4.0-4.2 1080p @ 30fps
GOP Size 2-4초 (60-120 frames) 키프레임 간격
B-frames 2-3 양방향 예측 프레임
Rate Control CBR or VBR 일정 or 가변 비트레이트

FFmpeg 인코딩 예시:

# 1080p @ 5 Mbps
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -profile:v high \
  -level 4.2 \
  -b:v 5M \
  -maxrate 5.5M \
  -bufsize 10M \
  -g 60 \
  -keyint_min 60 \
  -sc_threshold 0 \
  -bf 2 \
  -pix_fmt yuv420p \
  -movflags +faststart \
  output_1080p.mp4

3.2.2 H.265 (HEVC) 설정

H.264 대비 50% 대역폭 절감이 가능합니다.

# 4K @ 15 Mbps (H.264라면 30 Mbps 필요)
ffmpeg -i input.mp4 \
  -c:v libx265 \
  -preset medium \
  -crf 23 \
  -b:v 15M \
  -maxrate 16.5M \
  -bufsize 30M \
  -pix_fmt yuv420p \
  output_4k.mp4

3.3 오디오 코덱

3.3.1 오디오 형식 비교

코덱 비트레이트 채널 용도
AAC-LC 128-192 kbps 스테레오 일반 강의
AAC-HE 64-96 kbps 스테레오 저대역폭
Opus 96-128 kbps 스테레오 WebRTC, 최고 품질
MP3 128-320 kbps 스테레오 호환성 (구형 기기)

3.3.2 WIA 오디오 표준

필수 사양:

코덱:      AAC-LC
샘플레이트: 48 kHz
비트레이트: 128 kbps (최소), 192 kbps (권장)
채널:      스테레오 (2.0)

선택 사양 (고급):

음악 강의:  AAC-LC @ 256 kbps
저대역폭:   AAC-HE @ 64 kbps
실시간:     Opus @ 96-128 kbps

3.4.2 WebVTT 예시

WEBVTT

NOTE
WIA 교육 스트리밍 표준 - 한국어 자막

00:00:00.000 --> 00:00:05.000
안녕하세요. WIA 스트리밍 표준 강의에 오신 것을 환영합니다.

오늘은 적응형 비트레이트 스트리밍에 대해 배워보겠습니다.

00:00:10.500 --> 00:00:15.000 line:10%
강사: ABR은 네트워크 상태에 따라...

3.4.3 접근성 요구사항

WIA 표준은 다음 접근성 기능을 필수로 요구합니다:

  • 자막 (Captions) — 청각 장애인을 위한 대사 및 소리 설명
  • 오디오 설명 (Audio Description) — 시각 장애인을 위한 장면 설명
  • 수어 통역 — 별도 비디오 트랙 또는 PIP (Picture-in-Picture)
  • 다국어 지원 — 최소 2개 언어 (원본 + 영어/한국어)

3.5 메타데이터 표준

3.5.1 교육 콘텐츠 메타데이터

WIA는 JSON-LD 기반 메타데이터 스키마를 정의합니다.

{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "WIA 스트리밍 표준 - 제1강",
  "description": "적응형 비트레이트 스트리밍 소개",
  "duration": "PT45M30S",
  "uploadDate": "2025-01-15",
  "contentUrl": "https://cdn.example.com/video.m3u8",
  "thumbnailUrl": "https://cdn.example.com/thumb.jpg",
  "educationalLevel": "대학교",
  "learningResourceType": "강의",
  "inLanguage": "ko-KR",
  "creator": {
    "@type": "Person",
    "name": "홍길동 교수"
  },
  "publisher": {
    "@type": "Organization",
    "name": "WIA 교육원"
  }
}

3.5.2 비디오 품질 메타데이터

필드 타입 설명
resolution string "1920x1080", "1280x720"
bitrate integer 5000000 (5 Mbps)
framerate float 30.0, 60.0
codec string "h264", "h265", "vp9"
audioCodec string "aac", "opus"

3.6 비트레이트 레더 (Bitrate Ladder)

3.6.1 WIA 표준 비트레이트 레더

모든 교육 콘텐츠는 다음 비트레이트 레더를 따라야 합니다:

해상도 비디오 (H.264) 오디오 (AAC) 총 비트레이트
240p (426×240) 250 kbps 64 kbps 314 kbps
360p (640×360) 500 kbps 96 kbps 596 kbps
480p (854×480) 1000 kbps 128 kbps 1.13 Mbps
720p (1280×720) 2500 kbps 128 kbps 2.63 Mbps
1080p (1920×1080) 5000 kbps 192 kbps 5.19 Mbps

3.6.2 저대역폭 최적화

개발도상국 및 농촌 지역 학생을 위한 특별 레더:

🌍 저대역폭 레더 (< 1 Mbps 네트워크):

144p (256×144) @ 150 kbps
   - 슬라이드 기반 강의 최적화
   - 텍스트 가독성 우선
   - 오디오: 64 kbps AAC-HE

240p (426×240) @ 250 kbps
   - 일반 강의
   - 화면 공유 가능

💡 팁:
   - 정적 콘텐츠 (PPT) → 낮은 비트레이트 효과적
   - 동적 콘텐츠 (실험) → 높은 비트레이트 필요

3.7 썸네일 및 미리보기

3.7.1 썸네일 스펙

용도 크기 형식
리스트 뷰 320×180 (16:9) JPEG, WebP
플레이어 1280×720 JPEG, WebP
소셜 미디어 1200×630 (Open Graph) JPEG

3.7.2 Trick Play 미리보기

마우스 호버 시 미리보기를 위한 저품질 비디오 트랙:

  • 해상도: 160×90 (매우 작음)
  • 프레임: 1fps (초당 1 프레임)
  • 비트레이트: 50 kbps
  • 형식: WebP 애니메이션 또는 I-frame 비디오

제4장: API 명세

"좋은 API는 개발자가 바로 이해하고 사용할 수 있습니다."

4.1 WIA 스트리밍 API 개요

WIA 스트리밍 API는 RESTful 원칙을 따르며, 교육 콘텐츠 관리를 위한 표준 인터페이스를 제공합니다.

4.1.1 API 계층 구조

WIA Streaming API 구조:

📡 REST API       — 콘텐츠 관리 (CRUD)
🔌 WebSocket API  — 실시간 이벤트
📦 SDK            — JavaScript, Python, Go
🎮 Player API     — 플레이어 제어

4.1.2 베이스 URL

Production:  https://api.wiastreaming.com/v1
Sandbox:     https://sandbox.wiastreaming.com/v1

4.2 인증 (Authentication)

4.2.1 API 키 인증

모든 요청은 API 키를 헤더에 포함해야 합니다.

GET /videos
Authorization: Bearer wia_sk_live_abc123...
Content-Type: application/json

4.2.2 OAuth 2.0 (선택)

사용자 대신 API 호출 시 OAuth 2.0 사용:

흐름 용도
Authorization Code 웹 애플리케이션
Client Credentials 서버 간 통신

4.6 WebSocket API (실시간 이벤트)

4.6.1 연결

// JavaScript 예시
const ws = new WebSocket('wss://ws.wiastreaming.com/v1');

ws.onopen = () => {
  ws.send(JSON.stringify({
    type: 'auth',
    token: 'wia_sk_live_...'
  }));

  ws.send(JSON.stringify({
    type: 'subscribe',
    channel: 'stream:stream_xyz789'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Event:', data);
};

4.6.2 이벤트 타입

이벤트 설명
stream.started 라이브 스트림 시작됨
stream.stopped 라이브 스트림 종료됨
video.ready 비디오 처리 완료
viewer.joined 새 시청자 입장
viewer.left 시청자 퇴장

4.7 SDK

4.7.1 JavaScript/TypeScript SDK

// 설치
npm install @wia/streaming-sdk

// 사용
import { WIAStreaming } from '@wia/streaming-sdk';

const client = new WIAStreaming({
  apiKey: 'wia_sk_live_...'
});

// 비디오 업로드
const video = await client.videos.upload({
  title: '강의 제목',
  file: videoFile
});

// 라이브 스트림 생성
const stream = await client.streams.create({
  title: '실시간 강의',
  settings: {
    latencyMode: 'low',
    dvrEnabled: true
  }
});

console.log('RTMP URL:', stream.ingest.rtmpUrl);
console.log('Stream Key:', stream.ingest.streamKey);

4.7.2 Python SDK

# 설치
pip install wia-streaming

# 사용
from wia_streaming import WIAStreaming

client = WIAStreaming(api_key='wia_sk_live_...')

# 비디오 업로드
video = client.videos.upload(
    title='강의 제목',
    file_path='/path/to/video.mp4'
)

# 통계 조회
stats = client.analytics.get_video_stats(video.id)
print(f'총 조회수: {stats.total_views}')

4.8 플레이어 API

4.8.1 플레이어 임베드

<!-- HTML -->
<div id="wia-player"></div>
<script src="https://player.wiastreaming.com/v1/player.js"></script>

// JavaScript
const player = new WIAPlayer('wia-player', {
  videoId: 'vid_abc123',
  autoplay: false,
  controls: true,
  subtitles: 'ko-KR',
  quality: 'auto'
});

// 이벤트 리스닝
player.on('play', () => console.log('재생 시작'));
player.on('pause', () => console.log('일시정지'));
player.on('ended', () => console.log('재생 완료'));

// 프로그래밍 방식 제어
player.play();
player.pause();
player.seek(120); // 2분으로 이동
player.setQuality('720p');

4.8.2 플레이어 이벤트

이벤트 트리거 시점
ready 플레이어 초기화 완료
play 재생 시작
pause 일시정지
timeupdate 재생 위치 변경 (250ms마다)
qualitychange 화질 변경
buffering 버퍼링 발생
error 오류 발생

4.9 에러 처리

4.9.1 HTTP 상태 코드

코드 의미 설명
200 OK 요청 성공
201 Created 리소스 생성 성공
400 Bad Request 잘못된 요청
401 Unauthorized 인증 실패
404 Not Found 리소스 없음
429 Too Many Requests 요청 한도 초과
500 Internal Server Error 서버 오류

제7장: HL7/FHIR 표준 및 상호 운용성

"상호 운용성 없이는 진정한 디지털 의료가 불가능합니다. HL7과 FHIR는 병원 간 데이터 교환의 공용어입니다."

7.1 HL7 표준 개요

Health Level 7은 의료 정보 교환을 위한 국제 표준입니다.

📚 HL7 버전

  • HL7 v2.x — 가장 널리 사용 (파이프 구분 텍스트)
  • HL7 v3 — XML 기반, 복잡도 높음
  • HL7 CDA — Clinical Document Architecture
  • HL7 FHIR — Fast Healthcare Interoperability Resources (RESTful API)

7.2 FHIR 리소스

FHIR는 80+ 표준 리소스를 정의합니다:

  • Patient — 환자 정보
  • Practitioner — 의료진
  • Observation — 검사 결과, 바이탈
  • MedicationRequest — 처방
  • Encounter — 진료 이력

7.3 API 통합

RESTful API로 HIS 데이터 접근:

GET /fhir/Patient?name=김민지
GET /fhir/Observation?patient=P123456&category=laboratory
POST /fhir/MedicationRequest
PUT /fhir/Patient/P123456
DELETE /fhir/Appointment/APT123

제7장의 전체 내용은 공식 전자책에서 확인하실 수 있습니다.

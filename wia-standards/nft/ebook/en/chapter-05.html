CHAPTER 5

Marketplaces & Trading

NFT marketplaces are the lifeblood of the ecosystem, connecting creators with collectors and enabling price discovery through transparent trading. Understanding marketplace mechanics, integration patterns, and trading protocols is essential for anyone building in the NFT space.

Major NFT Marketplaces

OpenSea

As the largest NFT marketplace by volume, OpenSea supports ERC-721, ERC-1155, and cross-chain trading. It offers zero-cost listing using off-chain signatures (gasless listings), collection management tools, and the Seaport protocol for advanced trading scenarios. OpenSea takes a 2.5% fee on sales.

Rarible

Community-owned marketplace with governance token (RARI), supporting multi-chain NFTs and creator-centric features. Rarible pioneered the concept of marketplace rewards, distributing tokens to active users.

LooksRare

Launched as a community-first alternative to OpenSea, offering trading rewards in LOOKS tokens, 2% marketplace fee with staking rewards, and aggressive incentive programs for high-volume traders.

Blur

Professional trader-focused platform with zero marketplace fees, advanced portfolio management, sweep tools for batch buying, and optimized for speed and efficiency. Popular among NFT traders and collectors.

// NFT contract compatible with OpenSea
contract OpenSeaCompatibleNFT is ERC721 {
    // Proxy registry for gasless listings
    address public proxyRegistryAddress;

    constructor(address _proxyRegistry) {
        proxyRegistryAddress = _proxyRegistry;
    }

    // Override isApprovedForAll to whitelist OpenSea proxy
    function isApprovedForAll(address owner, address operator)
        public view override returns (bool)
    {
        // Whitelist OpenSea proxy contract for easy trading
        ProxyRegistry proxyRegistry = ProxyRegistry(proxyRegistryAddress);
        if (address(proxyRegistry.proxies(owner)) == operator) {
            return true;
        }
        return super.isApprovedForAll(owner, operator);
    }

    // OpenSea metadata
    function contractURI() public pure returns (string memory) {
        return "ipfs://QmCollectionMetadata...";
    }
}

Trading Mechanisms

Fixed Price Sales

The simplest trading mechanism where sellers list NFTs at a specific price. Buyers can purchase immediately at the listed price. This is implemented through marketplace approval systems where the seller approves the marketplace contract to transfer their NFT upon payment receipt.

Auctions

English Auctions: Traditional ascending price auctions where bidders compete by placing increasingly higher bids. The auction runs for a fixed duration, and the highest bidder wins.

Dutch Auctions: Price starts high and decreases over time until someone purchases. Popular for fair launches as it finds market price automatically.

Reserve Price Auctions: Seller sets a minimum acceptable price. If bidding doesn't reach the reserve, the NFT doesn't sell.

Offers and Counteroffers

Buyers can make offers below the listing price, which sellers can accept, reject, or counter. This enables price negotiation and discovery, particularly useful for illiquid or unique items.

Seaport Protocol

Seaport is OpenSea's advanced marketplace protocol enabling complex trading scenarios: partial fills, bundled listings, criteria-based offers, consideration items, and time-based restrictions.

Fees and Economics

Marketplace Fees

  • OpenSea: 2.5% of sale price
  • Rarible: 2.5% of sale price
  • LooksRare: 2% of sale price
  • Blur: 0% marketplace fee (as of 2024)

Creator Royalties

Typically 5-10% of secondary sales, paid automatically through ERC-2981 or marketplace-specific systems. However, royalty enforcement has become contentious, with some marketplaces making royalties optional.

Gas Costs

  • Minting: 50,000-200,000 gas depending on complexity
  • Transfers: ~65,000 gas for ERC-721
  • Listings: Often gasless using off-chain signatures
  • Sales: ~80,000-150,000 gas for transaction settlement

💡 Gasless Listings

Modern marketplaces use off-chain order books with cryptographic signatures. When you list an NFT, you sign a message authorizing the sale without submitting a blockchain transaction. Gas is only paid when the sale actually executes, paid by the buyer. This dramatically reduces friction for sellers.

Aggregators and Tools

Marketplace Aggregators

Gem (acquired by OpenSea): Aggregates listings across multiple marketplaces, enabling users to find the best prices and sweep collections efficiently.

Blur: Functions as both marketplace and aggregator, showing listings from multiple platforms with optimized interface for professional traders.

Analytics Platforms

  • NFTGo: Comprehensive analytics including floor prices, trading volumes, holder distributions, and rarity rankings
  • Nansen: On-chain analytics tracking whale wallets, smart money movements, and emerging trends
  • DappRadar: Cross-chain NFT marketplace rankings and statistics

Building Custom Marketplaces

Basic Marketplace Contract

contract SimpleMarketplace {
    struct Listing {
        address seller;
        address nftContract;
        uint256 tokenId;
        uint256 price;
        bool active;
    }

    mapping(bytes32 => Listing) public listings;
    uint256 public feePercent = 250; // 2.5%

    event Listed(bytes32 listingId, address seller, uint256 price);
    event Sold(bytes32 listingId, address buyer, uint256 price);

    function list(
        address nftContract,
        uint256 tokenId,
        uint256 price
    ) external {
        bytes32 listingId = keccak256(
            abi.encodePacked(nftContract, tokenId, msg.sender)
        );

        IERC721(nftContract).transferFrom(msg.sender, address(this), tokenId);

        listings[listingId] = Listing({
            seller: msg.sender,
            nftContract: nftContract,
            tokenId: tokenId,
            price: price,
            active: true
        });

        emit Listed(listingId, msg.sender, price);
    }

    function buy(bytes32 listingId) external payable {
        Listing storage listing = listings[listingId];
        require(listing.active, "Not active");
        require(msg.value >= listing.price, "Insufficient payment");

        listing.active = false;

        uint256 fee = (listing.price * feePercent) / 10000;
        uint256 sellerAmount = listing.price - fee;

        IERC721(listing.nftContract).transferFrom(
            address(this),
            msg.sender,
            listing.tokenId
        );

        payable(listing.seller).transfer(sellerAmount);

        emit Sold(listingId, msg.sender, listing.price);
    }
}

Conclusion

NFT marketplaces continue evolving with new trading mechanisms, fee structures, and user experiences. Understanding marketplace integration and trading protocols is crucial whether you're launching a collection, building a project, or creating custom marketplace solutions. The trend toward aggregation and zero-fee models is reshaping the competitive landscape, while debates around royalty enforcement will define creator economics for years to come.

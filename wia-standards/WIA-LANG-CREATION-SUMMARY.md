## 💻 Developer Tools

### TypeScript SDK
```typescript
import { WIALangClient } from '@wia/lang-standard';

const client = new WIALangClient({
  apiKey: 'your-api-key'
});

const result = await client.languages.analyze({
  text: 'Sample text',
  language: 'ainu'
});
```

### CLI Tools
```bash
# Analyze language data
./cli/wia-lang-001.sh analyze recording.flac --language ain

# Search archive
./cli/wia-lang-001.sh search "language:ainu type:folktale"

# List supported languages
./cli/wia-lang-001.sh list --format json
```

### Installation
```bash
# Navigate to standard directory
cd WIA-LANG-001-endangered-language/

# Run installation script
./install.sh

# Start using
npm start
```

제4장: API 명세

"잘 설계된 API는 개발자와 학습자 모두에게 투명한 다리입니다."

4.1 API 개요

WIA-EDU-022는 RESTful API와 GraphQL을 모두 지원합니다.

🌐 Base URL

Production:  https://api.wialanguage.com/v1
Staging:     https://api-staging.wialanguage.com/v1
Development: http://localhost:3000/v1

🔐 인증

모든 API 요청은 Bearer 토큰으로 인증됩니다:

4.2 학습자 관리 API

👤 프로필 조회

GET /learners/{learner_id}

Response 200 OK:
{
  "id": "learner-123",
  "display_name": "김학습",
  "native_language": "ko",

      "language": "en",

  "message": "Profile updated successfully"
}

4.6 음성 처리 API

  "audio": [binary data],
  "reference_text": "She sells seashells by the seashore",
  "language": "en"
}

{
  "assessment_id": "pron-abc",
  "overall_score": 74,
  "scores": {
    "accuracy": 78,
    "fluency": 72,
    "completeness": 100,
    "prosody": 65

4.9 오류 처리

표준화된 오류 응답 형식:

코드 의미 예시
400 Bad Request Invalid input data
401 Unauthorized Missing/invalid token
403 Forbidden Insufficient permissions
404 Not Found Resource doesn't exist
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server-side issue 
Error Response Format:
{
  "error": {
    "code": "INVALID_INPUT",
    "message": "The 'language' field is required",
    "details": {
      "field": "language",
      "constraint": "required"
    },
    "request_id": "req-abc123",
    "timestamp": "2025-12-26T14:50:00Z"
  }
}

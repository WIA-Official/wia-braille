Chapter 7

ETL Processes and Data Pipelines

7.1 What is ETL?

ETL (Extract, Transform, Load) is the process of moving data from source systems into a data warehouse. It's the lifeblood of any data warehouse, ensuring data is clean, consistent, and ready for analysis.

7.2 Extract Phase

Extraction pulls data from source systems with minimal impact on operational performance.

Extraction Strategies

  • Full extraction: Pull all data every time
  • Incremental extraction: Pull only changes since last load
  • Change data capture (CDC): Track changes in real-time
  • Log-based extraction: Read database transaction logs

7.3 Transform Phase

Transformation cleans, standardizes, and enriches data to make it analysis-ready.

Common Transformations

Type Purpose Example
Cleansing Fix errors and inconsistencies Trim whitespace, fix typos
Standardization Ensure consistent formats Date format: YYYY-MM-DD
Deduplication Remove duplicates Merge customer records
Aggregation Summarize data Daily sales totals
Enrichment Add calculated fields Profit = Revenue - Cost

7.4 Load Phase

Loading writes transformed data into the target data warehouse.

Load Strategies

  • Full load: Replace all data
  • Incremental load: Add new and changed records
  • Delta load: Load only differences
  • Merge/Upsert: Insert new, update existing

7.5 ETL vs ELT

Modern cloud data warehouses enable ELT (Extract, Load, Transform), where raw data is loaded first and transformed within the warehouse using its processing power.

Aspect ETL ELT
Transformation Before loading After loading
Tools Informatica, Talend dbt, SQL
Best for Traditional warehouses Cloud warehouses

7.6 ETL Tools and Technologies

  • Commercial: Informatica PowerCenter, IBM DataStage, Microsoft SSIS
  • Open Source: Apache Airflow, Talend, Pentaho
  • Cloud-Native: AWS Glue, Azure Data Factory, Google Dataflow
  • Modern: dbt (data build tool), Fivetran, Airbyte

7.7 Data Quality and Validation

💡 Quality Checks

  • Row count validation between source and target
  • Data type consistency checks
  • Null value handling and constraints
  • Business rule validation
  • Referential integrity verification

7.8 Error Handling and Recovery

Robust ETL pipelines include comprehensive error handling, logging, and the ability to restart failed jobs from checkpoints.

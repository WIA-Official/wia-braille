2.1 Fundamental Wind Energy Principles

Understanding wind energy requires a solid grasp of fundamental physics and engineering concepts. Wind energy conversion is governed by the kinetic energy equation and Betz's law, which establishes theoretical limits for wind turbine efficiency. The power available in wind is proportional to the cube of wind speed, making accurate wind resource assessment critical for project viability.

// Wind Power Calculation function calculateWindPower(windSpeed, airDensity, rotorArea) { // Power = 0.5 × ρ × A × v³ // where: // ρ = air density (kg/m³) // A = rotor swept area (m²) // v = wind speed (m/s) const power = 0.5 * airDensity * rotorArea * Math.pow(windSpeed, 3); return power; // Watts } // Example calculation const turbineData = { rotorDiameter: 42, // meters rotorArea: Math.PI * Math.pow(21, 2), // m² airDensity: 1.225, // kg/m³ at sea level, 15°C windSpeed: 12 // m/s }; const availablePower = calculateWindPower( turbineData.windSpeed, turbineData.airDensity, turbineData.rotorArea ); console.log(`Available power: ${(availablePower / 1000).toFixed(2)} kW`); // Output: Available power: 633.68 kW // Applying Betz limit (59.3% maximum efficiency) const maxExtractablePower = availablePower * 0.593; console.log(`Max extractable: ${(maxExtractablePower / 1000).toFixed(2)} kW`); // Output: Max extractable: 375.77 kW

2.2 Essential Terminology

WIA-ENE-006 employs specific terminology that stakeholders must understand for effective implementation. This section defines key terms used throughout the standard.

2.2.1 Turbine Components and Systems

Rotor: The rotating assembly consisting of the hub and blades that captures wind energy and converts it to rotational mechanical energy.
Nacelle: The housing mounted on top of the tower containing the drivetrain, generator, control systems, and other critical components.
Drivetrain: The mechanical system that transmits rotational energy from the rotor to the generator, typically including a gearbox (in geared turbines) or direct-drive connection.
Yaw System: The mechanism that rotates the nacelle and rotor to face the wind direction, optimizing energy capture and managing loads.
Pitch System: The mechanism that adjusts the angle of the blades relative to the wind, controlling rotational speed and power output.

2.3.2 Wind Shear and Vertical Profile

Wind speed varies with height above ground due to surface friction. The wind shear exponent (α) characterizes this relationship and is crucial for estimating wind speeds at hub height from measurements at other elevations.

// Wind Shear Power Law function windSpeedAtHeight(knownSpeed, knownHeight, targetHeight, shearExponent = 0.14) { // V₂ = V₁ × (H₂ / H₁)^α // where: // V₁ = wind speed at known height // H₁ = known height // V₂ = wind speed at target height // H₂ = target height // α = shear exponent (typically 0.14-0.20) const targetSpeed = knownSpeed * Math.pow(targetHeight / knownHeight, shearExponent); return targetSpeed; } // Example: Extrapolate from 10m to 80m hub height const speed10m = 6.5; // m/s const hubHeight = 80; // m const speedAtHub = windSpeedAtHeight(speed10m, 10, hubHeight, 0.14); console.log(`Wind speed at ${hubHeight}m hub height: ${speedAtHub.toFixed(2)} m/s`); // Output: Wind speed at 80m hub height: 8.39 m/s

2.5 Power Curve and Energy Capture

The power curve represents the relationship between wind speed and turbine power output. It is one of the most important characterizations of turbine performance and is used for energy yield predictions and performance validation.

// Simplified Power Curve Model class TurbinePowerCurve { constructor(cutIn, rated, cutOut, ratedPower) { this.cutIn = cutIn; // m/s this.rated = rated; // m/s this.cutOut = cutOut; // m/s this.ratedPower = ratedPower; // kW } getPower(windSpeed) { if (windSpeed < this.cutIn) { return 0; // Below cut-in } else if (windSpeed >= this.cutIn && windSpeed < this.rated) { // Region 2: Partial load - cubic relationship const normalized = (windSpeed - this.cutIn) / (this.rated - this.cutIn); return this.ratedPower * Math.pow(normalized, 3); } else if (windSpeed >= this.rated && windSpeed < this.cutOut) { // Region 3: Rated power return this.ratedPower; } else { return 0; // Above cut-out } } calculateAEP(windSpeedDistribution) { // Annual Energy Production based on Weibull distribution let totalEnergy = 0; for (let speed of windSpeedDistribution) { totalEnergy += this.getPower(speed.windSpeed) * speed.hours; } return totalEnergy; // kWh/year } } // Example usage const turbine = new TurbinePowerCurve(3.5, 12, 25, 150); // Test at various wind speeds const testSpeeds = [3, 5, 8, 12, 15, 20, 26]; testSpeeds.forEach(speed => { console.log(`${speed} m/s: ${turbine.getPower(speed).toFixed(2)} kW`); }); // Output: // 3 m/s: 0.00 kW // 5 m/s: 3.11 kW // 8 m/s: 37.31 kW // 12 m/s: 150.00 kW // 15 m/s: 150.00 kW // 20 m/s: 150.00 kW // 26 m/s: 0.00 kW

2.6 Grid Integration Terminology

Wind energy systems must integrate seamlessly with electrical grids, requiring understanding of grid-specific terminology and requirements.

2.6.1 Power Quality Parameters

Frequency Regulation: Maintaining grid frequency (50/60 Hz) through active power control. Modern wind turbines provide frequency response capabilities.
Voltage Regulation: Controlling grid voltage through reactive power management. Wind farms provide voltage support via power electronics.
Power Factor: The ratio of real power to apparent power. Grid codes typically require power factors between 0.95 leading to 0.95 lagging.
Fault Ride-Through (FRT): The ability of wind turbines to remain connected during grid faults, providing critical stability support.

2.9 Maintenance and Reliability Concepts

Effective maintenance strategies are crucial for maximizing turbine availability and lifetime. WIA-ENE-006 defines specific maintenance terminology and requirements.

Preventive Maintenance: Scheduled maintenance activities performed at regular intervals to prevent failures and extend component life.
Predictive Maintenance: Condition-based maintenance using sensor data and analytics to predict failures before they occur.
Corrective Maintenance: Unscheduled maintenance performed in response to failures or performance degradation.
MTBF (Mean Time Between Failures): Average operating time between failures, a key reliability metric typically measured in years for major components.
MTTR (Mean Time To Repair): Average time required to repair a failed component and return turbine to service.

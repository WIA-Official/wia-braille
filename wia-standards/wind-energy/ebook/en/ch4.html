4.2 Wind Resource Assessment

Accurate wind resource assessment is critical for project viability and turbine selection. WIA-ENE-006 specifies rigorous measurement and analysis protocols.

// Wind Resource Analysis class WindResourceAnalyzer { constructor(measurementData) { this.data = measurementData; // Array of wind measurements } analyzeResource() { const windSpeeds = this.data.map(d => d.windSpeed); return { meanWindSpeed: this.calculateMean(windSpeeds), weibullParameters: this.fitWeibull(windSpeeds), windRose: this.generateWindRose(this.data), turbulenceIntensity: this.calculateTurbulence(this.data), energyDensity: this.calculateEnergyDensity(windSpeeds), shearExponent: this.calculateShear(this.data), annualEnergyEstimate: this.estimateAEP(windSpeeds) }; } fitWeibull(windSpeeds) { // Fit Weibull distribution: f(v) = (k/c)(v/c)^(k-1) * exp(-(v/c)^k) // where k = shape parameter, c = scale parameter const mean = this.calculateMean(windSpeeds); const variance = this.calculateVariance(windSpeeds); const cv = Math.sqrt(variance) / mean; // Empirical approximation for k const k = Math.pow(cv, -1.086); // Scale parameter from mean and k const c = mean / this.gammaFunction(1 + 1/k); return { shapeParameter: k, scaleParameter: c }; } estimateAEP(windSpeeds) { // Annual Energy Production estimation const powerCurve = this.loadPowerCurve(); const weibull = this.fitWeibull(windSpeeds); let aep = 0; for (let v = 0; v <= 30; v += 0.5) { const probability = this.weibullPDF(v, weibull.shapeParameter, weibull.scaleParameter); const power = powerCurve.getPower(v); aep += power * probability * 8760; // hours/year } // Apply losses const losses = { wake: 0.05, // 5% wake losses availability: 0.03, // 3% downtime electrical: 0.02, // 2% electrical losses environmental: 0.02 // 2% icing, soiling, etc. }; const totalLossFactor = 1 - Object.values(losses).reduce((a, b) => a + b, 0); return aep * totalLossFactor; // kWh/year } weibullPDF(v, k, c) { if (v < 0) return 0; return (k/c) * Math.pow(v/c, k-1) * Math.exp(-Math.pow(v/c, k)); } calculateMean(values) { return values.reduce((a, b) => a + b, 0) / values.length; } calculateVariance(values) { const mean = this.calculateMean(values); const squaredDiffs = values.map(v => Math.pow(v - mean, 2)); return this.calculateMean(squaredDiffs); } gammaFunction(z) { // Stirling's approximation for gamma function return Math.sqrt(2 * Math.PI / z) * Math.pow(z / Math.E, z); } } // Usage example const analyzer = new WindResourceAnalyzer(measurementData); 4.3 Turbine Selection and Layout

Selecting appropriate turbines and optimizing their layout maximizes energy capture while respecting site constraints and minimizing wake losses.

4.3.1 Turbine Selection Criteria

  • Wind Class Match: Turbine class must match or exceed site wind class (IEC 61400-1)
  • Hub Height Optimization: Higher hub heights access stronger, less turbulent winds but increase costs
  • Rotor Diameter: Larger rotors capture more energy but increase loads and costs
  • Specific Power: Lower specific power (W/m²) better for lower wind sites, higher for high wind sites
  • Generator Type: DFIG vs. PMSG vs. SCIG - each has advantages for different applications
  • Noise Levels: Critical for sites near residential areas
  • Grid Code Compliance: Must meet local grid connection requirements
  • Logistics: Component sizes must fit site access routes

4.5 Installation and Commissioning

Turbine installation is a complex operation requiring specialized equipment, skilled personnel, and favorable weather conditions.

4.5.1 Installation Sequence

  1. Foundation Preparation: Cure concrete (minimum 28 days), install anchor bolts, verify leveling
  2. Tower Erection: Assemble tower sections using large crane (typically 3-4 sections)
  3. Nacelle Installation: Lift complete nacelle assembly onto tower top, secure to tower flange
  4. Hub and Blade Installation: Two methods:
    • Assemble rotor on ground, lift complete assembly (requires very large crane)
    • Install hub first, then blades individually (more common, lower crane requirements)
  5. Electrical Connection: Connect turbine to collection system, test continuity and grounding
  6. Commissioning: Systematic testing and verification of all systems
⚠️ Safety Critical: Installation activities are among the most dangerous in wind energy. Strict adherence to safety protocols, weather limits, and lift plans is mandatory. Wind speeds typically must be below 12 m/s for crane operations.

4.6 Commissioning Procedures

Commissioning verifies that all systems function correctly and safely before commercial operation.

4.8 Grid Interconnection

Connecting a wind farm to the electrical grid requires technical studies, agreements with the utility, and compliance with grid codes.

4.8.1 Interconnection Studies

  • Feasibility Study: Initial assessment of grid capacity and connection point
  • System Impact Study: Analysis of wind farm's effect on grid stability, voltage, and protection
  • Facilities Study: Design of required grid upgrades and interconnection equipment
  • Detailed Design: Engineering specifications for all interconnection facilities

4.10 Training and Capacity Building

Ensuring personnel competence is critical for safe, efficient operations. WIA-ENE-006 specifies training requirements for all roles.

4.10.1 Training Programs

  • Basic Wind Energy Awareness: All site personnel (4-8 hours)
  • Turbine-Specific Training: Operators and technicians (2-4 weeks, manufacturer-provided)
  • Advanced Troubleshooting: Senior technicians (1-2 weeks)
  • Safety Training: All personnel (recurring, minimum annually)
  • High Voltage Safety: Electrical technicians (certified training required)
  • Working at Height: All tower climbers (certified training, recurring)
  • SCADA Operations: Control room operators (1-2 weeks)
  • Emergency Response: All personnel (recurring, minimum annually)

# WIA MED Standard: sleep-monitoring

## Overview

This standard defines requirements and protocols for sleep-monitoring in medical applications.

## Components

- `/spec` - Technical specifications
- `/api/typescript` - TypeScript SDK
- `/simulator` - Interactive web simulator
- `/ebook` - Full documentation

## Installation

```bash
npm install @wia/sleep-monitoring
```

## Usage

```typescript
import SDK from '@wia/sleep-monitoring';

const client = new SDK({
  apiKey: 'your-api-key',
  environment: 'production'
});
```

## Documentation

See the full ebook documentation in `/ebook` directory.

## Testing

Open `simulator/index.html` in a browser to test the standard interactively.

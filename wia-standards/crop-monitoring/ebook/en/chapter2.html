Chapter 2: Data Format & Schema

2.1 Overview

The WIA Crop Monitoring data format defines a standardized JSON schema for recording crop growth, health metrics, and environmental conditions. This ensures interoperability across sensors, platforms, and countries.

2.2 Base Structure

{
  "cropId": "CROP-2025-001",
  "farmId": "FARM-KR-12345",
  "timestamp": "2025-06-15T10:30:00Z",
  "location": {
    "gps": {"latitude": 37.5665, "longitude": 126.9780},
    "fieldId": "FIELD-A-01"
  },
  "cropType": "rice",
  "variety": "Koshihikari",
  "growthStage": {
    "code": "BBCH-30",
    "description": "Vegetative stage",
    "daysSinceSeeding": 45
  },
  "measurements": {
    "plantHeight": {"value": 45.5, "unit": "cm"},
    "chlorophyllSPAD": {"value": 42.0, "unit": "SPAD"}
  }
}

2.3 Field Specifications

Required Fields

  • cropId: Unique identifier (e.g., "CROP-2025-001")
  • farmId: Farm or organization ID
  • timestamp: ISO 8601 datetime
  • location: GPS coordinates
  • cropType: Species (rice, corn, tomato, etc.)
  • growthStage: BBCH phenology code
  • measurements: Growth and health metrics

2.4 Measurement Types

Growth Metrics

"measurements": {
  "plantHeight": {"value": 45.5, "unit": "cm"},
  "leafAreaIndex": {"value": 3.8, "unit": "m²/m²"},
  "biomass": {"value": 2500, "unit": "kg/ha"}
}

Health Metrics

"healthStatus": {
  "overall": "healthy",
  "diseases": [
    {
      "name": "Late Blight",
      "severity": "low",
      "confidence": 0.85
    }
  ]
}

2.5 Validation Rules

Data Integrity

  • Timestamps cannot be in the future
  • GPS coordinates must be valid (-90 to 90 lat, -180 to 180 lon)
  • Growth stages must align with crop type
  • Numeric values must be within specified ranges

2.6 Examples

Healthy Rice Crop

{
  "cropId": "CROP-2025-RICE-001",
  "farmId": "FARM-KR-12345",
  "timestamp": "2025-06-15T10:30:00Z",
  "cropType": "rice",
  "growthStage": {"code": "BBCH-30", "description": "Vegetative"},
  "measurements": {
    "plantHeight": {"value": 45.5, "unit": "cm"},
    "chlorophyllSPAD": {"value": 42.0, "unit": "SPAD"},
    "ndvi": {"value": 0.75}
  },
  "healthStatus": {"overall": "healthy"},
  "predictions": {
    "yieldEstimate": {"value": 5500, "unit": "kg/ha"}
  }
}

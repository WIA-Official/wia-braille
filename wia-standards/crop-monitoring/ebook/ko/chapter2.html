챕터 2: 데이터 형식 및 스키마

2.1 개요

WIA 작물 모니터링 데이터 형식은 작물 생육, 건강 지표, 환경 조건을 기록하기 위한 표준화된 JSON 스키마를 정의합니다. 센서, 플랫폼, 국가 간 상호운용성을 보장합니다.

2.2 기본 구조

{
  "cropId": "CROP-2025-001",
  "farmId": "FARM-KR-12345",
  "timestamp": "2025-06-15T10:30:00Z",
  "location": {
    "gps": {"latitude": 37.5665, "longitude": 126.9780},
    "fieldId": "FIELD-A-01"
  },
  "cropType": "rice",
  "variety": "고시히카리",
  "growthStage": {
    "code": "BBCH-30",
    "description": "영양생장기",
    "daysSinceSeeding": 45
  },
  "measurements": {
    "plantHeight": {"value": 45.5, "unit": "cm"},
    "chlorophyllSPAD": {"value": 42.0, "unit": "SPAD"}
  }
}

2.3 필드 사양

필수 필드

  • cropId: 고유 식별자 (예: "CROP-2025-001")
  • farmId: 농장 또는 조직 ID
  • timestamp: ISO 8601 날짜/시간
  • location: GPS 좌표
  • cropType: 작물 종류 (벼, 배추, 고추 등)
  • growthStage: BBCH 생육단계 코드
  • measurements: 생육 및 건강 지표

2.4 측정 유형

생육 지표

"measurements": {
  "plantHeight": {"value": 45.5, "unit": "cm"},
  "leafAreaIndex": {"value": 3.8, "unit": "m²/m²"},
  "biomass": {"value": 2500, "unit": "kg/ha"}
}

건강 지표

"healthStatus": {
  "overall": "healthy",
  "diseases": [
    {"name": "도열병", "severity": "low", "confidence": 0.85}
  ]
}

2.5 검증 규칙

데이터 무결성

  • 타임스탬프는 미래일 수 없음
  • GPS 좌표는 유효해야 함 (위도 -90~90, 경도 -180~180)
  • 생육단계는 작물 종류와 일치해야 함
  • 숫자 값은 지정된 범위 내에 있어야 함

2.6 예제

건강한 벼 작물

{
  "cropId": "CROP-2025-RICE-001",
  "farmId": "FARM-KR-12345",
  "timestamp": "2025-06-15T10:30:00Z",
  "cropType": "rice",
  "growthStage": {"code": "BBCH-30", "description": "영양생장기"},
  "measurements": {
    "plantHeight": {"value": 45.5, "unit": "cm"},
    "chlorophyllSPAD": {"value": 42.0, "unit": "SPAD"},
    "ndvi": {"value": 0.75}
  },
  "healthStatus": {"overall": "healthy"},
  "predictions": {
    "yieldEstimate": {"value": 5500, "unit": "kg/ha"}
  }
}

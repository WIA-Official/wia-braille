챕터 3: IoT 센서 및 현장 장비

3.1 센서 유형

토양 수분 센서

체적 수분 함량 측정 (0-100%). 관개 일정에 중요.

  • 정전용량 센서: 가장 일반적, 저렴 (2~5만원)
  • TDR 센서: 고정확도, 비쌈 (20~50만원)
  • 설치: 헥타르당 3개 센서, 깊이 15cm, 30cm, 60cm

기상 관측소

온도, 습도, 바람, 강수량, 일사량 측정.

기상 관측소 데이터:
{
  "temperature": {"value": 25.5, "unit": "°C"},
  "humidity": {"value": 70, "unit": "%"},
  "windSpeed": {"value": 12, "unit": "km/h"},
  "rainfall": {"value": 5.2, "unit": "mm"}
}

카메라 및 드론

AI 분석을 위한 시각 데이터 캡처. 병해 감지용 RGB 카메라, NDVI용 다중분광 카메라.

3.2 통신 프로토콜

센서용 MQTT

const mqtt = require('mqtt');
const client = mqtt.connect('mqtt://crop-monitoring.wiastandards.com');

client.publish('wia/crop/FARM-001/soil-moisture/SM-001', JSON.stringify({
  sensorId: 'SM-001',
  timestamp: new Date().toISOString(),
  measurements: {
    soilMoisture: { value: 85, unit: '%' }
  }
}));

원격 현장용 LoRaWAN

저전력, 장거리(5-15km) 통신으로 WiFi/모바일 통신이 없는 원격 지역에 적합.

전력 관리

태양광 센서는 수년간 작동 가능. 정상 모드에서 5분마다, 경보 시 30초마다 전송, 야간에는 절전 모드로 전력 절약.

3.3 설치 가이드

  1. 현장 조사: 현장 지도화, 다른 토양 유형 구역 식별
  2. 센서 배치: 헥타르당 수분 센서 3개, 중앙에 기상 관측소
  3. 교정: 알려진 수분 조건에서 센서 테스트
  4. 네트워크 설정: WiFi/LoRaWAN 게이트웨이 구성
  5. 클라우드 연결: 센서 등록, 데이터 전송 확인

3.4 실시간 데이터 수집

# Python 센서 읽기 스크립트
import time
from sensors import SoilMoistureSensor
from mqtt import MQTTClient

sensor = SoilMoistureSensor(pin=17)
client = MQTTClient('mqtt://crop-monitoring.wiastandards.com')

while True:
    moisture = sensor.read_moisture()
    client.publish('wia/crop/FARM-001/soil', {
        'value': moisture,
        'timestamp': time.time()
    })
    time.sleep(300)  # 5분마다

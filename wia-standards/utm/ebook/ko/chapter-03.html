Chapter 3

🆔 드론 식별 시스템: Remote ID

3.1 Remote ID의 개념과 필요성

Remote ID(원격 식별)는 드론이 비행 중 자신의 신원과 위치 정보를 실시간으로 방송하는 시스템입니다. 자동차의 번호판에 비유할 수 있으며, 공공 안전과 UTM 시스템의 핵심 기반 기술입니다.

드론의 급속한 확산과 함께 다음과 같은 우려가 제기되었습니다:

  • 승인받지 않은 드론의 운영
  • 프라이버시 침해 우려
  • 공항 인근 불법 비행
  • 사고 발생 시 책임 소재 불분명
  • 보안 시설 근처의 위협적인 드론

Remote ID는 이러한 문제들을 해결하기 위해 개발되었으며, 2020년대 들어 전 세계적으로 의무화되고 있습니다.

📡 Remote ID의 핵심 목표

  1. 식별(Identification): 비행 중인 드론과 운영자를 고유하게 식별
  2. 추적(Tracking): 드론의 실시간 위치와 경로 파악
  3. 책임(Accountability): 사고 발생 시 책임 소재 확인
  4. 안전(Security): 불법 드론 탐지 및 대응
  5. 통합(Integration): UTM 시스템과의 원활한 연동

3.2 Remote ID의 작동 원리

3.2.1 방송 방식

Remote ID는 두 가지 주요 방식으로 정보를 방송합니다:

방식 설명 장점 단점
Broadcast Remote ID Wi-Fi 또는 Bluetooth를 통해 직접 방송 인터넷 불필요, 지역 주민이 직접 수신 가능 제한된 범위 (약 1km)
Network Remote ID 인터넷을 통해 USS/FIMS에 전송 무제한 범위, 중앙 데이터베이스 구축 인터넷 연결 필수

대부분의 국가는 두 방식을 모두 요구하며, 하나가 실패해도 다른 방식으로 작동할 수 있도록 합니다.

3.2.2 전송 데이터

Remote ID는 다음과 같은 정보를 1초마다 방송합니다:

Remote ID 메시지 구조 (ASTM F3411 기준) Basic ID Message: - UAS ID Type (Serial Number, CAA Registration, Session ID 등) - UAS ID (고유 식별자) - UA Type (Fixed-wing, Rotorcraft, Hybrid 등) Location/Vector Message: - Latitude, Longitude, Altitude (드론 위치) - Height (이륙 지점 대비 높이) - Horizontal/Vertical Speed - Track Direction (진행 방향) - Timestamp System Message: - Operator Location (조종사 위치) - Operator Altitude - Area Count (군집 비행 시) - Area Radius - Timestamp Operator ID Message: - Operator ID Type - Operator ID (조종사 식별자)

3.2.3 암호화와 보안

Remote ID 데이터는 일반적으로 암호화되지 않습니다. 이는 공공 안전을 위해 누구나 드론을 식별할 수 있도록 하기 위함입니다. 그러나 민감한 임무(정부, 군사, 긴급 대응)의 경우 예외가 인정될 수 있습니다.

🔒 프라이버시 우려

Remote ID는 드론 운영자의 프라이버시를 침해할 수 있다는 우려가 있습니다. 특히 개인 취미용 드론 조종사들은 자신의 위치가 실시간으로 공개되는 것에 반대했습니다. 이에 대응하여:

  • 운영자 개인정보는 일반에 공개되지 않고, 법 집행 기관만 접근 가능
  • 역사적 비행 데이터는 제한된 기간만 보관
  • 익명화 옵션(제한적)

3.3 Remote ID 표준

3.3.1 ASTM F3411 표준

ASTM International은 Remote ID의 가장 널리 채택된 표준인 F3411을 개발했습니다. 이 표준은:

  • 메시지 형식: Remote ID 메시지의 구조와 내용을 정의
  • 전송 프로토콜: Wi-Fi Beacon과 Bluetooth 5 Long Range를 지원
  • 성능 요구사항: 전송 빈도, 범위, 신뢰성 기준
  • 테스트 절차: 제조사가 준수 여부를 확인하는 방법

3.3.2 국가별 규제

각국은 ASTM 표준을 기반으로 자국의 규제를 수립하고 있습니다:

국가/지역 규제 기관 시행 시기 주요 내용
미국 FAA 2023년 9월 250g 이상 모든 드론에 Remote ID 의무화
유럽 EASA 2024년 1월 C1~C4 클래스 드론에 Direct Remote ID 필수
한국 국토교통부 2025년 2kg 이상 드론에 원격식별장치 장착 의무
일본 국토교통성 2022년 6월 100g 이상 등록 드론에 Remote ID 필수
중국 CAAC 2024년 7kg 이상 또는 상업용 드론에 실명 등록

3.4 Remote ID 구현 방법

3.4.1 내장형 Remote ID

가장 이상적인 방법은 드론 제조 시 Remote ID 모듈을 내장하는 것입니다. 2023년 이후 출시되는 대부분의 드론은 이미 Remote ID가 내장되어 있습니다.

  • DJI: 2020년부터 모든 신제품에 AeroScope 기술 기반 Remote ID 탑재
  • Autel: Remote ID 모듈이 통합된 EVO 시리즈
  • Skydio: 미국 FAA 규정을 완전히 준수하는 Remote ID 시스템
  • Parrot: ANAFI USA 등에 Remote ID 내장

3.4.2 애드온 Remote ID

기존 드론에는 별도의 Remote ID 모듈을 부착할 수 있습니다. 여러 제조사가 애드온 모듈을 판매하고 있으며, 주요 제품은 다음과 같습니다:

  • DroneTag: 유럽 기반의 플러그앤플레이 Remote ID 모듈
  • Cube ID: 오픈소스 하드웨어 기반의 Remote ID
  • BlueMark: Bluetooth 기반 경량 Remote ID
  • ServoCity RID: 조립형 드론용 모듈

3.4.3 소프트웨어 Remote ID

일부 드론은 스마트폰 앱을 통해 Network Remote ID를 구현할 수 있습니다. 드론 자체는 위치 정보를 앱으로 전송하고, 앱이 이를 USS/FIMS에 전달합니다.

📱 모바일 앱 기반 Remote ID 예시

AirMap: 드론과 페어링하여 Network Remote ID 제공

Aloft: 실시간 위치 추적 및 Remote ID 전송

Kittyhawk: 비행 계획과 통합된 Remote ID 솔루션

3.5 Remote ID 수신 및 활용

3.5.1 지상 수신기

Remote ID 신호는 특수 수신기나 스마트폰 앱으로 수신할 수 있습니다:

  • OpenDroneID: 오픈소스 Remote ID 수신기 프로젝트로, Android 앱과 하드웨어 수신기 제공
  • DroneScanner: iOS와 Android용 Remote ID 스캐너 앱
  • AeroScope: DJI의 전용 드론 탐지 시스템 (정부 및 공공기관용)
  • Dedrone: 고급 드론 탐지 및 식별 시스템

3.5.2 법 집행 기관의 활용

경찰, 소방서, 공항 보안 등 법 집행 기관은 Remote ID를 활용하여:

  1. 불법 드론 탐지 및 추적
  2. 공항 인근 비행 금지 구역 침범 감시
  3. 대규모 행사장 주변 드론 모니터링
  4. 사고 발생 시 운영자 신원 파악
  5. 긴급 상황 시 드론 회피 명령

3.5.3 UTM 시스템과의 통합

Remote ID는 UTM 시스템의 핵심 데이터 소스입니다. USS는 Remote ID 데이터를 수집하여:

  • 승인된 비행 계획과 실제 비행 경로 비교
  • 승인받지 않은 드론 탐지
  • 충돌 위험 실시간 평가
  • 공역 사용 통계 분석
  • 드론 밀도 맵 생성

3.6 Remote ID의 기술적 과제

3.6.1 전파 간섭 문제

Remote ID는 Wi-Fi(2.4GHz/5GHz)와 Bluetooth(2.4GHz)를 사용하므로, 다음과 같은 간섭 문제가 발생할 수 있습니다:

  • 도심 환경: 수많은 Wi-Fi 신호로 인한 혼잡
  • 군집 비행: 여러 드론이 동시에 방송하면 신호 충돌
  • 전파 방해: 악의적인 재밍(Jamming) 공격
  • 신호 감쇠: 건물, 나무 등 장애물에 의한 신호 약화

3.6.2 배터리 소모

Remote ID 모듈은 지속적으로 신호를 방송하므로 추가적인 전력을 소모합니다. 특히 소형 드론의 경우 비행 시간이 크게 단축될 수 있습니다. 이를 해결하기 위해:

  • 저전력 Bluetooth 5.0 Long Range 기술 사용
  • 효율적인 안테나 설계
  • 비행 중에만 작동하는 스마트 전원 관리

3.6.3 국경 간 운영

국가마다 Remote ID 표준과 주파수 규제가 다를 수 있어, 국경을 넘는 드론 운영이 어려울 수 있습니다. 국제 표준화 노력이 진행 중입니다.

⚠️ 스푸핑 위협

Remote ID는 암호화되지 않으므로, 악의적인 공격자가 가짜 Remote ID 신호를 방송하는 '스푸핑(Spoofing)' 공격에 취약합니다. 이를 방지하기 위해:

  • 디지털 서명을 통한 메시지 인증
  • USS/FIMS에서 이중 검증 (Broadcast와 Network Remote ID 비교)
  • 이상 징후 탐지 알고리즘
  • 암호화된 Network Remote ID 채널 사용

3.7 Remote ID의 미래 발전

3.7.1 5G 통합

5G 네트워크의 확산으로 Network Remote ID의 성능이 크게 향상될 것으로 예상됩니다:

  • 초저지연: 1ms 이하의 지연 시간으로 실시간 추적
  • 대규모 연결: km² 당 100만 대 이상의 드론 지원
  • 고신뢰성: 99.999% 가용성
  • 정밀 위치: 센티미터 단위 위치 정확도

3.7.2 블록체인 기반 Remote ID

일부 연구는 블록체인 기술을 활용하여 더 안전하고 탈중앙화된 Remote ID를 개발하고 있습니다:

  • 변조 불가능한 드론 신원 기록
  • 분산 원장을 통한 투명한 비행 이력 관리
  • 스마트 컨트랙트 기반 자동 규정 준수

3.7.3 AI 기반 분석

Remote ID 데이터를 AI로 분석하여 다양한 인사이트를 얻을 수 있습니다:

  • 이상 행동 탐지: 비정상적인 비행 패턴 식별
  • 예측 분석: 공역 혼잡 예측 및 최적 경로 제안
  • 자동 분류: 드론의 용도(배송, 촬영, 취미 등) 자동 분류
  • 위협 평가: 잠재적 보안 위협 평가

3.8 Remote ID 준수 가이드

3.8.1 드론 운영자를 위한 체크리스트

  1. 규정 확인: 해당 국가/지역의 Remote ID 요구사항 파악
  2. 드론 점검: 내장 Remote ID 여부 확인 (제조사 웹사이트 참조)
  3. 모듈 설치: 필요 시 인증된 애드온 Remote ID 모듈 구입 및 설치
  4. 등록: 드론을 항공 당국에 등록하고 고유 ID 발급받기
  5. 테스트: Remote ID 앱으로 신호 방송 확인
  6. 업데이트: 드론 펌웨어와 Remote ID 소프트웨어 최신 버전 유지
  7. 백업: Broadcast와 Network Remote ID 모두 작동하는지 확인

3.8.2 제조사를 위한 가이드

드론 제조사는 다음 사항을 준수해야 합니다:

  • 표준 준수: ASTM F3411 또는 해당 지역의 Remote ID 표준 준수
  • 인증 획득: FAA, EASA 등 규제 기관으로부터 인증 획득
  • 내장 설계: 드론 설계 단계부터 Remote ID 모듈 통합
  • 사용자 교육: 운영자에게 Remote ID 설정 방법 안내
  • 펌웨어 업데이트: OTA 업데이트를 통한 Remote ID 개선

3.9 요약

Remote ID는 UTM 생태계의 기초이며, 드론의 안전하고 책임있는 운영을 가능하게 합니다. Broadcast와 Network 방식을 통해 드론의 신원과 위치를 실시간으로 공개함으로써, 공공 안전을 보장하고 불법 운영을 방지합니다.

ASTM F3411 표준을 중심으로 전 세계적으로 Remote ID가 의무화되고 있으며, 5G와 AI 등 신기술과의 결합을 통해 더욱 발전할 것입니다. 모든 드론 운영자와 제조사는 해당 지역의 Remote ID 규정을 준수해야 합니다.

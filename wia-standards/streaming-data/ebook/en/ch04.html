4.2 Apache Flink

Apache Flink is a stateful stream processing framework with exactly-once semantics and event-time processing.

4.2.2 DataStream API Example

StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();

DataStream events = env
    .addSource(new FlinkKafkaConsumer<>("events", schema, properties));

DataStream alerts = events
    .filter(e -> e.getValue() > threshold)
    .keyBy(Event::getUserId)
    .window(TumblingEventTimeWindows.of(Time.minutes(5)))
    .aggregate(new EventAggregator())
    .filter(agg -> agg.getCount() > 10)
    .map(agg -> new Alert(agg));

alerts.addSink(new FlinkKafkaProducer<>("alerts", schema, properties));
env.execute("Anomaly Detection Job");

4.3 Apache Spark Streaming

Spark Streaming extends Apache Spark to handle streaming data using micro-batches.

4.3.1 Structured Streaming

// Structured Streaming with Spark 3.x
val df = spark
  .readStream
  .format("kafka")
  .option("kafka.bootstrap.servers", "localhost:9092")
  .option("subscribe", "events")
  .load()

val processed = df
  .selectExpr("CAST(value AS STRING) as json")
  .select(from_json($"json", schema).as("data"))
  .where($"data.amount" > 1000)
  .groupBy($"data.userId", window($"data.timestamp", "5 minutes"))
  .agg(count("*").as("count"), sum($"data.amount").as("total"))

processed
  .writeStream
  .outputMode("update")
  .format("console")
  .start()
  .awaitTermination()

4.3.2 Micro-batch Processing

  • Treats streams as series of small batches
  • Batch interval configurable (e.g., 1 second)
  • Leverages Spark's batch processing engine
  • Higher latency than true streaming (100ms+)

4.4 Kafka Streams

Kafka Streams is a client library for building applications that process data stored in Kafka.

4.4.1 Stream Processing Topology

StreamsBuilder builder = new StreamsBuilder();

KStream transactions = builder.stream("transactions");

// Stateless transformations
KStream filtered = transactions
    .filter((key, tx) -> tx.getAmount() > 100)
    .mapValues(tx -> tx.withEnriched(true));

// Stateful operations
KTable aggregated = transactions
    .groupBy((key, tx) -> tx.getUserId())
    .windowedBy(TimeWindows.of(Duration.ofMinutes(5)))
    .count();

// Join streams
KStream joined = transactions
    .join(userTable, (tx, user) -> enrich(tx, user));

// Output
filtered.to("filtered-transactions");

KafkaStreams streams = new KafkaStreams(builder.build(), config);
streams.start();

4.5 Apache Storm

4.5.1 Storm Topology

// Storm components
TopologyBuilder builder = new TopologyBuilder();

// Spout (data source)
builder.setSpout("kafka-spout", new KafkaSpout(spoutConfig), 3);

// Bolts (processing logic)
builder.setBolt("parser", new ParserBolt(), 5)
       .shuffleGrouping("kafka-spout");

builder.setBolt("enricher", new EnricherBolt(), 5)
       .fieldsGrouping("parser", new Fields("userId"));

builder.setBolt("aggregator", new AggregatorBolt(), 3)
       .fieldsGrouping("enricher", new Fields("userId"));

// Submit topology
StormSubmitter.submitTopology("analytics", config, builder.createTopology());

[00:00-00:05] [00:05-00:10] [00:10-00:15]

// Overlapping windows (5 min window, 1 min slide)

    [00:02-00:07]

4.9 Advanced Patterns

4.9.1 Stream Joins

// Join two streams
DataStream orders = ...;
DataStream payments = ...;

orders.join(payments)
    .where(Order::getOrderId)
    .equalTo(Payment::getOrderId)
    .window(TumblingEventTimeWindows.of(Time.minutes(5)))
    .apply((order, payment) -> new Fulfillment(order, payment));

4.9.2 Pattern Detection (CEP)

// Complex Event Processing with Flink CEP
Pattern pattern = Pattern.begin("start")
    .where(e -> e.getType().equals("LOGIN"))
    .next("middle")
    .where(e -> e.getType().equals("PURCHASE"))
    .within(Time.minutes(10));

PatternStream patternStream = CEP.pattern(events, pattern);
patternStream.select((map) -> {
    return new Alert("Purchase after login", map.get("middle"));
});

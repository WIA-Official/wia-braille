Chapter 06: Access Control and Privacy Protection

弘익人間 - "Privacy is a fundamental right that must be protected in digital document systems."

06.1 Role-Based Access Control (RBAC)

RBAC assigns permissions based on organizational roles:

  • Administrator: Full access to all documents and system configuration
  • Registrar: Create and issue new documents within jurisdiction
  • Verifier: Read-only access to verify document authenticity
  • Citizen: Access only to own documents
  • Auditor: Read-only access to audit logs
const rbac = {
  roles: {
    admin: ['create','read','update','delete','configure'],
    registrar: ['create','read','update'],
    verifier: ['read','verify'],
    citizen: ['read-own'],
    auditor: ['read-logs']
  }
};

06.2 Attribute-Based Access Control (ABAC)

ABAC enables fine-grained access policies based on attributes:

const policy = {
  subject: {department:'legal',clearance:'level-3'},
  resource: {type:'birthCertificate',classification:'confidential'},
  action: 'read',
  environment: {time:'business-hours',location:'on-premises'},
  decision: 'allow'
};

06.3 Encryption

All documents encrypted at rest (AES-256-GCM) and in transit (TLS 1.3). End-to-end encryption for sensitive documents ensures only authorized parties can decrypt contents.

import {DocumentEncryption} from 'wia-soc-013';
const encrypted=await DocumentEncryption.encrypt({
  document:pdfFile,
  algorithm:'AES-256-GCM',
  recipients:['citizen-public-key','registrar-public-key']
});

06.4 Zero-Knowledge Proofs

Prove attributes without revealing document contents:

const proof=await document.createZKProof({
  reveal:['ageOver18'],
  hide:['name','dateOfBirth','address']
});
const valid=await proof.verify();

06.5 Data Minimization

Collect and disclose only necessary information. Support selective disclosure for privacy-preserving verification.

06.6 GDPR Compliance

  • Right to Access: Citizens can download all their documents
  • Right to Erasure: Delete digitized copies (blockchain anchors remain for audit)
  • Right to Portability: Export documents in standard formats
  • Consent Management: Explicit consent required for document sharing

06.7 Audit Logging

Comprehensive logs of all access and modifications:

const log={
  timestamp:'2025-01-15T10:30:00Z',
  event:'document.accessed',
  actor:'user:citizen-456',
  documentId:'doc:wia:soc013:abc123',
  purpose:'passport-application',
  consentId:'consent-789',
  ipAddress:'192.168.1.100'
};

06.8 Consent Management

All document sharing requires explicit, informed, and revocable consent:

const consent=await ConsentService.request({
  citizen:'citizen-456',
  requester:'passport-office',
  documents:['birth-cert','ssn-card'],
  purpose:'passport-application',
  expiresAt:'2025-12-31'
});
if(consent.granted){
  await DocumentService.share({documentIds:consent.documents,recipient:consent.requester});
}

06.9 Data Residency and Sovereignty

Documents must be stored in jurisdictionally appropriate locations. Some countries require data to remain within national borders. WIA-SOC-013 supports multi-region deployments with data residency controls.

06.10 Incident Response

In case of security breaches, immediate revocation of compromised credentials, forensic analysis of audit logs, notification of affected citizens, and regulatory reporting as required.

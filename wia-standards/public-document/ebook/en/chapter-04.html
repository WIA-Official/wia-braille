Chapter 04: Metadata Schemas and Classification

弘益人間 - "Rich metadata transforms documents from static files into living, discoverable knowledge."

04.1 The Importance of Metadata

Metadata—data about data—is essential for document management, discovery, preservation, and compliance. Without metadata, a digitized document is merely an image file. With comprehensive metadata, it becomes a searchable, verifiable, contextually rich information asset.

WIA-SOC-013 defines three layers of metadata:

  • Descriptive Metadata: What the document is (title, author, subject)
  • Administrative Metadata: How the document is managed (rights, access, preservation)
  • Structural Metadata: How the document is organized (pages, sections, relationships)

04.2 Dublin Core Metadata Element Set

Dublin Core (ISO 15836) provides 15 core elements for resource description. WIA-SOC-013 mandates Dublin Core for all public documents.

04.3 PREMIS: Preservation Metadata

PREMIS (Preservation Metadata: Implementation Strategies) defines a data dictionary for preservation metadata. It captures technical details essential for long-term archival.

PREMIS Entities

  • Object: The document itself (file, bitstream, representation)
  • Event: Actions that affect the object (creation, migration, validation)
  • Agent: Entities responsible for events (people, organizations, software)
  • Rights: Intellectual property and access rights

04.7 Metadata Quality and Validation

Poor metadata undermines document management. WIA-SOC-013 includes validation rules:

Validation Rules

import { MetadataValidator } from 'wia-soc-013';

const validator = new MetadataValidator({
  schema: 'dublin-core',
  strictMode: true
});

const validation = await validator.validate({
  metadata: documentMetadata
});

if (!validation.isValid) {
  console.error('Validation errors:', validation.errors);
  // [
  //   {
  //     "field": "dc:date",
  //     "error": "Invalid date format. Expected ISO 8601.",
  //     "value": "01/15/2025"
  //   },
  //   {
  //     "field": "dc:language",
  //     "error": "Invalid language code. Expected ISO 639-1/639-2.",
  //     "value": "english"
  //   }
  // ]
}

04.8 Metadata Embedding and Extraction

Metadata should be embedded directly in document files and also stored in external databases for efficient querying.

PDF XMP Metadata Embedding

import { XMPEmbedder } from 'wia-soc-013';

const embedder = new XMPEmbedder();

await embedder.embed({
  pdfFile: documentPDF,
  metadata: {
    dublinCore: dcMetadata,
    premis: premisMetadata,
    custom: {
      'wia:documentID': 'doc:wia:soc013:abc123',
      'wia:securityLevel': 'confidential',
      'wia:retentionPeriod': '99 years'
    }
  }
});

Database Storage

import { MetadataRepository } from 'wia-soc-013';

const repo = new MetadataRepository({
  database: 'postgresql',
  connection: {
    host: 'db.gov.local',
    database: 'document_metadata'
  }
});

await repo.store({
  documentId: 'doc:wia:soc013:abc123',
  metadata: fullMetadata,
  indexes: ['dc:title', 'dc:subject', 'dc:date', 'dc:identifier']
});

// Query by metadata
const results = await repo.search({
  query: {
    'dc:type': 'birthCertificate',
    'dc:date': { $gte: '2025-01-01', $lte: '2025-12-31' },
    'dc:coverage': { $regex: 'California' }
  },
  limit: 100
});

04.9 Faceted Search and Discovery

Rich metadata enables powerful search interfaces with faceted navigation:

import { FacetedSearch } from 'wia-soc-013';

const search = new FacetedSearch({
  metadataRepository: repo
});

const results = await search.query({
  keywords: 'birth certificate',
  facets: {
    'dc:date': { ranges: ['2020-2024', '2025'] },
    'dc:coverage': { values: ['California', 'Texas', 'New York'] },
    'documentType': { values: ['birthCertificate', 'deathCertificate'] }
  }
});

04.11 Conclusion

Metadata transforms digitized documents from isolated files into interconnected knowledge assets. By implementing Dublin Core, PREMIS, custom taxonomies, and validation rules, governments can build document repositories that are searchable, preservable, and interoperable across systems and borders.

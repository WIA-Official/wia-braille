🏗️ 제2장: 기술 아키텍처

확장 가능한 설계

WIA-EDU-023 MOOC 아키텍처는 수백만 명의 동시 학습자를 지원하면서도 높은 품질과 성능을 유지하도록 설계되었습니다.

2.1 MOOC 플랫폼 아키텍처

2.1.1 5계층 아키텍처

WIA-EDU-023 MOOC 표준은 다음과 같은 5계층 아키텍처를 기반으로 합니다:

┌─────────────────────────────────────────────────────┐
│            1. 학습자 인터페이스 계층                  │
│  (Web, Mobile, Tablet, Desktop, Accessibility)      │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│            2. 콘텐츠 전달 계층 (CDN)                 │
│  (Video Streaming, Documents, Interactive Content)  │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│            3. 학습 관리 계층 (LMS Core)              │
│   (Enrollment, Progress, Assessment, Grading)       │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│            4. 소셜 학습 계층                         │
│    (Forums, Peer Review, Collaboration, Chat)       │
└─────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│            5. 분석 및 인사이트 계층                   │
│  (Learning Analytics, AI Recommendations, Reports)  │
└─────────────────────────────────────────────────────┘

2.1.2 마이크로서비스 아키텍처

각 계층은 독립적인 마이크로서비스로 구성되어 확장성과 유지보수성을 보장합니다:

서비스 책임 기술 스택
User Service 사용자 인증, 프로필 관리 Node.js, PostgreSQL
Course Service 강좌 메타데이터, 구조 관리 Python, MongoDB
Content Service 비디오, 문서, 자료 저장 Go, S3, CDN
Progress Service 학습 진도, 완료 상태 추적 Node.js, Redis, PostgreSQL
Assessment Service 퀴즈, 시험, 채점 Python, PostgreSQL
Forum Service 토론, 댓글, 소셜 학습 Node.js, MongoDB
Analytics Service 학습 데이터 분석, 예측 Python, Spark, ML
Certification Service 인증서 발급, 블록체인 저장 Node.js, Ethereum

2.2.2 CDN 전략

글로벌 콘텐츠 배포:

  • 전 세계 200+ 엣지 로케이션
  • 지역별 캐싱으로 지연 시간 최소화
  • 자동 장애 조치(failover)
  • 대역폭 최적화

오프라인 지원:

  • Progressive Web App (PWA) 기술
  • 비디오 다운로드 및 로컬 저장
  • 온라인 복귀 시 자동 동기화
  • 저장 공간 관리

2.3 학습 관리 계층

2.3.1 강좌 구조 모델

WIA-EDU-023은 계층적 강좌 구조를 정의합니다:

Course (강좌)
├── Module 1 (모듈/주차)
│   ├── Lesson 1.1 (레슨)
│   │   ├── Video 1.1.1
│   │   ├── Reading 1.1.2
│   │   └── Quiz 1.1.3
│   ├── Lesson 1.2

│   └── Assignment 1 (과제)
├── Module 2
│   └── ...
└── Final Exam (최종 시험)

2.3.3 평가 엔진

자동 채점 시스템:

  • 객관식/선택형 문제 즉시 채점
  • 코딩 문제 자동 테스트 (단위 테스트)
  • 수학 문제 기호 처리
  • 즉각적인 피드백 제공

동료 평가 시스템:

  • 최소 3명 이상의 동료 평가
  • 루브릭 기반 평가 기준
  • 평가자 신뢰도 점수
  • 이상치 탐지 및 조정

2.4 소셜 학습 계층

2.4.1 토론 포럼 아키텍처

기능 설명 기술
스레드 기반 토론 질문, 답변, 댓글 구조 MongoDB, Elasticsearch
실시간 알림 답변, 좋아요, 멘션 알림 WebSocket, Firebase
투표 시스템 유용한 답변 순위화 Redis, PostgreSQL
검색 기능 전체 텍스트 검색 Elasticsearch
모더레이션 부적절한 콘텐츠 필터링 AI/ML, 수동 검토

2.4.2 협업 학습 기능

스터디 그룹:

  • 학습자가 생성한 소그룹
  • 그룹 채팅 및 화상 회의
  • 공유 노트 및 자료
  • 그룹 과제 협업

라이브 세션:

  • 강사 주최 Q&A 세션
  • 게스트 강연
  • 워크숍 및 실습
  • 녹화 및 재시청 가능

2.5 분석 및 인사이트 계층

2.5.1 학습 분석 파이프라인

Data Collection → Processing → Analysis → Insights → Actions
      ↓               ↓            ↓          ↓           ↓
  Click Logs    ETL Pipeline   ML Models  Dashboards  Interventions
  Video Watch   Data Lake      Clustering Reports      Recommendations
  Quiz Scores   Streaming      Prediction Alerts       Personalization

2.5.2 핵심 학습 메트릭

메트릭 설명 활용
Engagement Rate 활동적인 학습자 비율 강좌 품질 평가
Completion Rate 강좌 완료율 콘텐츠 난이도 조정
Drop-off Points 학습자가 이탈하는 지점 문제 콘텐츠 개선
Time on Task 각 활동에 소요된 시간 학습 속도 예측
Assessment Performance 평가 점수 분포 학습 효과 측정
Social Interaction 포럼 참여, 동료 지원 커뮤니티 건강도

2.5.3 AI 기반 개인화

적응형 학습 경로:

  • 학습 스타일 탐지 (시각적, 청각적, 실습형)
  • 난이도 조정 (학습자 수준에 맞춤)
  • 콘텐츠 추천 (관련 자료 제안)
  • 학습 속도 예측 및 조정

조기 경고 시스템:

  • 이탈 위험 학습자 식별
  • 자동 개입 및 지원
  • 개인화된 독려 메시지
  • 추가 리소스 제공

2.6 확장성 설계

2.6.1 수평적 확장 (Horizontal Scaling)

로드 밸런싱:

  • 서버 인스턴스 자동 증설
  • 트래픽 분산 (Round Robin, Least Connection)
  • 지역별 라우팅
  • 헬스 체크 및 자동 복구

데이터베이스 샤딩:

  • 사용자 ID 기반 샤딩
  • 강좌 ID 기반 분할
  • 읽기 복제본 (Read Replicas)
  • 캐싱 계층 (Redis, Memcached)

2.6.2 성능 목표

지표 목표 측정 방법
페이지 로드 시간 < 2초 Lighthouse, WebPageTest
비디오 시작 시간 < 1초 CDN 메트릭
API 응답 시간 < 200ms (p95) APM 도구
동시 사용자 100만+ 부하 테스트
가용성 99.9% Uptime 모니터링

2.7 장 요약

핵심 내용:

  1. 5계층 아키텍처: 인터페이스, 콘텐츠, 학습 관리, 소셜, 분석
  2. 마이크로서비스: 독립적이고 확장 가능한 서비스 구조
  3. 비디오 스트리밍: 적응형 비트레이트, 글로벌 CDN
  4. 학습 관리: 진도 추적, 자동 채점, 동료 평가
  5. 소셜 학습: 토론 포럼, 협업 도구, 라이브 세션
  6. 학습 분석: AI 기반 개인화, 조기 경고 시스템
  7. 확장성: 수평적 확장, 로드 밸런싱, 샤딩

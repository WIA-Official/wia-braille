🔌 제4장: API 명세

RESTful API 표준

WIA-EDU-023은 모든 MOOC 플랫폼이 구현해야 하는 표준 RESTful API를 정의하여 상호운용성을 보장합니다.

4.1 RESTful API 설계

4.1.1 API 설계 원칙

원칙 설명 예시
리소스 중심 URL은 리소스를 나타냄 /courses, /learners
HTTP 메서드 표준 HTTP 동사 사용 GET, POST, PUT, DELETE
상태 코드 적절한 HTTP 상태 코드 200 OK, 404 Not Found
버전 관리 URL에 버전 포함 /api/v1/courses
페이지네이션 대량 데이터 분할 ?page=2&limit=50
필터링 쿼리 파라미터 활용 ?level=intermediate

4.1.2 Base URL 및 인증

Base URL: https://api.mooc-platform.com/api/v1

Authentication:
  Type: OAuth 2.0 + JWT
  Header: Authorization: Bearer {access_token}

Rate Limiting:
  - Free tier: 100 requests/hour
  - Premium: 10,000 requests/hour
  - Header: X-RateLimit-Remaining: 95

4.2 강좌 관리 API

4.2.1 강좌 목록 조회

GET /api/v1/courses

Query Parameters:
  - page: 페이지 번호 (기본값: 1)
  - limit: 페이지당 결과 수 (기본값: 20, 최대: 100)
  - search: 검색어
  - level: 난이도 (beginner, intermediate, advanced)
  - language: 언어 코드 (ko, en, es, etc.)
  - provider: 제공 기관
  - sort: 정렬 (newest, popular, rating)

Response 200 OK:
{
  "success": true,
  "data": {
    "courses": [
      {
        "course_id": "mooc-ml-2025",
        "title": "Machine Learning Fundamentals",

        "level": "intermediate",
        "enrolled_count": 125000,
        "rating": 4.8,
        "thumbnail_url": "https://cdn.mooc.com/ml-2025.jpg"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 2547,
      "total_pages": 128
    }
  }
}

4.3 등록 및 진도 API

4.3.1 강좌 등록

POST /api/v1/courses/{course_id}/enroll

Request Body:
{
  "track": "verified",  // or "audit"
  "payment_method": "card",  // for verified track
  "payment_token": "tok_..."  // Stripe token

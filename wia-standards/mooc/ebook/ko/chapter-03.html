3.5.2 블록체인 기반 검증

스마트 컨트랙트 구조:

// Ethereum Smart Contract (Solidity)
contract MOOCCertificate {
  struct Certificate {
    string certificateId;
    string learnerId;
    string courseId;
    uint256 completionDate;
    uint8 grade;
    bool revoked;
  }

  mapping(string => Certificate) public certificates;

  event CertificateIssued(
    string indexed certificateId,
    string learnerId,
    string courseId
  );

  function issueCertificate(
    string memory _certId,
    string memory _learnerId,
    string memory _courseId,
    uint256 _completionDate,
    uint8 _grade
  ) public onlyAuthorized {
    certificates[_certId] = Certificate({
      certificateId: _certId,
      learnerId: _learnerId,
      courseId: _courseId,
      completionDate: _completionDate,
      grade: _grade,
      revoked: false
    });

    emit CertificateIssued(_certId, _learnerId, _courseId);
  }

  function verifyCertificate(string memory _certId)
    public view returns (bool) {
    return !certificates[_certId].revoked;
  }
}

3.6.2 버전 관리

의미론적 버전 관리 (Semantic Versioning):

  • Major (1.x.x): 호환되지 않는 변경
  • Minor (x.1.x): 하위 호환 기능 추가
  • Patch (x.x.1): 하위 호환 버그 수정

마이그레이션 전략:

  • 이전 버전 최소 2년 지원
  • 명확한 마이그레이션 가이드 제공
  • 자동 변환 도구 제공
  • Deprecation 6개월 전 공지
